## 4. 资产生成方案（风格锁后）

### 4.1 按尺寸分级（不要一套提示词打天下）

| 尺寸班 | 例子 | 生成策略 |
|---|---|---|
| 40~68px | 普通敌（旧 20~34 ×2） | 仍靠剪影节奏；灯/角等锚点按 ×2 |
| 64px | 四英雄 | **现行契约**；细致哥特可保留风衣语言 |
| 96px | 精英（旧 48 ×2） | 双角；无管线描边 |
| 240~256px | Boss（旧 120/128 ×2） | 可密写；屏占比仍 ≤1/4 |
| 64px tile / UI | 地面、图标 | 各走 T3/T5，不套角色提示词 |

### 4.2 流程

```
风格锁门：守夜人 4 帧 → raw → process → **64px** 一眼可读风衣
→ 管线：边缘洪水抠图 → lanczos 安全框 → 同色相明度阶量化 → 无描边 → 校验
→ pack 3 图集 → asset-spec §5.1
```

原图评审不够。必须看管线后的 **64px**（英雄）成品，不要只看 raw。

### 4.3 提示词模板（五类）

每类：**像素预算 → 主体/姿态 → VS 微俯构图 → 填色（谁当主体色）→ 画布与禁项**。描边不写进提示词。

- **T1 角色**：v3.5 剪影参考 + 银主体 + 身份锚点（帽/弩/烛/耳）
- **T1 小敌**：3~5 色块剪影，零五官
- **T1 精英**：暗红填充 + 双角（描边归管线）
- **T1 Boss**：独有剪影，可密写
- **T2~T5**：武器 / tile / 特效 / UI（批次 2+；技能环走引擎 FX，不画进角色 PNG）

### 4.4 守夜人像素预算（锁风格用，对齐 silhouette-v35）

| 特征 | 预算 | 禁止 |
|---|---|---|
| 帽檐宽 | 26px，全身最宽 | 圆顶便帽 |
| 锥顶 | 顶在帧内，对齐 y≈-14 语言 | 脸、胡子 |
| 灯体 | 4×5，髋侧 | 10px 级大灯、铁栅细节 |
| 灯芯 | ≥2px 冷青常亮 | 把灯芯当唯一身份（须帽+灯同时在） |
| 主体色 | 月银白填充 | 海军袍当主色、棕皮、金 |
| 技能 a/b | 只换姿态（举灯 / 前刺） | 冲击环、光晕bloom、粒子（归 FX） |
