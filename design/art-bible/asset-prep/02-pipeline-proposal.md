## 1. 管线职责

提示词定「形」与填色；管线强制执行契约：透明底、目标尺寸、14 token、**后置描边**、验收报告。

| 验收项 | AI 直出问题 | 管线 |
|---|---|---|
| #3 尺寸 | 原图 512~1024² | 降到契约尺寸 |
| #5 透明 | 常带底 | 优先用原图 alpha；否则边缘洪水抠底（只清连到边的底；tile 全幅跳过） |
| #7 色板 | 新色相 / 中间调 | 色相锚 14 token，同色相明度阶；角色禁草地 token |
| #8 对比度 | 玩家可能偏暗；敌本就暗红 | 玩家/召唤物 L*≥45；暗红敌豁免（描边或形状可读） |
| #9 描边 | 模型画边不稳，降采样会稀释 | **管线后置**（玩家 2 / 精英 3 / Boss 4）；提示词禁止画边 |
| 时间轴 | 每帧独立 contain 居中 → 走路抽搐 | **P-6**：同族共享缩放 + 脚底对齐；重心/脚底/面积门禁 |

## 3. 现网流程（`process.mjs` v0.5）

```
assets/raw/<帧名>.png
  → ① 抠图（alpha / 边缘洪水 / tile 全幅）
  → ② 裁紧包围盒 → 同动画族共享 contain 缩放（取能装下最大姿势的 scale）
       → lanczos3 → 脚底对齐（maxY 贴画布 −5% 边距，水平包围盒居中）→ 硬化 alpha
  → ③ 同色相明度阶量化（角色禁草地）
  → ③.5 外部 AI 轨不后置描边（outlineW = 0）
  → ④ 写 assets/frames/<帧名>.png
  → ⑤ 写入 assets/report.json（填充边距 + L* 分治 + 时间轴 + pivot）
```

指定单帧时，会把同族已有 raw（`-v` / `skill-*` / `-entrance`）一并纳入共享缩放。

## 4. 风格锁改项（P-1~P-5 已写入 `process.mjs`）

| # | 项 | 口径 | 状态 |
|---|---|---|---|
| P-1 | 先安全框，再描边 | 填充 lanczos3-contain 到 `画布 − 2×描边宽 − 2×5%边距`，居中后再外扩描边 | ✅ |
| P-2 | 边距量填充盒 | Chebyshev 腐蚀 `outlineW` 后量包围盒；填充 ≤90% | ✅ |
| P-3 | 描边后置 | 外部 AI 轨 `outlineW = 0`；程序剪影兜底仍可自绘 | ✅ |
| P-4 | L* 分治 | 玩家/召唤物须银主体；暗红普通敌豁免；精英/Boss 靠体型 | ✅ |
| P-5 | 反破碎 | 边缘洪水抠图；同色相明度阶；低彩度走银；角色禁草地；lanczos 后再量化 | ✅ |
| P-6 | 时间轴 | 同族共享缩放；脚底对齐；重心/脚底/面积门禁；pivot 写入 meta 而非 frames[].pivot | ✅ |

原则仍成立：姿态不对 → 重绘；颜色/尺寸/描边/边距/**帧间对齐** → 管线纠。面积/重心超标说明原图两帧不是相邻姿态，管线只标 FAIL，不捏形。
