# 脸门规范（face-gate）

> 版本：v1 · 日期：2026-09-13 · 起草：编码机助理 · 依据：主理人 2026-09-12 决定「定脸的门」（②.1 确认）
> 状态：**现行。主理人 2026-09-13 检查通过。** **R24** 已编入 `combat-64-workflow-v1.md`（v1.21）。角色圣经 §0 指向本文。首用：`exp-e4-portrait-restage-face-gate-v1.md`（E4 部分过）。
> 一句话：**一个角色的图1′ 锁定当日，就必须派生「立绘级」与「视频级」两条同脸验收；此后该角色任何全分辨率出图（立绘、场景、视频、D 轨料）都先过脸门，再谈好不好看。** 战斗 128 / 192 仍按现行呼吸级判，不走此门。

---

## 0. 为什么要这道门

E1 / E2 证明参考在上下文的工具能守住「零件表级」身份，判法是 128 上零件可指、脸按呼吸。这个判法对局内帧够用，对立绘、场景、视频不够：E1 记录里「脸比底更二次元、眼更红」在 128 上被近邻抹平，在 768 以上就是「像她亲戚」。没有全分辨率的同脸门，扩展用法（其它立绘、场景、视频、LoRA 料）会在不知不觉里换人。

## 1. 三档

| 档 | 用在 | 标准 | 判什么 | 条文 |
|---|---|---|---|---|
| **战斗级**（128 / 192） | 局内 idle / 走 / 技能 | 呼吸级：零件表可指，眼能指；脸不细判 | 零件表 | 现行 `combat-64-pixel-workflow-v1.md`，**不变** |
| **立绘级** | 立绘、选人卡、图鉴、宣传图、视频首帧、**D 轨训练料** | **同脸**：§4 四判项全过 + 零件表 | 胸像 ≥768 高 A/B | 本文（新） |
| **视频级** | 剧情 / 宣传视频段、H3 / Wan 出片 | **不换人 + 段内不漂**：首 / 中 / 尾三帧四判项均不得「换人」；「近亲」最多 1 帧且不在首帧 | 三帧胸像 vs 基准 + 全身缩略 | 本文。首用 E6（2026-09-17 段间过，五列卡可判） |

视频级比立绘级宽，是因为 480p 里一张脸只有几十像素，像素级同脸无意义；但首帧本身若是 Identity Edit 出的，首帧须先过**立绘级**。

## 2. 触发与基准

| 时点 | 做什么 | 落盘 |
|---|---|---|
| 图1′ 锁定当日 | 裁**基准胸像**（`00-bust-ref.png`，768 高）+ **基准全身缩略**（`00-full-ref.png`，512 高）| `characters/<id>/identity/face-gate/` |
| 立绘线每张新出图（re-stage、换装、换机位、进场景） | 出立绘级同脸卡 → 主理人判 | 同上，`<yyyymmdd>-<topic>-<n>-fg.png` |
| 视频每段 | 出视频级同脸卡 → 主理人判 | 同上，`…-vfg.png` |
| D 轨候选每张 | 立绘级同脸卡；**未过不进 dataset** | 同上 + `lora/dataset/` 只收过的 |
| 已过历史锁图（H23、gpt-ok、gpt-e、bulk-a、edmund-gpt） | 补发基准胸像；**不回溯判** | 同上 |

**基准胸像裁法**（固定，便于同位对照）：以两眼中点为水平中心；上边 = 头顶（含角 / 帽）再留 5% 空；下边 = 锁骨下缘；宽 = 高 × 3/4；缩放到 768 高（看图用，lanczos 即可，不是入盒）。新图用同一比例、同一锚点裁。侧面 / 背面机位按同规则裁，背面不判五官，只判发型与标志件。

## 3. 同脸卡规格

石板底 `#2A3444`，不加描边，不叠文字在脸上。标题行写：角色 id · 档 · 图源路径 · 日期。

**立绘级（三列 + 一行）**

| 列 1 | 列 2 | 列 3 |
|---|---|---|
| 基准胸像 768 | 新图全身缩略 512（远认） | 新图同位胸像 768 |

底部一行：零件表勾选（助理填）+ 四判项空格（主理人填）+ 结果格。

**视频级（五列 + 一行）**

| 列 1 | 列 2 | 列 3 | 列 4 | 列 5 |
|---|---|---|---|---|
| 基准胸像 768 | 首帧胸像 | 中帧胸像 | 尾帧胸像 | 三帧全身缩略竖排 |

底部一行：每帧结果三格 + 段结论。

## 4. 判项（四条 + 零件表）

| # | 判项 | 看什么 | 不算不同 |
|---|---|---|---|
| 1 | 五官比例 | 眼距、眼鼻口三角、脸长宽比、下颌 | 表情、角度、光影 |
| 2 | 眼形与眼色 | 眼裂形状、眼尾、瞳色、眼影色 | 高光位置、瞳孔大小 |
| 3 | 发际与发型 | 发际线、分缝、刘海、长度、卷直 | 被风吹起的走向 |
| 4 | 标志件 | 角、疤、饰、妆、耳形 | 被遮挡（须可分类记录，见 `combat-64-workflow-v1.md` §1.1 表） |
| + | 零件表 | 衣件（沿用各角色零件表） | 降密度、动作位移 |

**结果三态**

| 结果 | 定义 | 后果 |
|---|---|---|
| **过** | 四项全同 + 零件表过 | 可当参考、可进 dataset、可进现网立绘 / 视频 |
| **近亲** | 四项里 1 项不同，或整体读成「亲戚」 | 不过。可记参数再打一枪（两枪封顶）；不进 dataset |
| **换人** | ≥2 项不同，或一眼不是 | 废。按 `combat-identity-drift-v1.md` 记漂类「换人」，停 Queue |

## 5. 判者与流程

- **判者只有主理人。** 助理做三件事：出卡、勾零件表、预筛排序。预筛可用相似度（CLIP / DINO 余弦）只排序不代判——二次元脸上这类度量不可靠。
- **交法**：一次一板 ≤6 张卡；只交预筛「疑过」的；预筛明显「换人」的直接废、记账、不交。
- **记录**：角色账本一行：日期 · 图 · 档 · 结果 · 主理人备注；卡文件留在 `face-gate/`。
- **两枪封顶**沿用：同一目标（同机位同表情）两枪仍「近亲」→ 停，换参数或换轨（见各实验卡）。

## 6. 与其它规则的关系

| 规则 | 关系 |
|---|---|
| 战斗呼吸级（现行） | 不冲突。战斗帧不走脸门；但战斗帧的**印戳源**若来自新立绘，那张立绘须先过立绘级 |
| 零件表 | 脸门只管头，零件表管身。两者都过才叫「过」 |
| R23（编辑模型满降噪合法） | 脸门是 R23 的配套验收：工具合法 ≠ 产出合格 |
| 漂停 | 「换人」= 漂类换人，当场停 |
| D 轨（LoRA 料） | **硬门**：未过立绘级的图不进 `lora/dataset/`。同一 dataset 只收同一衣套。过关场景成片（含 Cursor 少枪融景）可进；GenerateImage **角色抽卡**失败枪不准进 |
| 建议新条 R24 | 未过立绘级脸门的图不得当参考、不得进训练集、不得进现网立绘；未过视频级的段不得出片。**编号与措辞由主理人定** |

## 7. 工具

`tools/face-gate/make-card.mjs`（Node + sharp，无 GPU）。**已入库（2026-09-13）。** 用法见 `tools/face-gate/README.md`。

- 输入：`--ref <图1′>` `--new <新图>`（或 `--frames f1,f2,f3` 视频级）`--id <角色>` `--topic <说明>`；裁框按 §2，锚点在 `00-anchors.json`，`--eyes x,y` 兜底。`--init-ref` 只发基准胸像 / 全身缩略。
- 输出：卡 PNG + 同名 JSON（路径、裁框、零件表勾选留空、判项留空、结果留空）。
- 主理人填结果后，助理把 JSON 结果写回账本。

## 8. 例外与边界

- 目前只对**英雄与召唤物**（卡珊德拉、艾德蒙、守誓、魔化、加尔文、守誓者）。敌人 / Boss 暂不设脸门，另案。
- 一体两面 = 两个基准（守誓、魔化各一），互不当参考。
- 风格化 pass（WAI 低降噪）之后**必须再过一次**立绘级；风格化不是免检。
- 图1′ 本身若日后重派，基准胸像同日重发，旧基准退对照，历史「过」不回溯。**E4 卡珊德拉：主理人裁定不换**，H23 仍为图1′，未重发基准。
- **远景（E5 · 2026-09-15）：** 人物在画幅里 **≥60% 高** → 立绘级（胸像卡）。**<60% 高** → 零件表 + 全身缩略，不裁立绘级胸像代判。E5 过关两张由主理人看全图过，未另出 Cursor 脸门卡。
