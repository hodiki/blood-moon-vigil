## 2. 方案 C 做成什么样

裁定里的一句，展开成可执行的形态：

**每个战斗身份只建一具体块模型。正交相机烘朝右的帧。近邻收入现有帧名和 128 / 192 入盒。立绘仍是头像。战斗画面是体块小人，哥特细部留在立绘。**

| 锁 | 内容 |
|---|---|
| 作者 | 一具体块，一个身份。新姿从这具模型再烘，不换种子、不换人 |
| 相机 | 正交。无透视大小头。朝屏幕右。引擎用 `flipX` 镜像向左，不烘左脸 |
| 入盒 | 透明底 → 近邻。英雄 **128**。守誓者 **192**（必须比守誓薇奥莱高）。已过 64 的世界缩放仍是 `128 / 帧宽` |
| 画法 | 大色块、硬边、眼能指、无外描边。蕾丝、网、鞋饰、伤痕留在立绘 |
| 验收 | 战斗帧听裁定 §2 四句。零件表逐像素对位不再用于新战斗帧 |
| 引擎 | 仍是 PNG 帧。不把 Spine 或实时三维接进 Phaser |

这是形象套**第三层（战斗设计）换作者**。剪影和立绘不动。同一角色不能长期一半印戳、一半体块。试点只并排；要替换已过帧，主理人另点「这一族改由这具模型重烘」。

## 8. 开工核查（按即将进游戏重核）

引擎能播方案 C 的帧：朝右、`flipX` 向左、六步顺序 `a,e,b,c,f,d`、8fps，画布宽 ≥128 时世界缩放是 1。图集按文件里的实际像素打包，`walk-c/d/e/f` 不用改注册表就能进 characters 图集。缺的是烘焙条，以及下面四条会在第一次进 `assets/frames/` 时发作。

### 8.1 正视 idle 和朝右走不能进同一族门禁

已过加尔文 idle 是正视。准备稿的走是朝右转约 20°。时间轴把每一张走和**族基帧 idle** 比（`layout.mjs` `comparePair`）：128 上重心 hypot ≤ **6px**，脚底 ΔY = **0**，面积差 ≤ **25%**。换朝向的重心移动会超过 6px。

因此「走改体块、已过 idle 留在现网」过不了 `--check`，进游戏也会在停步和迈步之间换一套人和一个朝向。

开工若以进游戏为终点：第一包里的体块 idle 必须和六步同一具模型、同一机位，并且主理人点头用它换掉已过 idle。只交六步、不动 idle，只能当过目，不能当工作流终点。

### 8.2 六步的契约尺寸是裂的

`frame-specs.mjs` 里 `hero-galvan-walk-a/b` 仍是 **64、默认 lanczos3**。`walk-c/d/e/f` 没有单独条目，继承基帧 **128、nearest**。

现在盘上只有旧的 `walk-a/b`（64，弓背兽形）。若先放进 c–f、a/b 还是旧图，引擎已经六帧齐全，循环会在兽形和体块之间切。a/b 若用现规格重跑，会被 lanczos 压成 64，眼点保不住；c–f 仍是 128。`tickPlayer` 每帧按帧宽设缩放，64×2 和 128×1 的世界边都是 128，人不会跳大小，但清晰度和脚底会跳。

进游戏之前要把 `hero-galvan-walk-a/b` 改成 128、`kernel: 'nearest'`，并和 c–f 同一批替换。这一改在主理人说走「过」之后做，不在试点过目之前改。

### 8.3 不带 `--solo` 的 process 会重写已过 idle

`assets/raw/` 里已有 `hero-galvan.png`、`-v`、`walk-a/b`、`skill-a/b`。`process.mjs` 对任何一个加尔文帧名都会 `expandToFamilies`，把这些 raw 一起缩放并写回 `assets/frames/`。共享缩放取**这一批第一张**的契约边：若第一张是仍标 64 的 `walk-a`，已过的 128 idle 会按 64 的填充盒被缩小后塞回 128 画布。

试点和未点头之前：不对 `hero-galvan*` 跑 `process.mjs`，也不跑 `--all`。六步要共享缩放时，只能在 §8.2 改完规格之后，`--solo` 点名六张走（必要时加上同一机位的新 idle），不要把旧 skill raw 卷进来。

### 8.4 量化会吃掉橄榄披

`process.mjs` 收尾一律 `quantizePixels`，角色禁草地阶。色键上的狼披橄榄会被收成银灰（`ta-pipeline-color-handoff-v1.md` 已测：`#4A5C4E` → `#4D5157`）。暗红滚边会留在敌潮红上。已过 idle 能看见橄榄，是因为那张没有再跑量化。

方案 C 的入盒停在：**硬透明、无抗锯齿边缘、近邻进 128 方框、脚已经在同一行。** 不过 `finishPixels`。半透明边会被当成「已有 alpha」而跳过洪水抠图，`hardenAlpha` 再把 α&lt;160 的边切掉或留成一圈脏描边。

`-v` 若要烘，重心相对 idle 不超过 4px。看不出就交同一张。
