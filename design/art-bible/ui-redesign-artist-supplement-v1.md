## 2. 明细规格

### S-1 专武立绘卡 ×8（U-1）

**左右分屏 = 两把专武 2 选 1**（每边一张卡），不是「一张图里画基础形态 + 质变形态两个人」。

- 8 武器各 1 张：破旧提灯 / 圣徒左轮 / 血契双刃 / 月痕长弓 / 安魂圣铃 / 圣辉十字 / 葬仪巨斧 / 月啸号角。
- 卡面立绘只画**该武器基础形态**的剪影主体。质变方向用卡面文案 / 小符号（设计稿），不要在立绘里叠第二套装备；若分层，质变差异层单独图层、默认关闭。
- 主题色：ui-handoff **表 T-1**（只用于卡面装饰层，禁止当 HUD 语义色）。
- 透明底；主体 L\*≥45；**徽记占位留白**（C-3 叠上去，立绘不画徽记）。
- 底光：DOM CSS 渐变，**不画光晕、不交 wglow 帧**。
- 帧名：`exw-card-lantern` / `revolver` / `twinblade` / `longbow` / `bell` / `cross` / `axe` / `horn`（已注册）。
- 尺寸：等 P0-3 版式冻结后回填。样张建议最长边 512、透明底、仅桌面 2x。
- **先交提灯 + 左轮样张**，主理人拍板再铺其余 6 张。

### S-2 敌头顶状态图标 ×3（C-11）

- 24×24；硬控 / 软控 / 易伤各 1。形状可辨（色盲下仍可读）。
- 帧画中性灰/白形；引擎 tint：**硬控纸白 `#F2F5F9`、软控冷青 `#54E6C9`、易伤幽紫 `#B06AF0`**（对应 GDD「减速青、易伤紫红」——紫红用幽紫，不新色相）。
- Boss「免疫」0.3s 用引擎文字，**不出帧**。
- 不依赖 G-8（G-8 是地面 telegraph 色值，与本图标无关）。
- 帧名：`sticon-hard` / `sticon-soft` / `sticon-vuln`（已注册）。

### S-3 滤月壁面装饰底（可选）

- 无字纹理 1~2 张。不交则纯色 + 噪点 + CSS。仅主理人点名时才画。

### S-4 余辉货币小图标（C-10）

- 旧 `merit-*` 是 **4 张加成卡图标**，不是货币符号，**不能复用**。
- 新做 24×24，余辉金 `#FFC93C` 结晶/灯屑形。`hud-merit-glow`（已注册）。
