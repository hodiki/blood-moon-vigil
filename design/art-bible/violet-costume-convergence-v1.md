# 薇奥莱 · 类修女方向的设计收敛

> 2026-10-30 · 基于主理人给的四条方向（头巾 / 旗袍 / 丝袜 / 高跟鞋）
> 目的：把"方向"收敛成"能画、能分辨、能过工作流"的锁

---

## 0. 先说最大的风险：她会滑进卡珊德拉的地盘

第二张图是四人同屏的剪影测试（上排彩色、下排纯黑剪影）。

现在是四个人分工清楚的：

| | 靠什么区分 |
|---|---|
| 卡珊德拉 | 马尾 + A 形展开的下摆 + 黑丝细高跟 |
| 艾德蒙 | 帽檐横条 + 斗篷帆 |
| 薇奥莱 | **一根没有腰、没有腿的竖柱**（信息最少，但也最独特） |
| 加尔文 | 狼耳 + 矮壮 |

而你说的新方向——**旗袍 + 高衩 + 丝袜 + 高跟**——正好是卡珊德拉已有的三个特征：**收腰、露腿、细高跟**。

在 128 上，两条腿各只有 **3–4 像素**。如果两人都是"黑丝 + 尖头高跟 + 细腰"，远看就是同一个人换了件衣服。

**所以这个设计成不成，不取决于旗袍好不好看，取决于三条硬区分能不能立住：**

| 维度 | 卡珊德拉 | 薇奥莱（必须拉开） |
|---|---|---|
| 头 | **马尾**，向后甩出一条动态线 | **头巾**，头顶一个拱形，往下垂到肩 |
| 身形 | **A 形**：腰细、下摆展开 | **H 形**：直筒、不收不放 |
| 腿 | **黑丝 + 尖头细跟** | **白丝（偏灰的纸白）+ 粗跟/横带鞋** |

这三条守住，她俩就不会撞；守不住，就得回炉。

---

## 1. 一句话定位

> **不是"穿旗袍的修女"，是"穿丧服式旗袍的守夜人"。**
>
> 黑是主色、白是仪式感、光是她的身份。她的优雅来自"挺直"而不是"飘逸"。

---

## 2. 六个锁定项（给出 128 尺度上的具体值）

### 2.1 头巾

| 项 | 锁 |
|---|---|
| 形态 | **盖在头上，不包裹**：头顶一块黑巾，前缘压在发际线后 1–2px，两侧垂到肩（y≈40），后面让长发放出来 |
| 底色 | 近黑 `#14141A` |
| 边 | 前缘**一道纸白细边**（1px，`#E8E6E1`）——这是 128 上唯一能读出"头巾"的信号 |
| 禁忌 | 不要半透明。128 上半透明＝糊成一团灰。要透感就靠"高光边 + 内里一道浅色"，不要用 alpha |
| 宽度 | 比头宽 4–6px（约 22–26px），这样剪影上是一个**拱**，与马尾的**尖**形成对比 |

> 半透明是你方向里的原话，我必须说清楚：**这一条在 128 上做不到**。要么不透明、要么做大到能看见内层头发——但那样头会变成一个色块。

### 2.2 领与上衣

| 项 | 锁 |
|---|---|
| 领 | **立领，白色**（`#E8E6E1`），高 3–4px |
| 上衣 | 黑色为主，**胸前一块白色结构**——但**不要做成十字**（卡珊德拉已经是"黑高领 + 白十字"，会撞；而且你要避开宗教符号） |
| 白色结构 | 建议**斜襟**（旗袍的右衽），一条白边从立领斜下到右腋——斜线在 128 上比块面更耐缩 |
| 金属 | 一排 3 枚小盘扣（银），每颗 1×1px |

> **盘扣是她的"胸甲肩"替代品**：形锁锁了"胸甲肩"，但旗袍配胸甲很怪。用**银盘扣 + 硬挺的肩线**保留"她有武装感"，比硬加肩甲自然。

### 2.3 衣身与开衩

| 项 | 锁 |
|---|---|
| 身形 | **H 形**：胸到胯同宽（20–24px），**不收腰**——这是与卡珊德拉最根本的区别 |
| 开衩 | **左右开衩到大腿中部**（不是腰部）。衩口最高点在 y≈62–66，行走时形成 **V 形缺口** |
| 前片 | **短、硬**（到大腿中部），不要垂到膝下 |
| 后片 | 略长（到膝上 2–3px），但**不得过膝** |
| 禁忌 | 不要做成长而软的两片布——Wan 一转起来布片会飞，既难看，也会**把脚盖住**，把步帧测量重新毁掉 |

> 你说"开到腰"在立绘上很美，但在 128 走循环里有一个硬问题：**衩口越高，前片越容易在走路时摆过去盖住腿**。所以取大腿中部，是"好看"和"量得到脚"的折中。

### 2.4 腿

| 项 | 锁 |
|---|---|
| 颜色 | **纸白偏灰** `#D8D5CE`，阴影 `#9A968F`。**不要纯白**——暗底上纯白会过曝，把注意力从脸抢走 |
| 高度 | 大腿以上（裤袜或高筒都行，128 上看不出区别） |
| 宽度 | 每条 3–4px，膝下略收 |

> 为什么是白丝而不是黑丝：这是与卡珊德拉拉开距离最省力的办法。她一黑你一白，远看就不会混。

### 2.5 鞋

| 项 | 锁 |
|---|---|
| 形态 | **粗跟（5–7mm 等效）+ 一条横带**（玛丽珍式），鞋头**略圆** |
| 颜色 | 近黑 `#101014`，横带纸白 |
| 对比 | 卡珊德拉是**尖头细跟**，你是**圆头粗跟**——剪影上一个是"钉"，一个是"块" |

### 2.6 光（形锁要求"带光"）

| 项 | 锁 |
|---|---|
| 形式 | **手提一支细长烛台**（选人卡原本就写"执烛"），或胸口一枚发光圣徽 |
| 色 | 余辉金 `#FFC93C`，**小面积**（2–3px 的光点 + 一圈 1px 的晕） |
| 禁忌 | 不要整身发光；不要做成提灯——**艾德蒙已经有髋侧提灯**，两个提灯会撞 |
| 理由 | 黑白配色在暗底上容易糊成一团灰，**这一个暖光点是把她从背景里拉出来的锚** |

## 3. 和形锁的两处冲突（要你裁定）

| 形锁条款 | 冲突 | 处理 |
|---|---|---|
| **O-3 剪影已过** | 换装＝剪影全变，O-3 不再成立 | **必须重开一次剪影评审**（可叫 O-4）。这是流程要求，不是挑刺 |
| **胸甲肩**（§124 锁定） | 旗袍配胸甲会变成"铠甲旗袍"，两边都不像 | 建议：**用银盘扣 + 硬肩线替代**，正式把"胸甲肩"这条改成"武装感" |

其余锁定项不受影响：**长发**（从头巾下面放出来）、**D2 色板**（黑白本来就在里面）、**"带光女人"**（烛台/圣徽保留）。

---

## 4. 三条最容易翻车的地方

1. **半透明头巾**——128 上必然糊。不接受 alpha，只能靠边线和高光。
2. **纯白丝袜 + 纯白上衣**——整个人会变成"白多黑少"，而她是黑为主的角色。白只做**边、领、衩口**，面积控制在 15% 以内。
3. **宗教符号**——十字、念珠、光环都不要。要仪式感就用**几何**：菱形、放射线、扣子的排列。

---

## 5. 定了之后怎么验收（我这边的硬指标）

1. **剪影测试**：纯黑后与另外三人并排，能只靠轮廓分出她 → 才继续。
2. **`feet ≥ 2`**：入盒后跑量测，每一拍至少要能数出两只脚 → 否则回炉改服装，不往下走。
3. **走帧不自遮**：六帧里开衩前片不得盖住超过一只脚。

---

## 6. 要你定的

1. **白丝 or 黑丝**（我强推白丝，这是和卡珊德拉拉开距离的关键）
2. **胸甲肩**：换成银盘扣（推荐）/ 保留一块小肩甲 / 直接去掉
3. **光**：手提烛台（推荐）/ 胸口圣徽 / 都不要（那"带光"这条就废了，需重开）
4. 开衩高度：**大腿中部（推荐，能量测）** / 腰部（好看但会遮腿）
