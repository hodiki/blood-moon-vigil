## 7. 技能帧：设计提取与驱动需求

### 7.1 她的技能是什么（从代码里取的，不是猜的）

`src/config/balance/active-skill.ts`：

| 项 | 值 |
|---|---|
| 名称 | **血影突袭** |
| 类型 | `MOBILITY`（位移技） |
| CD / 层数 | 12s · 2 层 · 每层回充 8s |
| 冲刺 | 距离 **240px** · 有冲刺时长 |
| 伤害 | 40 · 命中后标记 1.2× 易伤 · 持续 4s |
| 被动 | 半裔之血：受击后 3s 内移速 +10% |

**结论：不是站桩施法，是一次向前冲刺。** 姿态必须读出「蹬地—前冲—到位」。

### 7.2 引擎怎么播这两帧

`src/fx/skill-pose.ts` + `src/config/balance/fx.ts`：

```
释放 → skill-a 播 300ms → skill-b 播 150ms → 回 idle
```

非艾德蒙角色走 `combo`，所以 **a→b 是连续的两个时刻**（前摇 → 施放），不是两张独立的站姿。这决定了：

- a 与 b 必须是**同一次冲刺**的两个瞬间（同方向、同前倾、衣摆拖曳方向一致）
- 两帧之间的脚位要能接上（a 的后脚 → b 的前脚），否则 300ms 那一下会跳

### 7.3 要不要驱动视频：要

三条理由，按分量排：

1. **这是一次位移动作。** 冲刺姿态里躯干前倾角、前腿蹬直、后腿拖曳、衣摆与马尾的滞后，文字提示很难一次说全；上一版 skill-b 就翻过车——写「起身收势、手收在腰侧」，出来是**叉腰**。
2. **a 和 b 必须互相对得上。** 同一条驱动片段里取两个时刻，倾角、方向、拖曳天然一致；两枪独立出图则要事后对齐，且很容易差一个人。
3. **240px 的位移在游戏里是会让玩家盯着的动作**，姿势不对立刻穿帮，比 idle 容错低。

### 7.4 需要什么样的驱动视频

| 项 | 要求 | 为什么 |
|---|---|---|
| 人数 | 单人 | Wan 只搬一个人的动作 |
| 朝向 | **朝画面右**（与角色一致） | 引擎默认朝右，`-v` 才是镜像；反了要额外翻 |
| 构图 | 全身入镜，头顶与脚底各留约 5% 余量 | 出图要按内容高 112 入盒 |
| 背景 | 纯色（黑或绿），无地影、无道具、无文字 | flood-key 去底 |
| 动作 | 1.5–2s：**起手前倾 → 蹬地前冲 2–3 步 → 急停/收势** | 一段覆盖 a（起手）与 b（到位）两个时刻 |
| 速度 | 中速，别快到糊 | 源帧按步长 2 取样，折合约 12–16fps，单帧要能看清 |
| 服装 | 紧身或短裤，**不要长裙 / 长外套** | 长衣会挡住腿的转折，Wan 学不到膝和胯 |
| 手持 | 空手 | 她手空（弩囊在髋侧，不持械） |
| 帧率 | ≥24fps | 取样后仍够看 |
| 分辨率 | ≥720p 竖幅（如 720×1280） | 会缩到 384×672 |
| 时长 | 1.5–3s | 49 帧 ≈ 3s @16fps |

> 走路那条 `8c3b8794-drive-generic-walkinplace.mp4` **不能拿来出技能**：动作是匀速走，没有前倾与急停，取出来还是走姿。

### 7.5 不做驱动的备选

文字提示出两张（同一提示词、相邻 seed），再人工挑「同侧腿在前」的一对。省事，但：

- a 与 b 的倾角/拖曳可能对不上，300ms 连播时会「跳一下」
- 已经有过一次失败（叉腰），不保证第二次不出别的

**建议：先按 §7.4 弄一条冲刺驱动。** 如果一时拍不到，先用文字版做一版放在过目板上，明确标注「一致性未验证」。
