## 什么叫严重漂（立刻停 Queue）

出现任一条，**当场停**，不准再加枪、不准换引擎碰运气、不准新开 LoRA「先练着」。

| 类 | 看着像什么 |
|---|---|
| 换人 | 修女、错甲、没红羽、跪了、她进了他的帧、他进了她的帧 |
| 丢脸 | 128/96 上指不出眼或盔缝，只剩肤块/钢块 |
| 错产品 | 选人表、正背三视图、双人、网格 |
| 风格横跳 | Q、油画、写实金属、和已过 128 不像同一套像素 |
| 连打不认 | **同一条底连打 3 枪**，人仍对不上锁稿，还在加 denoise / 换提示词形容词 |

停了先写过目：漂了哪一类，和锁稿差在哪一层（轮廓 / 衣脸盔羽 / 色面积）。没写完不准再 Queue。

## 停了按这个解析（不要另开一条）

冲突仍听形象套：轮廓听剪影，衣发脸盔羽听立绘，战斗色面积听色键。

1. 成法还在不在？作者仍是 **带眼（或盔缝）硬色块印戳 → 近邻入盒**。破了就回到成法，不发明第四条。
2. 已过角色的下一帧：**C 轨作者 = Identity Edit**（参考 = 过关印戳，满降噪合法）。B 轨印戳仍 denoise 宁低勿高（守誓 wave14：0.52 已洗掉烛）。低 denoise i2i **不当换姿作者**。
3. 新人第一张：立绘**单人裁** → 印戳 → 入盒。禁止硬切双人成片，禁止无脸色键当脸源。
4. 对不上的是哪一层？只修那一层。不要同时换引擎、换画布、加 LoRA。

## LoRA 不是唯一一致性，也不是这几类切换的作者

近两周的消耗，多半是同一件工具被要求同时做三件事：认人、认甲零件、认战斗画法。过关的那张（守誓 idle from-a）只做了第一件：底已经是带眼印戳，近邻入盒。模型没有记住她。

| 你要稳住的 | 实际作者 | LoRA 做不到的 |
|---|---|---|
| 同一套人 | 锁立绘单裁 → 印戳已是此人 → 低 denoise i2i | 把错甲的印戳「炼回」立绘零件 |
| 盔甲正面 / 裙甲等零件 | **听立绘。** 印戳里必须已经有这些件 | 训练集若已是罩袍骑士，炼完仍是罩袍 |
| 硬色块战斗帧 | 带眼/盔缝印戳 → 近邻入盒 | 立绘 LoRA 会把帧拉回绘画 |
| 换动作 | **Identity Edit**（满降噪 · 画面向指令）；走 = Animate 2 + 驱动 | 低 denoise i2i 碰姿；高 denoise t2i；站姿当走 |
| 64 ↔ 128 / 192 | 画布裁定 + 同一成法，禁止压回 | 像素 LoRA t2i（出过选人表） |
| 风格横跳（Q ↔ 写实） | **另一套形象**，三层补齐 | 旧风 LoRA 串人 |

`GenerateImage` 在 Vf1 上去沙漏、去背景拟眼，是 **同一人减法补强**，所以一致性还在。它没有骨骼/种子/身份槽，当 64 / 走条作者会漂——那不是「再调提示词」，是接口不当走条。**少枪融景**（E5 已过：少枪优先闭源融景）是另一用法，见 `pipeline-gpu-first-v1.md`；仍不当角色锁稿、不当走条。

本地开源条能锁引擎和步数，锁不住「这套胸甲和这套裙甲」，除非底图里已经有。B 把 D2 硬色写进提示词，甲零件更离立绘。

身份 LoRA 只在 **A+B 仍严重漂、且后面帧多** 时上：低权重，只挂出印戳的引擎，料是立绘单裁 + 过关印戳 + 已过战斗帧。它不是风格开关，不是 64/128 开关，也不是现在守誓者缺的那一档。
