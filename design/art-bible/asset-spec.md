## 2. 图集打包方案

| 图集 | 内容 | 尺寸上限 | 格式 |
|---|---|---|---|
| characters.png | 5 角色动画帧（约 69 帧） | ≤2048²（v0.2 实约 256²） | JSON 数组 + PNG |
| effects.png | 弹体/拾取/tile/陷阱/粒子（12 帧） | ≤2048²（v0.2 实约 256×128） | JSON 数组 + PNG |
| ui.png | 图标/HUD/结算/摇杆（24 项） | ≤2048²（实约 1024²） | JSON 数组 + PNG |

统一：TexturePacker 输出 JSON 数组格式（Phaser 3 atlas 原生）；`premultipliedAlpha=false`；tile 用 2 次幂 64×64；加载只走 atlas 单请求，禁止零散图。
v0.2 注记：程序剪影 v2 落地后 characters/effects 仍为运行时 canvas 图集（256²/256×128，均 ≤2048²、premultipliedAlpha=false，保持程序图集优势）；`tile-ground`/`tile-grass` 两张背景 tile 独立（map 双材质，2 draw call）。

## 4. 双端资产差异

- **共享（同一资产同一规格）**：全部世界实体——角色/敌人/Boss/弹体/拾取/tile/障碍/陷阱；升级图标、武器槽图标为矢量可缩放，双端同源。
- **移动端简化（720×1280 收敛）**：虚拟摇杆仅移动端（桌面键盘 WASD）；飞弹拖尾 1 短条、死亡粒子 8 粒（桌面 16）、冲击波单环；Boss 血条屏宽 60%→50%；HUD 缩 75% 并上移让出拇指区；结算页独立版式。
- **UI 出档**：升级图标/武器槽/HUD 按桌面 2x、移动 1x；tile/几何/矢量 UI 运行时缩放共享，不额外出档。

## 5. 缺失资产应急方案

> v0.2 状态：应急方案已升级为「程序剪影 v2」并**落地**（TASK-22），不再只是兜底。帧名契约不变，后续接入 CC0 素材只需替换对应帧绘制/图集帧，实体零改动。

任一 CC0 素材找不到，统一走 **canvas 几何 + 本圣经色板** 程序生成兜底，不阻塞管线：
- 角色/敌人/Boss：Phaser Graphics 绘制剪影级形状（圆帽披风/骷髅头/尖牙鼠形/双角盾形/Boss 王冠披风），预烘焙为 sprite 帧，描边色按 art-bible §4（已落地，见 `procedural-textures.ts` v2）。
- tile/障碍/陷阱：canvas 噪声+色板生成石板/草地（双 tile，已落地）、灰蓝墙块+顶缘高光（已落地）、红斜纹贴花（未启用）。
- 弹体/拾取物/粒子：程序生成（箭头弹体/高光圆核/双层环/白描边蓝菱，已落地；粒子贴图随 fx-manager 接入）。
- UI 图标：canvas path 矢量绘制，复用升级图标"底色分型"编码，保一致（未落地，CSS 圆点占位）。
