## 0. 先认错：撞型判断不成立

v1 里我说"会滑进卡珊德拉的地盘"，是拿"旗袍 + 高衩 + 丝袜 + 高跟"这四个词去套，没看图。

看完四张参考，这个方向的实际语言是——**及地薄纱 + 敞开的前襟 + 大腿袜 + 尖头跟**。它和卡珊德拉差在**四个层面**，不是差在细节：

| | 卡珊德拉 | 薇奥莱（参考方向） |
|---|---|---|
| 头 | 高马尾，向上甩的**尖** | 头纱，向下的**罩** |
| 身形 | 收腰 + A 形展开的大衣 | **直筒柱体**，敞开前襟 |
| 色 | 酒红 / 栗 | **黑 + 白**，无彩色 |
| 材质 | 哑光皮革 | **薄纱 / 缎 / 缎面** |
| 拖尾 | 马尾一条线 | 纱一片面 |

四个维度全不同，128 上不会认错。**这条我撤回。**

## 1. 四张图的共同语言（这才是要提炼的东西）

| 要素 | 图1 | 图2 | 图3 | 图4 | 共同点 |
|---|---|---|---|---|---|
| 头纱 | 及地、前开 | 齐肩 | 及地、前开 | 及地 | **从头顶罩下、前面敞开** |
| 裙/裤 | 前中开衩到底 | 侧开衩到胯 | **短裤 + 长外披** | 前中绑带开口 | **下半身必须敞开** |
| 腿 | 薄黑丝 | 裸腿 | **白不透明大腿袜** | 黑丝 + 吊带 | **高筒 + 露袜口** |
| 鞋 | 尖头细跟 | 尖头细跟 | 厚底 | — | **尖头或厚底** |
| 白 | 极少 | 领口白片 | **整件白上衣** | 极少 | 白只在**上半身** |

**一句话概括**：上半身是"封闭的仪式感"，下半身是"完全敞开的腿"，中间由**开衩/开襟**连接。

## 2. 但这里有个硬冲突，必须先解决

四张参考里，图1、图3、图4 都是**及地长纱**。而形锁 §123 明令：

> **「守誓薇奥莱禁止再靠光滑 A 字圣袍」**

**一片及地的纱，从头顶罩下来，就是一个 A 字。** 而且它会把腿和脚一起盖住——那正是她今天做不了步帧的原因（实测 `feet = 0`）。

所以关键不是"要不要长纱"，是**纱怎么挂**：

| 做法 | 结果 |
|---|---|
| 纱从头顶**向前罩**、垂到地 | ✗ A 字 + 遮脚，重复旧问题 |
| 纱**只挂在身后**，前面完全敞开 | ✓ 剪影是"人 + 身后一片"，不是 A |
| 纱垂到地但**开前襟**（如图1） | ⚠️ 立绘成立，但 128 走循环里纱会飘到前面 |

**我的建议：纱垂到小腿、挂在身后、前襟完全敞开。** 既保住"及地薄纱"的戏剧性，又不侵占腿的可读区。

## 3. 128 上怎么落地（六条硬规则）

### 3.1 下半身必须"先解决可见性"，再谈好看

参考图给了两种解法，**图3 那种最稳**：

| 方案 | 做法 | 步帧可行性 |
|---|---|---|
| **A（推荐）** | **黑色短裤打底 + 两侧/身后挂长片** | ✅ 腿永远露着，走起来不会被布盖住 |
| B | 前中开衩到底（图1） | ⚠️ 前片在走循环里会摆过去 |
| C | 侧开衩到胯（图2） | ✗ 3/4 视角下前片正好盖住两条腿 |

> 侧开衩在**正面立绘**上最美，但在**3/4 行走**里是最差的——前片会横在两条腿前面。这就是我今天反复说的那个坑。

### 3.2 薄纱在 128 上不能用 alpha

128 上半透明 = 一团灰。翻译成像素的做法：

- 纱 = **近黑 `#1A1A22`**（比主体黑 `#0E0E14` 亮一档），边缘 **1px 冷灰 `#5A5A66`**
- 靠"比身体亮一档 + 一道边"读成"纱"，而不是靠透明度
- 纱与腿重叠时**不要透出腿**——直接把纱画在腿后面，别做叠加

### 3.3 大腿袜的袜口是她最好认的记号

一条 **1px 的浅色横线**（白丝用 `#E8E6E1`，黑丝用 `#6E6E78`），在 y≈78–82。

- 这是 128 上唯一能读出"大腿袜"的信号
- 也是她和卡珊德拉（连裤黑丝、无袜口）最干脆的区别

### 3.4 白色占比控制在 15% 以内

参考图2、图3 的白面积很大，但那是**亮背景**下成立的。我们的背景是近黑：

- 白只给：**立领 + 前襟一条 + 袜口 + 袖口**
- 上衣主体仍是黑，白做"结构线"不做"面"
- 若整件白衣，128 上她会变成一块白斑，抢过脸

### 3.5 鞋：尖头细跟 or 厚底，二选一

- 图1/2 是**尖头细跟**——但卡珊德拉已经是这个，会削弱区分
- 图3 是**厚底**——更"现代修女"，也更压得住长纱
- **建议厚底/粗跟**：剪影上是"块"不是"钉"，跟卡珊德拉分开

### 3.6 宗教符号一律几何化

图2 的领口上有十字。我们的方向是"通俗化、不直接涉宗教"，所以：

- 十字 → **菱形**或**四叶**（几何化的圣辉，不指向具体宗教）
- 颈链/吊坠保留，但坠子做菱形
- 不要光环、不要念珠

## 4. "带光"这条怎么办

形锁要求她是"**带光女人**"（这是她和另外三人区分的关键读点之一），但四张参考都没有光源。

三个选项：

| 方案 | 做法 | 评价 |
|---|---|---|
| **L1** | 手提一支**细长烛台**（选人卡原本就写"执烛"） | 推荐。与艾德蒙的髋侧提灯区分：她**手提、更高、更小** |
| L2 | 纱的**内缘一圈微光** | 有光环嫌疑，慎用 |
| L3 | 胸前菱形圣徽**自发光** | 可与 3.6 的几何化合并，最省 |

**建议 L1 + L3 合并**：手提烛台（主光）+ 胸前菱形徽（次级微光）。黑白配色在暗底上容易糊，这两个暖点是把她拉出来的锚。

## 5. 一句话定位（更新）

> **不是"穿旗袍的修女"，是"披着黑纱的守夜人"。**
>
> 上半身封闭到领口，下半身完全敞开；黑是主体，白是结构线，光是唯一的暖色。
> 她的优雅来自**站得直 + 纱垂得顺**，不是来自布多。

## 6. 要你定的

1. **下半身**：短裤打底（推荐，最稳）/ 前中开衩到底 / 侧开衩到胯
2. **纱长**：小腿（推荐）/ 及地 / 及腰
3. **腿**：黑薄丝（贴近参考）/ **白不透明大腿袜**（与卡珊德拉区分最强）
4. **鞋**：厚底粗跟（推荐）/ 尖头细跟
5. **光**：手提烛台 + 胸前菱形徽（推荐）/ 只要一个
