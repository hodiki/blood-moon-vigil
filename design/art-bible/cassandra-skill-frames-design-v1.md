## 0. 先厘清一个容易搞反的地方

代码里 `EXCLUSIVE_TO_DERIVATIVE` 写的是**「选了 A → 得到 B 的技」**：

```ts
xw_twinblades: 'dv_moon_snipe',   // 选双刃 → 长弓落选 → 月痕狙击
xw_longbow:    'dv_blood_dash',   // 选长弓 → 双刃落选 → 血影突袭
```

但两个衍生技自己带着 `sourceExclusiveId`，标的是**技的形态归属**：

| 技 | `sourceExclusiveId` | 形态 |
|---|---|---|
| 血影突袭 `dv_blood_dash` | `xw_twinblades` | 双刃的突进斩 |
| 月痕狙击 `dv_moon_snipe` | `xw_longbow` | 长弓的蓄力狙 |

**所以按形态分槽**：`-skill-a` = 血影突袭（双刃），`-skill-b` = 月痕狙击（长弓）。这与你说的“血契双刃、月痕长弓”一致。

## 1. 血影突袭（双刃）· `-skill-a`

### 数值

| 项 | 值 |
|---|---|
| CD | 14s |
| 动作 | 向**敌群最密方向**突进 **200px**，沿途斩击 |
| 伤害 | 15 / 段 |
| 附加 | 命中挂**血契印记**：受所有伤害 **+15% / 5s** |

> 注：她的**主动技**也叫血影突袭（cd 12、2 层、突进 240、40 伤、标记 1.2×/4s）。两者同名不同数值：主动技是常驻，衍生技是选长弓后的替代。

### 姿态必须读出什么

1. **低重心前冲**——躯干前倾约 45°，不是直立
2. **两把短刃一前一后**——近侧手向前压、远侧手向后拖，形成交叉
3. **前脚蹬直、后腿拖曳**，大衣向身后掀开
4. 马尾向后甩（她的剪影锚）

### 128 像素下的读点与风险

| 读点 | 风险 | 对策 |
|---|---|---|
| 双刃要看得见 | 两把刃同色会糊成一条 | **一明一暗**：近刃亮银、远刃压暗半档 |
| 刃要有“血契”语义 | 全银就看不出是血契 | 刃身银白，**刃缘一线血橙红** `#FF3B30` |
| 前冲要成立 | 大衣遮腿 | 刃举过腰线，腿露在大衣开衩以下 |

### 与现有资产的关系

现有 `-skill-a` 是“冲刺起手”（来自冲刺驱动第 10 帧），**动作方向对，但手里没有刃**。
→ 不是整张重做，而是**在起手姿上补双刃**。若补刃后轮廓糊掉，再考虑重出。

## 2. 月痕狙击（长弓）· `-skill-b`

### 数值

| 项 | 值 |
|---|---|
| CD | 20s |
| 蓄力 | **1.2s** |
| 发射 | **贯穿全屏巨矢**，60 伤、全贯穿 |
| 附加 | 首个命中目标**眩晕 1s**（Boss 免疫、精英 ×0.5） |

> 长弓本体：22 伤 / 2.2s、直线、贯穿 3、弹速 500px/s。是**慢速重狙**，不是连射。

### 姿态必须读出什么

1. **侧身拉弓**——弓臂前伸持弓，拉弦手贴颊，**弦被拉成 V 形**
2. **弓的弧线要露在身体轮廓之外**（否则和身体糊在一起）
3. **箭尖探出轮廓**，指向右
4. 后脚稳、重心后坐——这是**蓄力**，不是速射
5. 弓身带**电光蓝** `#4FC3F7` 的月光辉；箭身**月银白 + 冷青尾羽**（`ta-redesign-handoff-v1.md` §99 的弹体基准）

### 128 像素下的读点与风险

| 读点 | 风险 | 对策 |
|---|---|---|
| 弓是细弧线，容易被大衣吃掉 | 弓与大衣同为暗色 | 弓比大衣亮一档，压月白/冷青 |
| “拉满”要看得出来 | 弦是 1px | 弦与手、箭尖形成三角形空洞，靠**负空间**读 |
| 蓄力感 | 站姿太正会像普通射击 | 重心后坐、前腿绷直、身体侧对 |

## 3. 两张的对比关系（同屏连着看要成立）

| | skill-a 血影突袭 | skill-b 月痕狙击 |
|---|---|---|
| 朝向 | 前冲（向右） | 侧身（面向右，身体侧对） |
| 重心 | 低、前压 | 后坐、稳 |
| 色彩重音 | 血橙红（刃缘、印记） | 电光蓝（弓、月光箭） |
| 剪影 | 横向拉长（冲刺） | 纵向 + 弓的弧（三角负空间） |

两张放一起，一眼要能分出「近战突进」和「远程蓄力」。
