## 1. 设计 token 摘录（全 UI 通用，唯一来源 = art-bible v0.3 + asset-spec v1.3 §2.4）

### 1.1 十四 token 色板（只许 token 或其同色相 alpha 派生，禁止新色相）

| 语义 | token | UI 用途 |
|---|---|---|
| 基底 | 墨夜蓝黑 `#0B0E14` / 暗紫灰 `#131722` | 面板/卡片底、遮罩（禁纯黑） |
| 玩家侧 | 月银白 `#E8F0FA` / 冷青 `#54E6C9` | 正文纸白见下行；冷青 = 选中态/玩家侧信息/属性浸染 |
| 正文 | 纸白 `#F2F5F9` | 正文/数值（≥4.5:1） |
| 危险/血 | 暗血红 `#7E1E1E` / 血橙红 `#FF3B30` / 猩红 `#FF3B3B` | 危险态/受击/血量/Boss |
| 奖励/余辉 | 琥珀金 `#FFC93C` | 余辉金 = 质变节点/稀有/数值型卡底 |
| 信息/经验 | 电光蓝 `#4FC3F7` | 经验/机制型卡描边/「图鉴联动幽蓝」候选（见 §5 缺口） |
| 精英/魔法 | 幽紫 `#B06AF0` | 精英语义/超武进化卡底/敌方魔法 |
| 治疗 | 青绿 `#43D17C` | 治疗语义 |

### 1.2 硬标准（验收级）

- 对比度：UI 文字对背景 ≥4.5:1；图形/图标 ≥3:1；背景明度 L\*≤18，玩家侧点亮元素主体 L\*≥45。
- 字号：正文 ≥16px；数值/HP ≥20px；卡片标题 ≥22px 加粗；移动端实际渲染 ≥14px 物理像素；树界面剩余余辉大数字 ≥28px（gdd-talent-tree §⑧）。
- 触区：移动端全部可点目标 ≥44×44px；桌面鼠标 ≥32×32px（视觉可 24px + 外扩热区）。
- 双基准：桌面 1920×1080 / 移动 720×1280，两套设计空间独立、互不裁切；UI 出档桌面 2x / 移动 1x（asset-spec §2.5）。
- 可访问性：信息双编码「颜色 + 形状/图标」，形状优先于颜色；支持字号 125% 档；「减少闪烁」开关下禁呼吸/闪烁动效（art-bible §9）。

### 1.3 全局功能语义（解题循环可读性优先）

- **余辉金（#FFC93C）= 点亮/奖励/可购**：质变节点、余辉货币、稀有掉落、无限弹期。
- **冷青（#54E6C9）= 玩家侧可选/可共鸣/属性浸染**：选中态、属性节点、共鸣 ready 预告、减速状态色调。
- **暗红/血橙红 = 危险/不可用/敌侧**：危险 telegraph、受击、弹巢空转、awaiting 之外的禁止态。
- **telegraph 配色与形状语法（gdd-enemies-v3 §④，全 UI/演出对齐）**：形状 = 危险范围（扇形/箭头线/预警圈/警告线/阵纹/弹道细线/环形波缝），全部**渐亮式**（透明度随蓄力推进，下限 α≥0.12）；敌侧预警 = 红 + 幽紫（阵纹）双语义、形状区分；玩家侧演出 = 冷青/月银白。UI 设计师不得把「渐亮地面形状」改译为全屏红晕/震屏（art-bible §5 禁全屏红晕）。

## 3. 交付格式与验收

### 3.1 切图规范

- 格式：带 alpha PNG（图标兜底）或 WebP（纯色块 UI，约 -60% 体积）；PNG 必须含透明通道，禁白/黑底垫图。
- 尺寸：升级卡图标桌面 128×128 / 移动 96×96；槽位/技能/图鉴图标 64×64 / 48×48；圣物/复活/共鸣徽记随槽位档（徽记内图形主体 ≥3:1 对比）。
- 出档：桌面 2x / 移动 1x 两档齐（asset-spec §2.5）；共享矢量 UI 以 2x 为准运行时缩放。
- 帧名：走 asset-spec §2.1.1 契约（`upg-<key>` / `wslot-<slug>` / `skill-<slug>` / `hud-*` / `codex-*`）；**新增 UI 帧名必须先入 frame-registry 与 content-id-frame-map**（流程见 ta-handoff §2）。
- 图集：交付 `<atlas>.png` + `<atlas>.json`（TexturePacker JSON 数组）成对，禁止零散图；ui 图集超 2048² 时拆 `ui-upgrades` / `ui-slots`（asset-spec §2.3 预留拆包口径）。

### 3.2 动效规格

- 全部动效声明时长/缓动/循环，交付 Lottie 或逐帧规格表 + 引擎侧参数（进 `balance.ts` FX 块，禁魔法数）。
- 呼吸/闪烁类动效全部受「减少闪烁」开关；屏幕级演出（圣物）可设置降级。
- 点亮演出 0.8s / 圣物演出 ≥1.5s 锚为上限感知预算，超时须主理人批准。

### 3.3 与程序对接方式

- DOM 覆盖层维持 0 draw call 惯例（HUD/结算/选卡）；引擎内 UI 元素（徽记/telegraph）走精灵批次。
- 每个界面交付：设计稿（双端基准）+ 切图包（帧名清单）+ 状态机表（本档表格直接引用即可）+ 动效参数表。
- 验收走 asset-spec §5.1 验收总表（v1.3 共 14 项；含对比度脚本与色盲模拟滤镜肉眼双检）。
