## 1. 原则与纪律

1. **三要素编码不破坏**：每实体仍以「体型 + 色相 + 角饰」任意两要素可区分；v3 细节全部是"形状/纹饰"增强，不引入新色相（仅复用 `PALETTE.playerAccent` / `PALETTE.danger` / `BOSS.COLOR_GOLD` / `PALETTE.uiPaper` / `INK` 既有 token）。
2. **色盲可辨**：所有细节形状优先，颜色仅作强化（如玩家提灯=方形+冷青；屠夫屠刀=刀形+纸白刃光；Boss 宝石=圆+红）。
3. **描边等级不变**：玩家冷青 2px 烘焙（1.12 放大层）、普通敌纯剪影无描边、Boss 猩红 4px 烘焙（桌面 1.05，移动端 outlineEnabled=false）。细节随各实体描边纪律走，不为细节新增描边。
4. **帧内不超界**：每项细节给边界校验（内容坐标 × 描边放大层 ≤ 帧半宽/半高）。参照 TASK-28 C-1 教训——**逐项校验，尤其顶部与两侧**。
5. **双端 16px 最小实体**：细节不改变实体尺寸；移动端按 §9 LOD 规则省略亚像素细节。
6. **只做加法/微改**：不重做已验收的 v2 整体形态，仅在既有形状内加细节或重排局部多边形。

## 2. 玩家·守夜人（32×32，中心 (0,0)，描边放大 1.12）

**背景设定**：血月长夜中唯一还醒着的人——守夜人。他的武器是"守望"本身：圆帽、长袍、一盏冷青提灯。冷青是他与血月黑夜对抗的光。

**设定→视觉**：提灯 = 守夜人身份的具象（也是玩家冷青 accent 的叙事化）；帽带 = 制式夜巡帽；三边开衩 = 正式长袍下摆，移动时开衩翻飞，强化"走位是唯一操作"的运动剪影；月牙胸徽 = 对血月的誓约（以月牙对抗血月）。

### P0-1a 冷青提灯（复杂度 中）
- **实现位置**：在 `drawSilhouette(...playerShape)` **之后**、同帧 32×32 内单独绘制（正常比例）——避免描边放大层 1.12 双画导致提灯边缘残色。
- **坐标**（本地坐标，右前方，灯随精灵 flip/rotation 保持一致）：
  - 灯杆：`fillRect(8, -6, 1.5, 5)`，`PALETTE.uiPaper` alpha 0.55（从披风右肩伸出的细杆）
  - 灯体：`fillRect(10.5, -1.5, 3, 4)`，`PALETTE.playerAccent` alpha 0.95（3×4px 方形灯）
  - 灯芯光：`fillCircle(12, 0, 1.5)`，playerAccent alpha 0.8；外圈 `fillCircle(12, 0, 2.8)` alpha 0.22（柔光）
- **边界校验**：最右点 x=12+2.8=14.8 ≤ 16 ✔（提灯在描边层后绘制，不受 1.12 约束；即使计入 1.12：12×1.12≈13.4 亦 ✔）；y∈[-6,2] ✔。
- **移动端 LOD**：省略灯杆，仅保留灯体+光晕（§9）。

### P0-1b 帽带（复杂度 低）
- **背景映射**：夜巡制式帽的帽带圈。
- **坐标**：帽檐下缘 `y=-5` 处 1px 横条 `fillRect(-10, -5, 20, 1)`，playerAccent alpha 0.75；或沿帽冠下沿用 `strokeCircle(0, -6, 7)` lineWidth 1、只画 π~0 下半弧 alpha 0.6（更贴帽型，推荐）。
- **边界**：x±10 → ×1.12=11.2 ≤16 ✔。

### P0-1c 三边开衩披风（复杂度 中）
- **背景映射**：守夜人长袍（tailcoat 式三开衩）——比 v2 的随意锯齿更"制式、正式"，开衩在跑动中翻飞。
- **说明**：任务示例 "披风加三边开衩 x∈[±18,±26]" 超出 32×32 帧（帧半宽 16），按帧内等比缩为**三处开衩 x=-8 / 0 / +8**；若未来角色帧扩到 64×64，可回 ±18/±26 比例。
- **坐标**（重写 `playerShape` 披风主体为梯形 + 3 条 INK 镂空开衩）：
  - pose=0：`moveTo(-9,-5) → lineTo(9,-5) → lineTo(12,13) → lineTo(-12,13) → close`
  - pose=1：`moveTo(-9,-6) → lineTo(9,-6) → lineTo(14,14) → lineTo(-14,14) → close`（下摆外扩+下移，维持现有"摆动帧"语义）
  - 开衩（INK 镂空，宽 1.5px，从下摆上切）：
    - 左开衩：`fillRect(-8.75, 6, 1.5, 7)`（pose1 为 `fillRect(-8.75, 5, 1.5, 9)`）
    - 中开衩：`fillRect(-0.75, 6, 1.5, 7)`（pose1 `fillRect(-0.75, 5, 1.5, 9)`）
    - 右开衩：`fillRect(7.25, 6, 1.5, 7)`（pose1 `fillRect(7.25, 5, 1.5, 9)`）
- **边界校验**：最外点 x=±12（pose1 ±14）→ ×1.12=15.68 ≤16 ✔；y=13（pose1 14）→ 15.68 ≤16 ✔。开衩镂空不改变外轮廓，仅内部透背景色。

### P1-1d 月牙胸徽（复杂度 低）
- **背景映射**：守夜人对血月的誓约徽记——以月牙回应血月。
- **坐标**：披风胸口 `(0,2)`：`fillCircle(0,2,2)` playerAccent 再叠 `fillCircle(0.8,2,1.8)` INK 相减成月牙；或简化 `fillRect(-1.5,1,3,2)` + 右缘 1px INK 缺口。
- **边界**：x±2 ✔。与提灯同层（描边后）绘制。

### P2-1e 披风内衬高光（复杂度 低）
- 披风右缘 1px `fillRect(11.5, -4, 1, 15)` `PALETTE.uiPaper` alpha 0.35（月光勾勒）。
- 边界：x≈11.5 ✔。

## 3. 敌人·行尸（28×28，中心 (0,0)，纯剪影无描边）

**背景设定**：血月之下暴毙的村民，复起为行尸——尸潮主力。他们是"死过一次的人"，身上带着各自的死相。

**设定→视觉**：颅骨裂纹 = 致死伤（暴毙）；眉骨高光 = 骷髅结构强化（16px 可读）；断齿 = 腐尸缺齿；残发 = 生前痕迹未褪尽。

### P0-2a 颅骨裂纹（复杂度 低）
- **坐标**：额心 `strokeStyle=INK, lineWidth=1`：
  - 主裂：`moveTo(0,-8) → lineTo(0,-12)`
  - 右支：`moveTo(0,-10) → lineTo(2.5,-11.5)`
- **边界**：x≤2.5、y≥-13（颅顶 ry=12，cy=-1 → 顶 -13）✔。

### P0-2b 眼眶眉骨高光（复杂度 低）
- **背景映射**：骷髅结构线（形状优先，色盲可辨）。
- **坐标**：两眼眶上方各 1px 纸白弧线（alpha 0.5）：
  - 左：`strokeCircle(-4.5, -5, 3.4)` lineWidth 1、只画 π~0 上半弧
  - 右：`strokeCircle(4.5, -5, 3.4)` 同上
- **边界**：x=±(4.5+3.4)=±7.9 ≤14 ✔；y=-8.4 ≥ -13 ✔。

### P1-2c 断齿（复杂度 低）
- **背景映射**：腐尸缺齿，非对称更"尸体"。
- **坐标**：牙齿循环 `for i=-2..2` 中去掉 `i=-1`（最左第二颗），其余不动；或把 `i=0` 中心齿右移 0.8px 形成错位。推荐去 i=-1。
- **边界**：不变（牙口 x±7 在帧内）。

### P2-2d 残发（复杂度 低）
- 颅顶后侧 2 根 INK 短弧线：`moveTo(3,-12)→lineTo(4.5,-9)`、`moveTo(-4,-11.5)→lineTo(-5,-8.5)`。
- 边界：x≤5.5、y≥-12 ✔。

## 4. 敌人·血犬（24×24，中心 (0,0)，纯剪影无描边）

**背景设定**：血月腐化的猎犬——快、疯、嗜血，逼着玩家走位。v2 是"尖牙鼠形"，用户反馈要"凸显设定"：它不该是鼠，是**魔犬**。

**设定→视觉**：背脊棘刺 = 腐化骨刺（鼠形→犬形）；血口涎滴 = 嗜血疯狂；眼白高光 = 捕食者凶光。

### P0-3a 背脊棘刺（复杂度 低）
- **坐标**：躯干背线（y≈-4.5）3 个小三角（用 `PALETTE.enemyWolf` 同色，纯剪影）：
  - 棘刺 1：`moveTo(-4,-4.5) → lineTo(-3,-7.5) → lineTo(-1.5,-4.5)`
  - 棘刺 2：`moveTo(0,-4.5) → lineTo(1,-6.5) → lineTo(2.5,-4.5)`
- **边界**：x∈[-4,2.5]、y≥-7.5（耳尖 -8.2，棘刺不碰耳）✔；x≥-12 ✔。注意躯干椭圆 rx≈6.5 于 x≈1，棘刺 1 的 -4 点略出躯干上缘 1px——作为轮廓棘刺可接受（在帧内），如需内收可改 x∈[-3.5,-1]。

### P0-3b 血口涎滴（复杂度 低）
- **坐标**：吻下尖牙下方 `fillCircle(10.6, 3.2, 0.9)`，`PALETTE.danger` alpha 0.9。
- **备选**：若真机快照中"红=危险"语义有歧义（血滴被误读为危险区），改用 `PALETTE.uiPaper` 白涎（alpha 0.8）——二选一由快照拍板，形状不变。
- **边界**：x≈11.5 ≤12 ✔。

### P1-3c 眼白高光（复杂度 低）
- 现有深色眼 `fillCircle(8,-2.6,1.1)` 左上叠 `fillCircle(7.7,-2.9,0.4)` `PALETTE.uiPaper` alpha 0.85。
- 边界：x≈8.1 ✔。

## 5. 敌人·屠夫（48×48，中心 (0,0)，纯剪影无描边，精英幽紫）

**背景设定**：尸潮的屠夫——厚血精英，玩家集火目标。他是"处刑者"：刀、围裙、一身旧伤。

**设定→视觉**：屠刀 = 屠夫身份核心；围裙带 = 工作装束；角环 = 精英战利品刻痕；缝合伤疤 = 血月下多次战伤的幸存者；肩钉 = 重甲质感。

### P0-4a 屠刀（复杂度 中高）
- **坐标**（右手侧，肩下；与主体同色或 INK 刀柄区分）：
  - 刀柄：`fillRect(14, -2, 3, 8)`，INK alpha 0.85（握把深色）
  - 刀身：`moveTo(17,-5) → lineTo(22,-3) → lineTo(21,10) → lineTo(17,9) → close`，`PALETTE.enemyTank`
  - 刀刃高光：刀背 1px 竖线 `fillRect(21.5, -3.5, 1, 13)`，`PALETTE.uiPaper` alpha 0.55（x=21.5 在刀身 22 内 0.5px）
- **边界校验**：最右 x=22.5（高光 22+0.5）≤24 ✔（帧半宽 24，无描边放大层）；y∈[-5,10] ✔；不与右角（x≤12, y≤-24）重叠 ✔。
- **碰撞口径**：碰撞半径 22，刀尖视觉至 23——视觉略超碰撞 1px 可接受（仅视觉细节，不触碰 `ENEMIES.tank.radius`）。

### P0-4b 围裙带（复杂度 低）
- **坐标**：躯干 `y=3..4.5` 处 1.5px 横带 `fillRect(-15, 3, 30, 1.5)`，INK alpha 0.7（pose=1 肩更宽时 x∈[-17,17]）。
- **边界**：x≤17 ≤24 ✔。

### P1-4c 角环（复杂度 低）
- **坐标**：每角 2 条 INK 短横线（跟随角斜度）：
  - 左角：`moveTo(-8,-14)→lineTo(-7,-16)`、`moveTo(-6,-18)→lineTo(-5,-20)`
  - 右角：`moveTo(8,-14)→lineTo(7,-16)`、`moveTo(6,-18)→lineTo(5,-20)`
- **边界**：y≥-20 ≥ 角尖 -24（保留 4px 余量）✔。

### P1-4d 缝合伤疤（复杂度 低）
- **坐标**：腹部 `(0,8)`：两条 3px 斜线交叉成 X（INK lineWidth 1）：
  - `moveTo(-1.5,6.5)→lineTo(1.5,9.5)`、`moveTo(1.5,6.5)→lineTo(-1.5,9.5)`
- **边界**：x±1.5 ✔。

### P2-4e 肩部铆钉（复杂度 低）
- 双肩各 2 个 1px 纸白圆点 alpha 0.5：`fillCircle(-13,-6,0.8)`、`fillCircle(-11,-7,0.8)`、`fillCircle(13,-6,0.8)`、`fillCircle(11,-7,0.8)`。
- 边界：x≤13 ✔。

## 6. Boss·血月尊者（120×120，中心 (0,0)，桌面描边放大 1.05）

**背景设定**：主持血月仪式的祭司/化身——"血月尊者"。他的剪影要同时读"宗教领袖"+"终局威胁"。

**设定→视觉**：冠上血月宝石 = 自诩血月化身；权杖 = 仪式权柄（祭祀焦点）；月相徽记 = 教派徽章；披风金边 = 高位华贵（金=稀有）；冕旒 = 祭司冕冠（P2）。

### P0-5a 冠上血月宝石（复杂度 低）
- **坐标**：王冠中尖 `(0,-54)` 处（即现有 crown 中心 V 底点）：
  - `fillCircle(0, -54, 2.0)`，`PALETTE.danger`（血月之石）
  - 高光：`fillCircle(-0.8, -54.8, 0.6)`，`PALETTE.uiPaper` alpha 0.85
- **边界校验**：最上 y=-54-2=-56 → 放大 1.05：60-58.8=1.2 ≥0 ✔（C-1 教训：不可再上探；**不要**加 gold 外环 r3.5，-57.5×1.05 会削 0.4px）。

### P0-5b 权杖（复杂度 中高）
- **背景映射**：血月尊者的仪式权杖，杖首红宝石=血月焦点。
- **坐标**（右侧，画序：披风主体之后、侧翼之前——翼盖杖杆下部 2px 形成"持杖"错觉）：
  - 杖杆：`fillRect(47, -28, 2, 58)`，`BOSS.COLOR_MAIN`（y -28..30）
  - 杖首宝石：`fillCircle(48, -32, 4)`，`PALETTE.danger` + 外圈 `strokeCircle(48, -32, 5)` gold 1px alpha 0.9
  - 杖首月牙饰（P1 可选）：`moveTo(46,-36)→lineTo(48,-42)→lineTo(50,-36)` gold
- **边界校验**：最右 x=48+5=53 → ×1.05=55.65 → 绝对 60+55.65=115.65 ≤120 ✔；顶 y=-42（月牙饰）→ 60-44.1=15.9 ≥0 ✔；底 y=30 → 60+31.5=91.5 ≤120 ✔。不与右翼冲突（翼 y∈[-14,34] 区域有杖杆，视觉遮挡关系见上）。

### P1-5c 月相徽记（复杂度 低）
- **坐标**：袍胸 `(0,0)`（兜帽底 y=-6 之下，无重叠）：
  - `fillCircle(0,0,5)` `BOSS.COLOR_MAIN` + `strokeCircle(0,0,5)` gold 1px alpha 0.85
  - 内侧月牙缺口：`fillCircle(1,0,3.5)` INK alpha 0.9（暗红盘被月牙蚀去，呼应"月蚀"）
- **边界**：x±5 ✔。

### P1-5d 披风金边（复杂度 中）
- **坐标**：
  - 下摆：`moveTo(-56,44)→lineTo(56,44)`，gold 1px alpha 0.8
  - 侧翼外缘：左 `moveTo(-52,34)→lineTo(-30,26)`、右 `moveTo(52,34)→lineTo(30,26)`，gold 1px alpha 0.6
- **边界**：x±56 → ×1.05=58.8 → 118.8 ≤120 ✔（与 C-1 同界，安全）。

### P2-5e 冕旒（复杂度 中）
- 王冠两侧各 1 条 gold 垂链：`fillRect(±6.2, -50, 1, 6)` + 底珠 `fillCircle(±6.7, -43.5, 1.2)` gold。
- 边界：x≤7.9 ✔；注意链区与王冠/头圆重叠，画序需在王冠之后；若拥挤则砍掉（P2 保底可弃）。

## 9. 双端 LOD 与移动端降级

- 实体双端共享同一规格（asset-spec §4）；细节随帧烘焙，双端同源。
- 移动端（720×1280 设计空间）实体最小 ≥16px；当 24px 血犬/28px 行尸缩至 16px 显示时，<2px 细节不可辨。**LOD 规则**：
  - 保留轮廓级细节（P0 全部：提灯/开衩/裂纹/眉骨/棘刺/涎滴/屠刀/围裙/宝石/权杖）；
  - 省略 <2px 细节（眼白高光、肩钉、残发、冕旒——P1/P2 中像素级项），可在 `createCharactersAtlas` 内按 `cfg.isMobile` 条件跳过对应绘制（**收敛位：单一入口，不散落 isMobile**，请程基岩按 ARCH §4.2 收进 runtime-config 或等价开关）。
- Boss 移动端 `outlineEnabled=false` 无放大层，边界放宽到 ±60——权杖/宝石双端均安全。
