## 2. 色彩系统

**原则**

- 基底仍低饱和、低明度（背景 L\* ≤ 18）。
- **服装与材质可以有色。** 「高饱和只当信息」只约束 HUD、地面危险、拾取，不约束大衣、毛、甲。
- 不申请新色相：只用下表 token 或 **同色相派生**（提亮 / 压饱和 / 压暗）。派生不够用时另立项，禁止悄悄加霓虹色。
- UI 文字对背景 ≥ 4.5:1；图形 ≥ 3:1。玩家整体须明显亮于普通敌（不靠描边）。

## 3. 可读性（潮中）

- **敌我**：明度差 + 剪影，不共用头形。玩家锁形见角色圣经（马尾刃 / 中檐破斗篷灯 / 头巾或角 / 狼首短披）。敌人各有种形，不要求「全员尖牙鼠」。
- **轮廓光**：默认 **无**。角色与怪物 PNG 不画外圈；不常亮 `postFX` 描边（尸潮 draw call 与 64px 形锚都禁不起）。灯下的光 = 焰、金属高光、受击白闪。
- **高对比模式**（§9）才允许运行时后置描边。默认皮肤 ≠ 高对比。
- **血条**：普通受击显 2s（24×4）；精英常显（48×6）；Boss 顶栏。底 `#000A` + 血橙红 + 1px 白边。
- **识别距离**：标准屏 96px 内可分敌我种。世界精灵 **64 档一档**；手机靠缩放，不靠「缩到 16px 丢掉 1px 特征」当 LOD。最小 FX/宝石仍 ≥16px。
- 碰撞半径与画幅脱钩（hurtbox 不随 64 档膨胀）。

## 4. 角色与战斗层

外形、双线薇奥莱、守誓者站位：**只认角色圣经**。服装/发型/甲以成片为准（角色圣经 §6.2），色键不得改型。本文只锁局内编码。

| 层级 | 画幅 | 体型 | 色 | 描边 | 血条 |
|---|---|---|---|---|---|
| 玩家 | **64×64** | 1.0×（加尔文约 1.25 高，仍落在 64 框内） | §2.2 派生 + 月银亮部 | 无（默认） | HUD |
| 召唤（守誓者等） | 现网 48；**过了 192** | 守誓者站立、高于秉烛人（她 128，他 192） | 板甲材质；与同名敌用**主体色**区分，不用青圈 | 无 | 随玩法 |
| 普通敌 | 40～68 | 0.8～1.0× | 允许衣甲/骨/锈；整体暗于玩家 | 无 | 受击 2s |
| 精英 | **96×96** | 1.4～1.8× | 种色 + **双角画进图** | 无；不靠紫边分层 | 常显 |
| Boss | 240～256 | ≥3×，屏占比 ≤1/4 | 独有形 + 猩红倾向；金饰靠道具形 | 无 | 顶栏 |

**战斗层（方案 B）**

- 不是立绘缩小，也不是全身月银 + 冷青圈。
- 色键 v2 已过（角色圣经 §6.2）。卡珊德拉战斗套已过。`player` / `player-v` idle **已过（v9）**。`player-walk-a/e/b/c/f/d` **已过（V4）**。`player-skill-a/b` **已过（v1，独立基础姿）**。专武姿未过。流程：`combat-64-workflow-v1.md`（**v1.24**）。`hero-violet` 守誓 idle **已过（128 · from-a）**；走 **已过（128 · E2）**；技能 **已过（128 · A1 / B2）**。`hero-violet-fallen` 魔化 idle **已过（128 · B-lo）**；**skill 待技能设计**。加尔文 idle 128 开工。守誓 O-3 + D2 已过；魔化 F-3 + E1 已过。像素工作流：`combat-64-pixel-workflow-v1.md`。专武第二波未开。其余未过 `hero-*` 未点开工前不换。
- 灯/烛：焰心余辉金 2～4px；灯体随材质。拾取金必须是**箱/武器形**。
- 魔化禁全身红；狂化只许兽纹点缀变亮，主体不翻成敌色。
- 程序剪影兜底（32px 图集）仅作素材未到时的灰盒，**不是**造型目标。

## 5. 环境与地图

- 地形：石板 `#131722`、草地 `#18201C/#2A3B2E`，tile 64×64，明度 12–18%，不与角色抢眼。
- 墙：`#2A3346` + 顶缘 1px 高光；可挡画实，不可挡画虚。
- 陷阱 / 血池：血橙红 + 斜纹 + 闪烁；**禁全屏红晕**。装饰地毯不得抄危险编码（R-C）。
- 拾取：经验 = 蓝菱；治疗 = 绿十字；稀有 = 金箱。小图标可 1.5px 纸白边（对象是 10～16px 符号，不是 64px 角色）。
- 出界：暗红半透明 + 倒计时边，勿用角色描边语。

## 6. UI

- 布局（1920×1080）：左上等级/经验；左下 HP；右上武器槽；升级三选一居中偏下。
- **局外**选中 / 主 CTA = 余辉金（`ui-redesign-handoff`）。禁胶囊霓虹当主装饰。
- **局内 HUD**：冷青可用于条、准星、机制信息。升级三选一选中改为 **余辉金**（与入口同一「可点亮」，避免冷青垄断玩家侧）。禁用 60% 透明；底 80% 遮罩。
- 触区：移动 ≥44px；桌面视觉 24 + 热区 ≥32。
- 字号：正文 ≥16；HP/数值 ≥20；卡片标题 ≥22；移动实渲染 ≥14。

现网升级卡若仍是冷青选中，视为待换皮，不阻塞角色色键。

## 7. 动画与特效

- 玩家受击白闪 0.1s；敌受击红闪 0.1s + 2px 抖。禁长震屏。
- 死亡：8～16 粒、0.4s；池 ≤200。
- 磁吸 140px / 0.15s；滞留慢漂 80px/s。
- 震动 ≤4px、≤0.15s；移动端默认关。
- 残影 2～3 ghost。不用全屏模糊 shader。
- 单屏特效 draw call ≤8。环、粒子、冲击波 **不画进角色 PNG**。

## 8. 管线与镜头

- **视觉目标**：角色圣经锁形 + 本文灯下哥特。Kenney / 泛 top-down 包只可灰盒与碰撞，**不可**当角色或怪物成片参考。
- **镜头**：战斗为 **3/4 站立**，只 `flipX`，不出四向、不当纯俯视顶视角。
- **世界精灵**：已过 C/E 仍 64；**新英雄战斗帧 128**（评 C）。精英 96、Boss 240+ 本轮不升。UI 仍桌面 1920×1080 / 移动 720×1280；UI 出档 2x / 1x。世界实体不因竖屏另出一套造型。
- **LOD**：需要时另出 32 档或关掉内部高光；禁止用外圈描边冒充 LOD。
- 格式：精灵 PNG+alpha；图集 ≤2048²，characters / effects / ui 分包；`premultipliedAlpha=false`；tile 64²。
- 美工交 `assets/raw/<帧名>.png`；`outlineW=0`，不要空出描边等管线。

## 9. 可访问性

- HUD 信息双编码：危险 = 血橙红 + 斜纹/三角；治疗 = 绿 + 十字；经验 = 蓝 + 菱；精英 = 体型 + 角饰（色盲不靠紫边）。
- 高对比：**可选**运行时描边 2px→4px、背景降饱和、字加底。默认关闭。
- 字号 125% 档；减少闪烁开关（陷阱闪、受击闪、震动）。残影默认可关。
