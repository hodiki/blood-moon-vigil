## 1. 视觉身份总述

**一句话风格**：暗夜血月下的哥特剪影大逃杀——用最少的色相、最强的对比，让潮水般的敌人 3 秒内可读。

**三个关键词**：暗夜血月（Deep Gothic Night）· 高对比剪影（High-Contrast Silhouette）· 红色即危险（Red = Danger）

本圣经只锁定垂直切片"够用、好看、可复用"的规则，不为完整产品过度设计；新增资产必须对齐本规范，偏离即标注。

## 2. 色彩系统

**设计原则**：
- 画面 80% 以上为低饱和暗色基底，高饱和色只用于"信息载体"（玩家/敌人/拾取/危险区），颜色不用于装饰。
- 色彩语义遵循中国玩家直觉：**红 = 血 = 危险**；绿 = 安全/治疗；金 = 稀有/奖励；蓝 = 经验/信息。
- 亮度对比度硬标准：背景明度 L\* ≤ 18；主体剪影 L\* ≥ 45；UI 文字对背景 ≥ 4.5:1；图形/图标 ≥ 3:1。

## 3. 可读性法则

- **剪影区分**：敌我不共用形状。玩家 = 圆帽披风；普通敌 = 尖牙鼠形/骷髅头；精英 = 更高更宽 + 双角头饰；Boss = 独有剪影。标准屏（1920×1080）下 96px 内即可分辨。
- **轮廓光**：统一用 Phaser FX 描边。敌我 2px；精英 3px 幽紫；Boss 4px 猩红；玩家常亮冷青 2px。描边禁止与背景同色系。
- **血条可见性**：普通敌血条受击后显示 2s 渐隐（宽 24px 高 4px）；精英常显（48×6px）；Boss 用顶部 UI 血条（宽屏 60%）。血条 = 黑底 `#000A` + 红 `#FF3B30` 填充 + 1px 白边。
- **双端识别距离**：手机端（参考 390×844 物理竖屏）敌人在 1/3 屏高距离内必须可辨——即最小可识别剪影 ≥ 屏幕高度 4%。设计分辨率按平台定案（桌面 1920×1080 / 移动端 720×1280，见 §8）；移动端最小实体 ≥ 16px 以 720×1280 设计空间为准，保证 Scale 到物理屏后仍可辨。

## 4. 角色视觉规范

| 层级 | 体型比例 | 主色 | 描边 | 血条 | 备注 |
|---|---|---|---|---|---|
| 玩家 | 1.0x（32px 基准） | 月银白 | 冷青 2px 常亮 | 左下 HUD | 无敌帧闪烁 0.15s |
| 普通 | 0.8–1.0x | 暗血红剪影 | 无（靠剪影） | 受击显 2s | 群体出现，颜色统一 |
| 精英 | 1.4–1.8x | 暗红 + 幽紫 | 幽紫 3px | 常显 | 死亡掉落经验 10（TASK-39 R1 波次2 15→10，压后期经验通胀） |
| Boss | ≥3x（屏占比 ≤1/4） | 猩红 + 金饰 | 猩红 4px | 顶部 UI | 出场 0.5s 霸体闪红 |

**编码规则**：敌人层级用"体型 + 色相 + 角饰"三要素编码，任意两要素可区分——色盲下仍可辨（形状优先于颜色）。

## 5. 环境与地图视觉

- **地形**：`#131722` 石板/草地两种材质，tile 64×64，明度 12–18%，低饱和，不与角色抢眼。
- **障碍/墙**：灰蓝 `#2A3346`（明度 30–40%）+ 顶缘 1px 高光；可阻挡物画"实心"，不可阻挡物画"虚化"。
- **陷阱**：危险红 `#FF3B30` 或红色斜纹 + 0.8s 周期闪烁（透明度 60%→100%），地面贴花；**禁用全屏红晕**（避免与玩家受伤混淆）。
- **拾取物**：发光圆点 + 图标，统一 1.5px 白描边保证深色地面可见。经验 = 蓝菱（最小 10px），治疗 = 绿十字，稀有 = 金箱。
- **地图边缘**：暗角渐晕压暗 20%；出界危险区用红色半透明遮罩 + 1.5s 倒计时描边。

## 6. UI 视觉规范

- **布局**（1920×1080 基准）：左上 = 等级/经验条（240×8px）；左下 = HP 血条（240×14px）+ 数值；右上 = 武器图标槽；升级三选一弹窗居中偏下。
- **升级三选一弹窗**：三张卡片 320×180px、间距 24px，图标区 128×128px 上图标下文字；选中态 2px 冷青描边 + 缩放 1.03；禁用态 60% 透明度；背景 80% 黑遮罩聚焦。
- **触控热区**：移动端所有可点目标 ≥ **44×44px**（卡片/按钮/暂停键）；桌面鼠标 ≥ 32×32px（视觉 24px + 外扩热区）。
- **字号下限**：正文 ≥ 16px；数值/HP ≥ 20px；升级卡片标题 ≥ 22px 加粗；移动端实际渲染 ≥ 14px 物理像素。

## 7. 动画与特效风格

- **受击反馈**：玩家受击白闪 0.1s；敌人受击红闪 0.1s + 位移 2px 抖动；禁长震屏。
- **死亡消散**：8–16 粒子由实体色向透明扩散 0.4s 消失；粒子池上限 200，超限回收最早粒子。
- **拾取磁吸**：拾取物在 140px 内曲线缓动吸入（0.15s），吸入前闪烁提示；滞留宝石（落地 >3s）以 80px/s 慢漂向玩家（TASK-39 R1 波次2：磁吸 80→140）。
- **屏幕震动**：幅度 ≤4px、时长 ≤0.15s；仅 Boss 登场/精英死亡触发；移动端设置默认关闭。
- **残影**：冲刺/无敌时用 2–3 个半透明 ghost（30% 透明度、间隔 60ms），不用全屏后处理。
- **性能预算**：全部特效用粒子池 + 预烘焙精灵图集；禁用运行时模糊/全屏 shader；单屏特效 draw call ≤ 8。

## 8. 素材管线建议

- **开源素材方案（首选）**：
  - Kenney.nl（CC0）：Topdown Shooter、Roguelike/RPG 包，含角色/地砖/UI 全套，可商用无署名负担。
  - itch.io 免费包：搜 "top-down 2D game assets"，选 CC0/免费商用；避免 CC-BY（署名）包以减少发布负担。
  - 程序生成：基础几何 + 本圣经色板（canvas 生成地砖/发光圆点拾取物），可快速造料。
- **分辨率（C2 定案 · 双端双分辨率）**：
  - 桌面 1920×1080 横屏 / 移动端 720×1280 竖屏，两套设计空间独立、互不裁切。
  - 贴图档位：桌面按 2x 高清档；移动端按 1x 省显存档；共享资产（tile/几何/矢量 UI）以 2x 为准、运行时缩放复用，不额外出档。
  - 最小实体 ≥ 16px：桌面指 1920×1080 设计空间；移动端指 720×1280 设计空间（世界实体双端共享规格，UI/特效按各自设计空间收敛）。
- **格式**：带 alpha 用 PNG（精灵/图标，兜底兼容性最好）；纯色块/UI 可 WebP（体积约 -60%）；Phaser 3 原生支持两者。
- **精灵图集**：TexturePacker 或免费工具输出 JSON 数组 + 图集；单图集 ≤ 2048×2048（移动端显存友好）；按品类拆包（characters / effects / ui 分开）。
- **Phaser 兼容性**：用 atlas 而非零散图加载（减少 IO）；`premultipliedAlpha` 统一 false；WebGL 优先、Canvas 兜底；平铺用 2 次幂 tile（64×64）。

## 9. 可访问性

- **色盲友好**：信息双编码"颜色 + 形状/图标"——危险 = 红 + 三角，治疗 = 绿 + 十字，精英 = 紫 + 双角；提供 Protanopia / Deuteranopia 替换色板（切换后仍满足 3:1 图形对比）。
- **高对比模式**：全局描边 2px→4px、背景降饱和 30%、UI 文字加黑底。
- **字号**：正文下限 16px；支持系统级字体缩放（不把像素字号锁死到画布）；弹窗文字提供 125% 档。
- **动态效果**：提供"减少闪烁"开关（关闭陷阱闪烁、受击白闪、屏幕震动）；残影默认开、可关。
