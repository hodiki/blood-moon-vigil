## 0. 为什么是她

她的战斗套是齐的，而且规格没有裂开：`hero-cassandra`、`-v`、`walk-a`…`f`、`skill-a`、`skill-b` 全是 64。加尔文的走帧 a/b 仍是 64、c–f 会继承 128，不适合第一刀对照。

## 1. 环境

只加一个软件。不装 Comfy、不装 Qwen / Krea / H3 / Wan、不装 Spine、不装 PixelLab、不把 Aseprite 当作者。游戏工程里的 Node 和 `tools/asset-pipeline` 已经够用来近邻缩小和打包，试点不新装运行库。

| 装 | 不装 |
|---|---|
| **Blender 5.2.2 LTS**，Windows x64 便携 zip | 5.3 抢先版、Steam 版、插件市场里的像素风套件 |
| 官方包：<https://download.blender.org/release/Blender5.2/blender-5.2.2-windows-x64.zip> | 图生三维网站、动作捕捉、付费烘焙农场 |

解压到仓库外面，例如 `D:\tools\blender-5.2.2\`。不要放进 `vampire-survivors-like`。打开 `blender.exe` 能进默认场景即算环境好。Workbench 平涂不需要独显，不装 CUDA。

第一次打开后只改这些，然后存成启动文件（File → Defaults → Save Startup File），避免下一文件又变回电影色：

| 项 | 设成 |
|---|---|
| 渲染引擎 | Workbench |
| Lighting | Flat |
| Color | Material |
| 阴影、腔体、轮廓 | 关 |
| 抗锯齿 | 关 |
| Film | Transparent |
| 色彩管理 View Transform | **Standard**（不要 AgX / Filmic） |
| Look / Exposure / Gamma | None / 0 / 1 |
| 输出 | PNG，RGBA，8 bit |
| 分辨率 | **512×512**，100% |

平涂材质用 Emission 或 Workbench 的材质色，一个块一个色。不要灯光渐变，不要地面，不要辉光，不要降噪。

近邻从同一张 512 收出两套：64 是每个方向每 8 个源像素取 1 个，用来和现网印戳站在同一像素格子上比；128 是每 4 个源像素取 1 个，用来看 64 丢掉的马尾、收腰和下摆还剩多少。不要用 Blender 的缩放，也不要 lanczos。两套都不过量化。

## 2. 设计怎么进这一具模型

三份图各管一件事。相机这一刀改听**现网战斗帧**，不听加尔文那套「侧视转 20°」。她的已过 idle / 走 / 技能都是四分之三朝右；对照要看的是体块和印戳，不是另换一个角度。

| 图 | 路径 | 管什么 |
|---|---|---|
| 现网战斗帧 | `assets/frames/hero-cassandra.png` 及同套走、技能 | 相机、头脚占画布的比例、大色从哪取 |
| 剪影 | `characters/cassandra/identity/silhouette/lock-ce.png` | 马尾刃、收腰、三角下摆。外形打架时听它 |
| 立绘 H23 | `characters/cassandra/identity/source/h23.png` | 只回答「这块是什么」。不贴到模型上 |

块只有这些：银马尾（一块楔形，远看要宽）、高领、收腰、酒红大衣的三角下摆、两条腿、靴。大衣不要做成身后破斗篷。头发不要做成缕。

颜色从**现网 idle 的大块**上取，不另挑一个酒红，也不把立绘的细金边做进去：大衣一块酒红，头发一块银，金属一小块银。余辉金若现网帧上小到指不出，试点不建。

正交相机对准现网 idle 的朝向后锁死。六步和两个技能只转骨头，不转身体、不改块的大小和颜色。

| 帧 | 姿势（与现网同一读法） |
|---|---|
| `hero-cassandra` | 四分之三站立 |
| `-v` | 与 idle 同一张 |
| `walk-a` | 接触，朝右的脚跟着地 |
| `walk-e` | 落下 |
| `walk-b` | 经过，两腿收到身下 |
| `walk-c` | 对侧接触 |
| `walk-f` | 落下 |
| `walk-d` | 第二经过 |
| `skill-a` | 和 idle 一眼能分开的前摇，无拖尾 |
| `skill-b` | 和 idle、和 skill-a 都能分开的回收，无拖尾 |

十张里九个姿势加一张复制。烘的时候现网图只垫在相机背景里对位置，正式输出前关掉，不要烘进 PNG。

脚在两套的十张里各自落在同一行。头到脚占画面的比例和现网 idle 一致。进游戏时，现网 64 和体块 64 都是世界缩放 2；体块 128 是世界缩放 1。三种的世界边都是 128，人不会因为换分辨率突然变高。

## 4. 和原方案怎么比

两步，都看游戏尺寸，不看 Blender 视口。

**第一步，并排板。** 九行，三列都放到 256。左列现网 64，中列体块 64，右列体块 128。`-v` 不单独占一格。中列回答「同一格子里，体块和印戳差多少」。右列回答「格子加倍后，64 丢掉的设计回来多少」。

四句对中列和右列各问一次：

1. 还是她：马尾刃、收腰、三角下摆还在。
2. 三块色还在：酒红大衣、银发、一小块银金属。不要求下摆边缘和现网差几像素也对齐。
3. 六步有离地和重心移动；两个技能和 idle 一眼能分开。
4. 没有外描边、空心、脏边、碎点。这一套十张脚在同一行。

64 上第 1–3 句为否，记成这一格丢掉的设计，不单独取消进游戏。两套的第 4 句都要成立，才进入游戏。

**第二步，可退回的游戏对照，做两遍。** 先备份十张现网帧和 `assets/atlas/characters.png`、`characters.json`。第一遍换上体块 64，打包，选卡珊德拉走一段、放一次技能，然后还原。第二遍换上体块 128，再打包再看，再还原。两套都不能留在 `assets/frames/` 过夜，除非主理人另写一句。

十张必须一起换。只换走、不换 idle，会在停步和迈步之间切两套人。64 和 128 也不能混在同一次换图里。

看的是：走起来还认不认得出是她，和旁边仍是旧画法的角色站在一起是否能当战斗层。旧画法的其他人保持原样，这个差别记进结论，不单独判死。

测完从 `backup-live/` 拷回十张帧和图集。现网锁稿同时在 `characters/cassandra/combat/idle|walk|skill/`。试点不把体块留在 `assets/frames/` 里过夜，除非主理人另写一句让这套留下。

`frame-specs.mjs` 里她仍是 64。试点不改这行。因此不要对这十张跑 `process.mjs` 或 `--check` 当结论；检查会按 64 把 128 判失败，或压回去。
