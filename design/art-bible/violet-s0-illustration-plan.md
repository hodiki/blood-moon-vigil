# S0 · 薇奥莱角色立绘（选人卡 + identity source）

> 2026-11-02 · **方案待确认，未出图**
> 目的：产出一张能当**选人卡立绘**、也能当**下游生成参考**的正式插图，替换掉 V3-07 原型（它只是设计草稿）

---

## 0. 为什么必须有这一步

V3-07 原型不能当立绘，三个硬伤：

| 问题 | 说明 |
|---|---|
| **没有守誓者** | 她的身份读点是「**带光女人 + 高个子同伴**」。立绘没有骑士，等于丢半个身份 |
| **画风不对** | 原型是**平涂赛璐璐**（局内概念稿画法）；选人卡要的是**绘画哥特/半写实**（见 §2） |
| **动作是草稿态** | 重心偏一侧、手部随意，不是成品的构图 |

---

## 1. 项目里「立绘 / card / source」分别指什么

| 词 | 实际含义 | 出处 |
|---|---|---|
| **立绘** | 选人卡用的角色插图：**绘画哥特 + 有脸 + 只带身份道具** | `ui-redesign-handoff-v1.md` §59/§65 |
| **头像** | 从立绘**裁胸像**，供选人卡顶栏 / HUD / 余辉树复用 | 同上 §67 |
| **source** | `characters/<hero>/identity/source/` 下的**身份参考图 + source.md**，是后续所有生成的锚（卡珊德拉的是 `h23.png`） | `characters/cassandra/identity/source/` |

薇奥莱目前**没有 `identity/` 目录**——所以 S0 是从零建立这套。

## 2. 画风：这里有个必须先说清的落差

**原型是平涂，立绘不是。**

| | 原型 V3-07 | 立绘（h23 那一档） |
|---|---|---|
| 画法 | 平涂赛璐璐、硬边、无描边 | **半写实**：软过渡、材质高光、可见体积 |
| 皮肤 | 单层色块 | 有血色与透光 |
| 金属/皮革 | 平涂 | 有反射与磨损 |

`character-art-bible` §1.1 定的是「**半写实绘画哥特：有体积、有脸、有织物与金属；不是像素放大，不是动漫大眼**」。

你的第 ⑤ 条也确认了"动作和画风不作为最终效果"。**所以 S0 要换画法重出，不是把原型放大。**

## 3. 两处已锁的条目会被这次设计改掉（要你点头）

新设计很漂亮，但它推翻了薇奥莱身上**两个已经过审的锁**：

| 锁 | 原内容 | 新设计 | 影响 |
|---|---|---|---|
| **O-3 剪影** | 长发 + **胸甲肩** + **髋侧剑形** | 眼罩 + 开衩裙 + 无剑 | 剪影全变，O-3 不成立 → 需重开（记 O-4） |
| **D2 色板** | **披裙夜行灰**为大块；银只胸/肩；**烛焰一点**；骑士中钢+红羽 | **白上衣 + 黑裙 + 白袜**为主 | 主色从"灰"变成"黑白"，D2 不成立 → 需重开（记 D3） |

**但有一处能接住**：D2 里那句「**烛焰一点**」，正好可以由**离体光球**承担——她"秉烛人"的称号和语义都还在，只是烛变成了浮在肩侧的一点光。这一条不需要重开。

> 我的建议：**正式把 O-3/D2 记为"被新设计取代"，另立 O-4/D3**，而不是偷偷改。否则以后对图会互相矛盾。

## 4. 守誓者（立绘里必须出现）

规格直接取自 `character-art-bible` §308/§381，都是已过的：

| 项 | 锁 |
|---|---|
| 画布 | **192**（她 128 的 1.5×），**必须比她高** |
| 姿态 | **站立**，不是跪姿（现网 48px 跪姿是废稿） |
| 甲 | **板甲**，闭面盔，盔与肩甲可辨 |
| 色 | **中钢为主 + 红羽点缀**，银只做边；**禁熏黑钢、禁整身镀银** |
| 出场 | **只出现在守誓线立绘 / 局内实体，不画进她的战斗帧** |
