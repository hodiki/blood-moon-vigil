## 1. 血契双刃 · 形语言

从卡面读出来的要素：

| 要素 | 描述 |
|---|---|
| 基本形 | **双持短弯刀**，两把成对，左右镜像 |
| 刃身 | 宽、单刃、**明显内弧**，刀尖上翘；刀背靠护手处有一排**锯齿突起** |
| 护手 | 短十字护手，两端带尖；护手下方有**十字纹**（与白十字同源） |
| 柄 | 深色缠绕柄，末端一枚小圆头 |
| 色 | 钢面 `#B0C0C0` → 高光 `#E0F0F0` → 暗部 `#707070`；**刃内侧一条血橙红** `#B02020`（高光 `#F03030`、暗 `#701010`）；护手/柄近黑 `#202030` |
| 语义 | "血契"＝刃饮血；红只在**刃线**，不做整把红 |

### 在 128 上的尺寸约束

| 项 | 建议 | 理由 |
|---|---|---|
| 单把刃长 | **26–32px** | 角色高 112；再长会横向吃满画布 |
| 握持位置 | 掌心，刃向前斜上 30–40° | 与冲刺方向一致 |
| 两把的明暗 | **近手亮一档、远手压半档** | 否则两条银线糊成一条 |

## 2. 月痕长弓 · 形语言

| 要素 | 描述 |
|---|---|
| 基本形 | **反曲弓**，上下弓臂各一个反弯，末端向外翻 |
| 弓臂 | 银灰弓体，**外侧有棘刺/叶状突起**（不是光滑的弓） |
| 弦 | 冷青细弦，拉满时成 V |
| 握把 | 中段有蓝色缠绕区，带两枚小饰件 |
| 箭 | 叶形/晶体箭头，银色箭杆，冷青尾羽 |
| 色 | 弓体 `#9090A0` / `#B0C0C0`，暗 `#405050`；**蓝色 `#40C0F0`**（亮）与 `#306070`（深）；弦与尾羽用冷青 |
| 语义 | "月痕"＝月光冷辉；蓝只在**弓弦/握把/箭尖**，不做整把蓝 |

### 在 128 上的尺寸约束

| 项 | 建议 | 理由 |
|---|---|---|
| 弓高 | **64–76px** | 约角色高的 0.6–0.7。按真实比例（≈身高）会占满画布，读不出角色 |
| 弓的朝向 | 弦在身体一侧、弓臂向外 | 让**弦—手—箭**围出三角负空间 |
| 对比 | 弓比大衣亮一档 | 大衣是暗酒红，弓是银灰，天然有差；再压冷青高光提亮 |

## 3. 两张锚点插图（这一步要出的东西）

### A. 武器插图（两把并排，单品，无人物）

用途：给后续所有帧一个"武器长什么样"的唯一事实来源。

要点：
- 纯黑底、正视/微侧，**两把武器并排**，同一光照
- 双刃：两把交叉或并排，刃线朝上，能看到锯齿背与十字护手
- 长弓：完整反曲轮廓，弦绷直（未拉），箭头搭在弦上
- 平涂赛璐璐、硬边、无描边（与角色同一画法）
- 输出 1024×1024，透明或近黑底

### B. 角色 + 武器插图（两张，各持一把）

用途：确定"她拿起来是什么比例、什么角度"，这是 128 帧真正的锚。

| 图 | 内容 |
|---|---|
| B1 | 卡珊德拉**双持血契双刃**，低重心前压（血影突袭的准备姿），朝右 |
| B2 | 卡珊德拉**拉满月痕长弓**，侧身、重心后坐（月痕狙击的蓄力姿），朝右 |

要点：
- 沿用她的形锁：高马尾刃形、高领收腰大衣、黑丝、细高跟、胸前白十字
- **手空 → 持武**是这一批唯一要改的地方，其余不动
- 表情：猎人眼，不笑
- 输出 768×1344（与印戳同比例），后续再入盒

## 4. 顺序（按主理人的意思）

1. 先出 **A 武器插图** → 过目
2. 再出 **B1 / B2 角色持武图** → 过目
3. 拿 B1 去**补刃**到现有 `-skill-a`（不整张重出）
4. 拿 B2 重出 `-skill-b`（长弓整张新做）
5. 两张都过 128 入盒 + 规格自检
