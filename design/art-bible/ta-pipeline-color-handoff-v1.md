## 1. 问题清单（按会不会「脱离设计」）

### P0 · 量化器与方案 B 对不上（主因）

文件：`tools/asset-pipeline/tokens.mjs`  
函数：`classifyFamily` → `nearestRamp` → `quantizePixels`  
顺序：`lanczos3` 降到 64 **之后**再量化（`process.mjs` P-5）。

规则现状：

| 规则 | 行为 | 设计后果 |
|---|---|---|
| 彩度 &lt; 16 | 强制 `silver` 阶 | 压饱和布料（酒/巡夜/圣袍/橄榄）变灰 |
| 彩度 ≥ 16，按 a/b 贴 14 锚 | 暖中调进 `blood` | 肤高光 → **血亮-2 `#FF3B3B`**（危险/受击红） |
| `blood` 明度阶 | 墨夜 → `#7E1E1E` → `#FF3B3B` | 没有「苍白→暖阴影」的中间，只有敌潮红 |
| 角色禁草地 | 橄榄不能走草阶 | 加尔文披要么灰，要么（若放开）变草地 |
| §2.2 派生色 | **不在 PALETTE** | 文档有色、管线无色 |

实测（同一 `nearestRamp`，角色禁草）：

| 圣经色 | hex | 量化后 | 是否还像设计 |
|---|---|---|---|
| 猎手酒红 | `#6B3942` | 银-2 `#4D5157` | 否 · 灰大衣 |
| 巡夜布 | `#3A4554` | 银-2 `#4D5157` | 否 · 与酒同一灰 |
| 圣袍灰 | `#3A4250` | 银-2 `#4D5157` | 否 · 三人同一灰 |
| 墨衣 | `#2A3038` | 银-1 `#2B2E34` | 弱 · 几乎墨夜 |
| 狼披橄榄 | `#4A5C4E` | 银-2 `#4D5157` | 否（放开草则 `#2A3B2E` 草叶，更糟） |
| 骨灰毛 | `#C4B8A8` | 银-5 `#BEC5CE` | 弱 · 失暖 |
| 苍白肤 | `#D2B4A0` | 银-5 `#BEC5CE` | 弱 · 冷灰脸 |
| **暖肤高光** | `#C3996E` | **血亮-2 `#FF3B3B`** | **否 · 红脸** |
| 焰心 / 角 / 头巾纸白 | token 原值 | 原值 | 是 |

卡珊德拉现网：银阶 **85.6%**（495px），血阶 14.4%（83px，其中猩红 20px）。契约 L* 仍 PASS（高亮 9.7% 靠银发），所以 **验收在表扬走样**。

idle-v6 / 试切已把脸阴影画暖，给了跳崖燃料；**放大器是量化**。立绘 v2 脸颊均值偏暗棕，同样过量化器几乎不会出荧光红——所以「重绘一张更冷的脸」只能减轻，不能治四人布料全灰。

### P0 · 三份契约互相打架

| 文档 | 玩家填色 | 管线 |
|---|---|---|
| art-bible v1.0 §2.2 | 布料用派生；高饱和红只点缀 | **未执行** |
| character-art-bible §1 / §6 | 苍白脸；酒红压饱和，禁敌色整身 | 形已跟；色被改写 |
| asset-spec §2.4 + `process.mjs` P-4 + pipeline README | 「玩家必须是银主体」；L\*≥45 或高亮≥3% | **正在执行** |

P-4 注记仍写「须银主体」。方案 B 已允许大衣有色。不改验收文案，TA 修好色阶后，偏暗的正确酒大衣可能被打回 FAIL。

### P1 · 族共享缩放（生产流程，不是色）

`process.mjs` 对任一帧名会 `expandToFamilies`：idle 与 walk/skill 共用 contain。旧兜帽 walk 的包围盒会决定新 idle 的缩放。卡珊德拉本轮高度碰巧接近（约 824px），未压矮；**下一角色若 idle 作物比旧 walk 小/大，会一起被撑满或缩小**。

另：只换 idle、不换 walk 时，局内一走仍是旧形（现网已如此）。这是内容债，不是量化 bug。

### P1 · 先 lanczos 再量化

中间色（酒×肤×虚空）在 64 格上先被滤成暖灰/桃，再被 `classifyFamily` 推下悬崖。P-5 用 lanczos 是为了反椒盐，**顺序合理**；缺专属阶时，混合像素比 nearest 更伤设计。修 PALETTE 后此条降为残留。

### P2 · 抠图 / 硬化可能吃 1px 形

| 步骤 | 风险 | 何时发作 |
|---|---|---|
| 边缘洪水 `THRESH=24` | 近黑靴、开胸 V、暗褶若连到画布边，会被当底清掉 | 暗衣贴边；`#000`↔`#0B0E14`≈27，余量很小 |
| `hardenAlpha`：α&lt;160→0 | lanczos 半透明边丢掉 | 高跟钉、银缝 1px |
| `breathe-from-idle.mjs` | 1024 上扩 18px → 64 上约 1px → 量化后与 idle **同像素** | 现网 `-v` 已证实无呼吸 |

这三项不制造红脸，但会让「已过的高跟 / 银缝」在重跑管线时变钝。

### 不是问题（避免 TA 重复施工）

| 项 | 说明 |
|---|---|
| 入盒 56 高、两侧留空、脚贴底 | 方案 B / §6.3 故意如此 |
| `outlineW = 0` | 方案 B：默认无外圈描边 |
| 试切站姿形 | 已过目。不要为红脸重切 idle 剪影 |
| 14 token **锚点 hex 本身** | 语义槽位过载见 `art-bible-v03-review.md` §2。本交接不要求先加新色相 |
