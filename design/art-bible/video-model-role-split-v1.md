# H3 与 Wan Animate 2 不是同一类工具

> 2026-10-21 · 回应「为何生视频需求基本都推 Wan Animate 2，H3 不是更新更好的开源模型吗」
> 状态：说明稿。不改裁定，不动权重。

---

## 0. 一句话

**H3 是"通用视频生成器"，Wan Animate 2 是"动作迁移器"。** 拿榜单排名去比这两件事，就像拿"拍照最好的手机"去比"扫描仪"——都出图，但一个负责创作，一个负责复刻。

顺带更正一个前提：**H3 并不更新。** H3 公布 2026-07-31、权重 2026-08-02；Wan-Animate-2 是 2026-08-07。后者晚五天。

## 1. 两者各干什么

| | MiniMax H3 | Wan Animate 2 |
|---|---|---|
| 类别 | 通用全模态视频模型（T2V / 首尾帧 I2V / 多模态参考 R2V，带原生音频） | 角色动画 / 动作迁移 |
| 典型输入 | 一段提示词；或一张首帧；或 ≤9 图 + ≤3 视频 + ≤3 音频 | **一张角色图 + 一段驱动视频** |
| 动作从哪来 | 从提示词与首帧"生成"出来 | 从驱动视频"搬"过来 |
| 输出 | 4–15s，768p（2K 走重生成），24fps，32kHz 立体声 | 参考帧率，短段，无音频 |
| 强项 | 画面质感、物理、镜头、声音、复杂多模态指令 | 身份保持 + 逐帧动作复刻 |

## 2. 对"六帧走循环"这件事，差别在哪

战斗走循环要的是：**六个特定相位（触地 / 落下 / 过渡 / 对侧触地 …）、同一脚底、同一身高、可复现。**

| | Wan Animate 2 | H3（I2V） |
|---|---|---|
| 能不能指定"现在是触地还是过渡" | 能——驱动视频里就是 | 不能。写"她走路"只能希望它走对 |
| 一段内是不是同一人 | 是，一段视频天然同一个人 | 每枪一个新采样，身份会漂 |
| 帧能不能复用 | 一段里挑六帧，脚底再入盒即可 | 挑完还得逐张对脚底 |
| 失败怎么处理 | 换驱动视频或换 seed，动作框架不变 | 重抽可能换人（所以有"两轮停手"） |

他们自己的 README 写得很准：**"身份从参考图来，姿势从驱动视频来，一段视频里的帧天然是同一个人。走循环从「六张独立签」变成「一段里挑六帧」。"**

## 3. 为什么本机 H3 会"能跑但效果受限明显"

这句话不是显卡不够，是三件事叠在一起：

1. **量化更狠。** 本机 H3 是 `Q3_K_M` GGUF（3-bit）+ 32B 文本编码器 `Q2_K`；Wan 是 `int8` distill。同一个 8GB 盒子，H3 被压得比 Wan 狠一档。
2. **H3 的"大脑"没开源。** 官方明说 `H3-Context-IR`（把自由输入解析成模型能懂的结构化指令）**不在开源发布里**，只在 API。本机跑的是没有这层的裸模型，得自己手写它认的提示词结构——这一步做不好，观感直接掉一档。
3. **任务不匹配。** 即使 H3 满血，它也是"生成一段好看的视频"，不是"把这个角色的左脚在第 3 帧放到这个位置"。

## 4. 但 H3 确实更强的地方，也要说清

- 通用画面质量、物理、镜头语言、**原生音频**：H3 领先。发布时它在 Artificial Analysis 视频编辑榜排第一、T2V / I2V 进前三——这是真的。
- 时长 4–15s、768p、2K 重生成：比 Wan 的短段宽。
- 多模态参考（9 图 + 3 视频 + 3 音频）：做剧情、做宣传，这是资产。

**所以"该用 H3"的场景是**：过脸门的立绘 → 5 秒有镜头有氛围的小动作；段间 first+last 续；宣传片素材。**不该用 H3 的场景是**：需要精确相位、精确脚底、逐帧可复现的战斗循环。

补一句：H3 的 Ref2VA 能吃视频参考，但那是"借信息"（身份、风格、镜头、声音），**不是逐帧动作迁移**，拿它替代 Wan 出走循环没有验证过，也不在它的设计目标里。

## 5. 许可也是一条

| | 许可 | 门槛 |
|---|---|---|
| Wan 2.2 Animate 2 | **Apache 2.0** | 无；不主张生成物权利 |
| MiniMax H3 本机权重 | Community License（2026-08-02） | 适用地**排除**美 / 欧 / 英 / 韩；年收入 >2000 万美元须授权；**商业产品界面须显著标 "MiniMax H3"** |

最后那条会进游戏的界面 / 制作人员表，是一个长期义务。不是不能接受，但要知道它会留在成品里。

## 6. 决策规则（以后不用再问）

- **要"这个角色照这段动作动"** → Wan Animate 2。战斗走循环、技能姿、任何需要精确重复的动作。
- **要"一段有镜头、有氛围、有声音的片子"** → H3。本机受限，复杂就走线上 API。
- **两者不冲突**：不同时占显存，磁盘够就都留，按任务 `/free` 切换。
