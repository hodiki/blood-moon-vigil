# 《血月守夜》系统地图（System Map）

> 版本：v0.1 · Phase 2 系统设计 · 垂直切片 Demo 范围
> 上游依据：`design/concepts/concept.md`（四支柱与 §5 范围分层）；本文件为全部 GDD 的索引与依赖基线。

## 1. 子系统清单

| 编号 | 系统 | 范围 | 说明 |
|---|---|---|---|
| S1 | 输入层 | 双端移动向量抽象 | WASD / 方向键 / 虚拟摇杆 → 统一移动向量 |
| S2 | 角色与移动 | 守夜人 | 生命 / 移速 / 伤害倍率 / 无敌帧，随等级成长 |
| S3 | 武器系统 | 3 武器自动开火 | 飞弹 / 环绕球 / 冲击波，全部自动触发 |
| S4 | 敌人系统 | 3 敌人 + 1 Boss | 面板、接触伤害、经验掉落 |
| S5 | 敌潮生成器 | 强度曲线 + 波峰波谷 | 生成预算递增、构成分阶段、同屏上限、20 分钟 Boss 收束 |
| S6 | 经验与升级 | 宝石掉落 → 升级 | 经验点数、磁吸拾取、升级需求曲线、角色成长 |
| S7 | 升级池三选一 | 12 项卡池 | 暂停选卡、机制改变 ≥50%、效果作用于 S2/S3 |
| S8 | 碰撞与伤害结算 | 弹道 / 接触伤害 | 伤害倍率汇总、无敌帧、死亡处理、掉落 |
| S9 | 地图与障碍 | 3000×3000 单图 | 有限边界、障碍物拉扯、出生环带约束 |
| S10 | 结算页 | 局终汇总 | 存活时间 / 击杀 / 等级 / build 回顾 |

## 2. 依赖关系

```
S1 输入 → S2 角色移动
S3 武器 → S8 伤害结算 → S4 敌人（死亡）
S5 生成器 → S4 敌人（实例化，依赖敌人面板与同屏上限）
S4 敌人死亡 → S6 经验（掉落宝石）
S6 经验 → S7 升级池（触发三选一，应用 buff）
S7 升级池 → S3 武器 / S2 角色（回写数值）
S9 地图 → S2（碰撞阻挡）；S8 → S10 结算（汇总数据）
```

## 3. 实现优先级排序

- **P0 必须（闭环顺序）**：S1 输入 → S2 角色移动 → S9 地图碰撞 → S3 武器 → S8 伤害结算 → S4 敌人 → S5 生成器 → S6 经验 → S7 升级池 → S10 结算。
- **P1 增强（表现层，不阻塞玩法闭环）**：磁吸吸入动画、击杀粒子、波峰预告（心跳 BGM 加速 / 边缘红光呼吸）、Boss 入场演出、屏幕震动。

## 4. 排序理由

1. **核心循环是单向依赖链**：移动 → 输出 → 击杀 → 掉落 → 升级 → 变强，每一环必须在前一环可用后才能验收，故按链序实现。
2. **生成器依赖敌人面板**：强度公式要用敌人生命/速度/经验做匹配校验，敌人须先定稿。
3. **升级池是爽点核心但依赖经验闭环**：没有掉落与升级曲线，三选一无处触发；但其数值需与武器/敌人同时规划，避免返工。
4. **结算最简单、只读数据**：最后接入，从战斗统计聚合即可。
5. **P1 全为表现层**：不影响"移动 + 决策"闭环，时间紧张可直接裁剪，符合 Lean 评审。

> 范围红线：本表仅覆盖概念文档 §5 核心必备；联机 / 局外成长 / 多地图 / 主动技能均不出现。
