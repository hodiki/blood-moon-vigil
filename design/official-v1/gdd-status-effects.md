## ① 概述

统一状态效果层：把现状散落在武器配置中的眩晕（提灯闪耀 2.5s、月全食 1s）与减速（荆棘圣环 30%、血池 20~40%）收编为**三类状态枚举 + 叠加规则 + ICD + 抗性规则**的最小规格系统（WD-6）。所有专武衍生技、共鸣改造、通武的 CC 效果统一走本层；细则归怪物域（每敌/Boss 抗性表在 enemies-v3 重做时对接）。

## ② 设计支柱

1. **最小规格起步**：三类状态（眩晕/减速/易伤）起步，不做韧性条等复杂机制（WD-6：首版复杂度控制）。
2. **同类取最强、异类共存**：叠加规则一句话可解释，认知成本趋零。
3. **Boss 硬控免疫、精英折减**：Boss 战不容被硬控锁死，精英保留受控窗口但不锁死（WD-6）。
4. **设计实装同步**：状态层 GDD 与实装同版本交付（防「配置已备、运行时未接」重演——汇编首报表教训）。

## ③ 系统规则

### 3.1 状态枚举（三类起步）
| 状态 | 类别 | 定义 |
|---|---|---|
| 眩晕 | 硬控 | 目标停止移动与攻击 |
| 减速 | 软控 | 目标移速 ×（1 − 减速值） |
| 易伤 | 减益 | 目标受到的所有伤害 ×（1 + 易伤值） |

- 状态枚举为**封闭集合**：新增状态类型须走 GDD 修订（防配置侧私自扩类）。

### 3.2 叠加规则
- **同类不叠加，取最强**（眩晕取最长剩余、减速取最高减速值、易伤取最高易伤值）；同类后到者刷新为两者较强值并重置时长。
- **不同类可共存**（一目标可同时：眩晕 + 减速 + 易伤）。
- 减速不与地图减速区（血池等）特殊互斥——同走「取最强」。

### 3.3 ICD（内置冷却）
- **硬控（眩晕）通用内置冷却：10s / 单目标**（锚，承守夜环灯 0.5s 眩晕案例）——同一目标在 10s 内只能被眩晕命中 1 次（无论来源）。
- 减速/易伤不设 ICD，靠时长与数值上限控制。
- ICD 计数在状态结束即开始（非命中时开始），口径实现时二选一并写死注释（**待模拟验证项**：推荐「状态结束时开始」，防长眩晕自续）。

### 3.4 抗性规则
| 目标 | 眩晕（硬控） | 减速（软控） | 易伤 |
|---|---|---|---|
| Boss | **免疫** | 生效 | 生效 |
| 精英 | 生效，时长 **×0.5** | 生效，时长 ×0.5 | 生效（不折减——数值减益，锚点） |
| 普通敌 | 生效 | 生效 | 生效 |

- 裁决来源：WD-6「Boss 硬控免疫、精英受控折减 ×0.5」；0.5s 级微眩晕在精英身上等效 0.25s（守夜环灯案例，R2 §C1）。
- 敌怪个体 CC 抗性差异（如某 Boss 类精英额外减速抗性）= 怪物域重做的配置接口（§⑥），本层只提供字段位。

### 3.5 与旧体系冲突处置
| 冲突 | 处置 |
|---|---|
| 现状眩晕/减速散落武器配置、无统一层（baseline 域3） | 全部迁移至状态层声明式配置；旧散落字段在实施阶段清点收编（含 legacy 双源清理，域4 技术债 S 档项联动） |
| Boss 硬控「免疫」vs「韧性制」 | 韧性条不做（WD-6），免疫为定稿 |
| 月全食等旧超武控制效果 | 随超武退役；圣物「月蚀之陨」的 2s 全屏眩晕走本层（Boss 免疫规则同样适用） |

## ⑤ 数值锚点汇总（待模拟验证）

1. 硬控 ICD 10s 的 Boss 战节奏影响；2. 精英 ×0.5 折减后的实际受控时长分布；3. 全屏减速 40%（圣物）与常驻减速的叠加实测；4. 易伤 15%/20% 的 Boss 战等效增益（参照血影突袭标记 33% uptime = +6.7% 的算法口径，`gdd-active-skill.md` §3.3——该口径文件退役后算法保留，见专武 GDD 附录 A）；5. ICD 起算时点（状态结束 vs 命中）二选一实测。

## ⑥ 与怪物域的接口约定（enemies-v3 重做时对接）

1. **每敌/Boss CC 抗性表**：敌配置新增抗性字段位（硬控/软控/易伤三维，默认值按 §3.4 表），怪物域可逐敌覆写。
2. **敌方 AI 可选中友方实体**：守誓者承伤替身需要索敌扩展（enemy.ts updateMovement/索敌逻辑 target 选项）——与 CC 层**同批次接线评估**（R2 §D 工程影响登记）。
3. **精英词缀设计**（现无 GDD，仅 docs-review 登记待做）：词缀若含 CC 类（如「霸体」「免减速」），按本层抗性字段实现，不另起机制。
4. 反制设计关系：enemies-v2「5 类特殊行为每图 ≤2 种且有反制」口径不变；CC 体系是玩家侧新增的反制手段，不替代敌怪行为反制设计（怪物域重做时统一裁决敌侧反制 vs 玩家侧 CC 的攻防表）。

## ⑦ 边缘情况与反例

1. **叠加类**：三来源眩晕同帧命中（取最长，其余消耗 ICD 判定但不重复生效）；减速区（血池 40%）与武器减速 30% 叠处（取最强 40%，非叠乘）。
2. **免疫类**：Boss 免疫硬控但承受伤（眩晕来源的伤害段独立结算，免疫只豁免控制部分）；圣物月蚀之陨对 Boss 眩晕无效但演出照常（视觉与逻辑分离）。
3. **时序类**：状态载体死亡（图腾/残焰/圣火）时其上的减速/灼烧状态同步移除；目标死亡时 ICD 计数清除（防复活类敌种永久免疫——当前无敌种，规则前置防患）。
4. **反例红线**：❌ 新增第四类状态不走 GDD 修订；❌ 同类状态叠乘（只能取最强）；❌ 精英/普通敌用不同状态枚举（统一集合）；❌ 状态层后置实装（同版本交付硬项）。

## ⑧ UI 与表现 + 验收判据

**UI/表现**：敌头顶状态图标（≤3 枚槽位：硬控/软控/易伤各一，同类取最强只显示生效值）；Boss 免疫命中显示「免疫」字样微反馈（0.3s，可关闭）；减速/易伤用色调编码（减速青、易伤紫红）；移动端图标随帧率降级为色环。

**验收判据**：
1. 三类状态枚举 + 叠加规则 + ICD + 抗性规则全部实装且配置驱动（非硬编码）。
2. §④ 登记表逐项走状态层（来源-状态-参数断言测试）。
3. Boss 硬控免疫 / 精英 ×0.5 生效（Boss 战用例：守夜环灯眩晕 0 次生效于 Boss；精英受控时长 = 配置 ×0.5）。
4. 状态层实装与本文档**同版本交付**（版本号绑定验收，汇编首报表教训硬项）。
5. 遥测：各状态施加次数/生效时长分布、Boss 战硬控免疫触发率、ICD 命中/拦截比。
