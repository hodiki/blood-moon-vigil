## 0. 用户核心重做思路（逐字忠实收录，最高约束）

> ※核心重做思路：怪物设计和类型上希望做出明确区分和不同的战斗体验，希望怪物域更加有"配合"与"战术"，给玩家一定的战术压力，让玩家可以：面对困境→操作、打法、移动→解决困境→奖励→更好面对新的困境……的"解题"循环，而不是简单的"数值对拼"。精英怪物需要给玩家明确的威胁点，达到"我想好办法解决这个精英怪了"，而不是"我可以无脑吃掉这个精英怪"。在此之上，通过怪物"组合"、怪物"方阵"让玩家和怪物进行更有效的交互。
> ①普通怪物：行尸、血信徒、灰狼：作为常规且大量持续出现的炮灰型单位。血犬、血蝠、暗影狼：强调"高速突袭"、"低生命值"、"有一定伤害"，在玩家失去警惕、失误时，造成少量生命值损失。墓穴甲虫：废弃，定为与行尸类似。亡魂：废弃，目前不以障碍物为核心玩法内容之一。
> ②精英怪物（目前缺乏远程攻击型、位移型精英怪物）：守墓者：攻击模式改变，在玩家进入一定攻击范围后，会停止移动并蓄力进行一次 180 度的范围攻击。血肉畸体：攻击模式改变，在玩家进入一定范围后，会短暂蓄力，并进行一次固定方向和距离的快速冲刺。石甲狼：拥有额外生命值，额外生命值存在时移动速度和攻击抬手较慢，生命值降低到一定程度后（石甲完全破碎），移动速度、攻击速度较大提升。
> ③方阵与方阵怪物（1.不会单独出现，出现时会伴随着普通和精英怪物。2.方阵怪物都基于特定方阵组合。3.所有通过怪物技能召唤的怪物，都不提供经验掉落奖励）：
> - 追猎方阵：尸巫(治疗)+2 血犬，接近玩家一定距离后，血犬加速发起冲刺，尸巫停留在原地，持续给血犬恢复生命值，血犬全部死亡后，进行召唤仪式（若被击杀可打断仪式）重新召唤血犬，并重复上述动作。
> - 苏生方阵：2 尸巫(召唤)+守墓者，方阵会先进入到玩家可见范围的边缘，停止移动，并开始持续召唤行尸，当方阵受到玩家攻击时，守墓者才会对玩家发起追踪和攻击。
> - 宝藏护卫方阵：4 守墓者+4 行尸+1 尸巫(治疗)，宝藏护卫会尝试从地图一端移动至另一端（到达终点时方阵消失），宝藏护卫不会主动发起攻击，4 行尸负责驮运宝藏，4 行尸被击杀时，视为宝藏落地，宝藏落地后玩家可以拾取，获得一次额外抽卡机会，但宝藏护卫会切换到攻击状态。
> - 腐朽骑士团：3 腐朽骑士，血量低于守墓者，但拥有更快的移动速度和攻击速度。该方阵暂定为仅次于 BOSS 的高威胁战斗，第一次遇到玩家时会以固定站位组合向玩家发起固定方向和略带跟踪的高速冲锋（玩家需要保持移动才能躲避）。
> 。。。。请补充和扩展更多方阵设计
> ④boss 怪物：希望 boss 拥有完整的攻击循环和技能设计（1 普通攻击+3 普通技能+1 高威胁技能），而不是单纯的站桩怪物。例：血月尊者改为召唤系 boss，技能包括一定范围的 2 动作普通攻击、召唤血犬（普技）、召唤行尸（普技）、召唤守墓者（普技）、召唤腐朽骑士（高威胁技能）。

**本轮职责**：忠实承接 → 结构化展开（§A/§B/§C）→ 补充扩展方阵（§D-3）→ Boss 攻击循环（§E）→ 开放决策点（§H）。仍不写正式 GDD。

## A. 「解题循环」设计支柱落档与 R1 框架裁决

### A-1. 四支柱定稿（怪物域 v2 设计支柱，取代 R1 隐含支柱表述）

| # | 支柱 | 定义 | 反模式（红线） |
|---|---|---|---|
| **P1 怪物差异化** | 敌种按「炮灰型 / 突袭型 / 精英（技能化）/ 方阵」四档明确分工，每档有独立战斗体验与反制语法 | ❌ 全员直线追踪的"数值对拼"（现状 updateMovement 单一 AI） |
| **P2 战术压力与解题反馈** | 完整循环：面对困境（威胁呈现）→ 操作/打法/移动（解题输入）→ 解决困境（反制窗口）→ 奖励（资源/负空间）→ 更好面对新困境。每个威胁必须**可读、可解、有奖** | ❌ 不可读威胁（无预警演出）；❌ 无解威胁；❌ 解题无奖励（负反馈断裂） |
| **P3 精英威胁点** | 精英 = 明确的"解题对象"：telegraph（预警）→ 反制窗口 → 奖励。玩家击杀精英前的心理应是「我想好办法了」而非「我数值够了」 | ❌ 精英 = 大号血牛（仅 HP/伤放大）；❌ 无脑吃掉精英 |
| **P4 组合与方阵** | 怪物以「方阵」为单位呈现协同行为（治疗/召唤/护卫/冲锋/增援），方阵不单独出现、伴随普通与精英；召唤物一律无经验 | ❌ 方阵退化为"多个怪同时出现"；❌ 协同不可读（玩家看不懂配合） |

- **支柱间关系**：P1 是地基（敌种分工），P2 是目标体验（循环成立），P3 是中段抓手（精英=小型 Boss），P4 是后段抓手（方阵=战术考题）。四支柱全部服务于 R1 §B-1 的正反馈循环（build 成长→难度提升→战胜），**不与之冲突，是其在怪物侧的具体化**。
- **与「数值对拼」的关系裁决**：P2 不取消数值维度——玩家 DPS 仍须足以在反制窗口内完成击杀；解题循环决定「何时/何处能安全输出」，数值决定「窗口内能否打完」。**数值对拼要防（H5 对策仍需），解题循环要立（本轮主轴）**——两者分层不互斥。

## C. 精英改造规格化（telegraph 解题设计）

> 设计总原则：**telegraph（预警演出）是解题的输入**——玩家凭什么能"想好办法"？答案 = 预警的**时长 ≥ 反应所需**、**形状 = 危险范围**、**强度 = 危险等级**。三精英统一模板：触发距离 → 蓄力（预警）→ 释放 → 反制窗口/硬直 → CD。全部数值为锚点，待模拟验证。

### C-0. 蓄力 × CC 交互设计原则（全精英通用，供 MN-20 拍板）

1. **硬控（眩晕）可打断蓄力**——CC 是解题的增益手段，不是唯一解（对齐状态层 §⑥-4 反制攻防原则：CC 让反制更容易，不替代反制）。精英受控时长走 ×0.5 默认折减；打断 = 取消本次攻击并进入 CD 的 50%（锚，防白嫖）。
2. **蓄力末段锁定窗**：蓄力最后 **0.3s** 进入锁定（霸体窗，硬控无效）——防「ICD 内连环眩晕永久锁死精英」（打不出任何攻击 = 负反馈红线）。
3. **软控（减速）不打断、不延长蓄力**——减速影响的是释放后的追击能力，保持「减速改走位压力、眩晕改节奏」的分工。
4. **ICD 沿用状态层 10s/单目标**——同一精英 10s 内只能被眩晕打断 1 次。
5. 精英技能伤害为**独立技能伤害字段**（不沿用面板接触伤），进 Boss/精英独立曲线（R1 §B-2.2）。

### C-1. 守墓者（g1_6）——「180° 蓄力扫」

| 字段 | 规格（锚） |
|---|---|
| 触发 | 玩家进入 **100px** 攻击范围 → 停止移动、进入蓄力 |
| 蓄力 | **0.9s**；预警演出：举铲红光 + **180°/130px 扇形地面预告渐亮**（透明度 0→100% 随蓄力推进）——扇形即危险区，形状可读 |
| 释放 | 180° 扇形横扫，半径 130px，技能伤 **22** |
| 反制窗口 | ①蓄力期离开扇形（0.9s × 玩家速 235 ≈ 210px 位移余量，从容）②挥空后 **0.6s 硬直** = 输出窗口 ③蓄力前 0.6s 可眩晕打断（C-0） |
| CD | 4s |
| 解题点 | 贴身绕背（扇形死角）or 预警期拉开——「我想好办法了」= 读扇形、选站位 |
| CC 交互 | 眩晕 ×0.5 折减可打断（C-0）；减速生效 |

## E. BOSS 攻击循环设计

### E-0. 五槽模板与通用规则

- 模板：**1 普攻 + 3 普技 + 1 高威胁技**（用户规格）；普攻 = 循环基底（持续施压），普技 = CD 轮转（节奏变化），高威胁技 = 低频大考（解题高潮）。

- 与既有阶段 2 配置衔接：boss_2/3 阶段 2 机制（enemies-v2 §3.4：召唤 2 侍僧+血池 / 冲锋扑击+2 灰狼）**全部纳入新循环**，不弃配置（接线清单 W-2 义务不变）；boss_1 阶段 2（召唤强化）升格为高威胁技解锁节点。
