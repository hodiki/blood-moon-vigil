## ① 概述

难度总纲定义《血月守夜》6 分钟局（BOSS_TIME 360s + Boss 战 65~85s 收束）的**压力曲线、死亡锚与验收判据**，是怪物域三份 GDD 的顶层标尺。本 GDD 回答两个问题：**压力多大、何时来**（数值骨架，§③/⑤）；**压力成立的标准是什么**（解题循环 + MD 判据，§②/④）。

- 行为骨架（压力长什么样、怎么解）归 `gdd-enemies-v3.md`；生成机制（压力怎么投放）归 `gdd-spawner-v2.md`。本 GDD 只定标尺与联动参数（缩放 / XP / budget / unlockAt 三轨总表）。
- 硬依赖兑现：`gdd-talent-tree.md` §⑨-1 登记的「b/d/s1 共存开局强度（锚 27~43、30s 窗口峰值 ≈39~62）」由本 GDD §④ MD 判据体系承接验收（SC-1 裁决：验收含「抵消 b/d/s1 全开 DPS ×3.0 开局强度」总项）。
- 双源清理联动：缩放实现落 ENEMY_CONFIGS 单一来源，legacy ENEMIES 随 W-8 实施退役（域 4 技术债 S 档，不在本 GDD 展开）。

## ② 设计支柱

### 2.1 双层声明（顶层裁决落档）

| 层 | 声明 | 内容 |
|---|---|---|
| **顶层：解题循环**（用户哲学，最高约束） | 怪物设计与类型明确区分、怪物域更有「配合」与「战术」，给玩家战术压力，形成 **面对困境→操作/打法/移动→解决困境→奖励→更好面对新困境** 的解题循环，而非「数值对拼」。精英必须给明确威胁点——击杀前心理是「我想好办法了」，不是「我数值够了」 | 行为面由 enemies-v3 四支柱（P1 差异化 / P2 解题反馈 / P3 精英威胁点 / P4 组合方阵）具体化 |
| **底座：数值骨架** | M3 混合缩放（MN-1/MN-2）+ budget 分段曲线 + XP 曲线 c 案修订（SC-2 × MN-7 合并）+ unlockAt 三轨阶梯——保证循环的「数值维度」成立：解题循环决定「何时/何处能安全输出」，数值决定「窗口内能否打完」 | **数值对拼要防（H5），解题循环要立（本轮主轴）——两者分层不互斥** |

- 正反馈循环量化目标（R1 §B-1 继承）：build 成型→变强可感知→难度提升不快过台阶（防挫败）也不慢到无压力（防碾压）。
- 红线（继承设计理论红线）：❌ 主导策略（任一精英/方阵/流程无唯一最优解法，双解法并存原则）；❌ 经济失衡（XP/宝石簇膨胀，SC-2 收敛约束）；❌ 认知过载（词缀单词缀、方阵不吃词缀、CC 抗性不逐敌细分）；❌ 支柱漂移（任何新内容须可映射回四支柱之一）。

### 2.2 动态难度否决（MN-13，定稿）

budget/XP 挂玩家状态反馈的动态难度**否决**：与难度确定性、可测性、MD 判据冲突。M3 的等级滞后宽容（§5.1）是受限替身——只救落后者、不削领先者、触发率遥测监控防滥用（§⑥-3）。

## ③ 三档死亡锚与玩家档位模型

> 三档玩家模型（复用 m2-feedback 方法论）：首局档（0~2 局，无树/树未成型）、熟练局档（3~10 局，树层 2 大部）、毕业局档（树成型 + build 成型）。SC-4 裁决：**死亡档以校准基线为「易」端**——沙盘校准报告中距系死亡中位 84~123s（风筝系 200~330s 存活）作为锚区间的下沿对齐面（方向性结论可信、绝对值真机复测）。

| 档位 | 死亡锚（模拟复测锚） | 通关率锚 | 辅助判据 |
|---|---|---|---|
| **首局档**（MN-8 定稿） | 首死中位 **90~150s**（现状 35~42s → 后移 2.5~3.5 倍）；易端 = 中距系校准实测 84~123s 对齐 | 15~35% | 失败局「死于 S2 后段/Boss 前」占比 ≥50%（差一点感）；死亡谷从「未学会拉扯的前 1 分钟」后移到「已建立 build 雏形的中段」 |
| **熟练局档** | 首死中位 **≥240s** | 40~60% | 死亡集中于 S3 后段与 Boss 战；每次失败可定位「差一个台阶」 |
| **毕业局档** | 首死 **≥300s** 或零死亡为主 | **≥75%** | **仍需 ≥1 次濒死事件**（HP<30%，MD-5 一票否决「无损通关」）；Boss 战承担 ≥50% 濒死事件 |

- 局时长轴**不动**：6min 口径（BOSS_TIME 360s），全部既有窗口锚（P1 30~60s / P4 第 8~14 次升级 / 阶段表 S1~S3 / 精英保底）在此轴上定义。
- 中段威胁阶梯判据（H7 对冲终检）：120~300s 每 ≥90s 引入 ≥1 次**威胁质变事件**（新敌种 unlockAt / 方阵首现 / 精英技能化 / 词缀精英首现——三轨见 §5.4）；主观刻度「中段有新东西」≥70%。
- 终局压力判据（H5 对冲终检）：S3（240~360s）生成需求 DPS 相对玩家成型 DPS 利用率锚 70~90%；同屏压力峰值落 300~360s 窗口。
- 方阵在场时段的死亡分布不形成新死亡谷（挂模拟复测项 S-9，enemies-v3 §⑤）。

## ⑤ 数值修订锚（模拟复测锚）

### 5.1 敌面板缩放：M3 混合（MN-1）+ 仅 HP（MN-2）

- **M3 混合模型（MN-1 定稿）**：主体 = 局时曲线 scale(t)——**0~60s 豁免 = 1.0**（前期豁免，H2 对冲怪物侧条款）、60~120s 线性爬入缩放曲线、S2 缓 / S3 陡，**360s 终值锚 2.2~3.2**；叠加**等级滞后宽容**：玩家等级低于局时预期等级 ≥3 级时，其接触敌 HP ×(1 − 0.1×滞后级数)，**下限 ×0.7**——只救落后者、不削领先者。
- **仅 HP 缩放（MN-2 定稿）**：首版敌伤害不缩放（接触伤 6~18 / Boss 25~32 维持）；承伤压力由生成密度 + 突袭/远程/冲锋行为 + Boss 承担。预案：模拟显示 S3 承伤利用率 <50% 再开「S3 段伤害 ×1.1~1.2」轻缩放（修订流程）。
- **c 案 HP 联动（SC-2）**：基础面板 HP 在 scale(t) 之下叠乘 c 档位联动系数（×1.05~1.20，三档见 §5.2）——与缩放终值联调防「同一时段双陡升」。
- **精英/Boss 独立曲线**：精英（350~500 HP 基座）与 Boss（3000~4500）不吃普通 scale(t)；Boss 锚定「双路线成型 DPS 下 65~85s」反推（MD-4）。

### 5.2 XP 曲线：c 案 × MN-7 X1+X2 合并框架（SC-2 定稿，参数不定死）

> 现状落差（校准报告）：offers 中位 25~39（Lv26~40）vs GDD 基准局 14 = **1.8~2.8×**。c 案 = needXp 上调 + 敌 XP 下调 40~50% + 敌面板 HP 上调联动，与 MN-7 X1+X2 两段式**合并核算**。以下三档为**模拟复测锚**，由模拟裁决后单轮冻结，本 GDD 不定死参数。

**三联动结构**：① needXp 两段式上调（X1 前段加速保首级时点 + X2/c 中后段加陡）② 敌 XP 产出下调 ③ 敌面板 HP 联动上调（§5.1 联动系数）。

| 档 | needXp 两段式（need(1) / 前 3 级增量 / 中后段增量） | 敌 XP 下调 | 敌 HP 联动 | 预期 offers 落差收敛 |
|---|---|---|---|---|
| **c-温和** | 4 / 3 / 5 | −40% | ×1.05~1.10 | 1.4~1.6× |
| **c-标准（推荐基准）** | 4 / 3 / 6 | −45% | ×1.10~1.15 | 1.2~1.4× |
| **c-陡峭** | 5 / 4 / 7 | −50% | ×1.15~1.20 | 1.0~1.2× |

**硬约束（任一档必须满足，违者换档）**：
1. **首级 ~18~22s**（X1 保留，H2/H3 对冲）——注意耦合：敌 XP 下调会推迟首级，need(1) 与前 3 级增量须抵消该影响（故 need(1) 区间 4~5 而非 R1 原 3~4，前段构成「needXp 微升 × 敌 XP 大降」的对冲组，模拟裁决）；
2. 首精英时点（90~150s）前 offers ≥3（P1 保底席位可承接）；
3. 6min offers 中位收敛至基准局口径 14 的 ±30%（**锚 12~18**）；
4. 6min 等级终值复测锚 **Lv14~20**（原口径 Lv27，两段式 + c 案叠加后重标）；
5. 中后段**升级间隔中位 ≤30s**（判据口径，v1.1 语义明确：防 XP 断层挫败的玩家体验指标按中位分布判定）；**最坏间隔 ≤45s 为 budget 联调观测项**（非冻结判据，允许模型口径归因复测）——联调方向：优先上调 S3 budget 终值斜率（3.2~3.6 → 3.4~3.8 锚），needXp/lateStep 在 c 案冻结期不动（S-3 复测解冻后才可作为次选）。

**联动复测三件套**（X1+X2 落地重标定，R1 §B-4 继承）：① offer 次数口径（基准局/全通）② P4 窗口「第 8~14 次升级」按新口径重标 ③ 天赋树 Q-f「≈白送 3 级」强度换算 ≤3% 复测；连带：卡 2 兜底 N=8（FQ-1，enemies-v3 §③-4）按新 offer 间距复测。

### 5.3 budget 分段曲线（H2 前段压平，B2 案定稿）

- 四段均值端点锚：**0~60s 0.9~1.1**（60s 均值 1.44 → **1.0~1.2**，前段斜率降 ~17~30%，平台配合缩放豁免）→ **120s ~1.6** → **240s ~2.4** → **360s 3.2~3.6**（S3 陡升收尾）。
- 正弦波幅 ±0.2~0.3、周期 60s 保留（波峰波谷 = 走位呼吸感既有资产）。
- **方阵预算占比 25%**（MN-19 b 激进锚；方阵成组预扣，占 budget 内份额，enemies-v3 F-2 / spawner-v2 §③-4）。
- **分工红线**：budget 管「量」（数量压力），scale(t) 管「质」（面板压力）——严禁同一时段双陡升（S3 段 budget 终值与缩放终值错峰校准，模拟联调项）。
- 完整公式与生成规则落 spawner-v2 §③-1，本 GDD 只登记端点锚。

## ⑥ 边缘情况与容错

1. **滞后宽容滥用监控**：宽容触发率为遥测项——若触发率 >15%/局（锚），视为变相动态难度，走修订流程收紧（触发阈值 3 级→4 级或下限 ×0.7→×0.8），不在实施期就地改（MN-13 纪律延伸）。
2. **落后玩家双保险失效**：滞后宽容下限 ×0.7 仍死亡中位 <90s（首局档）→ 优先复测 budget 前段端点（0.9→0.85），不动缩放模型（M3 结构定稿不改）。
3. **领先玩家穿透**：树全开 + 高命中率局首死 >360s 且通关率 >80%（MD-2 破）→ 启动 ⑨-1 降档预案（修订流程），不临时上怪。
4. **双源过渡期**：legacy ENEMIES 与 ENEMY_CONFIGS 并存期间，缩放参数只进 ENEMY_CONFIGS；legacy 路径敌不受缩放（W-8 退役前禁止双源缩放漂移）。
5. **方阵预算挤压**：方阵占比 25% 若挤压尸潮基本盘（炮灰同屏 <下限锚）→ 方阵掷点概率降档（S3 0.9→0.7），不挤缩放/budget 端点（模拟复测项）。
6. **死亡锚绝对值漂移**：1D 径向等效模型死亡时点系统性偏最坏情形（近战系尤甚）——三档锚以真机遥测 deathsAtSeconds 直方图终检（R1 F-1 D-1 项）；SC-5 绕行系数 1.5 真机回填后复测。
7. **反例红线**：❌ 动态难度（MN-13）；❌ 伤害侧缩放首版启用（MN-2）；❌ 方阵/精英/budget 任一单域私调难度破坏 MD 标定原点；❌ XP 参数绕过模拟直接定死。
