## 5. 主理人补充信息解析（2026-09-03 深夜 · 四条补充信息的消化结论）

### 5.1 补充①：代称可读性 → 叙事写作规范

**现状确认**：v0.8 GDD 体系内编号代称密度极高——裁决编号（WD/NW/GT/MN/FQ/NV）、节点编号（Q-b/Q-f1/L-1/A-1/P1~P5）、结构编号（R-1~R-8/F-1~F-9/E-0/W-1~16）、内容 ID（g1_1/boss_1/wpn_a_1）。

**解析结论**：这是分层问题，不是文档问题——
- **工程层保留编号**：内容 ID（g1_1/boss_1/wpn_a_1）被帧名契约、CI 脚本、ENEMY_CONFIGS 依赖，**不可动**；裁决编号是台账追溯工具，保留在 GDD 内部。
- **叙事层全面可读化**：面向玩家的所有文本（图鉴档案、天赋树文案、圣物/共鸣描述、词条与播报）**只出现中文名，禁止编号代称入文**。现有资产大部分已达标（圣物名「月蚀之陨」、方阵名「追猎/苏生」、词缀「血月印记·坚韧」、天赋节点「认灯/伴灯」均已是可读命名）——规范落点是 **N2/N3 写作纪律**：编号只允许出现在文档的 key/ID 映射列，正文叙述一律用名字。
- **落点**：写进 narrative-framework v1.2 的风格指南（§6 增补一条）。

### 5.2 补充②：美术重做支持（preview 解读）

**已读素材**：`assets/ui-menu/preview/` 四角色 v2 选人立绘 + character-bible 剪影探索（Edmund 剪影、四人 lineup、Violet explore、Galvan explore）。

**美术方向解读**：
- **风格**：写实厚涂 + 黑底单光源的古典明暗对照法；**光源 = 角色身份符号**（薇奥莱=烛、艾德蒙=提灯）——与 14-token 调色板「余辉金」语义吻合。
- **符号具象化**：Edmund v2 = 破旧提灯 + 守夜会徽章 + 工人帽（「末代提灯人」从名字变成了可见的形象）；Galvan = 完整狼人形态；Cassandra = 马尾猎人 + 腰间武器。
- **对故事侧的支持请求（反向）**：本次叙事更新要为美术供给 4 类弹药——①角色档案的「身份句」与立绘符号对齐（艾德蒙=灯与徽章、薇奥莱=烛）；②薇奥莱三形态（守誓/半魔化/同框）各配叙事卡；③守誓者的「铠甲骑士」视觉需要「誓约具象化为守护骑士」的故事解释；④守夜会徽章等组织符号需要圣经层面的语义（纹章学一句：灯与银）。

### 5.3 补充③：薇奥莱双路线（本次角色重构的核心）

**用户设定**：原设单薄，重做为两条玩法路线——
- **守誓者路线**：圣辉 / 善良 / 克制 / 虔诚；**守誓者守护薇奥莱**，二者互相帮助、共同前行。
- **魔化路线**：欲望 / 放纵 / 独行 / 血月；**守誓者不再存在**，留下魔化（或半魔化）的薇奥莱。
- 叙事期望：**一体两面**，或两种完全不同的角色故事演进路线。

**美术对应**（char-bible-violet-explore-v1 三联剪影）：V-A = 修女 + 跪地铠甲骑士（守誓路线，二人同行）；V-B = 生角 + 蝙蝠翼 + 破头纱的半魔化修女（魔化路线，**独行、无骑士**）；V-C = 两形态同框（一体两面的视觉宣言）。三联图本身就是叙事结构的分镜。

**解析与设计提案**：
1. **内核句**（N2 写作用）：薇奥莱 = 同一场撕扯的两种回答——「守誓者路线 = 誓言赢了她」「魔化路线 = 她放开了誓言」。一体两面的哲学根基：**两条路线都不是血月的赐予，都是薇奥莱自己的选择**（守誓=人自己点燃的光，魔化=人自愿靠近的暗）——这正是补充④解除一元论送给这个角色的空间。
2. **守誓者本体论**（结合补充④）：守誓者 = **祷言与誓约凝成的守护骑士**——不是血月滤出的圣辉造物，而是「人说出的话自己站了起来」。这解释了它为何守护她（誓约的另一方是它自己）、为何魔化后它消失（誓言被放弃，它便散去）——「守誓者不再存在」从机制描述升级为叙事事件。
3. **与 GDD 冻结的关系**：专武 GDD 薇奥莱双专武 = 安魂圣铃（守誓者核心）× 圣辉十字（HALLOWED 爆发），均已冻结。**魔化路线的机制载体（武器/形态）在 GDD 中尚无对应物**——建议叙事先行：N2 把「一体两面内核 + 守誓线完整叙事 + 魔化线『坠向』叙事（半魔化状态）」写进圣经与角色卡，魔化路线的完整机制映射**留接口待玩法侧定稿后回填**（与 FQ-1/NW-2 挂账同模式），不强行掰弯已冻结的圣辉十字。
4. **图鉴/档案承载**：薇奥莱档案条目从 1 条扩为「本篇（含双路线描述）+ 双形态叙事卡」，与 V-A/V-B/V-C 三图一一对应；台词组可考虑双路线变体（受台词红线约束，见 §5.5 裁决点 2）。

### 5.4 补充④：解除「血月一元论」→ 改写方案

**用户决定**：去掉「不存在独立于血月的魔法体系」——故事与玩法都需要拓展空间。

**影响面**：world-bible §2 设定红线、§8 红线 1（一元论）、红线 3（无独立魔法）三处表述；§4 力量体系语义；G2 中多项新实体的解释路径（掷骨者「堕落圣辉」、守誓者、殉道者圣髑、BONE tag 争议）全部因此松绑。

**改写方案（推荐：一元论 → 主导论）**：
- **新口径**：「血月是这个时代**压倒性的**力量源——亡潮、兽化、血术皆源于它；但它不是唯一的源。极少数属于『人自己的力量』独立存在：誓约与祷言凝成的光、殉道者圣髑中的余温、更古老时代留下的契约。它们微弱、稀有、稀见于世，且代价内在（以自身为薪），不借血月之力。」
- **为什么推荐「主导论」而非彻底放开**：保留 90% 超自然归因血月 → 世界观凝聚力不散、既有 GDD（powerTag 体系/敌人设定/圣物锚点）零返工；只开一个窄口子（人源之力）→ 守誓者、殉道者、薇奥莱双路线、未来拓展全部有处安放，且「人的力量 vs 血月之力」的对立本身就是主题句（守夜 = 人以自身之微光对抗月亮的血）。
