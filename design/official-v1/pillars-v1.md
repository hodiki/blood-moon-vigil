## 1. 裁决概要

**结论：支柱 1 由「走位是唯一操作」修订为「走位为主 + 主动技为辅」。** 其余三支柱（build 决策是唯一爽点 / 压力递增险而不绝望 / 一局约 7 分钟局局不同）维持不变，但需按新输入面做措辞与可检验含义的微调（见 §5）。

**修订理由（D4 用户拍板）**：
1. 主动技是角色身份差异化的最强载体——4 角色若只有数值差异，角色感薄；主动技让"换角色 = 换打法"成立。
2. 幸存者 like 品类内主动技已是成熟结构（吸血鬼幸存者圣经/大魔法、Hades 冲刺等），能提升"关键时刻的掌控感"，补足 Demo 纯自动在 Boss 战的被动感。
3. 风险可控：主动技定位为**低频（CD ≥12s）、情境化（不是无脑连打）、占比低（DPS ≤15%）**，不改变"自动武器 + 走位拉扯 + build 决策"主循环。

**修订边界（红线）**：
- 主动技**不引入第二个高频操作**：CD ≥12s，平均每局触发 ≤18 次，目标中位 ~12 次（约每 30s 一次）。
- 主动技**不成为通关必需**：无主动技操作（仅移动 + 升级）也必须能击杀 6:00 Boss（保 Demo 已验证核心循环的兜底）。
- 主动技**不打断移动**：释放不阻塞移动输入，冲刺类技能结束后保留原输入向量。
- 主动技**不做资源/法力管理**：统一 CD 制（个别角色用充能制），不新增第二资源条，控认知负荷。

## 3. 修订后核心体验承诺

**一句话概念（修订）**：血月之下你被无尽尸潮围攻，武器自动开火——你多数时间在走位拉扯、每隔几十秒决定"这一局怎么变强"，并在关键时刻按下一个属于你的主动技扭转战局。

**核心体验承诺（修订）**：在约 7 分钟一局里（6:00 Boss 收束 + 60~90s 击杀终局），体验从"被围殴的脆弱者"到"割草无双的怪物"的权力成长曲线。**操作只占很小一部分——移动走位是身体语言，主动技是思考后的重音**；剩下的 99% 仍是 build 决策的纠结与兑现。主动技不稀释"决策是核心乐趣"的品类定位，而是给"走位拉扯到极限"的那一瞬间一个发力点。

**可检验的体验转变**：Demo 玩家"只用移动"通关 Boss；v1.0 玩家"移动 + 每 30 秒一次的主动技决策"通关 Boss，且主动技按下时大多是"我知道为什么按"（被围保命 / 波峰清屏 / Boss 爆发 / 精英集火），而非"冷却好了就按"。

## 4. 修订后 MDA 分析

| 层 | Demo v0.1 | v1.0 修订 |
|---|---|---|
| 机制 M | 移动（唯一输入）· 自动攻击 · 经验宝石 · 升级三选一 · 敌潮生成 · 角色成长 | + **主动技（每角色 1 个，CD 型，双端输入）**；+ 武器进化（超武合成）；+ 3 地图参数集；+ 局外解锁/图鉴 |
| 动态 D | 走位拉扯聚怪 → 清屏；宝石贪心风险；升级时机决策 | + **主动技时机博弈**：留着应对下一波峰 vs 现在清屏加速发育；Boss 战爆发窗口 vs 保命底牌；精英集火 vs 群怪清屏；+ 超武进化规划（被动钥取舍） |
| 美学 A | 权力幻想 · 紧张—释放交替 · 收集成长 | 不变（主动技强化"关键帧掌控感"与"角色身份感"，不新增美学主题） |

**爽点循环映射（更新）**：移动拉扯（M→D 聚怪）→ 武器爆发清屏 → 宝石喷涌（D→A 满足感）→ 升级三选一（A→M build 变强）→ **主动技在压力峰值按下（M→D 破局）** → 更敢深入敌阵 → 压力提升 → 回到移动拉扯。主动技是闭环里的"可控爆发节点"，其余咬合关系不变。

## 6. 主动技系统顶层规则（v1.1 裁决）

> 本节约为系统级顶层规则，供 M1b 拆 GDD `gdd-active-skill.md` 与工程 S1 输入层扩展直接引用；细数值/边缘情况在 M1b 定稿。

### 6.1 设计目标
每个角色的身份核心：**1 主动技 = 1 角色人格**。主动技解决三类问题之一：保命（被围）、爆发（波峰/Boss）、机动（位移/拉扯）。不追求 DPS 主导，追求"关键时刻可感知地改变战局"。

### 6.2 数量与定位
- 每角色 1 个主动技，**不叠加、不可装备多技能**（超武/升级不新增技能位）。
- 定位三选一（角色设计时明确）：**防御型**（眩晕/无敌/护盾）· **爆发型**（范围伤害/标记易伤）· **机动型**（位移/冲刺/加速）。
- 主动技类型标签进入数据配置：`activeSkill: { id, type: 'DEFENSE'|'BURST'|'MOBILITY', cd, charges, ... }`。

### 6.3 输入层（双端）
| 端 | 输入 | 规格 |
|---|---|---|
| 桌面 | `Space`（主键）· `Shift`（备用键，防 Space 与跳转/浏览器冲突） | 按下触发；释放瞬间即结算（无蓄力，控复杂度） |
| 移动 | **技能按钮**：右下角，视觉 96×96px、热区 ≥44×44px；与右上暂停键对角对称，不与摇杆（左半屏）冲突 | 点按触发；非 RUNNING 态按钮隐藏（对齐 control-manifest §5 状态联动） |
| 双端 | 升级三选一 / 暂停 / 结算期间 | 不可释放（世界冻结，按下无效） |

**HUD**：技能按钮旁显示冷却转圈（径向遮罩）+ 充能数（若有）；图标与武器槽同风格（art-bible §6）。

### 6.4 CD / 资源规则
- 统一 **CD 制**：CD 12~25s 按角色定（机动型短、爆发/防御型中长）。
- 个别角色用**充能制**（如血猎手冲刺 2 段充能，充能间隔 8s，总 CD 等效 ~16s）——充能是差异化不是普遍规则。
- **无消耗品、无法力/怒气资源条**；不新增第二资源 UI（认知负荷红线）。
- 释放瞬间结算；不积压（CD 归零后按键即释放，无"存储"）。

### 6.5 与 DPS 曲线关系（平衡红线）
- **占比红线：主动技对单局总输出贡献 ≤15%**（埋点 `activeSkillDpsShare`；效果型不计伤害但必须有可感知战局影响）。
- **数值对齐**：伤害型主动技单次价值 ≈ 当前冲击波（60 伤）的 1.5~2.5 倍，CD 20s 上下；随角色成长曲线线性放大，但**不独立吃全部伤害倍率**（如只吃 50% 总伤害倍率，防后期失控）。
- **校验**：6 分钟模拟，主动技 DPS 贡献 ≤15%；关闭主动技的对照局仍可击杀 Boss（QA）。
- **升级池强化**：主动技强化分支（每角色 3 项：CD -25% / 二次充能 / 效果增强）可将占比推高至 **~20% 封顶**，不无限膨胀。

### 6.6 与状态机联动
| GamePhase | 主动技 |
|---|---|
| RUNNING | ✅ 可释放 |
| LEVEL_UP | ❌ 冻结（世界暂停） |
| PAUSED | ❌ 冻结 |
| GAMEOVER | ❌ 冻结 |

### 6.7 边缘情况（顶层，M1b 细化）
1. 释放瞬间切 LEVEL_UP（经验达标）：按下即结算已生效，冻结后不追加。
2. 移动中释放：不打断移动；冲刺类技能结束后保留释放前输入向量。
3. CD 归零连续按键：无额外消耗，CD 保证低频；释放后 100ms 输入锁定防抖。
4. 玩家死亡：技能立即不可用；重开（scene.restart）CD 重置。
5. Boss 战：可用，计入 Boss 战节奏（Boss 战中位 60~90s 判据不变，主动技加速但非必需）。
6. 移动端误触：按钮置于右半屏拇指自然区，非 RUNNING 态隐藏；热区 ≥44×44px。

### 6.8 验收标准（顶层）
1. 4 角色各 1 主动技，类型标签/CD/充能与本文件一致（埋点断言）。
2. 桌面 Space/Shift、移动端按钮均可触发；非 RUNNING 态不可触发。
3. 6 分钟模拟主动技 DPS 占比 ≤15%；关主动技对照局可击杀 Boss。
4. 释放不打断移动；冲刺类技能结束后移动向量保留。
5. 双端按钮热区达标（桌面 ≥32×32、移动 ≥44×44）。

## 7. 设计理论红线检查（修订后）

| 红线 | 检查结论 |
|---|---|
| 主导策略 | ✔ 无。主动技 4 种类型（防/爆/机动）无单一最优；主动技 DPS ≤15% 决定其不是"必点连打"，而是情境工具 |
| 经济失衡 | ✔ 无。主动技不引入新资源；升级池扩容后 30~40 项仍按标签过滤抽取，不稀释单局决策质量 |
| 认知过载 | ⚠️ 新增输入面需验证：CD/充能/按钮三要素在移动端 ≤1 个可感知 UI 元素；操作动作数从 1（移动）升为 2（移动 + 低频主动技），属可接受增幅；若 Playtest 发现"忘了按"或"乱按"，回调 CD 至 ≥18s 或改被动 |
| 支柱漂移 | ✔ 无。支柱 1 是显式修订而非漂移；其余三支柱措辞微调但语义不变；本文件即为裁决基线 |

**残留风险**：主动技是 Demo 已验证核心循环的最大改动点。缓解 = M1 收尾"主动技迷你验证"（质量门，plan-v1 §二）：原型 1 角色 + 1 主动技手感/占比实测通过后再进 M2；不通过则回调 CD/占比或降为纯被动。
