## ① 概述

生成器 v2 把难度总纲的数值骨架（budget 分段 / unlockAt 三轨 / 方阵预算）与行为骨架（方阵组生成 / Boss 生成链 / 召唤物 noXp）落为生成侧机制。相对现状（v0.5 域 5）的三项结构升级：

1. **budget 单段线性 → 分段曲线**（H2 前段压平 + S3 陡升，端点可独立断言）；
2. **威胁阶梯单轨（数量斜率）→ 三轨**（敌种 unlockAt + 方阵 unlockAt + 精英技能化 unlockAt，机制同为 per-kind 字段过滤）；
3. **单体生成 → 单体 + 组生成双模**（spawnGroup 方阵预约组单元，复用精英保底预约落地架构）。

## ② 设计支柱

1. **压力三源分层**：budget 管量、scale(t) 管质、unlockAt 管质的时间表——三源严禁同一时段双陡升（budget 与缩放错峰联调，difficulty-v3 §5.3）。
2. **确定性生成**：掷点/解锁/保底全部为局时确定性规则（MN-13 否决动态难度；方阵预约制不构成玩家状态反馈）；同参数种子可复现，可测试性优先。
3. **方阵 = 组生成单元**：不进普通槽位池、成组预扣、伴随生成、黑板协同——「配合与战术」的生成侧根基。
4. **通道唯一性**：普通槽（尸潮量）/ tank 槽（精英）/ 方阵槽（协同考题）/ Boss 链（终局）/ 宝藏护卫路径（强奖励）五通道各司其职，预算占比锁死防挤压。

## ③ 系统规则与数值规格

### ③-1 budget 分段曲线（修订定稿）

- 现状：`budget(t) = 1.2 × (1 + 1.2t/360) × (1 + 0.3sin(2πt/60))`，均值 1.2→2.64，60s ≈1.44（H2 前期斜率未降）。
- **修订（B2 分段曲线）**：分段线性插值，均值端点锚——

| 局时 | 0s | 60s | 120s | 240s | 360s |
|---|---|---|---|---|---|
| budget 均值（点/s） | **0.9~1.1** | **1.0~1.2**（H2 前段压平：1.44 → 1.0~1.2） | **~1.6** | **~2.4** | **3.2~3.6** |

- 正弦波幅 **±0.2~0.3**、周期 60s 保留（波峰波谷走位呼吸感既有资产；相邻周期峰谷差 ≥30% 可感知判据维持）。
- **方阵预算预扣**：spawnGroup 成组预扣，方阵占比 **≤25%**（MN-19 b 激进锚；预扣计入 budget 总盘，不另开预算）。
- 实现口径：端点参数化（五端点 + 波幅 + 周期 6 参数），分段插值；逐图覆盖机制沿用（§③-6）。

### ③-2 槽位池改造（三抽象槽 → 五通道）

> R-C3-RULING 槽位语义（tank = 精英、特殊行为归 zombie/wolf）延续，结构扩展为五通道。

| 通道 | 内容 | 预算占比锚 |
|---|---|---|
| **普通槽**（zombie/wolf 两槽保留） | 普通槽池 10 敌种（enemies-v3 §③-2 定稿表；甲虫 = 行尸变体池形态） | ~70~75% |
| **精英槽**（tank） | 精英 5（守墓者/畸体/掷骨者 · 畸体/忏悔者 · 石甲狼分图落槽）；保底预约落地制沿用（S2 30s / S3 20s，S1 随机 0.5%） | ~3~5% |
| **方阵槽**（新增） | spawnGroup 组生成单元，9 阵配置（首版入池 7）；不进普通槽位池 | **≤25%**（预扣） |
| **Boss 链** | BOSS_TIME 生成链（§③-5）；Boss 战期间 budget 恒 0 | 不占日常预算 |
| **宝藏护卫路径** | 宝藏护卫方阵横穿生成（每局 ≤1，方阵槽内特例） | 计入方阵 25% |

- 每槽 unlockAt=0 基础敌 ≥1 的结构校验项维持（墓地 zombie=行尸 / wolf=血犬；教堂=血信徒/血蝠；狼穴=灰狼/暗影狼）。

### ③-3 unlockAt 三轨生成侧落法（MN-3 扩展定稿）

- 机制：per-kind / per-formation / per-elite-skill 的 `unlockAt` 字段 + pickEnemyKind / pickFormation 过滤（t < unlockAt 跳过，过滤后池空回退该槽基础敌）——三轨共用同一机制，槽位权重逻辑零重开。
- **轨①敌种**：炮灰 0s / 突袭 60~90s / 特殊行为普通 120~150s（逐图微调：教堂远程系提前、狼穴冲锋稍后、墓地基准——difficulty-v3 §5.4）。
- **轨②方阵**：逐阵 unlockAt（追猎 100s / 围猎 110s / 苏生 150s / 血旗 160s / 锁链 180s / 宝藏护卫 180s 起窗口掷出 / 骑士团 240s；铁石 180s、献祭 120s 二批）。
- **轨③精英技能化**：180s 起生成的精英携带技能化行为 + 词缀；180~210s 掷骨者/忏悔者精英入池；解锁前生成的精英 = 基础厚血形态（enemies-v3 §⑥-6）。
- 断言：三轨逐条进配置断言；S1 无特殊行为敌 / S1 末方阵首现 / 180s 首技能化精英三里程碑用例。

### ③-4 方阵生成框架（spawnGroup，W-10~11）

| 项 | 规格 |
|---|---|
| 生成方式 | **预约制组生成**：成组预扣 budget（按成员面板 XP 等效点数）→ 落地点预约（环带）→ 2.5s 阵纹预警 → 成组落地（≤5 只/帧分帧，受 maxEnemies 节流不丢组）；复用精英保底预约落地架构（enemy-spawner.ts:128-153 同源） |
| 掷点节奏（MN-19 b 激进锚 · v1.1 口径收敛） | S1 末即入；掷点间隔 **60~90s**（不变）；触发概率 **S1 末段 0.3 / S2 0.6 / S3 0.9**（不变）；**同屏 ≤2**（双阵时至少 1 低/中档，高档不叠高档）；每局次数锚 **3~4 次（期望 ≈2.7~3.3，v1.1 收敛：原 4~7 锚与 60~90s 间隔 × 三段概率在 100~360s 窗口的数学期望不符，以期望对齐为准）**；占比 ≤25%（上限非配额）；BOSS_TIME 后停掷；boss_4 在场停掷。**事件感预案（复测项）**：若模拟/真机显示方阵事件感不足，唯一上调预案 = S3 概率 0.9→1.0（走修订流程，不加密掷点间隔——呼吸感保留） |
| 伴随生成 | 落地时周围普通生成权重瞬时 **+20%**（持续 10s 锚，制造「伴随普通怪」场面）；高威胁阵（骑士团）落地时同屏无精英 → 预约 1 只伴随精英（词缀互斥不适用于伴随精英本体——伴随精英可带词缀，但与高档阵压力错峰：骑士团同屏期间不叠词缀精英预约） |
| 组黑板（W-11） | 成员共享 group黑板（仪式/旗帜/收拢相位/宝藏/激活状态）；成员索敌目标可指向组内逻辑实体（尸巫→血犬）——enemy.ts 索敌扩展与 W-4 守誓者友方索敌**同批评估** |
| 落地分布 | 方阵成员以预约点为心 80~150px 半径散布（阵型站位：骑士团三角 300px、宝藏护卫横队列——逐阵阵型参数挂组配置） |
| 破阵/解散 | 破阵条件逐阵定义（enemies-v3 §③-6/§⑥-1）；解散 = 清黑板 + 增援溃散演出 + 压力即刻下降；成员转为普通个体 AI（无组状态） |

### ③-5 BOSS_TIME 与 Boss 生成链

- **BOSS_TIME = 360s 维持**（轴不动）；360s 清场（普通敌/方阵/召唤物全清，不掉经验）→ Boss 出场（320px 处，0.5s 霸体闪红）。
- **按图分发**：墓地 = boss_1 血月尊者 / 教堂 = boss_2 血主教·尼禄 / 狼穴 = boss_3 狼王·芬里厄 / boss_4 血月化身 = 任意图稀有（4:30 后每次判定 5%，已触发本局不再触发——MN-12）。
- Boss 面板走 ENEMY_CONFIGS/BOSSES 统一源（弃 legacy spawn('boss')，双源退役联动 W-8/W-3）；boss_4 击杀回调链（图鉴隐藏条目 + 功绩 +5 + 稀有宝箱）接可达入口（W-3）。
- **Boss 召唤生成规则**：Boss 技能召唤实体 noXp=true（W-12）；召唤计数同源计数（per-Boss），上限 6（P2 8）；Boss 死亡随清场清除召唤物。
- **宝藏护卫路径生成**（W-14 生成侧部分）：每局 ≤1，180s 起 S2 末~S3 窗口掷出（独立于常规方阵掷点的高优预约）；生成点 = 地图一端边缘（远离玩家 ≥600px），路径 = 直线横穿至对端（速 40，避开 Boss 战舞台 320px 净空区）；到点/BOSS_TIME = 方阵离场。

### ③-7 召唤物 noXp 全量生成规则（W-12，MN-23/用户规则 3）

- **判定口径**：生成来源 = 敌方技能（尸巫重召/侍僧召唤/Boss 技能/血旗增援/苏生唤尸/狂化复活体）→ `noXp=true`；生成来源 = 生成器（槽位池/方阵本体/保底预约）→ 正常 XP。
- 实现：敌配置新增 `noXp` 字段（静态）+ 动态召唤实体默认 noXp=true（运行时）；击杀反馈链跳过宝石生成（PlayScene 击杀链挂点）；noXp 实体不计入击杀 XP 统计口径（遥测区分 kills/xpGained 口径校准）。
- 祭品（decoy）为方阵本体成员，noXp=false（XP ×3 锚）。

## ④ 交互与反馈

- **阵纹预警**：方阵落地前 2.5s 阵纹地面标记 + 生成方向指示（幽紫，F-7）；伴随精英预约 = 既有血月印记 2.5s。
- **波峰预告**：心跳 BGM 随 budget 加速（BPM_CURVE 端点随分段曲线复测联动，audio-bible）；屏幕边缘红光呼吸沿用（移动端关闭）。
- **解锁时刻演出**：新敌种/方阵/技能化精英首见 = 一次性登场演出（图鉴侧边浮字「守夜日志已更新。」联动）——威胁质变事件的可读仪式感；仅首次（per-save 幂等）。
- 精英保底低音 / Boss 出场心跳重音沿用。

## ⑤ 平衡与曲线

- **压力曲线表（均值锚，difficulty-v3 §5.3 同源）**：0s 0.9~1.1「开打即稳」→ 60s 1.0~1.2「平台（玩家台阶 30~60s 前置）」→ 120s 1.6「首方阵+特殊行为敌（威胁质变段）」→ 240s 2.4「技能化精英+词缀+骑士团前夕」→ 360s 3.2~3.6「Boss 前峰值爬升」。
- **通道占比自检**：普通 70~75% + 精英 3~5% + 方阵 ≤25% = 100%（方阵拉满时普通槽下限 70% 为炮灰基本盘红线，挤压触发降档预案 difficulty-v3 §⑥-5）。
- **与玩家成长咬合**：首级 ~20s（c 案 X1）对 budget 0.9~1.1 平台；首精英 90~150s 对中段第一奖励节拍；BOSS_TIME 360s 对成型 DPS（终局利用率 70~90%）。
- **方阵观察项（S-8/S-9）**：激进锚全参数复测；方阵在场时段死亡分布无新死亡谷；占比挤压降档演练。

## ⑥ 边缘情况与容错

1. **同屏达上限**：暂停 2s 重试不丢预算（单体）；spawnGroup 分帧落地（≤5 只/帧）+ 组预算已预扣不回收（防止组残缺破坏黑板协同）。
2. **玩家死亡**：立即停止生成，清预约队列（方阵/精英/Boss 链全清）。
3. **unlockAt 过滤后池空**：回退该槽 unlockAt=0 基础敌（结构校验项保证每槽 ≥1）；三轨独立回退互不影响。
4. **方阵掷点与 Boss 清场竞态**：BOSS_TIME 触发帧丢弃未落地预约（预算返还口径：已落地成员照常清理，不二次结算）。
5. **boss_4 与常规 Boss 竞态**：4:30 判定独立于 BOSS_TIME；两者同帧时常规 Boss 优先，boss_4 本局不再触发。
6. **宝藏护卫卡障碍**：路径预计算（直线 + 障碍规避偏移锚 80px）；被完全围堵时驮尸优先受击逻辑不变（玩家堵路 = 合法解题）。
7. **帧率无关**：预算按秒 deltaTime 累加，掉帧不跳怪（沿用）；spawnGroup 分帧落地同样按帧预算。
8. **移速加权边界**：狼穴 ×1.08 不含 Boss 与方阵召唤物（noXp 实体随源敌种面板，不二次加权）。

## ⑧ 验收标准

1. budget 分段五端点 + 波幅/周期可独立断言；60s 均值落 1.0~1.2（H2 压平断言）；方阵预扣 ≤25% 断言。
2. unlockAt 三轨逐条配置断言 + 三里程碑用例（S1 无特殊行为敌 / S1 末方阵首现 / 180s 首技能化精英）；过滤回退用例。
3. spawnGroup 成组预扣/分帧落地/伴随 +20%/同屏 ≤2 断言；组黑板状态机逐阵用例（仪式打断/斩旗溃散/收拢相位/宝藏落地）。
4. Boss 生成链：三图分发用例 + boss_4 触发/不触发两态 + legacy spawn('boss') 退役断言；Boss 召唤 noXp + 上限 6/8 + 死亡清场断言。
5. noXp 判定口径断言（技能召唤实体零宝石路径 / 方阵本体正常掉落 / 祭品 ×3）。
6. 宝藏护卫：每局 ≤1 + 横穿路径避 Boss 区 + 到点离场断言。
7. 3 图差异参数逐项断言（含方阵主副場权重与禁列表）。
8. 桌面 400 / 移动 250 上限生效；移动端中端机 30fps+（方阵分帧落地计入）。
9. 本 GDD 与 `gdd-difficulty-v3.md` / `gdd-enemies-v3.md` 同版本交付（怪物域冻结轮三项一体验收）。
