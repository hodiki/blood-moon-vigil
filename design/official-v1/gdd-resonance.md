## ① 概述

通武 = 通用武器池（14 把，原主武器池继承者），提供组合变化与叙事载体——「**通武定肉**」（R2-4）。共鸣 = 条件形态质变：每专武 1 把共鸣通武，共 **8 对**（R2-7）；持有配对专武 + 对应共鸣钥（双条件）时，该通武形态改造。未配对 6 把保持普通形态，作为纯组合肉。

## ② 设计支柱

1. **互补配对**：共鸣通武的行为基因与专武玩法互补而非重复（守夜之环的环绕 × 提灯的领域为基准例）。
2. **共鸣即预告**：已持配对专武时，共鸣通武卡面显示共鸣徽记，抽卡前可预期（R1 拓展 2 原则③）。
3. **一眼可辨**：共鸣形态必须改变剪影/颜色/光效至少两项（原则①）。
4. **手感不变**：共鸣改「做什么」不改「怎么操作」（原则②，Survivors-like 无操作差异包袱）。
5. **叙事载体**：每把通武是一段「守夜见闻」；强化卡专属命名 + 一句话见闻文案（R2-8）。
6. **强化正交**：共鸣后通武仍可吃通武强化，但降低总强化卡数量（R2-15）——共鸣改形态、强化改数值，两层正交。

## ③ 系统规则

### 3.1 共鸣触发（双条件）
- 条件 = **持有配对专武**（开局 2 选 1 时即确定）**且持有该对共鸣钥**（升级池 P2 席位）。
- 仅持通武未持专武（或反之）：通武为普通形态，钥为普通数值被动（旧钥数值效果全保留，仅身份重挂为共鸣前置——R2 §B3）。
- 共鸣为原子形态切换（工程口径同旧 WeaponSystem.evolve 原子切换模式，weapon-system.ts:379-391）；切换不可逆（取得即保留至局终）。
- 前置锚：共鸣条件达成时的出现权重对齐旧进化卡 ×5 惯例（待模拟）；进入 P2 保底序列。

### 3.2 共鸣改造统一八字段模板
| 字段 | 说明 |
|---|---|
| 共鸣名 | world-bible §7 词根命名 |
| 触发条件 | 配对专武 + 对应共鸣钥 |
| 形态变化 | 剪影/颜色/光效 ≥2 项可辨 |
| 行为变化 | 「做什么」变，「怎么操作」不变 |
| 伤害频率 | 新增/变更频率口径（锚点） |
| 控制效果 | 进 CC 状态层，带 ICD（若有） |
| 强化正交 | 共鸣后仍吃通武强化 |
| 未配对形态 | 该通武无专武时的行为（= 现行普通形态，零变化） |

### 3.3 通武池重设计（WD-5 裁决）
- **规模：14 把保留**（数量不增不减，继承 `gdd-weapons-v2.md` §3 面板与手感归属）；8 把挂共鸣、6 把普通形态（血月猎手 wpn_a_1 / 圣银火铳 wpn_a_3 / 荆棘圣环 wpn_b_2 / 月蚀脉冲 wpn_c_1 / 血池喷涌 wpn_c_2 / 血蝠群 wpn_d_1）。
- 与专武的区分：专武 = 身份声明（开局唯一、不可反悔）；通武 = 升级池解锁、随局组合（获取/成长/叙事三维对照表见 R2 §B2，此处引用）。
- 手感重复武器（观察名单）：血月猎手 × 银针连弩同为高频直射系——首版不删，遥测选取率与贡献率数据回调（WD-5「标记观察名单」口径）。
- 首版共鸣总量 = 8 对，**不扩**（WD-4 节制延续）；扩位候选 = 6 把普通形态通武。

### 3.4 通武强化卡（10 张，NW-7 落定）
- 构成：4 手感类 × 2 分支 + 2 通用（详表见 `gdd-upgrade-pool-v3.md` §4）；来源 = 旧类强化 12 项精简（淘汰第 3 分支 ×4，1~2 项元素回流通武叙事卡，R2 §B6）。
- 共鸣形态下仍可取该通武的强化卡（正交），但全局强化卡总量压至 10 张、为卡池主体。

### 3.5 通武叙事性方案（R2-8 落定）
1. **命名强化卡**：弃用泛用名（「伤害 +20%」），每卡专属命名 + 一句话见闻文案（示例：「殉道者的花冠——环带曾在教堂门前锈成花环」）；文案走 world-bible §7 词根；零机制成本、纯叙事注入。
2. **图鉴条目**：每把通武 + 每张强化卡在 codex 独立条目；首次获得触发解锁；共鸣形态另立条目（对接 `gdd-codex.md`）。
3. **寻获演出**：新通武解锁卡保留 ★ 徽记；解锁瞬间 0.8s 卡面定格演出（「寻获」命名 + 词根色底光）；复用动画模板，不新增帧管线负担。

## ⑥ 数值锚点汇总（待模拟验证）

1. 8 对共鸣的伤害频率/加成倍率（R-1 6伤/0.4s ~ R-7 ×1.5，逐项 §④）；2. 共鸣条件达成权重 ×5 惯例校验；3. 回充计数（3 次/弹）与左轮射速的循环匹配；4. 血契印记 15% uptime 对 Boss 战贡献；5. 圣域 −18% 减伤 + 转化率 +20pp 的辅助流强度；6. 余焰 8伤/s×3s 的区域收益；7. 葬仪铁钉 −8% 重击冷却的 DPS 等效；8. 通武强化 10 张的选择密度（若 S2~S3 空转，通用 2→4 张扩容预案，红线 32~40 内）。

## ⑦ 边缘情况与反例

1. **双条件半满足**：持钥未持专武 = 普通被动；持专武未持钥 = 普通通武 + 卡面显示「可共鸣」灰态徽记（预告不达成的可视化）。
2. **上限冲突**：狼群誓约期召唤上限共享——猎犬在场时月狼召唤请求在上限满时静默丢弃；猎犬消失瞬间释放锁存请求（1 次防连刷）。
3. **形态原子性**：共鸣切换瞬间在途弹体/伤害段沿用旧形态结算完毕，不做中途重算；拖拽目标已死亡（葬仪断罪）时拖拽无效化、伤害段不落空。
4. **反例红线**：❌ 共鸣做成纯数值 +20%（违背形态质变原则）；❌ 共鸣后禁止取强化卡（违背 R2-15 正交裁决）；❌ 每专武配 2 把以上共鸣（WD-4 节制，首版锁 8 对）。
