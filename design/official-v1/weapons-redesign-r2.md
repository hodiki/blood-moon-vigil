## B. 全局结构定稿草案（四层架构 + 两系统）

```
┌─ L1 专武层（定骨）────────────────────────────────┐
│ 开局 2 选 1（不可反悔）→ build 骨架声明            │
│ 成长 = 1~2 张全质变强化卡（赠送 + P1 保底，见 B6） │
├─ L2 通武层（定肉）────────────────────────────────┤
│ 14 通武池规模保留，重设计：叙事载体 + 组合变化      │
│ 通武强化卡精简，为卡池主体（WD-2/12）              │
├─ L3 共鸣层（质变）────────────────────────────────┤
│ 每专武 1 把共鸣通武（8 对），条件形态改造           │
│ 共鸣前置进入 P2 保底                              │
├─ L4 圣物层（叙事演出，新）────────────────────────┤
│ 替代超武：专用按键 + 极长 CD + 极少次数             │

├─ S1 弹药资源维度（系统层新建）────────────────────┤
│ 全局 ammo 框架，当前仅左轮类消费                   │
├─ S2 升级池重构（P1~P5 新序列）───────────────────┤
└─ CC 状态效果层（最小规格，工程须同步接线）──────────┘
```

### B1. 专武层（定骨）

- **选择时点**：角色选定后、进图前，2 选 1；本局不可反悔（裁决 11）。选择演出沿用 R1 C.3 方向：左右分屏立绘双形态（提灯=暗金光晕 / 左轮=银白弹痕），落选专武卡面转入主动技槽 UI 并标注「转化为技能」。角色选择界面提供专武预览，降低误选率。
- **成长结构（裁决 2+12 的收口）**：每专武**恰好 2 张全质变强化卡**，无等级、无重复选择——「重复选择专武强化固定提升」的原始表述在 R1→R2 演化为「1~2 张一次性质变卡」。两张卡各自把专武推向一条形态分支？**否——两卡为串联结构**：卡 1 = 第一质变（扩玩法面），卡 2 = 第二质变（收身份钩子），先取卡 1 才能取卡 2（顺序解锁），路线仍固定、只是分两步兑现，与「定骨」承诺一致。
- **获取渠道（建议，NW-2/NW-3 待拍板）**：
  - **卡 1**：P1 保底席位在升级池出现（全局限 1 次，建议触发窗口 S1 后段 30~60s——直接对冲 H2 前期平台期，R1 B.7 已论证该抓手）。
  - **卡 2**：局内特殊内容赠送——候选：Boss 击杀掉落（必得型）/ 精英宝箱（概率型）/ 地图事件祭坛（探索型）。**推荐 Boss 击杀必得**：时点确定（360s 前后）、叙事演出天然（圣物节奏分离）、且让终局 build 在 Boss 战前成型。
  - 卡 2 亦可由「距离卡 1 获得后 N 次升级」兜底触发（防 Boss 前路线悬空，锚 N=8，待模拟）。
- **卡池占比**：专武强化卡共 2 项/专武，非当前专武的卡不进池——占比极小，符合裁决 2/5「卡池主体留给通武」。

### B2. 通武层（定肉）

- **与专武的区分原则**（裁决 4+8）：
  | 维度 | 专武 | 通武 |
  |---|---|---|
  | 身份 | 角色玩法核心声明（骨） | 组合变化与叙事载体（肉） |
  | 获取 | 开局唯一，不可反悔 | 升级池解锁，随局组合 |
  | 成长 | 2 张全质变卡（固定路线） | 精简强化卡（多路线自由） |
  | 叙事 | 角色 lore 深绑定 | **每把通武是一段「守夜见闻」** |
- **叙事性强化方案（裁决 8，建议）**：
  1. **命名强化卡**：通武强化卡弃用泛用名（「伤害 +20%」），改为每卡专属命名+一句话见闻文案（例：荆棘圣环分支卡「殉道者的花冠——环带曾在教堂门前锈成花环」）。文案走 `world-bible.md` §7 词根（powerTag 五系），零机制成本、纯叙事注入。
  2. **图鉴条目**：每把通武 + 每张强化卡在 codex 有独立条目；首次获得触发条目解锁，共鸣形态另立条目（与 `gdd-codex.md` 对接）。
  3. **获取演出方向**：新通武解锁卡保留 ★ 徽记，解锁瞬间加 0.8s 卡面定格演出（「寻获」命名 + 词根色底光）；成本 = 一段复用动画模板，不新增帧管线负担。
- **强化规模**：类强化 12 项改造为通武强化并**精简**（裁决 15），目标数量见 B6；共鸣后通武仍可吃通武强化（形态/数值正交，R1 WD-12 论证保留）。

### B3. 共鸣层

- **规模**：每专武 1 把共鸣通武 = **8 对**（裁决 7）。配对原则：通武行为基因与专武玩法互补（守夜人之环的环绕 × 提灯的领域；其余 7 对按同法逐角色配，下一轮细化）。
- **共鸣前置进入 P2**：每对共鸣对应 1 枚**共鸣钥**（裁决 16）。共鸣条件 = 持有配对专武 + 持有该对共鸣钥（双条件，向心性更强）；仅持有通武未持专武时，钥仍是普通数值被动（旧钥数值效果保留，身份改为共鸣前置——与 R1 WD-1 方案 A 的「数值钥保留」路线合流）。
- **共鸣改造前后形态对比框架**（8 对统一模板，守夜人 1 对在 §C 完整展开）：

| 字段 | 说明 | 守夜之环 × 破旧提灯 示例 |
|---|---|---|
| 共鸣名 | 世界圣经 §7 词根命名 | 「守夜环灯」（HALLOWED × MOON） |
| 形态变化 | 剪影/颜色/光效至少两项可辨（R1 拓展 2 原则①） | 球体→提灯色环带 |
| 行为变化 | 「做什么」变，「怎么操作」不变 | 环绕球→沿提灯领域边缘巡行 |
| 伤害频率 | 新增频率口径 | 环带触碰 6 伤/0.4s/目标（锚） |
| 控制效果 | 进 CC 状态层，带 ICD | 0.5s 眩晕，单目标 10s ICD |
| 强化正交 | 共鸣后仍吃通武强化（裁决 15） | 环带伤害受通武强化放大 |

- **共鸣即预告**：已持配对专武时，共鸣通武卡面显示共鸣徽记，抽卡前可预期（沿用 R1 拓展 2 原则③）。

### B4. 圣物层（新，替代超武；裁决 3）

- **定位**：叙事演出型特殊效果——「超出角色设计的、有故事的奇迹」。**不作为主要战斗元素**：不进 DPS 预算主线、不承清屏职责，价值 = 高潮叙事节拍 + 视觉奇观 + 一次战术翻盘窗口。
- **使用规格**：专用按键（移动端沿用「移动 + 单主动技键」极简输入，圣物键 = 新增第 2 技能键，唯一例外，需 UX 复核——标注给 UX 域）；**极长冷却**（锚 180~300s，待定 NW-1）；**极少量次数**（每局 1 次保底，上限 1~2，NW-1）。
- **获取方式候选（NW-1）**：A. Boss 击杀后剧情节点掉落（推荐：时点确定、演出天然）/ B. 地图事件·隐藏祭坛交互（探索奖励）/ C. 混合（Boss 必掉 1 + 祭坛概率第 2）。**推荐 C**，与「难获得」要求匹配。
- **与战斗的关系边界**：圣物效果允许强（一次全场演出级效果），但冷却与次数锁死总收益上限（锚：全程伤害占比 <5%，模拟口径，待验证）；不可叠加、不可升级、局内唯一。
- **旧 7 超武处置建议（NW-5）**（对照 `gdd-weapons-v2.md` §5.2）：
  | 旧超武 | 处置建议 |
  |---|---|
  | 月全食（双脉冲+眩晕） | **概念转圣物候选**：全场演出+控制，最贴圣物气质 |
  | 血海（巨池减速） | 概念转圣物候选（领域演出向） |
  | 血月天罚 / 血银霰弹 / 炽天使之环 | 行为拆解：弹幕分裂/溅射/击退基因回流通武强化卡与专武质变卡候选池 |
  | 血蝠风暴 / 狼群领袖（召唤增强） | 转通武强化候选（D 类成长钩子）+ 图鉴退役区收档 |
  - 共同底线：**全部 7 超武行为资产进图鉴「退役区」收档，不删除**；进化达成率验收体系（≥50%/80%）随之退役，替代口径 = 专武质变达成率（新埋点，见 R1 §E 遥测行）。
- **钥 7 项去向**：改造为共鸣钥（B3），数值效果保留——旧钥全部复用，仅身份重挂。

### B5. 弹药资源维度（系统层新建；裁决 10）

- **架构定位**：在武器系统层新建全局 `ammo` 资源框架（弹量上限/当前弹量/装弹时长/装弹状态四字段的标准组件），任何武器可声明 `usesAmmo`；**当前仅左轮类（圣徒左轮及其衍生技）消费**。
- **边界说明（不泛化，防 scope 蔓延）**：
  1. 不推广到其余 13 通武与 7 专武——`usesAmmo` 为声明式开关，未声明者零改动、零 UI；
  2. **无手动装弹键**（默认弹药耗尽自动装填，锚 1.0s；R1 拓展 6 维持）——保住「移动 + 单主动技键」输入极简性；
  3. 弹药 UI 不做独立资源条：绑定武器图标侧的弹巢点阵（6 点），规避「第二资源条」红线的精神（pillars-v1 §6）；
  4. 弹药不参与掉落/商店等经济系统（首版）——它是武器行为参数，不是全局货币。
- **正式修订要求**：`baseline-design-v05.md` §1.2 weapons-v2「全部自动触发、无弹药管理」定稿条款在定稿 GDD 中正式修订为「全部自动触发；弹药类武器例外（自动装填）」。

### B6. 升级池重构（P1~P5 新序列下的构成与预算）

现状池 40 项 = 全局 9 + 类强化 12 + 钥 7 + 主动技强化 12（`gdd-upgrade-pool-v2.md` §3.1；单局可选 31）。新序列（裁决 16）下的目标构成：

| 新卡类 | 目标数量 | 来源（现状 40 项对照） | 保底席位 | 淘汰/改造说明 |
|---|---|---|---|---|
| 全局基础强化 | **9**（保留，微调命名） | 全局 9 | — | up_g_1~4 数值卡保留为兜底可重复项；up_g_2 专精疾射保留（DPS 重算登记项不变） |
| **专武强化卡** | **2**（仅当前专武的 2 张） | 新增 | **P1**（卡 1 全局限 1 次） | 卡 2 走赠送不进池；非当前专武卡不进池 |
| **共鸣钥** | **8**（每对共鸣 1 枚） | 旧钥 7 改造 + 新增 1 | **P2** | 旧钥数值效果全保留，身份重挂为共鸣前置；新增 1 枚的挂靠对象见 NW-5 附注 |
| **通武强化卡** | **8~10** | 类强化 12 改造精简 | **P3**（已拥有） | 4 类 ×3 分支 → 4 类 ×2 分支（淘汰第 3 分支共 4 项），其中 1~2 项元素回流通武叙事卡；精简幅度为裁决 15 的量化收口，锚 8~10 待模拟（NW-7） |
| 主动技强化 | **0 或 8**（NW-4） | 旧主动技强化 12 退役 | **P4**（若保留） | 保留案 = 8 套衍生技各 1 张特色强化；退役案 = 效果并入衍生技本体（裁决 6 本就要求拆元素） |
| 通武解锁 | 走 P5 变体（不单列） | 沿用 §3.7 解锁变体机制 | **P5** | 通武强化项兼任解锁卡身份的机制保留 |

| **合计** | **27~37 项（锚 34~38）** | 现状 40 | P1~P5 | 池总量小于现状是**有意收敛**（认知负荷下降）；厚度缺口由 up_g 可重复卡 + 通武强化双分支满层吸收，需模拟验证选择密度不空洞 |

- 淘汰/改造清单速览：类强化第 3 分支 ×4（淘汰，元素回流）；旧主动技强化 12（退役，元素拆入 8 衍生技——裁决 6）；旧钥 7（改造重挂）；超武进化卡 5（随裁决 3 退役）。
- 池规模红线复核：R1 红线「总池 40~46」在专武强化/共鸣钥/圣物新结构下自然落在下沿以下，建议本条红线修订为「总池 32~40、单局可选 ≤30」，待用户确认。

### B7. CC 状态效果层（最小规格，裁决 9；工程须同步接线）

- **状态枚举（三类起步）**：眩晕（硬控）/ 减速（软控）/ 易伤（减益）。
- **叠加规则**：同类状态不叠加取最强；不同类可共存。
- **ICD**：硬控（眩晕）通用内置冷却常量 **10s/单目标**（锚，承共鸣 0.5s 眩晕案例；减速/易伤不设 ICD，靠时长与折减控制）。
- **抗性规则**：**Boss 硬控免疫**（仅软控/易伤生效）；**精英受控时长 ×0.5**。

### C4. 双专武体验分工总结（骨）

## D. 修女召唤物机制扩展（裁决 17a 规格草案）

> 归属：薇奥莱（修女）× 安魂圣铃辅助流。命名建议「**守誓者**」（HALLOWED 词根，待 NW 一并确认）。

- **定位**：辅助流的「明确辅助对象」（用户裁决原文要求）——一个强力单体召唤物，承伤替身而非输出单位。
- **属性规格（锚点）**：
  - 存在形态：1 只常驻实体，HP 锚 **= 修女最大 HP ×150%**（或固定 200，两口径待模拟定一）；重召唤间隔：墓碑复活后立即回归（见下），异常消散后 CD 锚 20s；
  - **承伤替身**：召唤物存在时，以自身为优先仇恨/阻挡位——周围敌人优先攻击召唤物（半径 150px 锚内强制索敌），本体修女受该范围接触伤害转移（锚：转移 50%，待模拟）；
  - 输出：低频撕咬 8 伤/1.0s（锚，对齐 D2 狼影猎犬量级，不与输出流竞争）。
- **被击倒 → 墓碑**：召唤物 HP 归零后**不消失**，原地化为墓碑（持续 8~10s 锚）：半径 **120px** 内修友方（修女本体）**持续回血 2 HP/s**（锚）；墓碑期召唤物不可被再攻击（敌 AI 跳过该实体）。
- **回血加速复活**：修女其它回血效果（圣铃治疗光环等）命中墓碑时，按 **50% 转化率**（锚）折算为复活进度；进度满 → 守誓者原地复活满血。→ 形成「治疗在辅助流里同时是召唤物运营资源」的正循环，这正是裁决 17a「修女其它回血效果可加快其复活」的机制化。
- **新机制影响面（一行）**：⚠ **敌方 AI 需支持选中友方实体**（现有 enemy 索敌只指向玩家，`enemy.ts` updateMovement/索敌逻辑需扩展 target 选项）——工程影响登记，须与 CC 状态层同批次接线评估。
- 附加资产面：召唤物 HP 条、墓碑形态帧、复活演出（登记美术管线，帧名契约注册表扩容项）。
