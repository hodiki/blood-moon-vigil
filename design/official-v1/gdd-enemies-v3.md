## ① 概述

怪物域 v3 = **普通怪三档（炮灰/突袭/特殊行为）+ 精英技能化五体 + 方阵体系九阵 + Boss 五技能槽**的行为骨架，落在 difficulty-v3 的数值标尺上。核心交付：解题循环的怪物侧实现——每个威胁**可读（telegraph）、可解（反制窗口）、有奖（XP/宝石簇/负空间）**。

- 与 v2 的关系：面板基座继承 enemies-v2（ENEMY_CONFIGS），本 GDD 覆盖其行为判定与 roster 构成；v2 击杀时间对表按新缩放/XP 复测后由本 GDD §⑤ 替代。
- 全域反制语法收敛五种：**横移 / 集火 / 打断 / 借位 / 读圈**——零新增学习成本（认知过载红线自检）。

### ③-3 普通怪三档规格

#### 档 1 · 炮灰型（行尸 g1_1 / 血信徒 g2_1 / 灰狼 g3_1；甲虫 = 行尸变体）

- 定位：常规大量持续出现的尸潮基座，承担 budget 量变压力；炮灰不是威胁本体，是**威胁的容器**（占输出窗口与走位空间）。
- 行为：直线追踪、无技能无 telegraph、掉标准 XP；面板沿用现值（行尸 12/55/10 · 血信徒 14/60/12 · 灰狼 12/85/10）作 M3 缩放基座复测。

#### 档 2 · 突袭型（血犬 g1_2 / 血蝠 g2_2 / 暗影狼 g3_2）——「惩罚失误」模板

| 字段 | 规格（锚，三敌通用） |
|---|---|
| 面板 | 血犬 10/150/8 · 血蝠 8/130/8（空中）· 暗影狼 10/160/10；HP 低 = 惩罚「疼」不「致命」 |
| 突袭触发 | 跟随带 100~160px 游走；进入 **100px 内**（或玩家移速逆转/停滞 ≥0.5s 时 140px 内）→ 突进 |
| 预警 | 蓄身低伏 **0.25s**（身形压缩 + 短促嘶叫 + 轻微后坐）；血蝠 = 俯冲拉高 |
| 突进 | 90px 定向 @300px/s；接触伤 = 面板伤 8~10（约玩家 HP 8~12%） |
| CD | 突进后 **2.5s** 不二连；突进落空 **0.5s 硬直** |
| 反制 | 蓄身时方向已锁定，横移 30px+ 即落空；惩罚「走位失误」不惩罚「被围」（0.5s 无敌帧限流） |

### ③-4 精英技能化五体规格（P3 核心）

> 统一模板：触发距离 → 蓄力（telegraph）→ 释放 → 反制窗口/硬直 → CD。精英技能伤 = **独立技能伤字段**（不沿用面板接触伤），进精英独立曲线。

#### ③-4-0 MN-20 打断原则（全精英通用，定稿）

1. **硬控（眩晕）可打断蓄力**——CC 是解题增益非唯一解；受控时长走精英 ×0.5 默认折减；**打断 = 取消本次攻击并进入 CD 的 50%**（锚，防白嫖）。
2. **蓄力末段 0.3s 锁定窗**（霸体，硬控无效）——防 ICD 内连环眩晕永久锁死精英（负反馈红线）。
3. **软控（减速）不打断、不延长蓄力**——减速改走位压力、眩晕改节奏，分工不混。
4. **ICD 沿用状态层 10s/单目标**——同一精英 10s 内只能被眩晕打断 1 次。
5. Boss 硬控免疫不变（Boss 侧「吟唱/施法硬直」不是蓄力，不适用本原则——§③-7）。

- **默认三档不动摇**：Boss 硬控免疫 / 精英 ×0.5 / 普通全生效（状态层 §3.4）；首版不做逐敌细分级（可读性 + 模拟矩阵红线）。

- **反制攻防总表原则**（状态层 §⑥-4）：玩家 CC 让反制**更容易执行**，不替代反制（侍僧被眩晕 = 召唤暂停，仍需集火击杀源）；MN-20 打断原则是本原则在精英域的具体化。

## ④ 交互与反馈

- **telegraph 演出体系（W-13）**：扇形地面预告（守墓者/血月尊者）/ 地面箭头线（畸体）/ 预警圈（掷骨者/血井/月坠）/ 警告线（冲锋系，warningLine 复用三线扩展）/ 环形波缝（月相脉冲）/ 阵纹地面标记（方阵）/ 弹道细线（忏悔者/血珠）——全部渐亮式（透明度随蓄力推进），形状 = 危险范围。
- **状态标记扩展**：enemies-v2 §4.2 五标记沿用（亡魂残影标记随退役停用）；新增：阵纹（幽紫）、血旗（金红高空）、祭品金光、石甲高光/破碎白闪、治疗绿光束、召唤血光。
- **破阵反馈**：仪式打断/斩旗/破甲/溃散各配独立演出与音效（解题成功 = 可感知奖励节拍）；noXp 实体死亡无宝石生成（天然区分，不加额外标识防认知负担）。
- **精英登场**：血月印记 2.5s 预约预警沿用；词缀角饰光 / 方阵阵纹同族异形（词缀 = 角饰光、方阵 = 地面阵纹）。
- 受击/死亡/Boss 出场演出沿用 enemies-v2 §④；Boss 台词横幅不变。

## ⑤ 平衡与曲线

- **XP 定价（MN-25 保守锚）**：方阵本体成员按敌种面板 XP；解题宝石簇 5~10 XP（完整击破高档阵 15~20）；召唤物 0（noXp 全量）；方阵奖励**不使 offers 落差扩大**（SC-2 c 案合并核算，difficulty-v3 §5.2）。
- **精英击杀时间**：三精英 350~500 HP 基座 + 技能伤独立字段，随 M3 独立曲线复测；设计意图不变——前期绕开、5min 可选集火、6min 可击穿。
- **威胁档位对照**：炮灰（量）→ 突袭（失误惩罚）→ 特殊行为普通（单点反制教学）→ 精英技能化（小型 Boss，解题高潮中段）→ 方阵（战术考题，后段）→ Boss（五槽循环，终局）——与 unlockAt 三轨时间轴咬合（difficulty-v3 §5.4）。
- **方阵占比**：25% budget 锚 + 同屏 ≤2 + 每局 3~4 次（激进档，v1.1 口径收敛）；方阵在场时段死亡分布无新死亡谷（S-9 复测项）；占比挤压尸潮时的降档预案见 difficulty-v3 §⑥-5。
- **清召唤红线**：Boss 战清召唤 ≤40%（MD-4）；召唤上限 6/8 封顶。

## ⑥ 边缘情况与容错

1. **方阵成员部分死亡**：组黑板不重置——追猎剩尸巫仍可仪式重召；苏生守墓者死后尸巫不逃继续唤尸；血旗旗手死即解散（各阵解散条件逐阵定义，不做通用「半血解散」）。
2. **方阵跨 BOSS_TIME**：360s 清场时方阵与召唤物一并清除（不掉 XP，与普通清场同规则）；宝藏护卫横穿中遇 BOSS_TIME = 视同到达终点离场（宝藏不落地）。
3. **打断与 ICD 竞态**：蓄力末段 0.3s 锁定窗内命中眩晕 → 不打断但消耗 ICD（防窗口边界反复判定）；两来源同帧眩晕 → 取最长，第二来源仅消耗 ICD。
4. **召唤上限竞态**：召唤计数含跨来源（Boss + 方阵 + 侍僧），达上限全局暂停召唤（按召唤源分别计数不混算——实现取「同源计数」口径，配置断言）；召唤物死亡释放计数。
5. **宝藏护卫被卡位**：驮尸全灭前玩家堵终点 → 方阵照常行进，到点离场；宝藏落地实体 30s 未拾取消失（防永久存场）。
6. **精英在解锁时点前生成**（S1 随机 0.5% / S2 保底）：生成**基础厚血形态**（无技能化行为）；180s 起生成即技能化；已在场精英不追溯切换（形态切换可读性红线）。
7. **石甲狼破甲边界**：石甲 HP 与本体 HP 分池结算，溢出伤害不跨池；狂暴期不叠加词缀迅捷（同源增益取最强）。
8. **noXp 边界**：祭品（decoy）是本体成员非召唤物，掉 XP（×3 锚）；狂化复活体 noXp；宝藏实体不可被伤害。
9. **同屏上限**：方阵成组落地受 maxEnemies 节流——组内成员分帧落地（≤5 只/帧），不因上限丢弃组（预算已预扣）。
10. **移动端**：阵纹/预警圈/警告线加粗降级规则见 §⑦。
