### 5.8 【v0.3.2 新增 / v0.3.3 扩 · 可复用规则】新增「xx 骑士」/ 新 Boss 的色彩·剪影可区分性判定流程（含判据⑤「地表可辨」）

> **背景**：主理人裁决「骑士设计与命名不可能仅有一种」「后续可能有更多种不同的 boss 设计」。故「主体配色」**不按「token 归属」判定，而按「可区分性判据」判定**（§0.6-③）。以下为**新增实体**（我方伴生骑士 / 敌方骑士 / 新 Boss）落色前的**可复用判定流程 / 检查清单**：

**判定流程（七步 · 每步可留痕）**

1. **登记（前置）**：名称 / 阵营（我方伴生 · 敌方）/ 帧族候选（`summon-*-knight` 或 `enemy-*`）/ powerTag → 记入 §5.7 命名族表（命名族 6 条规则不变）。
2. **列撞色对象**：列出**同屏可能并存的实体**——普通敌（敌潮基线）/ 精英 / 已登记骑士（**血月骑士**、**腐朽骑士**）/ 各 Boss / 其他我方伴生 / **地图地表（石板 / 草地 / 草叶 / 墙，基线表见 §0.6-⑨）**。
3. **取基线并算主体身色平均 L***：**敌潮基线** = 普通敌主色（现网 `#7E1E1E`，**实测 L*≈28**）；只算「**身色**」（**排除黑甲、阴影、高光**）的像素加权平均。
4. **过五条判据**（§0.6-③）：① 明度 ΔL*≥15（亮向；Boss 可暗向 ≥20）；② 色相补偿（同族 <20° ⇒ 门槛提到 ≥18）；③ 黑 ≥30% + 贯穿躯干（身色为红 / 危险语义族时必判）；④ 剪影三要素 ≥2 可区分；**⑤ 地表可辨**（**大面积色块含黑甲** vs 地表基线：**地板 ΔL\*≥5 / 非地板 ΔL\*≥3**，细线另判）。
   - **任一不过 ⇒ 改色值（同色相提亮 / 压暗）或改剪影 ⇒ 重跑本步**。
5. **逐图地表可辨性复检（v0.3.3 新增）**：对该实体将出现的**每一张图**，**逐图**取该图**地板基线**（不取最严图一刀切）核判据⑤；**黑甲 / 大面积暗色块**在**默认无外圈描边**下与地板无分隔手段时，**必须**靠**明度差**或**内部高光 / 亮边**分离。
6. **双编码自检**：在 **P / D 两套色盲替换板**下仍可辨（形状独立于颜色，守 `asset-spec §2.4` 约束 7）。
7. **登记与过检**：写入 §5.7 命名族表 → 过 `consistency-anchors` **B 类视觉过检** → 方可开工。

**检查清单（速查）**

- [ ] 主体身色平均 L* 已量测，并与敌潮基线（≈28）比较
- [ ] 与撞色对象**逐一**过判据①②（不是只对普通敌）
- [ ] 同色相族（红 / 血橙红）⇒ 明度差 ≥18 + 结构 / 剪影补足
- [ ] 黑甲 + 黑结构线 ≥30% 且贯穿躯干（防「全身红 / 全身危险色」）
- [ ] **【v0.3.3 新增】逐图地表可辨性复检**：每一**大面积色块（含黑甲）** vs 该图**地板基线**（石板 ≥5 / 草地 ≥5）**与**非地板（草叶 / 墙 ≥3）——**逐图**，不只取最严图
- [ ] **【v0.3.3 新增】黑甲 / 大面积暗色块不与所在地表同色**，且不低于最小可辨差（§0.6-⑤）；**默认无外圈描边**下无分隔手段时，靠**明度**或**内部高光 / 亮边**分离
- [ ] 剪影不与任何已登记实体共用（体型 / 色相 / 角饰 ≥2 可区分）
- [ ] 色盲双板可辨
- [ ] `art-bible:55`（猩红 = Boss 主体倾向）**未被本实体「占用」**——新 Boss 仍可自由用猩红系

**新地图 / 新地表色加入时的复检（v0.3.3 · 通用检查项）**：任一新地表色须登记入 **§0.6-⑨「地表基线表」**，并对**全部已登记实体**（xx 骑士 / Boss / 我方伴生）**重跑判据⑤**（地板类 ΔL\*≥5、非地板类 ΔL\*≥3）。（对应 §10.5-⑤-13。）

**与 `art-bible:55` 的关系（明确）**：本流程**不改变**「猩红 `#FF3B3B` = Boss 主体倾向」的语义；**新 Boss 用猩红系时只需对同屏对象满足第 4 步判据即可**，**无需「先给谁用」的排他归属**。

### L* 复算口径（可复现）

标准 sRGB → 线性化 → 相对亮度 **Y = 0.2126R + 0.7152G + 0.0722B**（Yn = 1.0）→ **CIE L* = 116·f(Y/Yn) − 16**，`f(t) = t^(1/3)`（t > (6/29)³）否则 `t/(3·(6/29)²) + 4/29`。复算结果：猩红 `#FF3B3B` = **56.79**；`#D0342F` = **47.07**；`#C42B2B` = **43.71**；`#B92B2B` = **41.56**；**敌 `#7E1E1E` = 28.00**；`#0B0E14` = **3.94**；`#131722` = **7.83**；`#2A3038` = **19.60**；月银白 `#E8F0FA` = **94.47**；冷青 `#54E6C9` = **83.28**；金 `#FFC93C` = **83.63**。**结论**：v0.3.1 的 `#7E1E1E` **L*≈15 不成立**（应 ≈28）；「主体红 vs 敌色 **差 ≥30**」随之作废，改判 **Δ≈16（低中调）~29（含高光）**；本版建议取值下**身色平均 Δ≈20~24**。
