## 1. 形态定性（决策点 1）

### 1.1 方案对比

| 维度 | **A · 独立第 5 张角色卡** | **B · 局内形态切换** | **C · 隐藏解锁形态** |
|---|---|---|---|
| 定义 | 魔化薇奥莱作为独立 `hero` 条目进选人界面（第 5 卡） | 同一 `hero_violet`，局内由叙事事件触发形变，形变后换形象套 + 换武器组 | 默认同 A 或 B，但需达成隐藏条件（图鉴/局外）才解锁 |
| 工程成本 | 低（复用现有角色初始化路径，`hero_violet` 复制一份 5 号配置） | **高**（形变＝运行时换 model package + 换武器组 + 换技能组；需形变接线，README §6 明列未做） | 取决于挂 A 还是挂 B；解锁门额外（存档 + 图鉴前置） |
| 与 4 角色平衡锚关系 | **破口**：需新增第 5 条开局 DPS 基线进入「开局 DPS 9~16 平台带」（gdd-exclusive-weapons §⑤），并为其配 2 专武 → 新增 2 条 DPS 锚，侵蚀现有双路线 ≤±15% 校验体系 | **零新增基线**：形变后仍在同一角色内校验（角色内 DPS 差 ≤±15%，R2-13 口径）；不进平台带集合 | 同 A 或 B |
| 对选人 UI 影响 | **+1 卡**（4→5）；与 framework v1.5「选人界面仍按双线分卡」及 README「不是第五张选人卡」**冲突** | **零改动**（选人仍显示守誓 `[0]`） | +1 卡或加锁态卡（取决于挂靠） |
| 叙事自洽 | 把「一体两面」降级为「两个角色」 | **最贴合**：形变即「她放开那约的那一刻」（§3.3 内核句） | 可加「隐藏形态」的神秘感 |
| 落选风险 | 与「同框解禁是艺术手法、选人仍双线分卡」定调打架 | 工程量大、形变瞬刻演出需美术新帧/特效 | 解锁门若不透明，玩家找不到 |

### 1.2 推荐

**推荐 B（局内形态切换）**，并吸收 C 的「解锁门」作为**轻壳**（即：形变能力本身需达成一个图鉴/局外前置才可用；未解锁时该路线不可进入）。理由：

1. **文档一致性最高**：README 明写「一体两面，**不是第五张选人卡**。引擎 `[0]` 仍是守誓，**直到形变接线**」；`narratives-spec.md:71` 已预留 `routeVariants: {route:'oath'|'corruption', enterLine}[]`——工程接口已按「同一角色、双路线变体」设计，B 是唯一不改契约的选项。
2. **不扰动既有平衡锚**：魔化线在同一角色内校验，不进「开局 DPS 9~16 平台带」集合，不为第 5 卡新开 2 条专武锚。
3. **美术成本可控**：idle（128 已过）复用；只需补 skill-a/b（2 帧）+ walk（6 帧），与守誓线帧数结构对称。
4. **叙事最贴内核句**：「守誓与魔化，都是她自己的选择」——形变是**她做的选择**，不是「换了一个角色」。

> ⚠ 需主理人裁决：framework v1.5 说「选人界面仍按双线分卡」，与 README「不是第五张卡」表述需统一口径（§8-A1）。B 的落地＝选人**只显示一张卡**（守誓），魔化是局内形变结果。

### 1.3 与「一体两面」其他呈现的边界

- **同框**：形变瞬刻的「守誓者散去 / 暗回流」演出**是否允许同框对照**，取决于「同框禁令是否已解」，见 §9.1 冲突①（framework v1.5 已解禁 / art-bible 仍禁）。B 方案下建议：形变演出**默认不做双人同框战斗帧**，只做一次性过场（引擎层/特效层），避免与 art-bible「V-C 仍废」冲突。
- **独立专属**：魔化线**不新增角色 select 卡、不进图鉴「角色」类新增条目**（角色条目仍是 `codex_hero_violet` 1 条）；改以「路线档案 / 实体档案」承载（§5.4）。

## 2. 进入条件（决策点 2）

### 2.1 叙事事件 → 玩法触发的映射

**叙事事件**：`守誓者散去`（她放开那约的那一刻；堤散了，暗回流）。**触发语义**：这不是惩罚，是**她在十字路口的一次主动选择**（内核句：都是她自己的选择）。

### 2.2 方案对比

| 维度 | **A · 主动抉择（十字路口）** | **B · 被动（守誓者终亡）** | **C · 濒死转化** |
|---|---|---|---|
| 触发条件 | 达成窗口（如：S1 末~S2 初，首次精英击杀后 / 守誓者首次进入墓碑态），弹出「抉择」提示；玩家**主动确认**才形变 | 守誓者墓碑 8~10s 内未被治疗复活 → 直接**2 次终亡** → 自动「散去」→ 形变 | HP 归 0（本应死亡）时，若形变可用：守誓者替她挡下 → 散去 → 形变续命 |
| 时点 | 玩家可控（锚：90~180s，与首精英 90~150s 对齐） | 不可控（取决于战斗） | 极晚（死亡边缘） |
| 可逆 | **不可逆**（一次形变即锁本局路线） | 不可逆 | 不可逆 |
| 次数 | **每局至多 1 次** | 每局至多 1 次（守誓者第 2 次终亡） | 每局至多 1 次 |
| 玩家能动性 | **高**（她自己选） | 低（被形势逼） | 中（救命稻草，被动接受） |
| 与内核句「都是她自己的选择」 | **最吻合** | **冲突**（被迫，非选择） | 半吻合（选择感弱，但有戏剧张力） |
| 与守誓纯线共存 | ✅（不选＝纯守誓线，守誓者可存续整局） | ✅ 但守誓线玩家被迫接受形变 | ✅ 但复活链（Q-c/Q-e）优先级需重排 |
| 工程依赖 | 抉择 UI 事件 + 形变接线 | 复用守誓者墓碑/终亡逻辑 + 形变接线 | 与复活判定序（gdd-talent-tree §6.3）叠加，复杂度最高 |

### 2.3 推荐

**推荐 A（主动抉择 · 十字路口）**，参数口径：

| 字段 | 锚（区间，待模拟） | 说明 |
|---|---|---|
| 抉择窗口开启 | S1 末~S2 初（锚 90~180s）；条件 = **首次精英击杀已发生** 且 **守誓者在场** | 与 Q-f 首猎之赏（首精英锚 90~150s）节奏对齐，不与开局冲突 |
| 抉择形式 | 侧边浮字提示 + 一次按键确认（非阻塞，不弹窗挡操作——framework §1.3 轻叙事原则） | 可忽略；不选即维持守誓线至终局 |
| 可逆 | **否**（确认即锁） | 「放开的约，不回头」 |
| 每局次数 | **1** | — |
| 形变瞬间 | 守誓者散去演出（≥1.5s，可降级，同圣物演出惯例）+ 暗回流 | 引擎层过场，非她的战斗帧 |
| 形变后 | 形象套切 `hero-violet-fallen*`；武器组切魔化（§3）；技能组切 skill-a/b（§4） | 换皮原子切换，同 `WeaponSystem.evolve` 惯例 |

**为什么不用 B/C 作主方案**：B 把「她自己的选择」改成「被迫」，直接违背内核句；C 与天赋树复活判定序（护盾→圣物免死→天赋复活，gdd-talent-tree §6.3）叠加会产生「先复活还是先形变」的裁决歧义。**C 可作为 P2 备选**（若主理人认为「濒死时堤散了」更具戏剧性，需重排复活判定序）。

> **可逆性的叙事代价**：不可逆 = 本局无法回到守誓线。与「守誓线一整局」的玩家体验**不发生冲突**（不确认即不形变）。若主理人希望「可试可退」，见 §8-A2。

## 3. 武器与衍生技（决策点 3）

### 3.1 现状对照（守誓线专武锚，引自 gdd-exclusive-weapons §4.4/§4.5）

| 专武 | powerTag | 手感 | 开局 DPS 锚 | 与守誓者耦合 | 魔化线可保留性 |
|---|---|---|---|---|---|
| 誓约圣铃 `xw_bell` | HALLOWED | B 环绕/领域（辅助流） | 6~8（自身）/ ≈13~14（含守誓者合计） | **强耦合**（守护对象＝守誓者；铃响治疗它 / 墓碑转化 / 复活） | **不可保留**——守誓者散去，辅助对象消失 |
| 圣辉轮刃 `xw_cross` | HALLOWED | C 清屏（定点爆发） | 9~11 | **无关**（纯范围爆发，不依赖实体） | **可保留**（形态无关） |

### 3.2 决策点对比

| 维度 | **A · 单替换**（圣铃→魔化专武；轮刃保留） | **B · 镜像双武**（圣铃/轮刃各出魔化镜像） | **C · 保双武换模式**（同名武器，切形态翻行为） |
|---|---|---|---|
| 新增专武数 | **1** | 2 | 0 |
| 新增质变卡 | **2** | 4 | 0（改行为，不加卡） |
| 与选择时选铃/选轮刃的对称性 | **不对称**（选铃者→1 武；选轮刃者→2 武）→ 需 §3.5 规整规则消解 | **完全对称**（镜像槽位一对一） | 对称 |
| 对「机制载体」的补全 | 补齐（有明确专武＝载体） | 补齐 | 半补（载体＝「同名武器的新行为」，美术仍需新技能帧） |
| 美术成本 | 低（技能帧恒定 2 帧，空手） | 低（同上） | 低（同上） |
| 叙事力度 | 高（「放开的那盏灯，以另一副样子回来」） | 高 | 中（「同一件兵器，换了个魂」） |
| 工程成本 | 低（1 专武配置 + 形变时授予/转换） | 中（2 专武配置） | **最低**（0 新配置，仅行为开关） |

### 3.3 推荐

**推荐 A（单替换）**，理由：

1. **载体只需一个**：美术瓶颈是 `-skill-a/b` 两帧，不是武器数量；魔化 idle 已定「**空手**」（job card：无烛、无翼、无环、无粒子；「空手；禁止烛、禁止第二件持物」）→ 魔化武器宜**自体化、不持物**，故 1 个「自体领域」专武即可承载全部技能外观。
2. **保留圣辉轮刃**：它形态无关（定点爆发，不依赖任何实体），在魔化线继续生效，其质变卡与共鸣 R-6 一并继承——**零返工**。
3. **叙事最准**：誓约圣铃的「第二人生」＝她放开的那盏灯，以**魔化形态**（暗涌/回流）回到手里（对应意象Ⅱ暗回流）。
4. **B 作为对称备选**：若主理人更看重「两个选择完全对称」，改用 B（轮刃也出魔化镜像），成本 +1 专武 +2 质变卡。

### 3.4 新增专武规格（照 gdd-exclusive-weapons §4 格式）

> 名称待主理人定名（下表给候选）；powerTag 见 §3.5 裁决点；数值全为**锚点区间**。

**「回涌」/「暗涌」/「散誓之环」**（候选名，取一） —— 誓约圣铃的魔化形态（自体领域 · 吸蚀）
- **定位**：以「暗回流」为动力的**自体领域吸蚀流**——她不再守着领域里的人（守誓者的辅助逻辑），而是从领域里**取**（以暗为食，对应圣铃「以圣辉予」的反面）。
- **powerTag（候选，见 §3.5）**：MOON（血月直照；代价＝理智侵蚀，正好写「放纵」）**或** BLOOD（血井暗流＝血术源头的暗回流）。默推 **MOON**。
- **手感归属**：B 环绕/领域（自体吸蚀变体）——与圣铃同族手感（「怎么操作」不变，共鸣 GDD 支柱 4 口径）。
- **基础形态**：常驻暗涌领域 110px，对敌 **4~6 伤 / 0.8s**（tick）→ 有效 DPS 锚 **11~14（自体口径）**；领域内击杀 → 自身回复 **1~2 HP**（以暗为食）；暗墨光域 + 回流粒子。
  - **DPS 口径说明（关键）**：守誓线合计 DPS ≈13~14（圣铃 6~8 自体 + 守誓者 ≈5~6）；魔化线**无守誓者**，故其自体 DPS 锚设为 **11~14**，把守誓者让出的份额**内化到自体领域**。这样「形变前后」角色内 DPS 差落在 **≤±15%**（R2-13 口径），不产生「形变即变强/变弱」的断层。
- **质变卡 1「涌升之势」**：领域半径 **+50%**（110→165px）；领域内击杀留下**暗痕** 3s（60px，**8 伤/s** + 减速 10%，上限 5 处）——扩玩法面（镜像长明灯阵/亡者灯引的思路，但以「取」为语义）。
- **质变卡 2「噬心回潮」**：领域内敌人被挂「噬心」**易伤 +15% / 6s**（走状态层）；自身 HP **<50%** 时 暗涌伤 **+30%**（低血强化，与葬仪巨斧「低血」设计同族但独立触发）——收身份钩子（「越近暗，越强」）。

**圣辉轮刃 `xw_cross`（保留，零改动）**：基础形态、质变卡 1/卡 2、衍生技「圣辉审判」、共鸣 R-6（圣火判词）在魔化线**全部继续生效**。

### 3.5 落选专武 → 衍生技（魔化线处置）

沿用专武模型铁律「落选专武＝技能的第二人生」（gdd-exclusive-weapons §1.1）。魔化线形变**不新建 2 选 1**，只在形变时按 §3.6 规整武器组，落选技按下表处置：

| 誓约圣铃 | 圣辉轮刃 | 圣辉审判 `dv_holy_judgment` | **原样保留**（不依赖守誓者） |
| 圣辉轮刃 | 誓约圣铃 | 誓约回响 `dv_requiem` | **转为魔化衍生技**：因守誓者已散，「守誓者立即回满/复活」失去对象 → 替换为**自体强化版**（见 §4 技能 a/b 归属） |

### 3.6 形变时武器组规整规则（消解 A 的不对称）

## 4. 主动技能（决策点 4 · 美术卡住的直接原因，本节最细）

### 4.1 技能数口径（先定，避免美术空等）

### 4.2 技能 A ·「暗潮回涌」（→ `hero-violet-fallen-skill-a`）

- **叙事动机（对应既成意象Ⅱ 暗回流）**：守誓者压了多年的暗，此刻**顺着她的身体回来了**。她不再把它压下去——她让它**流过去**（纵容，而非克制）。外观＝自体内向外的暗色涌潮。
- **机制（锚点区间）**：

| 字段 | 锚区间 | 单位 / 口径 |
|---|---|---|
| 类型 | 自体领域型（复合技） | — |
| 半径 | 220~260 | px（自中心向外扩张） |
| 伤害 | 30~45 | 单次（击中全部领域内敌人） |
| 击退 | 100~140 | px（位移型，非状态，走位类） |
| 自身回复 | 3~6 / 命中（单次上限 20~30） | HP（以暗为食，镜像圣铃治疗） |
| 附加（可选，走状态层） | 减速 20~30% / 2s | CC 走 gdd-status-effects |
| CD | ≥20 | s（复合技锚） |
| 占比锚 | 15~18 | %（gdd-exclusive-weapons §⑤ 放宽口径） |

- **动作意图**：**收 → 张**。双臂先向胸前/身侧收拢、上身微沉（蓄），随即向画幅两侧**猛地摊开**、上身后仰——暗潮自体内向四周涌出。
- **给美术的画面描述（可直接开工）**：
  - **出现**：**角**（两只，**根黑尖红**，形锚 F-3）；**长卷墨发**（F-3，不比成片长）；**墨裙为最大色块**；**高叉红衬**（唯一暖色 accent）；**长蕾丝手套止于前臂（上臂有断）**；**红高跟**。

  - **描边语言**：玩家侧剪影＝**冷青 2px 描边**（content-id-frame-map §1 玩家侧惯例）；红仅作小面积 accent（≈10~20% 像素，听 E1 色键「角红、肤在脸/臂/叉」）。

- **机制（锚点区间）**：

| 字段 | 锚区间 | 单位 / 口径 |

### 9.2 边缘情况（≥3 类，锚）

1. **资源/状态类**：形变瞬间在途弹体/领域沿用旧形态结算完毕（原子切换，同共鸣口径）；形变时若守誓者为墓碑态 → 墓碑立即消散、转化为暗回流演出（不复活）；形变时若玩家正在释放技能 → 输入锁 100ms 后切换。
2. **叠加/触发类**：回涌领域击杀回 HP 与治疗效能属性节点（A-9）叠乘需设上限（防吸蚀滚雪球，锚：单次上限）；「噬心回潮」低血 +30% 与葬仪狂欢类低血加成**互不叠加**（不同 owner）；形变与圣物释放同帧 → 演出排队、不叠。
3. **交互类**：抉择窗口开启时玩家正在 Boss 战 → 抉择提示**延后**至非 Boss 战（防打断终局演出）；纯局内模式（gdd-talent-tree §3.8）下形变仍可用（属局内规则，不受属性层开关影响）；断线重连 → 形变状态落档恢复。
4. **流程类**：玩家拒绝抉择 → 本局纯守誓线，不再弹出（不重复骚扰）；抉择确认后不可回退；形变后无法再召唤守誓者（守誓者召唤 CD 语义作废）。

### 9.3 设计红线（反例）
