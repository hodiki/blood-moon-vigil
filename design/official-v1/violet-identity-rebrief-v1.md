# 薇奥莱双线形象 · 初步调整方向（转交文案）

> 2026-09-06 · 主理人  
> 用途：给叙事改故事。不是定稿称号，也不改玩法数值。  
> 美术：形象套已按本文重开，现开剪影层。旧锁只作对照。开工卡：`hero-violet-repackage-job.md`。

## 1. 为什么改

守誓线现在读成「虔诚天主教修女」（头巾全裹、圣袍 A 字、十字/念珠、持烛祈祷）。魔化线容易读成「同一人脱袍堕圣」。上线（Steam 等）要避开把玩家做成宗教职份、或把欲望线做成亵渎圣职。

**不是取消双线，是换一套对立的衣服与词。**

---

## 2. 必须保留

1. **守誓 / 魔化仍是一体两面**，反差要强：有伴 vs 独行，克制 vs 欲望，护光 vs 近暗。都是她自己选的，不是血月赏的。
2. **两线禁止同框**（选人、立绘、宣传）。
3. **守誓者仍在守誓线**：有一个跟她走的守护实体；魔化线它不在。来源改成「她说出口的誓约自己站起来」，不要「修女祷言凝成圣骑士」。
4. **烛仍可留给守誓线**，但是「那夜带出来的东西 / 她守着的一点光」，不是祭礼、不是圣器。魔化线仍不持烛。

---

## 3. 守誓线：弱虔诚，留一点旧影子

对标（气质，不是抄）：有的作品里「修女」只剩头巾或名字，其余已是世俗夜行装。

| 要 | 不要 |
|---|---|
| 世俗夜行 / 守夜会自己的人 | 天主教修女职份、修会、圣职 |
| **最多一件**轻痕迹：例如一块头巾或额巾，占剪影，不当全身 | 头巾全裹 + A 字圣袍 + 十字 + 念珠 + 合十/祈祷脸 |
| 克制、守约、护着一点光、身边有守护者 | 虔诚、安魂、侍主、唱诗 |
| 烛 = 私人物件 | 烛 = 圣坛、弥撒、为死者做礼拜 |

远看应先认出「带光的女人 + 高个子同伴」，不要先认出「修女」。

---

## 4. 魔化线：奇幻欲魔，不是堕圣

| 要 | 不要 |
|---|---|
| 世俗或奇幻里的女性恶魔 / 半魔 / 魅魔 / 欲魔 | 堕落修女、撕圣袍、倒十字、亵渎祭服 |
| 反差靠体态与气质（收腰、独行、无同伴、无烛） | 反差靠「把修女衣服脱掉」 |
| 角、夜色衣装可以有 | 头巾残片当圣物、腰间修女绳结、颈圈当倒置头巾 |

她和守誓是**同一个人的两条路**，不是「圣女白天、夜里亵渎」。

---

## 5. 文案请一并改的口（旧稿对照）

出处：`narrative-framework.md` §3.3 / §4A.2 / §5 / §6。下列是**旧说法 → 改时请避开什么**。新称号、新武器名由文案起，本文不定死。

| 旧 | 改时请 |
|---|---|
| 称号「夜祷修女」 | 去掉「修女」。身份改成守夜会里守约、执光的人 |
| 「血教堂幸存的执烛修女」 | 可以仍从那座沦陷的地方活下来，但她不是圣职 |
| 安魂曲、祷言、侍主、弥撒语感 | 改成誓约、守夜、送行、她自己点的光 |
| 濒死「主……不，月亮不会怜悯。」 | 删掉「主」这条例外。§6 可恢复「不出现宗教实指」 |
| 死亡「让安魂曲……替我唱完。」 | 换不礼拜的收束 |
| 守誓者「祷言为薪」 | 改成誓约 / 她说出口的话 |
| 专武「安魂圣铃」「圣辉十字」 | 机制可留（铃域治疗、投掷爆发）。**名字去掉安魂 / 十字 / 圣职感** |
| 入场「尘归尘，血归血。」 | 偏葬礼经文，建议换 |

**世界里可以仍有堕落的教堂与主教（尼禄）。** 那是反派的腐朽圣职，用来对照；玩家薇奥莱不再当修女。

力量标签 HALLOWED / 圣辉：可继续当守夜会自己的光，不要写成教会神恩。

## 6. 对立怎么写（给故事用的一句话）

- **守誓：** 她选择守住对自己说出口的约，带着一点光，和自己唤来的守护者同行。  
- **魔化：** 她选择放下那约，光与同伴都不再跟，独行，走欲望与半魔那条路。  

反差在选择与同行者，不在「圣 / 亵」。
