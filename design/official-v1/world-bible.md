## 1. 一句话世界观

**血月之下，死者苏醒、野兽狂化、血族复苏；守夜人举灯持银，撑过这一夜，等黎明。** 这个世界的超自然力量几乎都来自那轮"流血的月亮"——它不只是一场天象，而是一道被遗忘的封印正在渗血。几乎，但不是全部：唯有人自己点燃的微光不属于它（§4.5 人源之力）。

## 2. 血月起源（核心神话）

千年前，血族之王 **阿拉里克（Alaric）** 屠尽北境三城，以万千亡魂的血浇灌永夜。十二位守夜人（the First Vigil）将他钉死在月下荒原，以十二盏圣辉提灯为锁，把他封入地脉之下。血王临死前诅咒月面——**"我将回到月亮的眼里，用我的血喂养这世界，直到月亮落下。"** 他望向月亮，血顺着月光逆流而上，浸入月面——**月光从此成为诅咒的通道**：照亮之处，皆为血月领域。死者自墓中爬出，野兽获得月光之力，血族从长眠中苏醒。

**圣辉机制**：封印仪式本身是"滤月装置"——十二盏提灯既是锁，也将月光"洗净"为圣辉存入灯中。圣辉是有限资源（提灯余晖），每次守夜都在消耗封印的余力：这是千年后封印渗血、守夜会衰微的根因。

血王的诅咒常驻月面，随月相起伏：月亏时为暗红残月，亡潮零星；**唯有月圆之夜血月盈满——"血月盈满之夜"（Blood Moon Vigil，即游戏中的一夜）**，封印最弱、亡潮最盛。守夜会的职责：在每一夜血月盈满时，守住三处封印节点，直到黎明。

> 设定主线（主导论）：**血月是这个时代压倒性的力量源**——亡潮、兽化、血术，皆源于它；**月光是血月之力流通的媒介**（圣辉是经滤月仪式净化的月光、血术是主动攫取的月光）。但血月**不是唯一的源**：极少数属于"人自己的力量"独立存在——誓约凝成的光、殉道者遗物中的余温、更古老时代留下的契约（§4.5）。它们微弱、稀有、以自身为薪，不借血月之力。守夜，正是人以自身之微光对抗月亮之血。

## 4. 力量体系（血月之力法则）

> 绝大多数力量源于血月，形态与代价各不相同；此外存在微弱的人源之力（§4.5）。**角色的力量来源决定其专武与衍生技的语义**——这是内容设计的世界观约束。

### 4.2 相生相克（设计约束）
- **银器克制血族，圣辉克制亡者与骸骨，兽血撕咬血术，月光是双刃剑，骸骨与亡者同源共鸣**。
- 每条规则都是**设定标签**，落到数据：武器/敌人打 `powerTag`（`SILVER/HALLOWED/BEAST/BLOOD/MOON/BONE` 六标签），克制表可配置，供后续增伤/减伤/免疫扩展（T1 词条），1.0 不启用克制数值（防数值膨胀），仅作命名与视觉语义约束。

### 4.3 力量与数值映射原则
1. 任何新角色/武器/敌人必须声明 `powerTag`（六标签，§4.2），无标签视为设定缺失（consistency-anchors A2 检查项）。
2. 角色力量来源 → 双专武语义 + 衍生技语义（如守夜人=破旧提灯（MOON）×圣徒左轮（SILVER），衍生技为落选专武转化）。
3. 敌人力量来源 → 视觉编码（色相/特效）与行为（如血术怪带血池特效、亡灵带幽光、掷骨者为堕落圣辉的反转体——腐朽圣职的形态）。

### 4.4 力量的代价（借贷逻辑）
血月之力是"借来的力量"，使用必有代价，各系统一"借贷-偿还"逻辑（轻叙事只落一句语义，不做数值）：

| 力量 | 代价 |
|---|---|
| 圣辉 | 消耗提灯余晖（封印的存量）；誓约则**以自身为薪**（守约的坚持与心血） |
| 银器 | 消耗银（守夜会锻造，有限） |
| 兽血 | 失控风险（狂化过度则兽性盖过人性） |
| 血术 | 消耗自身之血 / 献祭他人 |
| 月光 | 理智侵蚀（过度则失控） |
| 骸骨 | 死气浸染（久用者渐似亡者） |
| 腐朽圣职（反转体） | 以他人为薪（腐化的圣职靠吸食信徒维系——血主教、掷骨者、忏悔者语义；反派侧，用来对照玩家侧的守约） |

> 设定含义：血月系力量都在"借血月的力"——圣辉是借来再净化的、血术是主动攫取的、兽血是被迫承受的，代价不同，来源同根（呼应 §8 红线 1）；人源之力不借血月，代价全在自身（§4.5）。
> **血月方阵**：血月之力驱动多体的协同形态（九阵，enemies-v3）——维系方阵的消耗由血月承担，破阵即断供（解散机制的世界观依据）。

### 4.5 人源之力（主导论下的窄门）

血月之外，人自己也能点燃力量——微弱、稀有、**代价内在（以自身为薪）**，不借血月之力：

- **誓约**：人说出口的誓言可以凝成真实的力量——不是教会的神恩，是守夜会自己的光，以坚持为薪。其最纯粹的形态即**守誓者**——薇奥莱在血井边说出口的誓约，自己站了起来：誓约的另一方是它自己，誓言被放弃，它便散去（§9 薇奥莱双路线的叙事锚）。**但立约之地是血井——血月的暗流顺着誓约渗进了它的骨缝，被它死死压在体内：守誓者既是守护，也是挡在她与血月之间的堤。**若誓言被放弃、堤散了，它扛了多年的暗会落回谁身上——这是魔化路线的伏笔与支撑（展开待玩法侧定稿，裁决⑧调整空间不变）。誓约的回响亦能及于亡者——响应叛逃者号角而来的**月狼**（自愿赴约的月下亡魂）即属此类。圣职会腐化：以他人为薪的**腐朽圣职**是其反面——血主教、掷骨者、忏悔者属此列（反派的堕落，只属于血廷与被血月扭曲者，玩家侧不再使用圣职身份）。
- **殉道者遗物**：千年来战死的守夜人（守夜会称**殉道者**）遗物中残存的余温。血月造物觊觎它——宝藏护卫方阵劫掠的「殉道者的遗物匣」、精英宝箱「殉道者的行囊」皆源于此；守夜会以命护送。（GDD 侧旧名「殉道者的圣髑匣」待复核同步——"圣髑"为宗教实指。）
- **古老的契约**：比血月诅咒更早的约定偶有残存，今夜罕见显形。**设定口从紧**：人源之力不得大规模扩张，新增人源实体必须在本圣经登记（来源/代价/边界）并评审（§8 红线 3）。

### 4.6 圣物与共鸣

- **圣物（Relics）= 有故事的奇迹**：守夜千年间被讲述、被铭记的瞬间凝成的力量结晶。当血月的意志降临（Boss 出场），那些故事会回应守夜人——今夜定稿五件：**月蚀之陨**（MOON，月亮眨了下眼）、**血海退潮**（BLOOD，血井也有潮汐）、**十二灯誓约**（HALLOWED，初代十二人的誓词仍记得）、**银潮汐**（SILVER，银炉最后一炉银）、**狼灵巡夜**（BEAST，有狼拒绝履约血月契约）。每局至多 2 件、释放 1 次——奇迹不是武器，是故事在替守夜人出手。
- **共鸣（Resonance）= 同根之力共振**：两件承载同一词根之力的器物相遇时，形态互相改造（8 对共鸣，gdd-resonance）——同为月之光、血之契、兽之誓的器物会"认出彼此"。命名走 §7 词根（守夜环灯、银潮轮舞、血月回旋、猎月贯钉、圣域壁垒、圣火判词、葬仪断罪、狼群誓约；"圣火判词"为去宗教化改名，GDD 侧待同步）。

## 5. 时间线（简）

| 纪元 | 事件 |
|---|---|
| 千年前 | 血王阿拉里克屠城 → 十二守夜人封印（滤月仪式）→ 血月诅咒常驻月面 |
| 千年间 | 守夜会世代守夜；血族蛰伏血教堂地下血井；兽群退入狼穴 |
| 数年前 | 封印千年渗血、圣辉变淡、人手失血，守夜会衰微；教堂失守，血主教尼禄夺占血教堂；狼王芬里厄统一狼穴诸部 |
| **今夜（游戏）** | 月圆之夜，血月盈满，三处封印节点同时告急：墓地/教堂/狼穴。玩家扮演守夜成员，各守一处 |
| 黎明 | 若守住，血月暂退、封印加固；若失守，血王苏醒，世界永夜（败北叙事） |

> 设计说明：**每一局 = 同一天夜里的一次守夜**。时间线不随玩家进度前进（轻叙事原则：时间线静态、玩家反复守同一夜）。
> **局外成长 = 滤月余辉的跨夜传承**：滤月装置千年运转，月光被洗净为圣辉**存入灯中**——那是封印的存量，守夜人不得动用；但装置运转时有微光自灯沿**滴落**，凝成余辉结晶——不属封印、不耗存量，是每一夜守夜自然滴落的馈赠。守夜会世代收集余辉，铭刻进继任者的灯与血（质变=铭刻，属性=浸染，gdd-talent-tree）。图鉴与解锁属于"守夜会的记录"。

## 6. 关键地点（3 地图 + 1 枢纽）

### 6.1 月下墓地（Moonlit Graveyard）—— 地图 1 · 基准图
- **设定**：千年前封印血王的荒原一角，如今是守夜会驻地外的乱葬岗。墓碑如林，枯树如指。血月第一缕光最先照到的地方。
- **封印节点**：墓地中央的封王石冢（Boss 战舞台）。
- **视觉锚点**：石板 + 草地双材质（继承 Demo）、墓碑/枯树/断墙障碍、幽蓝鬼火点缀。
- **玩法身份**：标准压力曲线基准图，教学向，生成器参数为基线。

### 6.2 血教堂（Blood Cathedral）—— 地图 2 · 高密度回廊
- **设定**：北境主教堂，血主教尼禄叛变后将其献祭给血廷。圣坛之下是千年前血王开凿的血井——血术的源头。彩窗映着血月，圣水早已干涸成锈。
- **封印节点**：地下血井井口（Boss 战舞台）。
- **视觉锚点**：室内石砖、暗红地毯、立柱/长椅/祭坛高密度障碍、彩窗血月投影（装饰光斑）。
- **玩法身份**：高障碍密度回廊 → 走位拉扯更重；环境危险区 = **血池**（踩上减速 + 持续伤害，红色即危险）。

### 6.3 狼穴（Wolves' Den）—— 地图 3 · 开阔山地
- **设定**：北境山脊的兽群巢穴。狼王芬里厄在此以兽血号令群狼。岩壁上的爪痕是狼群的血月契约，倒木与巨石间藏着兽骨。
- **封印节点**：山脊狼王祭坛（Boss 战舞台）。
- **视觉锚点**：山地岩地（暗灰岩 + 暗绿草）、巨石/倒木障碍、兽骨装饰、狼嚎氛围。
- **玩法身份**：开阔 + 障碍散布，敌人整体移速加权 → 更依赖机动与主动技位移。

### 6.4 守夜驻地（Vigil Outpost）—— 局外枢纽（非战斗）
- **设定**：守夜会最后的驻地，火塘与银炉。北境人类已退缩入高墙之城，今夜城墙外的世界归血月所有——这里是城墙外最后的火塘。会徽 = **灯与银的纹章**（灯为芯，银为骨），见于每一面城垛与每一件制服。图鉴与局外解锁在此叙事化：击杀记录 = 守夜日志，角色解锁 = 同袍入队，天赋树 = 滤月余辉之壁。

## 8. 设定一致性红线（供 consistency-anchors 引用）

1. **血月主导**：血月是这个时代压倒性的超自然源头，亡潮/兽化/血术/滤月圣辉皆可归因于血月或其变体（月光是流通的媒介）；**人源之力**（§4.5：誓约/殉道者遗物/古老契约）是唯一的例外窄门——微弱、稀有、代价内在。
2. **力量来源可追溯**：角色/武器/敌人必须声明 `powerTag`（六标签）且与表现一致；跨标签使用须有设定依据（如半血裔卡珊德拉驭 BLOOD 系——以血驭血正是她的存在方式；守夜人破旧提灯为 MOON——灯是滤月装置残骸，容器属月、灯中圣辉属光）。
3. **新增力量源须评审**：不预设"不存在其他体系"，但任何人源之力或体系外新设定（新标签/新源）必须在本圣经登记（来源/代价/边界）并评审——防止力量体系失控，人源之力不得大规模扩张（§4.5 设定口从紧）。
4. **时间线静态**：所有内容设定在同一夜内成立，不引入"前一局发生的事改变世界观"（局外成长 = 滤月余辉的跨夜传承，属守夜会记录，不改变血月夜本身）。
5. **命名语义一致**：新内容命名必须落在 §7 词根表内，否则标注偏离并评审；**面向玩家的叙事文本（图鉴/档案/播报/词条）只出现可读中文名，编号代称（Q-b/R-1/g1_1 等工程 ID 与裁决编号）禁止入文**，编号仅存在于文档的 key/ID 映射列。
