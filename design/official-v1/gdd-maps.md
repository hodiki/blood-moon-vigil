---

## ① 设计目标

3 地图 = 3 套生成器参数与 Boss（支柱 4 可检验含义③），跨地图重开动机成立。地图差异核心是**玩法身份**（world-bible §6）：
- 月下墓地 = 基准·教学向（标准压力曲线）
- 血教堂 = 高密度回廊 → 走位拉扯更重，主动技破局价值高
- 狼穴 = 开阔山地 → 机动权重高，位移型主动技价值高

---

## ② 玩家价值

- 同一角色跨地图有不同挑战侧重（走位/机动/清屏），重开动机成立。
- 地图叙事身份清晰（封印石冢/血井/狼王祭坛），Boss 战舞台有仪式感。
- 障碍/环境危险提供「拉扯资源」：墓碑挡弹、立柱绕柱、血池逼走位——走位不再只是绕着怪跑。

## ③ 系统规则与数值规格

### 3.0 通用规则（继承 Demo + 细化）

| 项 | 规格 |
|---|---|
| Tile | 64×64 2 次幂；地面双材质（石板+草地）共享，各图叠加主题 tile |
| 边界 | 有限边界（矩形），出界碰撞阻挡（玩家/敌人均不可出界） |
| 障碍 | 圆形碰撞体（`obst-*` 帧），玩家被阻挡；敌人普通型被阻挡、相位/空中型无视（§敌人⑥.7） |
| 障碍密度 | 以「每 1000² 障碍数」表达（见各图）；生成时按种子散布，禁重叠/禁贴出生点（距出生点 ≥200px） |
| 出生 | 玩家地图中心出生；敌人屏幕外环带（距玩家 600–900px 桌面 / 500–800px 移动） |
| Boss 舞台 | 地图中央 Boss 战区域（清场后登场，半径 320px 净空） |
| 环境危险 | 仅血教堂血池；危险区编码 = 红斜纹 + 闪烁 + 白描边（R-C 裁定，与地毯装饰区分） |

### 3.1 地图 1 · 月下墓地（map_graveyard）

| 项 | 规格 |
|---|---|
| 尺寸 | 3000×3000（继承 Demo） |
| tile | 石板 + 草地双材质（共享帧 `tile-ground`/`tile-grass`）+ `tile-grave-soil` 墓地土覆盖 |
| 障碍 | 墓碑 `obst-grave-tomb` / 断墙 `obst-grave-fence` / 枯树 `decor-grave-tree`；**中低密度 12 座/1000²** |
| 装饰 | 鬼火 `decor-grave-candle` / 兽骨 `decor-grave-bone`（纯装饰，无碰撞） |
| 环境危险 | 无 |
| 生成器覆盖 | **基准曲线**（`budget(t) = 1.2×(1 + 1.2×t/360)×(1 + 0.3×sin(2πt/60))`）；阶段表 S1/S2/S3 默认 |
| Boss | 血月尊者（boss_1，HP 4000） |
| 解锁 | 默认 |
| 玩法身份 | 基准·教学向：压力曲线标准、无环境危险、障碍低密，玩家先学「走位 + 升级 + 主动技」基础 |

### 3.2 地图 2 · 血教堂（map_cathedral）

| 项 | 规格 |
|---|---|
| 尺寸 | 2800×2800 |
| tile | 室内石砖 `tile-church-stone` + 暗红地毯 `tile-church-carpet`（装饰语义，低饱和 α0.35 无闪烁）+ 彩玻光斑 `decor-church-glasslight`（装饰，2 帧微闪可选） |
| 障碍 | 立柱 `obst-church-pillar` / 长椅 `obst-church-bench` / 祭坛 `obst-church-altar`；**高密度回廊 22 座/1000²**（约为墓地 1.8 倍） |
| 装饰 | 烛台/圣像（复用 `obst-church-*` 变体，纯装饰） |
| 环境危险 | **血池**（`decal-bloodpool`）：随机 8~10 处，半径 120~180px；踩上减速 30% + 持续伤 8/s；红色斜纹 + 0.8s 闪烁 + 1.5px 白描边（危险编码，R-C 裁定） |
| 生成器覆盖 | ① 出生环带缩近 500–800px（桌面；移动 420–680px）——回廊内敌人入场可见时间相近；② **快速怪权重 ↑**：S2 wolf 0.17→0.22、S3 wolf 0.33→0.38（血蝠/血犬类提速） |
| Boss | 血主教·尼禄（boss_2，HP 4500） |
| 解锁 | 通关地图 1 |
| 玩法身份 | 高密度回廊 → 走位拉扯更重，主动技破局价值高（提灯闪耀/安魂曲的眩晕减速在高密回廊收益放大）；血池逼走位（危险区 = 拉扯资源） |

### 3.3 地图 3 · 狼穴（map_den）

| 项 | 规格 |
|---|---|
| 尺寸 | 3200×3200（最大，开阔） |
| tile | 岩地 `tile-den-earth` + 暗绿草 `tile-den-grass`（低饱和暗绿，与共享草地同色系） |
| 障碍 | 巨石 `obst-den-rock` / 倒木 `obst-den-log`；**中密度散布 14 座/1000²**（较墓地略高，但地图更大更开阔） |
| 装饰 | 兽骨 `decor-den-bone` / 篝火 `decor-den-fire`（2 帧可选）/ 尖刺 `decor-den-spike`（装饰，非危险） |

> **R-C3-RULING 口径注（Boss 移速）**：×1.08 为生成器「敌潮构成」覆盖（E3-S7，作用于 spawner 侧敌潮单位），**不含 Boss**——Boss 移速是独立设计常量（enemy-panel.test 断言固定值）：① Boss 为 6:00 固定舞台战，移速属 BOSS 面板设计而非敌潮参数；② boss_4 血月化身可出现在任意图，若 Boss 吃地图系数会造成同一 Boss 跨图强度漂移（化身 40 vs 43.2）。后续若要强化狼穴 Boss 压迫感，走单点调芬里厄基础移速（32→34），不套全局系数。
| Boss | 狼王·芬里厄（boss_3，HP 4200） |
| 解锁 | 通关地图 2 |
| 玩法身份 | 开阔 + 快速野兽 → 机动权重高，位移型主动技（血影突袭）价值高；玩家靠移速与障碍脱战 |

## ⑤ 平衡与曲线

- 三图 Boss HP（4000/4500/4200）差 ≤13%，同一成型 DPS 下战时长 61.8/69.6/64.9s，均落 60~90s 判据（sim-verify §7）。
- 教堂快速怪权重 ↑ 拉高前中期压力（血蝠/血犬高速逼近），但回廊障碍提供绕柱资源——压力与资源同步上升（险而不绝望）。
- 狼穴移速加权 ×1.08 + 野兽构成 ↑ 拉高机动需求；玩家移速成长（+4px/5级）与位移主动技构成对价。
- 障碍密度差异目标：教堂回廊逼「绕柱走位」，狼穴开阔逼「脱战机动」，墓地基准逼「基础拉扯」——三种走位语汇。

## ⑥ 边缘情况与容错

1. **障碍贴出生点**：障碍生成种子禁距出生点 <200px（防出生即卡死）。
2. **障碍重叠**：生成时相邻障碍最小间距 ≥64px（防叠碰撞体穿模）。
3. **血池与障碍重叠**：血池优先于障碍（危险区覆盖障碍位，不生成重叠碰撞）。
4. **相位怪穿障碍**：亡魂/血蝠忽略障碍层（不对称规则，相位标记预告，敌人 §⑥.7）。
5. **玩家卡障碍角**：障碍圆形碰撞 + 玩家 14px 半径 → 最小过道 ≥64px（两相邻障碍间距），防卡死。
6. **Boss 舞台净空**：Boss 登场清场 320px 净空 + 0.5s 霸体（防 Boss 出生即被旧怪挤位）。
7. **双端地图**：同一地图数据双端共用；移动端出生环带缩近（入场可见时间对齐）。
8. **血池刷怪**：血池上不生成敌人出生点（防「池中怪」反直觉），但敌人可走入血池（玩家可利用）。

## ⑧ 验收标准

1. 3 地图尺寸/tile/障碍密度/Boss 与 §3.1~§3.4 表一致（埋点断言 `map-config.test`）。
2. 生成器参数覆盖生效：教堂快速怪权重、狼穴移速加权与基准差异可埋点验证（权重和 = 1.00）。
3. 血池危险区编码正确（红斜纹 + 闪烁 + 白描边），与暗红地毯装饰区分（视觉快照）。
4. 障碍生成种子可复现（同种子同布局）；无贴出生点/重叠/卡死通道。
5. 解锁流正确：墓地默认 → 通关解锁教堂 → 通关解锁狼穴。
6. Boss 战 60~90s 判据保持（三图 Boss 均达标，sim-verify 断言）。
7. 双端同屏上限生效；移动端 30fps+、桌面 60fps。
