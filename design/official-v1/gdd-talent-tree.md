## ① 概述

### 1.1 一句话定义
局外天赋树 = 守夜会的跨夜传承，叙事壳定名**「滤月余辉」**（GT-1）：每夜守夜滴落凝成的余辉结晶（货币），灌注为**质变铭刻**（改变「这一夜怎么开始」）与**属性浸染**（微调「这一夜怎么撑过」）。树结构 T3 混合形态（GT-3）：1 条全局主干（~26 节点，质变主线 + 属性干支）+ 每角色 3~4 节点支线，总锚 ≈40 节点、总成本 800~1000 点 ≈ 28~35 局。

## ② 设计支柱

1. **顶层目标 = 用户正反馈循环的局外起点**：每一局结算都产出余辉 → 点亮节点 → 下一局开局即携带已构建的 build 底座（质变节点改变开局阵容、属性节点抬高底座）→ 玩家感知「明显变强」→ 由怪物域重做承接难度提升 → 战胜 → 循环。本系统的职责是让循环的「变强」一端**每 1~2 局就有可感知的推进**（前 10 局节奏判据，§⑩-3）。
2. **质变主承担快感、数值克制**：局外成长的快感来源 = 结构性质变（改变开局阵容/流程/规则的 11 个质变节点位）；数值层 = 小颗粒 + 三桶总预算红线（R3，总口径 ≤10%）。**局外数值不与怪物域难度提升赛跑**——难度侧提升的空间不被局外数值平移侵占。
3. **与武器系统「全质变」支柱同构声明**：专武质变卡「全质变、非数值堆叠」（gdd-exclusive-weapons 支柱 2）↔ 本树「质变层/属性层」双层同构——质变层改结构与流程、属性层做克制的小颗粒微调，两层不许互相越界（反例红线 §⑦-2）。
4. **强度前提知情声明（硬依赖）**：节点 b 全额效力 + b/d/s1 共存（GT-7/GT-8）带来的开局强度是**有意的设计投入**，其成立前提 = 怪物设计/怪物生成重做大幅提升战斗难度（用户裁决）。本系统不以重新收紧数值来否定该裁决，而是登记硬依赖与降档预案（⑨-1）。

## ③ 系统规则

### 3.1 树结构（T3 混合，GT-3）
- **构成**：全局主干 ~26 节点（树根 1 + 质变 10 + 属性点位 15）+ 角色支线 4 × 3~4（锚 14）→ **总锚 ≈40 节点**。
- **深度 ≤4 层**：树根（层 1）→ 质变主枝（层 2）→ 分支展开（层 3）→ 枝顶（层 4）。
- **每层宽 ≤3 个可点亮位**；层 2 质变主枝 5~6 枝（质变节点挂载位）。
- **防跳点门槛（锚，待模拟）**：点亮条件 = 父节点已点亮 **且** 本层累计已消耗点数达门槛——层 2 门槛 30 点 / 层 3 门槛 120 点 / 层 4 门槛 260 点。
- 属性节点可重复点亮 2~3 层；质变节点单次点亮、不可重复（Q-f 三节点为结构串联，见 §④-1）。

### 3.2 节点计数口径（全局主干 26 = 下表之和）
| 类别 | 数量 | 明细 |
|---|---|---|
| 树根 | 1 | Q-a（默认习得，0 点） |
| 质变节点 | 10 | Q-b / Q-c / Q-d / Q-e / Q-f1 / Q-f2 / Q-f3 / Q-s1 / Q-s3 / Q-s4 |
| 属性点位 | 15 | 10 类型铺位（高价值类型双点位：伤害/攻速/生命/磁力/经验获取） |
| **合计** | **26** | + 角色支线 4×3~4（锚 14）≈ **40** |

### 3.3 节点成本锚（待模拟）
| 类别 | 单价锚 | 说明 |
|---|---|---|
| 树根 Q-a | 0 | 宿主节点，默认习得 |
| 质变节点 | 40~50/个 | 单次点亮 |
| 属性节点 | 10~15/层 | 按 purchases 层累计（全树属性层数合计锚 23 层） |
| 角色支线节点 | 15~25/个 | 含顶点「同袍之诺」 |
- **总成本校验**：≈10×45 + 23×12 + 14×20 ≈ **950~1050 → 落 800~1000 锚区间**（配置断言 §⑩-1；分布值为锚，总区间为验收口径）。

### 3.4 货币：功绩点改造（GT-4 + GT-2）
- 获取公式**沿用不变**：存活 +1/30s、击杀 +1/50、通关 +10、首杀 Boss/精英 +2/只、化身 +5（merit.ts `calculateMeritPoints` / gdd-codex §3.4），单局典型 **28~32 点**。
- 更名**「余辉」**（GT-1 叙事壳定名；工程侧 save.meritPoints 管线复用，更名止于文案与 UI）。
- 全树 800~1000 点 → **约 28~35 局解锁全树**（锚点待模拟）。
- 通关失败局仍产出（存活 + 击杀），挂机躺平局产出 ~20 点——长线节奏下限兜底。
- ⚠ **BUG-5 联动标注**：功绩账本设计 28~32/局 vs 外测 +1/局，待清档重采裁决（v0.5-summary / r3-test-plan T-F43）。若裁决确认产出远低于设计值，**修复优先级 = 修获取公式（工程）> 调节点成本表**；节点成本表在 BUG-5 关闭前不做定版（⑨-3）。

### 3.5 与功绩体系的替代关系（GT-2 = W1）
天赋树**完全取代**功绩 4 加成：功绩点改造为树货币（§3.4）；旧 4 加成数值**不沿用**，按对应属性节点重新核算进三桶预算（去向表见附录 A-3）；「最多装 2」限制自然消解为树前置结构；纯局内模式开关保留（口径 §3.8）。

### 3.6 属性红线：R3 三桶总预算（GT-5）
- **伤害类**（攻击/伤害/攻速/冷却折算 DPS 等效）合计 **≤8%**。
- **生存类**（生命/移速/治疗效能折算承伤等效）合计 **≤6%**。
- **节奏类**（经验获取/磁力/拾取半径）**不计入强度红线**（沿 gdd-codex 磁力裁决口径）。
- 合成对成型强度影响 **≤10%**（沿旧红线总口径演进为分桶执行）；工程做配置断言（沿 `allMeritBonusesWithinRedline` 惯例改 tree 版，§⑩-2）。
- **预留解耦接口**：树加成不随难度参数放大（难度联调挂账前提，R1 处置表 #5 义务）。

### 3.7 洗点规则（GT-6）
**免费洗点、下局生效**。所有重配发生在进图前，无平衡风险；战斗中树入口禁用；洗点即全量返还已消耗点数（spent 重算）、节点状态清空待重配。惩罚性收费方案否决（R1 B2 论证维持）。

### 3.8 纯局内模式（GT-11，状态标注）
- **现行口径（暂全开）**：开关开启时**关闭属性层全部加成**（`computeTreeApplication` 属性段返回空），**质变节点保持生效（全开）**——质变层已取代旧局外规则成为基准线，平衡基准 = 质变全开 + 属性全关。
- ⚠ **状态标注（GT-11 原文）**：纯局内模式整体设计**待商榷、后续可能去除**；当前保留开关作为 QA 兜底（gdd-codex §⑧ 标准 7 用例不受影响）。去留裁决挂账，不在本 GDD 定版范围内。

### 4.1 质变节点（10 + 树根，共 11 位）

**Q-a · 认灯（树根，默认习得，0 点）**
- 效果：宿主节点——所有角色默认已点亮、永不熄灭。即专武 GDD §3.1 开局流程（角色选定后、进图前 2 选 1、落选转衍生技、本局不可反悔）。
- 边界：不承载可关断效果；是「质变层」的定义样例；纯局内模式不摘除树根（专武选择属局内基准规则，GT-11）。

**Q-b · 伴灯（40~50 点，层 2）**
- 效果（GT-7 = **全额**，覆盖 R1 50% 建议）：开局自带所选招专武的**配对共鸣通武**（8 专武 ×1 通武映射 = 共鸣 GDD §④ R-1~R-8），以**未配对普通形态全额效力**入场；钥入池（P2）后自动升格共鸣形态——与共鸣 GDD §3.1 双条件机制零冲突（需工程确认开局挂载走 WeaponSystem 既有初始化路径）。
- 边界：与 Q-d 叠加见 Q-d（GT-8 共存口径）；开局强度表与硬依赖见 ⑥-2 / ⑨-1。

**Q-c · 残焰托誓（40~50 点，层 2）**
- 效果：HP 归 0 时复活一次，恢复 **50% 最大 HP**；复活瞬间 **1.5s 无敌帧**（锚）+ 周身击退 100px（锚）——防「复活即死」循环。
- 判定序（GT-9 = B4-Q-c 落档，详表 ⑥-3）：濒死护盾（未死）→ 圣物级免死（接口预留）→ **天赋复活（最低触发优先级）**。同帧多来源不叠用。
- 边界：墓碑形态（守誓者）不受影响；Boss 战允许触发（演出优先，同圣物惯例）。

**Q-d · 携行旧兵（40~50 点，层 2~3）**
- 效果（GT-8 = **不限、共存**，覆盖 R1 互斥建议）：树内配置页预选 1 把**已解锁**（图鉴首次获得过）的 14 通武之一，进图立即拥有（普通形态）。预选**独立于专武选择**，可与 Q-b 叠加（开局 3 武器）。
- 边界：若预选 = Q-b 自带配对通武 → **同名通武不重复发放**，预选槽实时校验置灰并提示（不退点，重选）；预选存档位持久化（save 新字段）；未解锁通武预选框灰显；断线重连沿用专武选择落存档惯例（专武 GDD §6.1-4）。

**Q-e · 再燃（40~50 点，层 3，前置 = Q-c）**
- 效果：Q-c 复活次数 1→2；第二次复活恢复 **30% 递减**（GT-9 落档 R1 推荐口径，弃 50% 平坦——长线容错边际衰减）。
- 边界：两次复活共享同一判定序末位；不做独立免死源。

**Q-f1/f2/f3 · 首猎之赏（三节点串联，GT-10）**
- 效果：每局**首个**精英被击杀时，获得不消耗 XP 的**额外三选一 offer**（获得后立即结算，非暂存券）。f1/f2/f3 各 +1 次，**前置递进 f1→f2→f3**，三条枝上独立节点（否决单节点三层——属数值堆叠；否决单节点复选 3 次）。
- 三节点全点亮 = 每局首个精英击杀连得 3 次 offer（≈ 白送 3 级的节奏收益）。
- 边界：仅每局首个精英触发（精英约 10/局，防雪球）；落在中期（首精英锚 90~150s，S1 末~S2 初），比开局类节点安全（锚：3 offer 对 6min 成型强度 ≤3%）。

**Q-s1 · 银炉预热（40~50 点，层 2，GT 补充采纳）**
- 效果：开局后 **30s 内伤害 +20%、攻速 +20%**（限时窗口，窗口结束即失效）。
- 设计意图：最直接的 H2 平台期对冲；限时 → 对 H5 雪球零贡献。与 Q-b/Q-d 共存（GT-8），窗口内乘区独立结算。

**Q-s3 · 遗言余烬（40~50 点，层 3，GT 补充采纳；图鉴轻联动 L-1）**
- 效果：每局**首次 HP 归零事件**时原地掉落一簇余烬宝石（锚 30 XP）。被复活来源救回 → 原地即时拾取生效；无复活来源的终局死亡 → 宝石折算为结算页 **+2 余辉**（锚，与首杀精英同级——「遗言化作传承」，保证节点在任意 build 下均有回报）。
- 前置：图鉴「血月化身」条目解锁（§⑤-3 L-1）。

**Q-s4 · 双灯并祀（40~50 点，层 3，GT 补充采纳）**
- 效果：开局专武 2 选 1 演出确认后，可**消耗本局 1 次升级三选一机会**，换取落选专武的衍生技强化卡（P4）提前至 S1 段即可被抽到（P4 窗口前移感知，**非机制改动**——仅前置该卡可出现窗口 + 卡面预告）。
- 边界：消耗即锁定不退回；与池 v3「P4 窗口错过不再出现」条款不冲突（不改窗口本体，仅提前预告——实施前与池 GDD 措辞复核登记）。

> **Q-s2 守夜旗语：不采纳**（GT 裁决），状态效果层无接线义务。

## ⑤ 叙事壳「滤月余辉」（GT-1 定稿）

### 5.1 壳阐释（对齐圣辉滤月机制，解决 N3 语义打架）
滤月装置（十二提灯封印）千年运转：月光被「洗净」为圣辉**存入灯中**——那是封印的存量，守夜人不得动用。但装置运转时有微光自灯沿**滴落**，凝成余辉结晶——它不属封印、不耗存量，是每一夜守夜自然滴落的馈赠。守夜会世代收集余辉，将其**铭刻**进继任者的灯与血：
- **质变节点 = 铭刻**：一次成形的誓约或仪式，改变「这一夜怎么开始」。
- **属性节点 = 浸染**：余辉的长年浸润，手稳一分、眼亮一寸。
- 结算产出的货币 = 本夜滴落并被回收的余辉。
> 语义裁决：变强消耗的是「滴落物」而非「封印存量」——「用余辉变强」与「余辉有限、封印渗血」不再打架；且保留「余辉稀薄」的克制气质，与数值红线支柱互文。
