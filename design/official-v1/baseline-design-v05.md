### 1.2 核心设计现状

- **规模定稿：14 主武器 + 7 超武**（D1 裁决「不增不减」，outline §1.1）。全部自动触发，无手动瞄准/弹药管理。

  - **D 召唤定向**：自动增援/定向挥击 → 后台输出、走位自由度

- **进化前置**（M3-DESIGN-1 同步后）：类成型（所属类**累计强化 ≥2 次**，单分支上限 2）+ 持对应被动钥 → 进化卡下一轮三选一**必占一席**（保底 P1），权重 ×5 供第二张/多进化（weapons-v2 §5.1）。
- **设计原则「三问反凑数」式约束**：文档中无此原文术语；对应的设计原则实际表述为——①每把武器有明确手感归属与玩家价值（四类手感覆盖四种诉求）；②「无进化 ≠ 弱」：7 把无超武武器以强单体/控制定位补偿，成型强度与超武差距 **≤20%**（weapons-v2 §5.3，sim-verify 断言）；③每局高概率 3~4 把成型，防「武器太多、单把太弱」稀释（认知过载红线，outline §3.2）。
- **powerTag**：全部武器带五系标签（SILVER/HALLOWED/BEAST/BLOOD/MOON），1.0 **不启用克制数值**，仅命名与视觉语义（weapons-v2 §3.0）。已知标注：wpn_a_5 outline 标 BONE，不在五 tag 规范内，按 world-bible §3 归入 BLOOD（weapons-v2 §3.2 注 / consistency-review §C2）。

### 1.3 数值口径

- **伤害流程**：`命中伤害 = 武器基础伤害 × 总伤害倍率`，总倍率 = `1 + 0.04×(等级−1) + Σ加成`（**加法叠加**，weapons-v2 §3.0）。
- **基础单目标 DPS 基准表**（weapons-v2 §3.6，倍率 1.0，含命中率建模）：A1 9.0 / A2 10.7 / A3 15.9 / A4 13.3 / A5 8.0 / B1 16.0 / B2 12.8 / B3 4.8（+承伤-10%）/ C1 7.5 / C2 8.0 / C3 8.8 / D1 11.1 / D2 8.9 / D3 7.4。命中率建模：A 追踪 0.90 / A 直线 0.75 / 霰弹单发 0.60 / 环绕 0.60 / 召唤 0.75 / AoE 1.00（§3.1）。
- **冷却缩减乘区**：key_tome -10%（全局）+ up_g_2 专精疾射（冷却最短 2 把武器独立乘区 ×0.88/层 ×2，与全局冷却**乘法叠加**）；标准 kit DPS 变化预判 ±5% 内，**待 M3-FB2 重算**（weapons-v2 §3.0 注）。
- **超武数值对齐**（§5.2 等效 DPS）：27.0 / 27.2 / 28.8 / 15.0 / 15.4 / 33.3 / 26.7。
- **角色成型 DPS 校验**（§5.4，标准 6min kit、Lv27、倍率 2.34）：守夜人 76.1 / 血猎手 80.0 / 修女 69.0 / 狼裔 69.0（差异 ≤±15%）；Boss 战 61.8/69.6/64.9s（实战 ×0.85），60~90s 判据内。
- 同屏弹体/实体上限：桌面 400 / 移动 250（全实体共享）；单武器另有弹体上限（A1 8 / A2 6 / A3 15 / A4 4 / A5 3）。

### 1.4 跨域耦合点

- **成长域**：武器强化完全来自升级池类强化 12 项（A/B/C/D 各 3 分支 ×2 层）；超武钥 7 项兼被动属性；进化条件判定消费类强化累计值（upgrade-pool-v2 §3.3）。
- **战斗域**：武器是自动输出主体（支柱 1 修订「走位为主 + 主动技为辅」）；圣光壁垒承伤 -10% 与升级池 up_g_7 减伤加法叠加（上限 -30%）。
- **怪物设计域**：血月猎手 12 伤 = 行尸 12 HP 一发秒杀（前期爽感锚点，consistency-review §1）；骨钉标枪 700px/s 需 swept collider 防高速穿透漏判（weapons-v2 §⑥.9）。
- **生成域**：无目标规则差异化（A 不发射/C 照常释放/D 召唤照常）与生成密度、同屏上限 400/250 共享。
- **叙事域**：武器命名遵守 world-bible §7 词根（银=克血族/圣=圣辉/血=血术/月=月光/骨=亡者兽）；解锁浮字（「银器出鞘。」）走 narrative §5。

### 1.5 已登记未实施 / 已知不一致

- **已登记未实施**：up_g_2 专精疾射改造后标准 kit DPS 重算（M3-FB2 待办，weapons-v2 §3.0/§5.1 注）；key_tome/key_silver「数值钥无感」的可选联动（10% 概率小效果，本期不做，upgrade-experience-v2 §2.3）。
- **已知不一致**：wpn_a_5 powerTag BONE vs 五 tag 规范（已裁定归 BLOOD，非未决）；outline §3.2 强化槽口径（B1 数量/B2 转速/B3 半径）与 weapons-v2 §3.3（B2 转速/B3 半径表述）一致，无冲突。
- **与 H2 关联标注**：开局 DPS 口径（单武器 9~16、三武器 ~33.5×倍率）与 60s 预算 1.44 点/s 的交叉，是 H2「战力平台期」假设的文档依据（docs-review-v05 §2.1 H2）。
- **与 H5 关联标注**：武器侧成长（等级倍率 + 类强化 + 超武）全部为玩家侧线性/叠加放大，敌侧零缩放 → 后期雪球的结构面之一。

### 2.2 核心设计现状

- **XP 曲线**：`need(n) = 5 + 3×(n−1)`（首级 5 点 ~30s 达成）。**升级 offer 次数口径（M3-DESIGN-1 裁决）**：基准局 **12~15 次（标称 14）** / 全通局 **26~28 次**；6 分钟累计经验 ~1100~1200 → Lv ~27（「单局 5~7 次」为 Demo 20min 遗留口径，**已废弃**，upgrade-pool-v2 §3.0 / upgrade-experience-v2 §1.1）。
- **升级池 40 项构成**（upgrade-pool-v2 §3.1）：
  - 全局基础 9（机制型 7/9）
  - 武器类强化 12（4 类 ×3 分支，各分支叠 2 次）
  - 被动·超武钥 7（兼进化钥，机制 5/数值 2）
  - 主动技强化 12（4 角色 ×3 分支，各 1 次）
  - 合计 40，**机制型 36/40 = 90%**；单局可选池 **31 项**（全局 9 + 钥 7 + 类强化 12 + 当前角色主动技 3；开局即满，满级剔除后递减）。
- **新武器解锁规则**（§3.7）：初始 1 把（守夜人 wpn_a_1 / 血猎手 wpn_a_2 / 修女 wpn_a_3 / 狼裔 wpn_d_2）；其余 13 把经三选一解锁——未拥有某类武器时选该类强化项 = 解锁 1 把该类未拥有武器（随机，★徽记），不应用分支强化。**这是新武器解锁唯一入口**。
- **保底席位 P1~P5**（§3.6 规则 6，`GUARANTEE_RELATED=true`）：每轮三选一保底 1 张「build 相关卡」：P1 进化卡 → P2 进化路径钥（该类类强化 ≥1 且未持钥）→ P3 已拥有类强化 → P4 主动技强化 → P5 未拥有类解锁卡；全空回退 up_g_1。保底与权重独立。
- **阶段节奏权重**（§3.6 规则 7，`STAGE_WEIGHT_MULT`）：S1(0-2min) 数值方向卡 ×0.5；S2(2-4min) 已拥有类强化 ×1.5（生效 ×3.0）、钥 ×1.2；S3(4-6min)+Boss 新武器解锁卡 ×0.6/×0.5、数值卡 ×1.2。乘算顺序：基础权重 × 阶段倍率 × 防重复倍率。
- **进化达成率目标**：基准局（14 offers）**≥50%** / 全通局 **≥80%**（upgrade-experience-v2 §1.2；「0 build 相关卡」≤1%、related offer ≥50%、纯数值 offer ≤10%）。
- **角色成长曲线差异化**（outline §2.6）：4 角色均为倍率 +4%/级，差异在 HP/移速——守夜人 100/+8/220（+4 每 5 级）；血猎手 85/+6/245（+4 每 4 级）；修女 115/+10/205（+4 每 6 级）；狼裔 125/+12/215（+4 每 5 级）。红线：成型 DPS 差异 ≤±15%。
- **「调参不动案」**：已登记于 `docs-review-v05.md` §5（叙事原则）：「档案文案是叙事不是数值——**面板调参不触发改写**，行为质变才触发；设计时优先『调参不动案』，可把叙事连锁压到最低」。属文档改写纪律，非数值方案。

### 2.3 数值口径

- 倍率公式 `1 + 0.04×(等级−1) + Σ加成`（加法叠加；v0.2 裁定消除 Lv1 off-by-one）。
- 自动成长：每级 +8 HP、伤害 +4%；每 5 级移速 +4 px/s（角色差异见上表）。
- 全局 9 项（§3.2）：up_g_1 武器共鸣（+0.15 可重复，公式锚点/回退兜底）/ up_g_2 专精疾射（冷却最短 2 把 -12% ×2）/ up_g_3 鲜血契约（+20HP + 受击后 5s 回 10HP，内置 12s CD ×3）/ up_g_4 踏月而行（+8% + 击杀后 2s +15% ×3）/ up_g_5 吸血 1HP / up_g_6 磁力 ×2 / up_g_7 减伤 -10% ×3（上限 -30%）/ up_g_8 濒死护盾 60 / up_g_9 拾取 +40px ×2。
- 类强化满层量化（§3.3）：A3 弹速 ×1.44、B2 转速 ×1.44、C1 半径 ×1.56、C3 持续 ×1.69、D3 存在 ×1.69 等；**类成型阈值 = 2**（`CLASS_UPGRADE_EVOLUTION_THRESHOLD=2`，已实装抽查确认）。
- 抽取权重基础值：已拥有类强化 ×2 / 未拥有类（解锁卡）×1 / 上次选过 ×0.5 / 进化卡 ×5（`WEIGHT_EVOLUTION=5`，已实装）。
- 标准强化口径（§5.1）：Lv27 倍率 2.04 + 2×伤害强化 = 2.34；标准 kit DPS 69.0~80.0。

### 2.4 跨域耦合点

- **武器域**：类强化 = 武器成长唯一来源；钥 = 进化前置条件之一；解锁卡 = 武器扩展唯一入口。
- **战斗域**：主动技强化 12 项属 build 相关卡（保底 P4），占比红线 15%/封顶 20%；鲜血契约受击回血、踏月而行击杀移速直接进玩家面板行为。
- **怪物设计域**：吸血/精英伤 15~20 构成「贪心风险对价」（§5.3）；濒死护盾与 Boss 伤 25~32 对冲。
- **生成域**：XP 收入由生成密度决定（S1≈197 / S2≈332 / S3≈513，upgrade-experience-v2 §1.1）；**基准局 14 口径以拾取率正常为前提**——若真机 `xpGainedPerRun` 中位 <400 需先修磁力/漂移再谈升级体验（前提与观测项）。
- **叙事域**：卡面文案/名称（武器共鸣/鲜血契约/踏月而行）需 asset-spec 新图标与文案（已登记待出图）。

### 2.5 已登记未实施 / 已知不一致

- **已登记未实施**：①M3-FB2 复模拟全套断言（进化达成率/向心性/纯数值占比——upgrade-pool-v2 §⑧ 8~10 标注「M3-FB2 复模拟断言」）；②up_g_7/up_g_9 可选增强（圣辉庇护/血月磁引，不强制）；③专精疾射/鲜血契约/踏月而行新图标与文案（asset-spec 待出）；④真机埋点 offersPerRun/xpGainedPerRun/evolutionComplete/relatedCardShare 校验（upgrade-experience-v2 §4.4）。
- **风险登记**：进化提前 → 战力峰值前移 → Boss 战中位可能 <60s（upgrade-experience-v2 §2.4 风险 2、outline §8 风险 8；预案 Boss HP 上调或超武系数 ×0.95，**不在升级体验方案内动 Boss**——与 H6 直接相关）。
- **文档内已消解的旧矛盾**（留痕，非未决）：基准局 14 vs 5~7 次口径矛盾（v1.3 已裁决废弃 5~7）；单局池「20~28」vs「31」口径（v1.2 已修正）；类成型 3 vs 2（v1.3 已同步）。

### 3.2 核心设计现状

- **核心战斗循环（支柱 1 修订表述）**：「走位为主 + 主动技为辅」——自动武器仍是输出主体；玩家输入 = 移动（高频基础）+ 每角色 1 主动技（低频情境决策）。修订红线：不引入第二高频操作（CD ≥12s、每局 ≤18 次、目标中位 ~12 次 ≈ 每 30s 一次）；不成为通关必需（关闭主动技仍可击杀 Boss，QA 用例）；不打断移动；无第二资源条（pillars-v1 §1/§6）。
- **爽点循环**：移动拉扯聚怪 → 武器爆发清屏 → 宝石喷涌 → 升级三选一 → 主动技压力峰值破局 → 更敢深入 → 压力提升（pillars-v1 §4）。
- **伤害结算规则（GDD 口径）**：
  - 命中判定：接触伤害按敌人攻击间隔循环；每次触发**玩家无敌帧 0.5s**（enemies-v2 §3.0）——多敌同帧接触只记 1 次伤害；高速弹体用移动扫掠（swept collider）防穿透漏判（weapons-v2 §⑥.9）。
  - 暴击：**五域文档中无暴击机制设计**（现状 = 无暴击）。
  - 受击反馈：敌人红闪 0.1s + 2px 抖动；击杀 8~16 粒子（移动 8）；玩家濒死（HP<30%）无文字提示（心跳加速承载，narrative §5）。
  - 减伤：圣光壁垒 -10% + up_g_7 加法叠加，**上限 -30%**。
- **4 主动技机制明细**（gdd-active-skill §3.2，与 outline §2 一致）：

| 守夜人 | 提灯闪耀 | DEFENSE | 20s | 240px 内眩晕 2.5s + 自身无敌 1.5s | 前摇 0.45s 表现叠层（`-skill-a` 300ms→`-skill-b` 150ms），按下瞬间即结算，不打断移动 | 0（效果型） |

- **强化分支 ×3/角色**（§3.3）：CD -25% / 二次充能（仅血猎手原生，其余替换为同强度效果增强）/ 效果增强（各角色 2 小项）。主动技占比：血猎手 ~7.8%→11.0%、狼裔 ~15.1%→18.2%（贴 20% 封顶线，留 1.2 个点余量）。
- **玩家面板构成**：初始 HP 100 / 移速 220 px/s / 倍率 1.0（upgrade-pool.md v0.2 裁定）；碰撞半径 14px（enemies-v2 表推算，玩家侧半径见 gdd-maps §⑥.5「玩家 14px 半径」）。
- **powerTag/力量体系**（world-bible §4）：圣辉克亡者、银器克血族、兽血撕咬血术、月光双刃剑——**1.0 不启用克制数值**，仅命名与视觉语义；全部内容必须带 powerTag（设定一致性红线 §8）。

### 3.3 数值口径

- 伤害型主动技单次价值基准 ≈ 冲击波（60 伤）的 1.5~2.5 倍，CD 20s 上下（pillars §6.5）；Lv27 基准下血影突袭 46.8 + 标记 debuff、血月狂化等效 294.4（buff 94.4 + 光环 200）。

- 状态机：RUNNING 可释放；LEVEL_UP/PAUSED/GAMEOVER 冻结。

### 3.4 跨域耦合点

- **武器域**：主动技定位为「自动输出主体」之外的低频破局节点；占比红线 15%（埋点 activeSkillDpsShare）以武器 DPS 为分母。

- **叙事域**：技能命名走 world-bible §7（动词+意象）；血月狂化色彩裁定 R-A（玩家侧不翻红）。

### 5.2 核心设计现状

|---|---|---|---|---|---|

| S2 | 120–240s | 0.80 | 0.17 | 0.03 | 每 30s |

### 5.4 跨域耦合点
