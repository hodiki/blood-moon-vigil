## ① 概述

升级池 v3 = 三层武器架构（专武/通武/共鸣）+ 圣物层在成长侧的收口：**定义 37 项、单局可选 ≤30 项**（红线 32~40，NW-7 采纳）。保底序列重排为 P1~P5（WD-13），向心性核心从「进化卡」转移为「专武质变卡」——build 意向声明（开局 2 选 1）之后，每一张保底卡都在为已声明的骨架服务。

## ② 设计支柱

1. **卡池主体留给通武**（R2-2/5）：专武强化仅 2 项进池、主动技强化单局仅 1 张——「少而强」替代「多而平」。
2. **保底即定向**（P1~P5 序列）：每级保底都回答「我现在该为 build 做什么」。
3. **有意收敛**（池总量 < 现状 40）：认知负荷下降是设计目标而非妥协；厚度缺口由可重复卡 + 通武强化双分支满层吸收。
4. **机制型占比不降**：沿用 v2「机制型 90% 不稀释决策质量」原则，v3 机制型占比锚 ≥85%（圣物不进池是关键前提）。

### 3.3 权重规则（S1~S3 沿袭 + 修订点）
- **沿袭**（`gdd-upgrade-pool-v2.md` §5 口径）：已拥有类强化 ×2 基准；防重复 ×0.5；阶段权重 S1 数值卡 ×0.5 → S3 ×1.2；三选一呈现制（池大小不直接决定单次认知负荷）。
- **修订点（v3 新增/变更）**：
  1. 专武强化卡权重对齐「已拥有类 ×2」，S1 额外 ×1.2（保证开局定向路线 2 分钟内出现 ≥2 次——R1 拓展 7 惯例延续）；P1 席位命中时必占一席。
  2. 共鸣钥 ×1.2（S2 起，沿旧钥权重惯例）；共鸣条件达成时 ×5（对齐旧进化卡向心性，待模拟）。
  3. P4 衍生技强化卡：S2 中段窗口内权重对齐 P3（×2 基准），窗口外不出现；单卡为质变级效果（NW-4）。
  4. 进化卡 ×5 + P1 进化保底**废止**（超武退役，R2-3）。
  5. 通武强化满层剔除规则沿用（取满后该项从池消失）。

### 3.4 获取特例（非池内）
- 专武质变卡 2：**赠送制**，不进池——渠道**暂定精英宝箱**（NW-2，待怪物设计/生成重做回填产出规则；兜底「距卡 1 后 N=8 次升级」为待模拟候选）；卡 2 在卡 1 未取得时开出进入待发队列（专武 GDD §6.1-4 防卡死规则）。
- 圣物：Boss 必掉 1 + 祭坛概率第 2（NW-1 混合口径），不占卡池席位。

### 3.5 XP 与升级节奏（沿用，修订归「成长系统剩余范围」）
- need(n)=5+3(n−1)、6min ≈ Lv27、offer 口径基准局 14 / 全通 26~28 沿用 v2（`refactor-baseline-v05.md` 域2）；本 GDD 不修订 XP 曲线（覆盖声明见 §7）。

## ⑧ 边缘情况与反例 + UI 与表现 + 验收判据

**边缘情况**：
1. 质变卡 2 先于卡 1 获得 → 待发队列（§3.4），取卡 1 立即补发。
2. P4 窗口错过（第 14 次升级前未触发）→ 该卡本局不再出现（不做窗口后补——少而强模式的稀缺性即设计）。
3. 三选一同时命中多条保底席位 → 席位优先级 P1>P2>P3>P4>P5（同帧冲突裁决规则，必须实装）。
4. 通武满层 + 钥已取 + 质变卡已取完的极端后期 → 池只剩全局可重复卡 + P5 解锁变体，属正常收敛（S3 数值卡 ×1.2 权重兜底）。
5. 反例红线：❌ 圣物进池；❌ 非当前专武质变卡入池；❌ 主动技强化恢复 12 项规模（NW-4 已裁决）；❌ 池扩容突破 40。

**UI 与表现**：三选一卡面按卡类徽记分区（专武徽记/钥徽记/★解锁/衍生技同名徽记）；保底席位命中时卡面带席位角标（P1~P5）；S1~S3 无感知（权重纯后端）；移动端三卡触达区域 ≥44px。

**验收判据**：
1. 37 项定义与 §4 表一致（配置断言；全局 9 以 v2 §3.1 对照映射）。
2. P1~P5 序列与优先级冲突规则生效（含 §⑧ 边缘 1~3 用例）。
3. 单局可选 ≤30（标签过滤断言）；池定义 37 不随局内状态膨胀。
4. 专武质变卡 2 走赠送管线、不出现于三选一（断言）。
5. 遥测：各卡类选取率、保底命中率、P4 窗口转化率、池空转指标（S2~S3 可选项 <3 的次数）。
