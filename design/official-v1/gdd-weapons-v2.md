## ① 设计目标

四类手感（content-design-outline §3.1）覆盖玩家四种价值诉求：
- **A 弹幕投射**：高频弹体，追踪/穿透/散射 → 即时反馈、单体收割
- **B 环绕护体**：近身持续/领域，无需瞄准 → 防御兜底、贴身清怪
- **C 范围清屏**：低频大范围爆发/区域 → 波峰翻盘、清屏高潮
- **D 召唤定向**：自动增援/定向挥击 → 后台输出、走位自由度

全部自动触发（支柱 1「走位为主」的自动输出主体）；build 形态可视化（分裂变多、环增多、波变大、召唤变群），每次升级有「看得见」的变化。

---

## ② 玩家价值

- **零瞄准成本**：无手动攻击/弹药管理；输入 = 移动 + 低频主动技（支柱 1 修订）。
- **build 决策兑现**：武器解锁/强化/进化是升级池三选一的主要「机制型」内容，兑现支柱 2。
- **无进化 ≠ 弱**：7 把无超武武器以强单体/控制定位补偿（成型强度与超武差距 ≤20%，§⑤校验）。

## ⑤ 平衡与曲线

### 5.1 超武合成规则（细化 content-design-outline §3.3）

| 规则 | 规格 |
|---|---|
| 条件 1 | 武器所属类**累计强化 ≥2 次**（任意分支组合，单分支上限 2 次；「类成型」判定；M3-DESIGN-1 进化前置，阈值 3→2，见 upgrade-experience-v2 §2.4） |
| 条件 2 | **持有对应被动钥**（`weapon_evolution { wpnId, keyId, evoId }`） |
| 触发 | 满足条件后，下次升级三选一**必占一席**（向心性保底 P1；占一个选项位；视觉裁定 R-B：幽紫底 + 冷青 3px 描边 + ★★ 双星徽记 + 「进化」文字标签） |
| 效果 | 超武 = 行为质变（非纯数值），不可逆；超武**不再吃类强化**（已质变，防再膨胀） |
| 权重 | 进化卡满足条件时自动加入可选池（权重 **×5**；首张由保底 P1 必占，×5 用于第二张/多进化进剩下 2 席） |
| 边缘 | 进化瞬间清空该武器旧弹体；玩家死亡重开无残留 |

### 5.3 无超武武器强度校验（≤20% 差距）

无超武武器（银针连弩/幽灵飞刃/骨钉标枪/荆棘圣环/圣光壁垒/审判圣火/断罪锁链）以**满类强化**（A/B/C 分支各 2 次满叠）对超武成型做对比。示例对（完整表见 `sim-verify-v1.md` §6）：

| 对比 | 成型 DPS* | 差距 |
|---|---|---|
| 银针连弩 满强化（A1×2+A2×2+A3×2） | 22.6 | 血月天罚 27.0 → **16.3%** ✔ |
| 荆棘圣环 满强化（B1×2+B2×2+B3×2） | 24.3 | 炽天使之环 28.8 → **15.6%** ✔（+减速控制补偿） |
| 审判圣火 满强化（C1×2+C2×2+C3×2） | 21.4 | 月全食 15.0 → 超武反而低（无超武武器面覆盖 + 持续伤害）✔ |

> 结论：无超武武器满强化成型强度与超武差距 ≤20%（多数 ≤16.3%），「无进化 = 弱」感知不成立。

### 5.4 角色成型 DPS 与 Boss 战（摘要，详见 `sim-verify-v1.md`）

- 标准 6 分钟 kit（Lv27、倍率 2.34）：守夜人 76.1 / 血猎手 80.0 / 修女 69.0 / 狼裔 69.0（差异 ≤±15%）。
- Boss 战（Boss HP 4000/4500/4200，实战 DPS = 理论 ×0.85）：61.8s / 69.6s / 64.9s，全部落在 60~90s 判据。

## ⑥ 边缘情况与容错

1. **无目标**：A 弹幕不发射（省资源）；C 范围照常释放（清屏价值）；D 召唤物照常存在（后台输出）。
2. **目标中途死亡**：追踪弹立即重寻最近敌人；直线弹继续飞行至射程/贯穿数耗尽；无目标则原地消散。
3. **同屏弹体上限**：达上限跳过本冷却，不积压、不报错。
4. **环绕球同目标连击**：0.4s 内置 CD 防单目标瞬间多段秒杀（Boss 也适用）。
5. **召唤物死亡/到期**：按重召唤间隔重新召唤；召唤物死亡瞬间移除碰撞，不再造成伤害。
6. **地面领域重叠**：血池/圣火同帧多池重叠时，每池独立 tick（不合并伤害），但同目标同一武器只计最高伤害源一次（防刷伤）。
7. **玩家死亡**：清除全部弹体/环绕球/召唤物/地面领域，冷却重置（重开无残留）。
8. **进化瞬间**：清空该武器旧弹体；新旧武器行为切换原子（无中间态）。
9. **弹速过快的直线弹**：骨钉标枪 700px/s 在极近距可能一帧穿透未命中——命中判定用「移动扫掠」（swept collider），防高速穿透漏判。
10. **火铳霰弹贴脸**：贴脸时 5 发全中（×5 段伤害），但近距射程 220px 限制使高风险高回报成立（Boss 战中贴脸 = 高承伤对价）。

## ⑧ 验收标准
