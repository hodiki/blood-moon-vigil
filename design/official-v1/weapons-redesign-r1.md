## A. 用户意图解读（确认理解一致性）

### A.1 三层结构模型（用我的话复述）

```
┌─ 专武层（角色身份 × 定向承诺）──────────────────────┐
│  每角色 2 把专武，开局 2 选 1（不可兼得）             │
│  专武 = 战斗玩法倾向的"声明"：                       │
│   · 破旧提灯 = 周身范围 + 持续伤害 + 控制（近身领域流）│
│   · 圣徒左轮 = 传统子弹远程 + 资源管理（射击流）      │
│  成长 = 专武强化：重复选择 → 固定路线数值/形态增长    │
├─ 主动技层（落选专武的"第二人生"）───────────────────┤
│  未被选择的专武 → 转化为该角色本轮的主动技能          │
│  选提灯 → 左轮成为主动技（6连射 + 挂"受提灯伤害增加"减益）│
│  选左轮 → 提灯成为主动技（眩晕周身 + 射速爆发 + 弹药无限窗口）│
├─ 通武共鸣层（通用武器池 × 条件形态质变）─────────────┤
│  通用武器池（原 14 主武器位置的继承者）               │
│  部分通武与特定专武有"共鸣配对"：                     │
│  当持有指定专武 → 通武形态改造（行为质变，非纯数值）    │
│  例：破旧提灯 × 守夜之环 → 旋转球体改为"提灯范围边缘环" │
│      = 额外伤害频率 + 0.5s 控制（单怪 10s ICD）       │
│  未选指定专武 → 守夜之环就是普通通武（原行为）         │
└─────────────────────────────────────────────────┘
```

设计逻辑一句话：**开局一次 2 选 1 完成 build 意向声明，专武强化锁定主路线，落选专武不浪费而是变成技能，通武通过共鸣被专武"点亮"出第二形态**。

### A.2 我读出的隐含推论（用户未明说，均**待用户确认**）

| # | 推论 | 依据 |
|---|---|---|
| INF-1 | **主动技体系整体动态化**：现役「每角色 1 固定主动技 + 3 强化分支」（gdd-active-skill）被「每角色 2 套专武衍生主动技」替代——4 固定技 + 12 强化项面临退役或改造 | 用户第 3 点「专武 2 选 1…没选到的专武转化为主动技」意味着主动技随专武选择变化，与固定主动技在结构上互斥 |
| INF-2 | **专武强化 = 升级池内的新卡类**：通过「重复选择专武强化」成长，即升级三选一中出现专武强化卡（固定路线、只对已选专武生效），取代/并入现行「类强化 12 项」的席位功能 | 用户第 4 点「通过重复选择专武强化，固定提高…」的表述与升级池交互模式一致 |
| INF-3 | **共鸣是条件触发型「进化」**：形态改造（守夜之环球体→提灯边缘环）与现超武进化的「行为质变」同构，但触发条件从「类强化≥2+持钥」变为「持有指定专武」 | 用户第 5 点「改造通武形态…若未选指定专武，则是普通通武」 |
| INF-4 | **超武/进化体系去向未明说**：用户五点未提及 7 超武与进化机制——是共存、改造还是退役，需裁决（见 WD-1） | 五点需求通篇无超武 |
| INF-5 | **弹药/装弹是全局新资源维度还是专武特例**：左轮「每 6 次攻击需装弹」——若仅左轮类拥有，则是特例机制；若推广，则打破 weapons-v2「全部自动触发、无弹药管理」定稿原则（baseline-design §1.2） | 用户第 4 点仅对左轮提及装弹 |
| INF-6 | **控制效果体系将成建制引入**：10% 减速、0.5s 眩晕+ICD、「挂减益（受伤害增加）」——现状战斗域无统一状态效果层（眩晕/减速散落在提灯闪耀/荆棘圣环/月全食/血池，无 ICD 概念），需新建状态效果层与 Boss 免疫规则 | 用户第 4、5 点三处提及控制/减益 |
| INF-7 | **专武 2 选 1 发生在开局**（角色选定后、进图前），而非局中抽取——「通过专武强化固定路线增长」的承诺感建立在此前提上 | 待确认（见 WD-8） |

## B. 专业审阅（逐点：优势 / 风险 / 与现状冲突）

### B.1 对 R3 主诉「build 定向性弱」的结构性解决价值

**优势（结构性，非补丁性）**：
- 现升级体验 v2 缓解了「选项无聊」，但定向性仍靠保底 P1~P5 与阶段权重**间接引导**——玩家的 build 意向从未被正式声明过。专武 2 选 1 把意向声明**前移到开局并制度化**，是比「保底席位」强得多的定向机制：每张专武强化卡都天然「与 build 意向有关」。
- 「落选专武→主动技」把 2 选 1 的沉没成本清零，2 个路线各做 1 套深度即可复用到两种体验，内容效率高。
- 固定路线强化直接对应 R3 三根因中「与 build 意向无关」的**结构面解**（H2/H5/H7 中的 H2 还能借专武强化前期保底对冲开局 DPS 平台期）。

**风险**：
- 固定路线 = 牺牲横向 build 自由度。Vampire-Survivors 类的乐趣一半来自「随机中构建」，若专武强化过于线性，中后期只剩「把固定清单点完」，可能出现新的无聊感（从「选项无聊」变「路径无聊」）。**对策**：专武强化只锁主线，通武组合与共鸣配对仍提供副 build 空间——专武定「骨」，通武定「肉」。
- 专武间强度失衡会被放大：2 选 1 意味着弱势专武=该角色直接劝退级体验（旧体系弱武器可绕开，新体系绕不开）。需要 B.7 的双路线对表约束。

### B.2 与现有超武/进化机制的关系（7 超武 + 钥 7 + P1 保底的命运）

现状：进化 = 类强化≥2 + 持钥 → 进化卡 ×5 + P1 保底（weapons-v2 §5.1；weapon-system.ts:379-391）。专武共鸣与进化在「行为质变」上同构，双轨并存会打架。**三个方案选项**：

| 方案 | 内容 | 利 | 弊 |
|---|---|---|---|
| **A. 共鸣取代进化** | 超武池退役；钥 7 项改造为通武强化被动（保留数值钥）；终局形态 = 专武共鸣改造 | 结构最干净，单一质变通道，与用户新模式最自洽 | 损失 7 超武已定稿内容与「进化达成率 ≥50%/80%」验收体系；钥-进化耦合需重接 |
| **B. 双轨并存** | 共鸣管通武形态，进化管专武终局（专武类强化≥N+持钥→专武「超武化」） | 保留超武资产，两条成长高潮 | 池膨胀 + 认知过载红线（outline §3.2）；两套质变规则并存解释成本高；保底席位更拥挤 |
| **C. 进化机制转挂专武** | 「超武」概念转义为「专武觉醒」：专武强化满级 + 持钥 → 专武觉醒形态（提灯/左轮的终态）；共鸣仍管通武 | 超武引擎与钥体系全复用（工程面改动最小），叙事上「觉醒」与守夜人 lore 契合 | 7 把旧超武行为资产需重新分配归属或废弃 |

**我的倾向：A 或 C**（A 最彻底、C 最省工程），B 不建议——违背「每局高概率 3~4 把成型」的防稀释原则。**待拍板（WD-1）**。

### B.3 与升级池 v2 的重构关系（40 项池的重组）

现状池 40 = 全局 9 + 类强化 12 + 钥 7 + 主动技强化 12（upgrade-pool-v2 §3.1）。新模式下三个子系统的去向：

**类强化 12 项去向**（A/B/C/D 各 3 分支 ×2 层）——三选项：
- **a. 改造为「专武强化」**：专武强化占用类强化的池位与保底席位，按专武路线重设分支（提灯：范围伤/范围半径/减速强度；左轮：弹伤/射速/穿透/补弹/跳弹）。旧 12 项退役或部分并入通武强化。→ 与用户第 4 点表述最贴合（INF-2）。
- **b. 类强化保留，改为「通武强化」**：继续服务通武成长（每把通武的分支），专武强化另立卡类（新增约 6~10 项）。→ 池规模 +，通武保留自成长，共鸣层更厚。
- **c. 混合**：专武强化新立（固定路线 5~8 级），类强化精简为「通武通用强化」少量卡。→ 折中。

**保底席位 P1~P5 重排**：P1（进化卡）在方案 A 下空缺，建议新 P1 = 专武强化卡（开局定向后最强向心卡）；P2 钥/共鸣前置；P3 已拥有通武强化；P4 主动技强化（若保留）；P5 通武解锁卡。**待拍板（WD-2/WD-13）**。

**池规模红线**：无论哪种组合，总池建议控制在 40~46 项、单局可选 ≤34 项，防认知过载。

### B.4 落选专武→主动技：强度锚点与旧体系去向

**与支柱 1 的自洽性核对**（pillars-v1：CD≥12s、DPS 占比 ≤15%/封顶 20%、关技能可通 Boss、单局 ≤18 次）：
- 左轮主动技（6 连射 + 挂减益）：单次伤害若为冲击波口径（60 伤 ×1.5~2.5 倍价值，pillars §6.5），6 连射总伤约 90~150，CD 建议锚 12~15s。减益「受提灯伤害增加」与提灯已无关（选了左轮）——**减益对象需要改写为通用易伤**（如「受到所有伤害 +X%」），这是一个用户方案内需明确的**内部一致性修正点**。
- 提灯主动技（眩晕 + 射速爆发 + 无限弹窗口）：复合效果强，**「无限弹」必须限时**（建议 4~6s），否则同时击穿「资源管理」身份与主动技占比红线。眩晕现状参照提灯闪耀 240px/2.5s/CD20s（balance.ts:863-868），新技建议眩晕时长 1.5~2s + CD ≥20s。
- 占比红线可保：只要主动技定位仍是「低频破局节点」而非常驻输出，15% 红线无需修改——但**左轮主动技若可重复挂易伤，单目标 Boss 战等效增益需计入模拟**（参照血影突袭标记 33% uptime = +6.7% 的算法，gdd-active-skill §3.3）。
- **关技能可通 Boss 用例必须保留**：QA 红线不因体系更换而豁免。

**原 4 主动技 + 12 强化项去向**——三选项：
- **a. 整体退役**：4 技效果元素拆散融入 8 套专武衍生技（如提灯闪耀的眩晕无敌基因进入提灯主动技）。
- **b. 叙事资产保留、机制退役**：技名/文案归档，行为由新体系覆盖。
- **c. 部分保留**：非专武角色（若有）或特殊模式继续用旧技。
**倾向 b**（「调参不动案」纪律 + 提灯闪耀与世界圣经强关联，叙事锚点不能丢）。**待拍板（WD-11）**。

### B.5 新机制引入面

**① 装弹/弹药（资源管理）**：
- 直接冲突现状定稿原则：「全部自动触发、无手动瞄准/弹药管理」（baseline-design §1.2 weapons-v2 规模定稿条款）。这是**用户有意的原则变更**，需在定稿时正式修订该条款。
- 设计风险：装弹期 DPS 塌陷是明确的资源管理代价，但 Survivors-like 是走位游戏——装弹窗口恰是「走位拉扯」的最佳教材，与核心循环（移动拉扯→爆发清屏）兼容性好。**前提**：装弹时长要短（建议 0.8~1.2s）且开局即装满。
- 范围裁决见 WD-7：建议仅限带装弹标签的专武/通武，不做全局资源系统（避免第二资源条红线，pillars-v1 §6「无第二资源条」——弹药条是第三资源，需用户确认豁免）。

**② 控制效果体系（CC + 状态效果层）**：
- 现状：眩晕（提灯闪耀 2.5s、月全食 1s）、减速（荆棘圣环 30%、血池 20~40%）散落各武器配置，**无统一状态层、无 ICD、无叠加规则**（baseline-eng §3.2/§4.2）。新设计要求 ICD（守夜之环共鸣：单怪 10s 内仅 1 次 0.5s 控制）——这是成建制引入，建议本轮**只定原则**：状态枚举（眩晕/减速/易伤三类起步）、同状态不叠加取最强、硬控 ICD 通用常量、Boss 硬控免疫改为「韧性制」或时长折减（如 Boss 受控时长 ×0.25 或仅软控生效）。
- 联动：怪物设计重做（DIFF-D3 enemies-v3 未启动）需同步定义每敌/Boss 的 CC 抗性表——**建议本草案只立「Boss 免疫硬控、精英受控折减」两条原则**，细则归怪物域。另注意「配置已备、运行时未接」教训：CC 状态层必须设计+实装同步接线，重蹈覆辙风险高（refactor-baseline 首报表）。

### B.6 通用武器池规模与共鸣配对节制

- 14 主武器映射——三选项：
  - **a. 全 14 保留**：0 内容浪费；但守夜人例只配 1 对共鸣，多数武器与专武无互动，共鸣系统存在感稀薄。
  - **b. 精简至 10~12**：每专武 1~2 把共鸣配对（4 角色 ×2 专武 = 8 套 ×1~2 = 8~16 对），淘汰手感重复或与新体系冲突的武器（如 B3 圣光壁垒承伤定位与新控制体系竞争资源）。淘汰武器移入图鉴「退役区」而非删除（资产保留）。
  - **c. 全 14 保留 + 强配对**：每专武配 2~3 把共鸣，共鸣总规模 16~24。→ 共鸣成为核心循环，但「每图 ≤2 特殊行为」式节制原则（enemies-v2 §4.2）被突破，形态定义与帧资产翻倍。
- **节制原则建议延续**：每专武共鸣配对 **1~2 把**起步（用户示例即 1 把），首版共鸣总规模 ≤10，验证手感后再扩。理由：共鸣改造 = 新行为 + 新帧（美术管线帧名契约注册表 194 帧需扩容，refactor-baseline 域1 注）+ 新数值验证，每对共鸣的真实成本 ≈ 半把新武器。**待拍板（WD-4/WD-5）**。
- 另一个必须裁决的细节（WD-12）：**共鸣形态下通武还能吃通武强化吗**？建议：能——共鸣改形态，通武强化改数值，两层正交（如守夜之环共鸣后伤害频率仍受强化放大），否则共鸣惩罚了选它的玩家。

### B.7 平衡锚点：守夜人双专武职责分工

| 维度 | 破旧提灯（领域控场） | 圣徒左轮（射击资源管理） |
|---|---|---|
| 手感类归属 | **B 环绕护体**（基准参照 B1 守夜之环 DPS 16.0 / B3 光环） | **A 弹幕投射**（基准参照 A1 9.0 / A2 10.7） |
| 职责 | 持续 AoE + 控场 + 贴身兜底，无需瞄准 | 单体爆发 + 精确走位收益 + 弹药节奏决策 |
| 初始 DPS 锚 | 周身范围伤（低）——建议 8~11（低于 B1 满配 16.0，因附带减速 10% 控制） | 6 发弹组循环——建议 10~14 峰值 / 装弹期 0，「有效 DPS」锚 9~12 |
| 与 H2 关系 | 提灯常驻 AoE 对开局尸潮友好，天然缓解 H2 前期压力 | 装弹节奏让前期更险，需靠「专武强化前期保底」或首级节奏对冲 |
| 挑战面 | 后期防「AoE 无脑滚雪球」：范围伤数值增幅应低于弹伤增幅（提灯成长靠范围/控制强度而非纯伤） | Boss 战验金石：单体爆发路线 Boss 战时长应 ≤提灯路线（60~90s 判据内分别达标） |

- 双路线 DPS 差建议 ≤±15%（沿用角色成型 DPS 红线口径，outline §2.6），**双路线 Boss 时长差建议 ≤10s**。
- 与「开局 DPS 9~16」平台期（H2）关系：新模式给了 H2 一个结构面抓手——**专武强化卡可作为 S1 阶段 P1 保底**，让 30~45s 平台期出现第一张定向强卡，直接回应「0~2min 仅有飞弹」。

## C. 拓展设计（均为**建议，待拍板**）

1. **专武强化阶梯结构**：建议**里程碑式 3/5/8 级**（或 3/6/9，随池结构定）——每 3 级一个「形态微质变」节点（提灯 Lv3：范围 +30% 且光晕加深；Lv5：减速 10%→18% 并附 0.3s 短暂迟滞；Lv8：周身灯环常驻实体化），数值层线性堆叠 + 节点层质变提示。优于纯线性：给「固定路线」保留可感知的里程碑爽点，对冲 B.1 的「路径无聊」风险。满级后专武强化卡从池中剔除（沿用满级剔除规则）。
2. **共鸣改造的视觉/手感差异化三原则**：①一眼可辨（共鸣形态必须改变剪影/颜色/光效至少两项——守夜之环共鸣后球体改为提灯色环带+控制命中白闪）；②手感不变原则（共鸣改「做什么」不改「怎么操作」， Survivors-like 无操作差异包袱）；③共鸣即预告（通武卡面在已持配对专武时显示共鸣徽记，抽卡前可预期）。
3. **双专武「身份感」表达**：开局 2 选 1 做成**角色立绘双形态选择演出**（左/右分屏：提灯路线暗金光晕 vs 左轮路线银白弹痕），选择后落选专武的卡面转入主动技槽 UI 并标注「转化为技能」；卡面文案走 world-bible §7 词根（提灯=MOON/亡者语义，圣徒=SILVER/圣辉语义，已自洽）。
4. **选择时点与反悔规则**：建议**开局（角色选定后、进图前）2 选 1，本局不可反悔**——build 承诺感是本模式价值根基，反悔会瓦解它；但可给「角色选择界面 → 专武预览」的自由查看，降低误选率。若真机反馈误选率高，再议 60s 内改一次的保险丝（不做进首版）。
5. **其他三角色专武概念占位**（各一句话，不展开）：
   - 卡珊德拉（血猎手）：**「血契双刃」**（贴身高频连击、以攻代守）× **「月痕长弓」**（蓄力穿透狙击、高风险高倍率）。
   - 薇奥莱（修女）：**「安魂圣铃」**（持续领域+治疗光环的辅助流）× **「圣辉十字」**（投掷审判的范围爆发流）。
   - 加尔文（狼裔）：**「兽骨双拳」**（贴身狂战士、击杀增益滚雪球）× **「月啸号角」**（召唤狼群协同、随从流）。
   - 每专武同样需预留 1~2 个共鸣配对候选（从 14 通武中按主题配：如卡珊德拉双刃 × 幽灵飞刃、薇奥莱圣铃 × 圣光壁垒——仅示例占位）。
6. **移动端装弹交互**：建议**默认自动装弹**（弹药耗尽自动触发 0.8~1.2s 装填，玩家只需走位），**不引入手动装弹按钮**——保住「移动 + 单主动技键」的极简输入布局；若后期想加深资源管理，可作专武强化项「手动提前装弹：装弹时间 −30%」的被动变体（仍是自动触发，只是参数差异）。
7. **专武强化在升级池中的出现频率**：建议专武强化卡权重对齐现行「已拥有类强化 ×2」，且 S1 阶段额外 ×1.2（阶段权重惯例，balance.ts:1048-1053），保证开局定向路线 2 分钟内至少出现 2 次。
8. **左轮装弹的强化钩子排序建议**（从用户列举引申）：弹伤 → 射速 → 穿透 → 击杀补弹 → 跳弹——「击杀补弹」建议排第 4（Lv5 里程碑位），它是资源管理路线从「约束」转向「奖励」的身份转折点；「跳弹」排第 5（Lv8），作为质变终节点（弹道从直线变弹射，视觉剪影差异最大，符合拓展 2 原则①）。
