## 3. 4 加成卡规格（gdd-codex §3.4 / merit.ts）

| ID | 名称 | 数值 | 对基础值比例 | 红线（≤10% 口径） | 解锁成本（功绩点） |
|---|---|---|---|---|---|
| merit_hp | 初始 +20 HP | 100→120 | +20%（绝对值口径） | ✔ ≈6.5%（对 Lv27 强度，merit.ts meritImpactPct） | **20** |
| merit_dmg | 初始伤害 +5% | 倍率 1.0→1.05 | +5% | ✔ | **30** |
| merit_magnet | 初始磁力 +40px | 140→180px | +28.6%（绝对值口径） | ✔ 只影响拾取节奏，不计强度（gdd-codex §3.4 注） | **40** |
| merit_speed | 初始移速 +4% | 220→228.8 px/s | +3.6% | ✔ | **30** |

> **红线口径**：以「对 6 分钟成型强度影响 ≤10%」为准（gdd-codex §3.4 注；merit.ts `allMeritBonusesWithinRedline` 断言）。
> **解锁成本合计 = 20 + 30 + 40 + 30 = 120 点** ≈ 4~5 局（gdd-codex §3.4 总成本 120）——分项分配为本次提案，**待主理人确认**（GDD 仅定总额，未定分项）。

## 4. 卡片三态

| 态 | 视觉 | 交互 |
|---|---|---|
| **未解锁**（meritPoints < 成本） | 灰显（降饱和 α0.5）+ 锁图标 + 「需 30 功绩」 | 不可点选 |
| **已解锁未装备** | 正常 + 效果描述 + 红线达标 ✔ 标识 | 点击 → 装备（冷青描边） |
| **已装备** | 冷青 `#54E6C9` 2px 描边 + 勾选态（gdd-codex §④「选中态冷青描边」） | 点击 → 卸下 |

- 图标：`merit-<id>`（新增，桌面 64×64 / 移动 48×48 出档；或复用升级卡图标体系，asset-spec §1.6）。
- 每卡字段：名称 / 效果数值 / 红线达标标识 / 解锁成本（已解锁后隐藏成本、显示「已解锁」）。
- 纯局内模式开启时：4 卡全部置灰 + 面板提示「纯净局：加成不生效」（见 §6）。

---

## 5. 装备交互（同时最多 2 个，gdd-codex §3.4/§6.4）

- 装备校验：`canEquipMerit(equipped, id)` —— 已装备则卸下；未装备且 <2 → 装备；未装备且 =2 → **替换确认**。
- **替换确认弹窗**（gdd-codex §6.4）：列出已装 2 个加成，选择 1 个替换（目标卡生效），或「取消」。弹窗样式与 results 面板一致（底 `#131722` + 边 `#2A3346` + 冷青主按钮 320×56）。
- 变更即时写入 save.meritEquipped（writeSave）；**下次开局生效，本局不中途变更**（gdd-codex §6.3）。

---

## 6. 纯局内模式开关（gdd-codex §3.4/§④/§6.3）

- **置顶开关**：checkbox + 说明「关闭全部功绩加成（纯净局 / 自证 / 平衡测试）」。
- 开启时：4 卡全部置灰 + 面板提示「纯净局：加成不生效」；`computeMeritApplication` 返回 `applied = []`（merit.ts）。
- 切换**即时生效（下次开局生效，本局不中途变更）**；持久化 save.pureInGame。
- QA 平衡用例在纯局内模式下执行（gdd-codex §⑧ 标准 7：「关闭主动技可击杀 Boss」判据不受功绩影响）。

---

## 7. 结算页功绩条

- 结算页新增「守夜功绩 +N」行 + 进度条（距下个加成解锁还需 X 点）；N = `calculateMeritPoints`（gdd-codex §3.4 表：存活 +1/30s、击杀 +1/50、通关 +10、首杀 Boss/精英 +2/只、化身 +5）。
- 单局典型 28~32 点；与「日志 +N」（codex-ui-spec §6）并列显示。
- 数值来源：session 结算（RunResult + 首杀 Boss/精英 + 化身击杀）；只读展示，不可跳转操作。

## 9. 数据流与状态

- **读**：save.meritPoints / save.meritEquipped / save.pureInGame。
- **写**：`toggleMeritEquipped`（`canEquipMerit` 校验 ≤2）+ pureInGame toggle；writeSave 持久化；不直接改游戏状态。
- 结算页功绩条：只读展示（本局结算值 + 累计）。
- PlayScene 开局消费：`computeMeritApplication(equipped, pureInGame, hero)` 返回 delta 写回 PlayerStats（merit.ts 已实现数据层，M3 接 UI + 装配）。

---

## 10. 边缘情况

1. **存档损坏**：save 回退空存档 → 功绩 0、无装备、纯局内关；不崩溃（gdd-codex §6.1）。
2. **加成上限 2**：第 3 个 → 替换确认（gdd-codex §6.4）；「取消」不生效。
3. **纯局内切换**：本局不中途变更；下次开局生效（gdd-codex §6.3）。
4. **功绩点数不足**：未解锁卡灰显 + 成本提示；进度条显示差值。
5. **多端存档**：桌面/移动独立，不云同步（gdd-codex §6.2）。
6. **写存档失败**（storage 满）：静默失败 + 面板一次性提示「保存失败」，不弹错不崩溃（save.ts 尽力而为）。

## 11. 治疗道具规格确认（附 · M3 随修女一起落地）

> 上游：content-design-outline §7.3 注「治疗道具（拾取·治疗 `#43D17C`，art-bible §2）建议 M3 随修女一起落地」+ asset-spec-v1 §1.5（`heal` 16×16 预留帧）+ art-bible §2/§6（治疗 = 绿 + 十字双编码）+ 修女被动「执烛之心」。

| 项 | 规格 |
|---|---|
| **掉落来源** | ① 精英敌人（守墓者 / 血肉畸体 / 石甲狼）保底掉 1 个（随 tank 槽 30s/20s 节奏，content-design-outline §4.2 R-C3-RULING）；② Boss 击杀掉 1 个；③ 血月化身稀有宝箱（chest）含 1 个（gdd-codex §3.2）。**普通怪不掉**（防掉落稀释）。 |
| **效果** | 拾取回复 **30 HP**（固定值；预案 25 若 M3 模拟治疗总量超标）。 |
| **满血拾取** | 道具**保留地面不消失**（回血后再捡有效；防浪费/挫败）。 |
| **视觉** | 16×16 青绿 `#43D17C` + 白十字（双编码：治疗 = 绿 + 十字，art-bible §2/§6）；呼吸发光（1s）+ 1.5px 纸白描边（拾取物统一，art-bible §2）；帧名 `heal`（asset-spec §1.5 预留帧，Demo 保留帧名）。 |
| **修女被动** | 执烛之心：拾取治疗道具效果 +50% → **45 HP**（30 × 1.5）。M3 随治疗道具一起生效；T0 兜底（无治疗道具版）= 被动改「击杀回血 +0.5」不再需要（content-design-outline §7.3 注）。 |
| **移动端** | 实体 **≥16px**（720 设计宽 1x；art-bible B5 双端最小实体；工程 scale 校验）。 |
| **平衡红线** | 治疗总量 = 精英保底（约 10/局）× 30 + Boss 1 ≈ **330 HP 上限**；对 6 分钟成型强度影响 ≤10%（与 merit 红线同口径，sim 校验）；**预案** = 回复 30→25 或精英掉率 100%→50%。 |

## 12. 验收标准

1. 4 加成卡渲染正确，三态齐全；装备 ≤2（第 3 个触发替换确认，gdd-codex §6.4）。
2. 解锁成本合计 120 点（分项 20/30/40/30 **待确认**）；进度条正确。
3. 纯局内模式开关置顶；开启后全部加成不生效（`computeMeritApplication` 断言 applied=[]）。
4. 结算页功绩条 +N 与进度正确（单局典型 28~32 点）。
5. 治疗道具：精英/Boss/化身掉落、+30HP、`#43D17C` + 十字、修女 +50%→45、移动 ≥16px。
6. 双端布局达标（网格 / 热区 / 字号 / 安全区）。
