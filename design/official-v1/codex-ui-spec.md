## 1. 入口与主菜单

- 主菜单（`start-overlay.ts` 扩展）：在「地图选择行」与「点击开始」按钮之间插入功能行：`[守夜日志] [守夜功绩]` 两个入口按钮（功绩见 `merit-ui-spec.md`）。
- 按钮规格：桌面 200×44 并排（间距 12）/ 移动 `flex: 1 1 0` 全宽、高 48（热区 ≥44×44，art-bible §6 触控热区硬标准）。
- 样式：与地图卡一致（底 `#131722` + 边 `#2A3346`；hover 冷青 `#54E6C9` 描边；文字 `#F2F5F9`）。
- 点击「守夜日志」→ 打开图鉴覆盖层（z-index **75**，盖在主菜单 70 之上）；「返回」回主菜单，不进入战斗。

## 4. 条目卡片（三态）

| 态 | 视觉 | 交互 |
|---|---|---|
| **解锁态** | 图标（asset-spec §1.6：`codex-event-<id>` ×6 + 复用角色/敌人/武器帧；桌面 64×64 / 移动 48×48）+ 名称 + powerTag/阵营小标签 | 点击 → 详情抽屉 |
| **锁定态** | 该条目剪影（同帧降饱和 + 暗化 α0.4）+ 中央「？」（纸白 `#F2F5F9`，≥32px）+ 下方解锁条件小字（如「首次击杀」） | 点击 → 提示解锁条件（toast 或卡片抖动），不进入详情 |
| **隐藏态（血月化身）** | **不放剪影**（保密），显示「？？？」占位 + 解锁条件「任意地图击杀（稀有月坠）」 | 不可进入详情；首杀后转为解锁态完整档案 |

> 锁定/隐藏态**不展示任何剧情字段**（名称/背景/台词保密）；「？」双编码（文字 + 形状），色盲可辨（art-bible §6）。

## 5. 详情抽屉（档案卡）

- 形式：桌面右侧抽屉（宽 480px）/ 移动底部弹出（高 60% 视口）；遮罩点击关闭；右上「返回」按钮。
- 字段渲染（每类字段与来源）：

| 类 | 字段 | 文案/数据来源 |
|---|---|---|
| 角色 | 名讳/阵营/powerTag/身份/背景/主动技/初始武器/台词 3 条/解锁条件 | narratives-spec §4（HeroArchiveText） |
| 敌人 | 名称/阵营/层级/HP·移速·伤·XP/特殊行为与反制/视觉编码/掉落 | balance ENEMY_CONFIGS + gdd-enemies-v2 + art-bible 编码表 |
| Boss | 名讳/阵营/powerTag/身份/背景/登场台词/击败台词/所属地图/掉落 | narratives-spec §5（BossArchiveText）+ balance BOSSES |
| 武器 | 名称/类/powerTag/基础数值/手感/强化槽/超武合成（若有） | balance WEAPON_CONFIGS + content-design-outline §3.2 |
| 超武 | 名称/合成（武器+钥）/行为质变/视觉表现 | balance EVOLUTIONS + outline §3.4 |
| 事件 | 档案文本（≤100 字） | narratives-spec §8.2（EventArchiveText） |

- 档案正文：桌面全宽（≤120 字）；移动单列、字号 **≥14px 物理**（gdd-codex §7 档案详情口径；局内台词 ≥16px 为叙事红线，两处口径不同，分别标注）。
- 图标复用 asset-spec 帧名（64×64 桌面 / 48×48 移动）；锁定态剪影 = 同帧降饱和。
- powerTag 徽章色（world-bible §4.1）：HALLOWED 冷青 / SILVER 月银白 / BLOOD 血橙红 / BEAST 暗血红 / MOON 幽紫——仅小标签，不占大面积（B7 语义）。

## 6. 新条目提示

- **局内**：CodexTracker 首次解锁任一条目 → 侧边浮字「守夜日志已更新。」（n_toast_codex，2.3s，narratives-spec §6）；多条目同帧合并 1 条。
- **结算页**：新增「日志 +N」（N = 本局新解锁条数），与「守夜功绩 +N」（merit-ui-spec §7）并列。

## 7. 血月化身隐藏条目（gdd-codex §3.2/§6.6）

- 解锁前：隐藏态卡片（「？？？」占位）出现在 Boss 页签**末位**；不显示名称/剪影/背景/台词。
- 解锁后（任意地图首杀）：转为完整档案；事件条目 n_event_moonavatar 同步解锁。

- 未击杀再次触发月坠：条目保持锁定，可再触发解锁（幂等，gdd-codex §6.6）。

## 9. 数据流与状态

- **只读**：save.codexUnlocked（持久化）+ CodexTracker.isUnlocked（会话态）；本层**不写**任何解锁状态（解锁由局内 CodexTracker.record 触发，M3 落 save）。
- 打开时快照当前解锁集；返回主菜单再进入时刷新（保证局内新解锁可见）。
- 事件：只发「返回主菜单」事件；不改变游戏状态（单向数据流，ADR-004）。

---

## 10. 边缘情况

1. **存档损坏**：save 回退空存档 → 图鉴全锁定，不崩溃（gdd-codex §6.1）。
2. **局内不可打开**：图鉴仅主菜单入口（局内不打图鉴，防打断节奏）。
3. **隐藏条目未解锁**：只显示「？？？」占位；不放剪影提示（防剧透）。
4. **多端存档**：桌面/移动独立（saveKey 后缀），不云同步（gdd-codex §6.2）。
5. **详情超长**：桌面全宽、移动单列滚动（桌面 max-height 760px / 移动 60% 视口）。
6. **全解锁空态**：计数徽章 4/4 等；无特殊空态（事件页未解锁前全锁定为正常态）。
7. **页签计数刷新**：局内解锁后返回主菜单再进，徽章/卡片即时更新（快照重取）。

---

## 11. 验收标准

1. 6 页签计数 = 角色 4 / 敌人 15 / Boss 4 / 武器 14 / 超武 7 / 事件 6，合计 **50**。
2. 三态渲染正确（解锁 / 锁定「？」 / 隐藏「？？？」）；锁定/隐藏不展示剧情字段。
3. 详情字段与 narratives-spec / balance 来源一致；专有名词走常量（consistency-anchors A4）。
4. 入口在主菜单可达；返回正常；不改变局内状态。
5. 双端布局达标（网格列数 / 热区 / 字号 / 安全区）。
6. 血月化身隐藏条目仅首杀后展示完整档案。
