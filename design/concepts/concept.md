# 《血月守夜》(Blood Moon Vigil) 游戏概念文档

> 项目代号：vampire-survivors-like（暂定）· 阶段：Phase 1 概念孵化 · 版本 v0.1
> 类型：幸存者 like（bullet heaven）· 2D 俯视角 · Web（Phaser 3 + TypeScript）· 桌面 + 移动双端
> 目标：先验证"好玩"，产出垂直切片 Demo 的概念基线，供 Phase 2 拆 GDD。

## 1. 一句话概念与核心体验承诺

**一句话概念**：血月之下你被无尽尸潮围攻，武器自动开火——你唯一要做的，是移动走位，并每隔几十秒决定"这一局怎么变强"。

**核心体验承诺**：在约 7 分钟一局里（6:00 Boss 收束 + 60~90s 击杀终局，TASK-31 节奏调整），体验从"被围殴的脆弱者"到"割草无双的怪物"的权力成长曲线。操作只占 1%，剩下的 99% 是 build 决策的纠结与兑现——这是该品类的核心乐趣，也是我们所有设计的出发点。

## 2. 核心支柱（4 条）

1. **走位是唯一操作**：所有攻击自动触发，玩家输入只有移动。
   - 可检验含义：Demo 中不存在任何瞄准、点击攻击或主动技能；移速与碰撞半径是玩家仅有的两个战斗参数。
2. **build 决策是唯一爽点**：升级三选一每 30~60 秒一次，选项以"改变行为"为主，而非纯加数值。
   - 可检验含义：升级池中机制改变型选项占比 ≥50%；单局至少出现 3 次"两个都想选"的纠结时刻。
3. **压力递增、险而不绝望**：敌潮密度随时间单调上升，但始终留给玩家"再撑一波就能变强"的余地。
   - 可检验含义：前 3 分钟新手死亡率低；第 5 分钟前后出现第一次濒死体验；压力曲线有波峰波谷，不是匀速平推。
4. **一局约 7 分钟，局局不同**：随机化（升级三选一、掉落、敌潮构成）保证重开价值。
   - 可检验含义：同一角色连续两局的 build 路径不重复；Demo 连续游玩 ≥3 局仍有新鲜感。

## 3. MDA 分析

- **机制（M）**：移动（唯一输入）· 自动攻击（各武器独立冷却/触发）· 经验宝石掉落与拾取 · 升级三选一 · 敌潮生成器（强度随时间上升）· 角色属性成长。
- **动态（D）**：走位拉扯（kiting）聚怪 → 武器清屏；经验宝石回收的"贪心风险"（冲进敌群捡 vs 保持安全距离）；升级时机决策（先扩范围还是先提伤害）。
- **美学（A）**：权力幻想（从被围到割草）；紧张—释放交替的节奏；收集成长的满足感。
- **爽点循环映射**：移动拉扯（M→D 聚怪）→ 武器爆发清屏 → 宝石喷涌（D→A 满足感）→ 升级三选一（A→M build 变强）→ 更敢深入敌阵 → 压力提升 → 回到移动拉扯。四类机制互相咬合，闭环内每一步都是下一步的动机。

## 4. 核心循环拆解（三层）

- **秒级循环**：走位躲避 → 自动武器输出 → 击杀 → 掉落经验宝石 → 靠近拾取。约 1~3 秒一轮，是操作手感层。
- **分钟级循环**：拾取积累 → 升级 → 三选一决策 → 战力跃迁 → 敌潮压力提升 → 走位压力升级 → 等待下次升级。约 30~60 秒一轮，是决策层。
- **局级循环**：开局弱势 → 前 2 分钟上手爽感 → 中期 build 成型 → 后期割草高潮 → 第 6 分钟终局收束 → 结算 → 重开（重开动机来自支柱 4）。

## 5. 垂直切片范围分层

### 核心必备（Demo 验收必须）

| 维度 | 内容 |
|---|---|
| 角色 | 1 名（暂定"守夜人"）；基础属性：生命 / 移速 / 伤害倍率，随升级自动成长 |
| 武器 | 3 种覆盖三种手感：① 自动飞弹（单体追踪、高频）② 护体环绕球（近身范围、防御向）③ 定时冲击波（大范围清屏、低频高伤） |
| 敌人 | 3 种：① 僵尸（慢速大量，尸潮主力）② 疾行者（快速少量，逼走位）③ 厚血怪（精英，掉大经验）；第 6 分钟 1 个收束 Boss |
| 升级池 | ≥12 项，三选一；机制改变型 ≥50%（例：飞弹分裂 +1、环绕球 +1、冲击波范围 +50%） |
| 地图 | 1 张，有限边界可包围，约 3000×3000 单位，含少量障碍物用于拉扯 |
| 系统 | 敌潮生成器（强度曲线随时间递增）、经验拾取、升级暂停选卡、结算页（存活时间 / 击杀数 / build 回顾） |
| 双端操作 | 桌面 WASD / 方向键；移动端左半屏虚拟摇杆；升级卡双端均为全屏居中卡片 |

### 增强项（时间充裕再加）

第二/第三角色（不同起始武器）· 武器进化合成（超武）· 被动饰品栏 · 局外解锁与金币 · 屏幕震动与击杀特效 · 设置页（音量 / 摇杆位置 / 画质）。

### 明确不做（防范围膨胀）

多人联机 · 多地图战役 · 局外永久成长树 · 手动瞄准 / 主动技能 · 剧情演出 · 商业化（内购 / 广告）· 云存档 · 成就系统。

## 6. 玩家心理学设计

- **自我决定论**：自主性 = 三选一自由决策；胜任感 = 走位存活 + 击杀成长的即时正反馈；关联感（单机弱项）用"本局 build 回顾 + 结算统计"轻量补偿。
- **心流**：敌潮压力曲线对齐玩家战力成长曲线，让"操作刚好够用"；三选一制造短期可掌控感，把压力转化为决策乐趣而非挫败。
- **压力曲线（前 3 分钟就爽的具体保障）**：
  - 0~10 秒：零铺垫直接开打，首批怪 5 秒内出现。
  - 0~60 秒：低压力、高击杀密度；首级升级门槛压到 5 颗宝石（约 30 秒内升级），新手立刻尝到"收割 + 变强"。
  - 1~3 分钟：压力缓升，第一次成规模的尸潮画面出现，玩家被迫开始走位——核心玩法在 3 分钟内完整亮相。
  - 之后：波峰波谷交替，第 6 分钟收束 Boss 作为终局高潮。

## 7. 视觉与听觉锚点

1. **暗红血月（Blood Moon）**：永恒夜空主色，唯一天幕光源。
2. **剪影敌潮（Silhouette Swarm）**：敌人以低细节剪影呈现，保证同屏数量与辨识度。
3. **高对比宝石光（Loot Glow）**：经验宝石高饱和自发光，成为画面焦点。
4. **霓虹哥特（Neon Gothic）**：哥特剪影 + 霓虹描边 / 粒子，低成本高辨识。
5. **心跳低音（Heartbeat Bass）**：低频脉冲随压力曲线加速，BGM 不抢操作注意力。
6. **奖励拟声（Reward SFX）**：击杀闷响 + 宝石叮声，强化收集奖励感。

## 8. 双端适配要点

- **统一方案**：战斗 / 生成 / 升级逻辑完全共用，差异只发生在"输入层"与"渲染层"。移动是唯一核心操作，双端输入统一映射为"移动向量"。
- **操作差异**：桌面 WASD / 方向键 + 鼠标点选升级卡；移动端左半屏虚拟摇杆 + 点按升级卡（触控目标 ≥44px）。
- **UI 差异**：桌面 HUD 贴边布局；移动端 HUD 上移让出拇指区、摇杆常驻；升级三选一双端一致全屏暂停选卡（同时缓解触屏误操作）。
- **性能差异**：同屏实体上限桌面 400 / 移动 250；移动端关闭远距离粒子与描边；Phaser 3 对象池 + 纹理图集 + 距离裁剪（只更新屏幕附近实体）。

## 9. 成功标准（垂直切片 Demo 验收）

- **留存**：中位存活时间 ≥4 分钟（6:00 局 Boss，4 分钟 = 2/3 局程；全通 ~7 分钟，TASK-31 节奏调整）；首局完成后同场会话"再来一局"比例 ≥50%。
- **决策质量**：三选一"纠结时刻"（埋点：停留 >3 秒或选项强度接近）≥ 每局 3 次。
- **上手**：无游戏经验测试者 30 秒内说出"只用移动"；60 秒内完成首次升级。
- **情绪**：测试问卷"3 分钟节点自评爽"≥80%；出现"停不下来""想再开一局"等自发言语 ≥ 半数测试者。
- **性能**：移动端中端机稳定 30fps+（目标 60fps），桌面 60fps 不掉帧。
