# 《血月守夜》UX 规格（UX Spec）

> 版本 v0.1 · Phase 4 预制作 · 作者：文策渊（设计策略师）
> 上游：concept.md §5/§8、art-bible.md §6/§9、accessibility-tiers.md §3、control-manifest.md
> 范围：垂直切片 Demo（无主菜单/设置页/商店）。UI 全部 DOM 覆盖层（ADR-004）。

## 1. 屏幕流（用户旅程）

**状态机**：BootScene（启动页，Scene 层）→ GameScene 内四态 RUNNING / LEVEL_UP / PAUSED / GAMEOVER（ADR-003）。

| 屏幕 | 进入条件 | 退出条件 | 状态机映射 |
|---|---|---|---|
| 启动页 | 页面加载完成 | 点击「点击开始」 | BootScene → RUNNING |
| 游戏中 | 点击开始 | 经验达标→升级；Esc/P/暂停键→暂停；HP≤0 或 20:00→结算 | RUNNING |
| 升级三选一 | 经验达标瞬间（世界冻结） | 选卡 / 30s 超时自动选第 1 张 | RUNNING → LEVEL_UP → RUNNING |
| 暂停菜单 | Esc/P/暂停键 | 继续→恢复；重开本局→scene.restart() | RUNNING ↔ PAUSED |
| 结算页 | HP≤0 或存活 20:00 | 再来一局→scene.restart()；返回启动→重载 BootScene | RUNNING → GAMEOVER |

要点：死亡/通关均立即切 GAMEOVER，不新增中间态，0.4s 死亡消散粒子作为结算页入场表现；启动页必须保留「点击开始」按钮——Web 音频策略要求用户手势解锁 AudioContext，此为工程硬前提。

## 2. HUD 布局规范

**通用规则**：桌面按 1920×1080 基准绝对坐标；移动端按视口缩放，字号走物理 px（不随画布缩放，满足 ≥14px 物理下限）。

**桌面（1920×1080）**：等级文本「LV n」左上 (24,16) 20px 加粗；经验条 (24,48) 240×8px，蓝 #4FC3F7 填充 / 黑底 #000A；HP 条 (24,1042) 240×14px，红 #FF3B30 填充 / 黑底，HP 数值 (24,1018) 20px；武器槽 3 个 48×48px 自 (1736,24) 横排、间距 8px；暂停无可见按钮（Esc/P），开局 0~5s 顶部中央提示「Esc 暂停」16px 后淡出。

**移动（720×1280 基准）**：HUD 上移让出拇指区（y>896 下方 30% 仅放摇杆）。顶部安全边距 24px：等级 (24,24) 20px；经验条 (24,56) 220×8px；HP 条 (24,80) 220×14px + 数值内嵌 20px（HP 从桌面左下上移至顶部，避开左拇指区）；暂停键贴右上角 (652,24) 44×44px（热区=视觉）；武器槽 3 个 44×44px 自 (512,24) 横排、间距 8px；虚拟摇杆常驻左下半区，底座中心 (180,1120)、视觉直径 96px、死区半径 9.6px（中心 10%）。

## 3. 升级三选一交互流

触发：经验达标 → GameState 切 LEVEL_UP（世界冻结、摇杆隐藏）→ 抽 3 项 → 覆盖层渲染。
展示：三卡居中偏上。桌面 320×180px、间距 24px，整行起点 (456,520)，图标区 128×128px（上图标下文字）；移动 200×112px、间距 16px，整行宽 632px 居中，垂直中心 y≈560，图标 72×72px，整卡热区远大于 44px。
操作：桌面鼠标点卡或数字键 1/2/3 直选；移动点按卡片。非卡片区点击/拖拽/长按无响应（遮罩拦截）。30s 超时自动选第 1 张。
选中反馈：冷青 2px 描边 #54E6C9 + 缩放 1.03（0.1s）+ 确认音效 → 应用效果 → 回 RUNNING。
**防误触设计决策**：①选卡期间冻结移动输入（与 control-manifest §5 一致），防选卡时角色漂移；②恢复 RUNNING 时移动向量强制归零——防按住方向键/摇杆残留导致恢复瞬间角色瞬移，为对上游的补充决策；③选卡期不响应暂停键（LEVEL_UP 优先）；④恢复后摇杆需重新按下激活，不继承旧向量。
标注：数字键 1/2/3 为新增映射，建议程基岩补入 control-manifest §3。

## 4. 结算页

通用：面板居中，遮罩拦截非面板区。标题/统计/Build 回顾/两按钮。
桌面：面板 640×760。标题「守夜失败」或「血月退散·守夜完成」32px 加粗；统计行存活时间/击杀数/等级 28px；Build 回顾（所选升级清单，标题 20px、每项 16px，超出 12 项滚动区高 240px）；「再来一局」320×56 主按钮（冷青描边）+「返回启动」160×44 次按钮。
移动：面板 92vw（≈662px）；统计 3 行竖排；Build 回顾滚动区 max-height 220px；按钮全宽竖排：「再来一局」高 64px、「返回启动」高 48px（热区均远大于 44px）。

## 5. 双端交互差异表

| 操作 | 桌面 | 移动 |
|---|---|---|
| 移动 | WASD/方向键 8 向，向量恒 1 | 左半屏摇杆，幅度 0~1；底座常驻 (180,1120)，死区 10% |
| 升级选卡 | 鼠标点卡 / 数字键 1/2/3 | 点按卡片（热区 200×112） |
| 焦点导航 | Tab+Enter（焦点态=冷青 2px+缩放 1.03） | 无（点按即选，无 hover） |
| 暂停 | Esc / P | 右上角 44×44 按钮 |
| 结算 | 鼠标点击 | 点按（按钮热区见 §4） |
| 通用 | hover 可用（缩放 1.03） | 无 hover，全部点按触发 |

## 6. 可访问性落实（Basic 8 条逐条对照）

| # | Basic 要求 | 本规格落实 | 满足层 |
|---|---|---|---|
| 1 | 信息双编码 | 升级卡图标/拾取提示强制「颜色+形状」；形状资产（三角/十字/菱形/角饰）由美术圣经 §9 提供 | UX 约定图标位 + 美术资产 |
| 2 | 对比度 ≥4.5:1 / ≥3:1 | 沿用 art-bible 调色板：卡底 #131722、文字 #F2F5F9、选中描边 #54E6C9 | UX 引用 + 工程校验 |
| 3 | 触控热区 ≥44px | 暂停键/卡片/再来一局/返回启动全部达标（见 §3~§5） | UX 满足 |
| 4 | 字号下限 | HUD 数值 20px、卡标题 22px、正文 16px，物理 px 不锁画布 | UX 满足 |
| 5 | 减少闪烁开关 | 暂停菜单底部开关（默认关），控陷阱闪烁/受击白闪/屏幕震动；移动震动默认关 | UX 入口 + 工程存储注入 |
| 6 | 焦点可见 | 桌面 Tab+Enter 导航，焦点态=冷青 2px+缩放 1.03；数字键 1/2/3 直选 | 需工程焦点系统（Phaser 无 DOM 焦点） |
| 7 | 高对比基础版 | 暂停菜单开关（描边 2→4px/背景降饱和/文字黑底）；⚠️ control-manifest A1 默认「关」与 accessibility Basic#7「Demo 期默认开」冲突，本规格建议默认开，待主理人拍板 | UX 入口 + 工程参数注入 |
| 8 | 重要事件双通道 | 升级=经验条满闪光+叮声；受击=红闪白闪+受击音；稀有拾取=金图标+独特音效（触发点见 §7） | UX 定义触发点 + 工程音频播放 |

**需工程/美术配合项**：焦点系统状态机、AudioContext 手势解锁、localStorage 持久化、色板 token 统一、震动 API、高对比/减少闪烁参数注入（工程）；双编码形状资产、高对比描边参数（美术）。

## 7. 微交互清单

| 微交互 | 参数 | 触发点 | 实现层 |
|---|---|---|---|
| 升级卡滑入 | 0.2s 自下 16px 上浮 + 透明度 0→1，三卡 60ms 错峰（左→中→右） | 进 LEVEL_UP | UI 层（CSS，DOM 不受世界暂停影响） |
| 选中反馈 | 冷青 2px 描边 + 缩放 1.03（0.1s） | 点卡 / 按 1/2/3 瞬间 | UI 层 |
| 选择确认音效 | 短促「叮」 | 选卡点击后立即 | 工程层（需启动页手势解锁） |
| 结算数字滚动 | 0→目标值 0.8s 缓出递增 | 进 GAMEOVER 后延迟 0.2s | UI 层（rAF 数字滚动） |
| 经验条填充 | 0.15s 缓动 + 满条闪光 0.3s | 经验变化 / 升级 | UI 层 |
| HP 受击反馈 | 条白闪 0.1s + 数值 1.05 缩放 0.1s | 受击事件 | UI 层 + 工程层（事件上报） |
| 摇杆激活反馈 | 底座亮起 0.05s + 拇指阴影 | 左半屏 pointerdown | 工程层 |
| 稀有拾取提示 | 右侧金图标浮现 1.2s 渐隐 + 独特音效 | 稀有掉落拾取 | UI 层 + 工程层 |
| 按钮 hover（仅桌面） | 1.03 缩放 + 冷青描边 | 鼠标悬停 | UI 层（移动无 hover） |
