## 1. E1 远程击杀 / 移速失衡

### 1.1 根因分析（数值依据）

| 数值 | 现值 | 含义 |
|---|---|---|
| 飞弹射程 | 400px/s × 3s = **1200px** | 可击杀距玩家 1200px 内的敌人 |
| 敌出生环带 | 600–900px（桌面）/ 500–800px（移动） | 飞弹 1.5–3s 内即可打中刚出生的环带敌人 |
| 玩家移速 | **220px/s** | 走 500px 需 2.3s（单程） |
| 磁吸半径 | **80px** | 以玩家为中心，桌面 1920 宽仅占 4%、移动 720 宽占 11% |
| 磁吸速度 | 320px/s | 80px 内 0.25s 吸入；**快于玩家移速** → "宝石追玩家"可行 |

**链路**：飞弹远距离击杀（典型击杀距离 300–800px）→ 宝石落在磁吸半径（80px）之外 → 玩家必须步行往返 1.4–7.2s 去捡 → 打断走位拉扯节奏（concept §6 MDA"贪心风险"本是"短暂冲进怪堆捡"，现实变成"长距离跑图捡"），高频时累积为"不方便"。
**磁吸速度 > 玩家移速**说明瓶颈是**半径**而非速度：扩大半径即可让宝石"追上来"，不必让玩家"走过去"。

### 1.2 候选方案

| # | 措施 | 数值范围 | 体验影响 | 风险 | 性能影响 |
|---|---|---|---|---|---|
| **A** | 提升玩家移速 | 220→230~245px/s（+4.5%~+11%） | 最直接；走路/拉扯/绕屠夫更快 | ① 削弱 5min 首次濒死压力（concept §6：尸潮持续贴脸靠移速拉扯，快=更易脱身）；② 移动端摇杆精度下更快更难控；③ 改 E1-S6 验收基线（moveDisplacement 断言 220） | 无（纯数值） |
| **B** | 扩大磁吸半径（+提速） | 80→120~160px；磁吸速度 320→340~400px/s | 直接缩短"走过去捡"；140px 下吸入 0.39s、手感顺滑；升级第 9 项变 140→280→420 | 削弱"贪心风险"张力（范围越大越无脑吸）；80→140 保留"还得靠近"，不破坏 MDA 动态 | 逻辑无渲染；磁吸中宝石数↑ → 桌面宝石拖尾粒子并发↑（见 §4，预算内） |
| **C** | 飞弹射程限制/命中后消散判定 | LIFETIME 3→2.2s（射程 880px）或速度 400→320 | 限制击杀距离，宝石掉近些 | **与品类爽点冲突**：远程割草是幸存者 like 本体，砍射程=砍前期清怪效率（出生环带 600-900px 部分打不到）；且问题在"捡"不在"打" | 无 |
| **D** | pull-to-kill（击杀瞬间玩家向目标短距吸附） | 吸附 30~80px | 宝石自然变近 | **劫持玩家控制**（强制位移打乱走位），手感负面；实现需处理"吸向怪堆"的危险方向 | 无 |
| **E** | 经验宝石向玩家缓慢漂移 | 远离时 60~120px/s；或 drop 瞬间向玩家 pop 40~80px | 远处宝石慢慢聚拢，无需走回头路 | ① 全图宝石齐漂 → 视觉噪点、丢失"地面战利品"美学（art-bible 锚点 3）；② 若速度过快=免费全屏拾取，摧毁贪心风险。**须限速 + 限时**（见推荐） | 纯 x/y 位移，无粒子；宝石并发漂移数上限=宝石池 300/200，可忽略 |

### 1.3 推荐方案 + 具体数值

**E1 = B（主）+ E-lite（辅）；A 列为用户可选附加**

1. **B：磁吸半径 80→140px，磁吸速度 320→360px/s**（`balance.ts GEM.MAGNET_RADIUS / MAGNET_SPEED`）
   - 理由：140px 覆盖"近距离击杀 + 稍偏离走位线"的绝大多数宝石；360px/s 让 140px 内 0.39s 吸入，手感干脆。
   - 升级第 9 项（×2/×3）随之变为 140→280→420px——第 2 级 280px 已接近全屏边缘吸附，仍是"想拿就拿"的后期爽点，不贬值。
   - 保守起见**不动** `PICKUP_RADIUS 16px`（拾取判定与磁吸分离，维持现有语义）。
2. **E-lite：滞留宝石慢漂**（收敛位：`xp-manager.ts stepGem` 的 idle 分支）
   - 规则：宝石**落地 >3s** 且距玩家 >140px 时，以 **80px/s** 向玩家漂移（低于玩家移速 220，追不上移动中的玩家 → 不会变"免费全屏拾取"）；进入 140px 磁吸半径后切换为 360px/s 磁吸吸入。
   - 理由：3s 延迟保留"即时掉落的宝石就地陈列"的短时反馈（不丢战利品美学）；80px/s 慢速只"回收"被遗忘的远击杀宝石，玩家仍需在远处击杀点附近停留一会儿才能收——贪心张力保留。
3. **A（可选，用户拍板）**：玩家移速 220→**235px/s**（+6.8%，`balance.ts PLAYER.MOVE_SPEED`）
   - 若要"走路体感更利落"再加此条；不强制。**注意**：会同步削弱 5min 濒死压力、需更新 E1-S6 验收断言（220→235）；若用户担心压力下降，可只上 B+E-lite，A 不做。

**明确不做**：C（砍飞弹射程）、D（pull-to-kill）——与支柱 1/3 或手感冲突，列为负面清单供评审留档。

## 2. E2 节奏慢 / 难度陡峭

### 2.1 根因分析

| 现象 | 数值根因 |
|---|---|
| **大部分时间秒小怪** | ① 8–15min 构成 65% 僵尸（12HP），飞弹 12 伤 1 弹秒杀，且玩家成型 DPS 60–124 ≫ 预算 2.4–3.45/s → 屏幕经常清空；② 预算正弦波谷过深（±40%，60s 处实际仅 ~0.84 点/s）→ 前期/谷期怪稀 |
| **突然来一个不好打死的精英** | 屠夫 600HP 首现于 3min 保底（180s+30s=210s）；5min 玩家 DPS ~26 → 需 **23s/只**；保底 30s + 随机 3% 叠加 → 3–5min 场上可同时 3–4 只 → 落差陡峭 |
| **没能坚持到 Boss** | 移动端 ZS-02 于 612s（10min）死亡、Lv23：中段（8–15min）僵尸为主+屠夫叠加，玩家 build 未成型（首级三选一 1/2 号新武器全不中概率 ~33%，E3 评审 §3）→ 战力不足以同时处理屠夫+尸潮 |
| **节奏慢（叠加）** | ① 前期怪稀（0–3min 95% 僵尸 + 低预算 + 深波谷）；② R1 ZS-01 满局 **Lv47** 越过 E3 预置 Lv45 预警线（lastUpgradeInterval 38s<45s）→ 战力过剩 → 秒小怪更明显、升级决策过密 |
| **精英无预警** | spawner §④ 仅"出生时"低音，无提前预兆 → 体感"突然" |

### 2.2 候选方案

| # | 措施 | 数值范围 | 体验影响 | 风险 | 性能影响 |
|---|---|---|---|---|---|
| **A** | spawner 难度曲线平滑化 | LINEAR_SCALE 2.5→2.8~3.2；WAVE_AMPLITUDE 0.4→0.25~0.35 | 谷期不再空场；中后段压力连续；波峰波谷仍可感知 | 改预算曲线 → `spawner.test/balance.test` 预算断言需同步（见 §5） | 无（纯逻辑；同屏上限节流不变） |
| **B** | 升级池前期 DPS/生存杠杆 | ① 首级三选一强制含 1/2 号武器；② 伤害强化 +15%→+18%；③ 冷却 -8%→-10% | ① 开局即得第二武器 → 5min 打屠夫快一半；②③ 提高中后期 DPS 上限 | ① 首级少 1 个自由选择（自主性轻微受损，仅 1 次）；②③ 战力再涨 → 更"秒小怪"（需与密度提升对冲） | 无 |
| **C** | 精英出现时机：延后 + 预警 | 保底首只 210s→延后或保留；**出生前 2–3s 血月印记**（敌出生点红圈+低音） | "看到它要来"→ 可提前绕开/集火，消除"突然" | 移动端 edgeWarning=false、screenShake=false → 需用出生点本地预兆而非全屏红光（不叠加全屏红晕，art-bible §5 防混淆） | 极低（1 个临时精灵，随屠夫出生销毁） |
| **D** | 中段填实（给中等强度敌） | 8–15min：僵尸 65→55、疾行 28→36、厚血 7→9；预算 LINEAR 提升 | 中段屏幕始终有事做：疾行逼走位、厚血逼集火，不再"秒完发呆" | 中段难度↑ → 新手中段死亡率↑（配合首级武器 + 预警对冲） | 无（敌人不新增类型） |
| **E** | 缩短开场（首怪时机） | 首怪 5s 内（已满足，concept §6）| 无需改 | 原话"3min→2min"实为"首次成规模尸潮提前"，由 A 的波谷变浅 + 0–3min 疾行 5→10 达成，不单独调 spawn 时机 | 无 |

### 2.3 推荐方案 + 具体数值

**E2 = A+D（敌潮曲线重构·主）+ C（屠夫预警）+ B①（首级强制武器）+ 厚血经验 15→10（E3 预授权判据已触发）**

1. **构成权重重构**（收敛位：`spawner.ts SPAWN_STAGES`）

| 阶段 | 现值 z/w/t | 建议值 z/w/t | 理由 |
|---|---|---|---|
| 0–3min | 0.95 / 0.05 / 0 | **0.90 / 0.10 / 0** | 开局多疾行：节奏加快、逼走位、2 经验加速首级（不伤新手：疾行 150 追不上 220） |
| 3–8min | 0.80 / 0.17 / 0.03 | **0.78 / 0.20 / 0.02** | 屠夫随机 3%→2% 减少叠加堆积（"突然一堆打不动"主因）；疾行补位维持压力 |
| 8–15min | 0.65 / 0.28 / 0.07 | **0.55 / 0.36 / 0.09** | 中段填实：僵尸↓、疾行↑、厚血↑ → 告别"秒小怪发呆"；厚血 9% 仍受 30s 保底约束外无额外堆积 |
| 15–20min | 0.50 / 0.35 / 0.15 | **0.45 / 0.35 / 0.16** | 末期维持高压但不超 C7 判据（≈原 15%，仅 +1） |

2. **预算曲线**（收敛位：`balance.ts SPAWNER`）
   - `LINEAR_SCALE 2.5 → 3.0`：20min 均值预算 4.2→**4.8** 点/s（+14%），中后段密度提升，抵消"成型后没怪杀"。
   - `WAVE_AMPLITUDE 0.4 → 0.3`：波谷 ×0.6→×0.7，60s 处实际预算 ~0.84→~0.99 点/s；峰谷比 2.33→1.86，**仍满足 spawner §⑧.2 "相邻周期差异 ≥40%"**（(1.3−0.7)/0.7 ≈ 86% ≥ 40% ✔）。
   - `TANK_GUARANTEE_EVERY_SECONDS` **保持 30s 不动**（C-7 记录：40→30 已因"厚血未发现"回调；本次不动数量、只加预警）。
3. **屠夫预警**（收敛位：`enemy-spawner.ts` 保底出生路径 / `fx` 复用）
   - 保底屠夫**出生前 2.5s** 在出生点生成"血月印记"（本地红圈精灵 + 精英登场低音提前），出生时印记销毁、屠夫落地。
   - 桌面 edgeWarning 可额外叠加"边缘红光脉动"（复用现有机制，不加新 draw call）；移动端因 edgeWarning=false，用出生点本地预兆（不叠加全屏红晕，art-bible §5 防混淆）。
4. **首级三选一强制含武器**（收敛位：`upgrade-pool.ts rollThree`）
   - 规则：**首次 rollThree**（`state.level` 相关无独立字段，可在 XpManager/PlayScene 侧记"首次抽取"标志）时，三选一**至少包含 1 或 2 号项**（随机取一，另外 2 项正常抽取）。
   - 理由：开局 DPS 10→含环（+16 参考）或波（+7.5）→ 5min 屠夫 TTK 从 23s 降到 ~12–17s；同时兑现 concept"前 3 分钟就爽"。代价=首级少 1 个自由项（仅 1 次，可接受）。
   - **备选**（若用户不想动抽取规则）：改第 10 项"伤害强化 +15%→+18%"或第 11 项"冷却 -8%→-10%"，但收益不如直接给武器、且会更"秒小怪"，故非首选。
5. **厚血经验 15→10**（收敛位：`balance.ts ENEMIES.tank.xp`）
   - E3 评审预置判据"真机 Lv≥45 → 厚血 15→10（首选，不动前期）"已被 R1 ZS-01（Lv47、lastUpgradeInterval 38s）**触发**，属预授权变更。
   - 作用：压后期经验通胀（厚血是后期经验大头），配合预算提升把满局等级从 ~47 拉回 **~42–45** 区间，缓解"升级过密/战力过剩秒小怪"。
   - **注意**：`art-bible §4` 有"厚血 3 倍经验"硬标准——现值 15 本已不严格对应"3×僵尸 1"，本次 15→10 需一并更新 art-bible 口径（列进变更清单，交林绘澄/主理人确认）。

**不做**：改 need 曲线（`XP.NEED_STEP 3→3.5`）——牵动 xp-curve 全部断言与 GDD，代价大；若 R2 后期升级间隔仍 <45s，再启用此备选（见 §6）。

## 4. 性能预算影响

**结论：所有推荐方案不超预算。** draw call ≤8、粒子池 ≤200/100 均满足。

| 预算 | 现状 | 变更后 | 说明 |
|---|---|---|---|
| draw call | ~5（背景1+characters1+effects1+ambient1+粒子1） | **~5（不变）** | 磁吸/漂移/权重/经验全是逻辑数值，无新纹理/图集/图层；血月印记=1 个临时精灵（复用 effects 图集，出生即销毁） |
| 粒子池（桌面 200） | 击杀 8–16 粒/只 + 拖尾等 | **仍 ≤200** | 磁吸半径↑ → 同时被磁吸的宝石↑ → 桌面宝石拖尾（GEM_TRAIL 150ms/颗、寿命 0.2s）最坏 ~300 颗全吸 → 并发 ~80 粒，加其他 FX 仍 <200 |
| 粒子池（移动 100） | fxTrails=false → 无宝石拖尾 | **不变** | 磁吸半径提升在移动端**不产生拖尾粒子**（fxTrails 关闭），漂移为纯 x/y 位移 |
| 实体数 | 敌 400/250、宝石 300/200、子弹 8 | **不变** | 预算提升只提高生成频率，同屏上限 + retry 节流逻辑已锁峰值（bench 场景 A 断言峰值=上限，不受影响） |
| 每帧磁吸遍历 | ≤300 宝石 | **不变** | 半径只改判定，遍历次数=池上限不变；漂移判定并入 idle 分支，无新增遍历 |

**移动端降档建议**：
- 血月印记在移动端用**出生点本地红圈**（禁全屏红光/震动——edgeWarning=false、screenShake=false 保持关闭）；印记精灵尺寸 ≥16px 最低实体（enemies §⑦）。
- 可选：移动端磁吸半径取 **130px**（桌面 140）以保留更大贪心张力——但为代码单一性，**默认同值 140**，仅当 QA 真机反馈"移动端捡得太容易"时降档（记录 CONCERNS）。
- 宝石漂移双端同值（纯逻辑，无渲染成本）；若真机发现"宝石追人"视觉噪点，移动端可关闭漂移（`runtime-config` 加开关，默认开）。

### 5.3 真机 / Playwright 建议测的路径
1. **玩家 vs 屠夫 1v1 时长**：5min 节点（首级已强制武器）单独引 1 屠夫，测击杀耗时——目标 **≤17s**（现 23s）。Playwright 可注入 spawn 调试。
2. **飞弹击杀距离统计**：临时埋点/日志记录"宝石落地距玩家距离"分布——目标：**80% 宝石落在 ≤140px 内或 5s 内进入漂移**（R1 反馈"不方便捡"的量化收敛）。
3. **宝石回收时延**：远击杀（≥300px）宝石从落地到拾取平均时延——目标 ≤6s（漂移 80px/s + 磁吸 360px/s 下 300px 约 4–5s）。
4. **首级升级时间**：firstLevelUpSeconds ≤30s（playtest-plan Q2，现 ZS-01 21s / ZS-02 18s，应保持）。
5. **5min 濒死点**：前 3 分钟低死亡率 + 5 分钟前后首次濒死仍出现（concept §6/§9）——**移速若上 A 需重点复测**。
6. **中段（8–15min）屏面活跃度**：QA 行为观察"秒小怪发呆"是否消失、疾行/厚血是否持续出现。
7. **后期升级间隔**：lastUpgradeIntervalSeconds 目标 **≥45s**（现 ZS-01 38s <45s 预警）→ 验证厚血经验 15→10 是否生效；若仍 <45s → 启用备选 need 3→3.5（§6）。
8. **移动端**：屠夫血月印记可见性（无全屏红光下 2.5s 预兆是否足够）；磁吸 140 在 720 宽屏上是否"捡太容易"。

### 5.4 基线对比建议
- R1 数据已收齐（ZS-01/ZS-02），**不回跑 R1**；但建议跑一次**同种子/同操作的"基线 vs 调后"对照**（桌面 20min 满局 + 移动端 10min），记录 kills / level / survivalSeconds / 升级间隔，供 R2 判定收敛。

## 6. 风险与备选

| # | 方案 | 潜在副作用 | 备选 / 回退 |
|---|---|---|---|
| 1 | B 磁吸 80→140 | 贪心风险张力下降；移动端可能"捡太容易" | 回退到 120px；或移动端单独 130px（需 runtime-config 分支，默认不做） |
| 2 | E-lite 漂移 | 视觉上宝石"追着人跑"，弱化地面战利品陈列；慢漂若被玩家反向拉远永不追上 | 关闭漂移只留 B；或将漂移阈值 age>3s 提到 5s、速度降到 60px/s |
| 3 | A 移速 220→235（可选） | 削弱 5min 濒死压力（concept §6 关键节点）；E1-S6 验收基线要改 | **默认不上**；若用户要"走路利落"再加，并配合 E2 预算提升对冲压力 |
| 4 | E2 预算 LINEAR 3.0 + 权重重构 | 中段难度↑ → 新手中段死亡率↑（移动端 ZS-02 类玩家可能更早死） | 回退 LINEAR 3.0→2.8；或 8–15min 厚血 9%→8%；保底权重 3–8min 0.02 已是保守值 |
| 5 | 厚血经验 15→10 | 后期升级变慢 → 若过头，Boss 战 DPS 不足（Boss 6000HP 需 ≥60–90s 内击杀，concept §9 / GAME） | E3 备选反转：若 R2 Boss 战 >90s，再回调厚血 10→12（折中）或降 Boss HP 6000→5000（C4 预案，E4 评审已预留） |
| 6 | 首级强制武器 | 首级少 1 个自由选择（自主性轻微受损） | 不做抽取规则改动，改为第 10 项 +15%→+18%（但收益弱、更秒小怪）；或开局免费送环（改 INITIAL_DPS_REFERENCE 口径，牵动更大，不建议） |
| 7 | 屠夫预警（血月印记） | 若预兆仅 2.5s 过短/过隐蔽，仍"突然" | 延到 3–4s；或桌面叠加边缘红光脉动（edgeWarning 复用） |
| 8 | 测试断言批量更新 | 改断言可能掩盖回归（把期望值改对但行为仍偏） | 断言更新必须**以新模型预期值**为准（§5.2 表），并跑一次基线实测对照（§5.4），禁止"改到绿为止" |

**设计理论红线复核**：
- 主导策略：无（三武器各司其职；首级强制武器不构成唯一最优 build，后续三选一仍随机）。
- 经济失衡：厚血经验 15→10 压通胀；磁吸扩大不改变经验数值本身。
- 认知过载：预警 + 少叠加 = 减噪；无新增机制/UI。
- 支柱漂移：支柱 1（走位唯一操作）✔；支柱 2（build 决策，首级仅一次保底）✔；支柱 3（压力递增且 5min 濒死保留——前提是**不上移速 A 或预算提升对冲**）✔；支柱 4（随机性：仅首抽保底，其余不变）✔。
