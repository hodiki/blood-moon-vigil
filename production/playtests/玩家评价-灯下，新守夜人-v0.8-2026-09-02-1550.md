# 玩家评价

- 玩家：灯下（新守夜人）
- 版本：v0.8
- 时间：2026-09-02 15:50
- 试玩：守夜人·艾德蒙 / 月下墓地 / 破旧提灯约 75 秒；同角色圣徒左轮约 89 秒。两局都到 LV5，未打完一夜。

这已经是一局能「玩起来」的守夜。点开始后很快进入「走位、清怪、捡蓝钻、停下来选卡」的循环，专武二选一和「落选变主动技」一句话说清楚了，比很多同类游戏的开局更有选择感。

手册里写的几件事，前 90 秒里能摸到一部分：

- **专武定骨**：提灯是贴身灯环，左轮是拉开打；同样转圈走位，提灯会挨打，左轮几乎不掉血，玩法差得足够大。
- **共鸣来得很快**：两局都在第一次或第二次升级就刷到对应共鸣钥（提灯的「圣辉坠饰」、左轮的「圣银弹丸」），选完 HUD 从「待取钥」变成「共鸣」，反馈及时。
- **专武强化也出现了**：提灯刷到「长明灯阵」，左轮刷到「圣痕连锁」，和手册「开局尽快拿第一件专武强化」对得上。

作为第一次上手的人，别扭主要在「界面在跟策划说话，没有在跟我说话」。

1. **选图、选武器、选升级都夹着内部术语。** 地图卡写着 `Boss: boss_1`；专武卡是 `MOON · B 环绕/领域混合`、`DPS 锚 12~14`；升级卡顶上是 `P2 保底`，底下是 `机制改变` / `A2 弹幕穿透` / `140→280→420px`。手册承诺「不用记数字」，卡面却把数字和编号摊开。第一次升级我会愣一下：这是奖励还是调试信息？
2. **键位几乎没人告诉我。** 开局只有短暂的「Esc 暂停」。WASD、空格（落选专武的技能）、Q（圣物）都要自己猜。桌面没有技能键图标，空格按下去也很难确认有没有放出来。
3. **HUD 缺「现在是夜里第几分钟」。** 血条和等级有，夜里进度没有。同类游戏玩家靠时钟判断要不要留大招、要不要贪经验；这里只能凭场上怪变不变多来猜。
4. **右上角武器槽和当前专武对不上直觉。** 提灯局槽位看起来仍像弓/杂物，灯环主要靠角色脚下一圈黄光来认；左轮局后半段能看出枪和弹道，辨识好很多。场上那颗大红球（血月）也很容易被认成怪或 Boss。
5. **「守夜日志已更新」toast 停得太久。** LV3 到 LV5 还挂着，会挡视野，也让人搞不清是不是又解锁了一次。

手感上，**左轮这 90 秒比提灯「像一个完整武器」**：有弹道、有枪图标、清场更干净。提灯更像「站在光里等怪撞上来」，灯环偏淡，伤害反馈不够响。两局都还没碰到 Boss、圣物、方阵和精英完整招式——手册后半本还没验到。
