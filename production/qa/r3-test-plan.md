## 2. 修复回归优先级 P0（先做这两组，再做其他）

### 2.0 P0-PRE 预热准备

开局一局，正常刷怪升级到能拿到进化卡的位置。建议至少打满 2 局备用。以下矩阵一次「三态」流程即可全部覆盖。

### 2.1 R3-P0-1 · BUG-1 回归：升级三选一「进化前 / 当次 / 后」三态矩阵

> 上轮报告 §9 用例 2 更新版。BUG-1 的原始现象：拿到进化卡消耗之后，下一次升级 UI 完全隐形（opacity 0、键盘鼠标全无响应），整局卡死只能刷新。

**流程**：在一局内依次制造下表三种状态，每次都按下表逐格勾选。
**通用预期**：任何一次升级弹层都必须——卡片可见；鼠标点卡可选；键盘 `1/2/3` 可选（保底输入）；选择后界面消失、游戏恢复运行；不出现需要刷新的情况。

| # | 三态 | 操作 | 卡片可见 | 鼠标可点 | 键盘 1/2/3 可选 | 选后恢复游戏 | 备注 |
|---|---|---|---|---|---|---|---|
| S1 | **进化前**某次普通升级 | 正常刷怪触发升级 | ☐ | ☐ | ☐ | ☐ | 与上轮一致即可过 |
| S2 | **进化当次** | 类成型（同一武器类强化 2 次）+ 持对应钥 → 进化卡出现并选中它 | — | — | ☐ | ☐ | 记录进化横幅是否出现；选中是否直接生效 |
| S3 | **进化后再升一级**（P0 核心） | 选完进化卡继续刷怪，触发下一次升级 | ☐ | ☐ | ☐ | ☐ | 上轮在此卡死。任意一格不过即为 P0 复现 |
| S4 | 进化后再升一级·第二次及以后 | 再多升 1~2 次 | ☐ | ☐ | ☐ | ☐ | 兜底确认没有延迟爆发的隐性回归 |

补充记录（任一格异常时必填）：

- DOM 是否存在 `.bmv-levelup-mask` / `.bmv-levelup-cards`（F12 Elements 搜 class 名）及其 opacity；
- `requestAnimationFrame` 是否仍在跑但画面冻结（上轮特征：画面锁死约 20fps）；
- 键盘 1/2/3、Esc 分别有无反应。

**通过标准**：S1~S4 全绿，整局无需刷新。

### 2.2 R3-P0-2 · BUG-2 回归：图鉴 / 功绩面板检查表

> 上轮报告 §9 用例 3/4 更新版。原始现象：启动蒙层 `.bmv-start-mask` 挡住面板，返回/勾选/页签全部点不到，Esc 无效，Tab 焦点漏到「点击开始」。

在启动页分别打开「守夜日志（图鉴）」「守夜功绩」，各执行一遍：

| # | 检查项 | 图鉴 | 功绩 | 通过标准 |
|---|---|---|---|---|
| M1 | 「返回」按钮鼠标可点 | ☐ | ☐ | 点击即返回启动页 |
| M2 | 自动化口径：`document.elementFromPoint(按钮中心坐标)` 命中按钮而非 mask | ☐ | ☐ | F12 Console 执行：把光标悬停在返回钮上，控制台敲 `document.elementFromPoint(event.clientX,event.clientY)` —— 需回按钮自身，不是 `.bmv-start-mask`（此步可选，做了更好） |
| M3 | Esc 关闭面板 | ☐ | ☐ | 按 Esc 返回启动页，且**不**误开暂停/误开局 |
| M4 | Tab 焦点陷阱：连按 Tab 后按空格/回车 | ☐ | ☐ | 焦点不出面板；焦点不会落到遮住看不见的「点击开始」（不会莫名开局）；关闭面板后焦点应还给「点击开始」 |
| M5 | 图鉴 6 个页签都能切换 | ☐ | — | 点每个页签有内容响应 |
| M6 | 功绩「纯局内模式」勾选可切换并可保存 | — | ☐ | 勾选→返回→重进仍记住该状态 |
| M7 | 功绩加点（若点数足够） | — | ☐ | 点得动、数值变化、刷新后仍在 |

**通过标准**：每列全绿。任一格失败请按 §8 格式报 Bug 并截图 Console。
