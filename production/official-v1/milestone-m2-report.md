## 三、关键工程决策（可追溯）

1. **数据驱动内容管线**：武器/敌人/角色/升级/地图全配置表（balance.ts），行为注册表模式（WeaponId→Behavior / spawnByConfig）
2. **超武合成**：类强化≥3 次 + 持钥 → 进化卡（×3）→ 行为质变不可逆
3. **单局池裁定（R-B）**：31 项固定池，组成随持有类数变化（未拥有类=新武器解锁卡）
4. **tank 槽精英化（R-C3）**：三图保底=该图 elite tier，新增守墓者补墓地精英缺口
5. **Boss 不吃地图移速加权**（舞台战常量）
6. **测试挂起根因**：`| tail` 管道缓冲（非测试问题），CI 用流式日志规避
