## 一、已确认决策（用户拍板）

| # | 决策项 | 结论 |
|---|---|---|
| D1 | 范围规模 | **均衡 1.0**：4 角色 / 12~15 武器+超武合成 / 12~15 敌人+3~4 Boss / 3 地图 / 图鉴+轻量局外成长 |
| D2 | 叙事深度 | **轻叙事**：世界观圣经（血月起源/阵营/时间线）+ 角色背景卡 + Boss/地图档案 + 局内点缀（序章文案/Boss 台词） |

## 四、内容规模目标（D1 定稿）

| 内容 | T0 均衡 1.0 | T1 增强（1.x 备选） |
|---|---|---|
| 角色 | 4 名（主动技+武器模板+被动+成长曲线差异化） | 6 名（含隐藏角色） |
| 武器 | 12~15 把（4 类手感）+ 超武合成 | 20+，词条系统 |
| 敌人 | 12~15 种 + 3~4 主题 Boss | 精英词缀/变异体 |
| 升级池 | 30~40 项（机制型 ≥50%，含主动技强化） | 50+ |
| 地图 | 3 张（分主题：墓地/血教堂/狼穴…） | 5 张 + 每日挑战 |
| 局外 | 角色解锁 + 图鉴收集 + 轻量局外成长 | 成就/多难度/皮肤 |
| 叙事 | 设定集 + 角色卡 + Boss 档案 + 局内点缀 | 过场/多结局 |
