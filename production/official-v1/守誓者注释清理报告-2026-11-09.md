## 1. 任务 1 · `src/weapons/companion/oathkeeper-runtime.ts:37-39`（推导块重写）

### 改前（330 时代，两个数字均已失效：圈周期 1.32s→720ms；步幅 32px→实测 24.87px）

```ts
 * 推导：walk 4 帧 × 330ms = **1.32s/圈**，一圈覆盖 2 个半步，美术踏步 ≈ **32px/步**；
 *  - 180px/s × 1.32s = 每步 **119px** ≈ 美术步幅的 3.7 倍 → 肉眼可见"脚不动却在地上滑"；
 *  - 120px/s × 1.32s = 每步 **79px** ≈ 2.5 倍（滑步幅度同比 −33%）。
```

### 改后（直接采用任务单给定数值，未自行改算）

```ts
 * 推导（2026-11-09 复核，取代 330ms/32px 旧口径）：
 * - 走帧 180ms × 4 = **720ms/圈**；一圈覆盖 2 个半步
 * - 美术实测**半步 ≈ 24.87px**（批 F 双足重心实测；旧口径 32px 含斗篷/剑，偏乐观 29%）
 * - 滑步比 = 每帧位移 ÷ (半步/2)：
 *     90px/s → 16.2px/帧 → **1.30**（但掉队 0.62s 更差，未采用）
 *    120px/s → 21.6px/帧 → **1.74**（CONCERNS，当前采用）
 *    180px/s → 32.4px/帧 → **2.61**（原值，肉眼可见"脚不动却在地上滑"）
 * - 结论：120 是"滑步/掉队"折中；**两者同时满足需美术重画交替步（M-2）**
```

**自核算验**（半步/2 = 12.435px）：16.2/12.435 = 1.303、21.6/12.435 = 1.737、32.4/12.435 = 2.606 → 与 `1.30 / 1.74 / 2.61` 一致，且 `1.74` 与 A/B 报告 §2 的 `120 × 0.180 / 12.44 = 1.74` 同源。三个速度的 120ms 位移（16.2 / 21.6 / 32.4 = 速度 × 0.18s）亦自洽。

**未动**：`export const FOLLOW_SPEED = 120;` 与紧随其后的「取区间上界 120 而非 90 的理由」、以及「批 F 实测再微调」段（后者是待办指引，不是过期数字）。
