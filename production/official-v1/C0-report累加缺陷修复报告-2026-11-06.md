## 1 · 缺陷与修法

### 1.1 缺陷代码（改前 · `process.mjs:506-510`）

```js
if (!cmp.ok) {
  variant.issues = [...(variant.issues || []), ...cmp.issues.map((i) => `时间轴 vs ${baseName}: ${i}`)];
  variant.ok = false;
  variant.passed = 'FAIL';
}
```

`variant.issues` 来自上一轮 `report.json`（`runCheck` 只对**点名的帧**刷新 `issues`，其余帧沿用旧数组），而 `applyTemporalGates` 对**全库每个 variant** 都跑一遍 ⇒ 每次 `--check <子集>` 都给全库非子集帧再叠一层。

### 1.2 修法（改后 · `process.mjs:49` + `509-520`）

```js
const TEMPORAL_PREFIX = '时间轴 vs ';          // :49 固定前缀，写/读共用

// :513-520 —— 语义：本轮结果**替换**旧时间轴条目，不累加
const temporalIssues = cmp.ok
  ? []
  : [...new Set(cmp.issues.map((i) => `${TEMPORAL_PREFIX}${baseName}: ${i}`))];
const others = (variant.issues || []).filter((s) => !String(s).startsWith(TEMPORAL_PREFIX));
variant.issues = [...others, ...temporalIssues];
const failing = variant.issues.length > 0 || !cmp.ok;
variant.ok = !failing;
variant.passed = failing ? 'FAIL' : 'PASS';
```

三个要点：

1. **只剔除以 `时间轴 vs ` 开头的旧条目**，其它来源的 issues（尺寸/边距/L\*/描边）原样保留 —— 不会误删。
2. `new Set(...)` 兜底：单轮内若 `cmp.issues` 有同义串也只留一条。
3. **通过时回写 PASS**（旧代码只在失败时写 FAIL）：否则「旧的时间轴 FAIL 文字留在 issues[] 里、判定却已通过」会永远卡在 FAIL。这条正是 `hero-violet-walk-d` 的痊愈路径（见 §4）。

`process.mjs:19` 的文件头注释同步改为「帧条目累加；**单帧 issues 的本轮结论整体替换**，时间轴条目亦不累加」，避免下一个人再按「累加」语义写回。

### 5.2 为什么 `report` 里会被污染（同一函数的伴生症状）

`process.mjs:523-532`（`applyTemporalGates` 尾部）把 base 的脚底 pivot **无差别**刷给全族成员：

```js
const basePivot = base.pivot;
if (basePivot) for (const name of names) report.frames[name].pivot = { ...basePivot };
```

`summon-oathkeeper` 是**跨尺寸混档族**（base 192×192 + `-tombstone` 48×48，`frame-specs.mjs` 明确「48/192 同族混档是已知口径」），于是墓碑自测 pivot 被 192 基准替换：

| | 自测（`pivotFromFoot(footY, h)` = `(footY+0.5)/h`，`layout.mjs:183-185`） | 被覆盖后 |
|---|---|---|
| `summon-oathkeeper` | (191+0.5)/192 = **0.9974** | 0.9974 ✔ |
| `summon-oathkeeper-tombstone` | (45+0.5)/48 = **0.9479** | **0.9974** ✘（`+0.0495`，即 48px 画布上 ≈2.4px 脚底偏移） |

`batch C` 的 `pack.mjs:29-38` 正是读 `entry.pivot` 写 `pivots.json`，所以**若不还原，批 C 会把 0.9974 写进交付物**。本次已按指令单值还原（`report.json` 仅 `summon-oathkeeper-tombstone.pivot` 一处改动，其余不动）。
