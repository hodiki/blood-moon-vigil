## 2. B2 · F4 flipX 半落 —— **查证结论：有意（art-blocked），非代码缺陷**

- `enemy-greywolf.png` → **朝右**

### ⚠ e2e 边界一：**进程关停不彻底（环境性）**
- 现象：断言全过、`1 passed` 已打印，但 `playwright test` **进程不自行退出**；一旦被外部终止，会**残留 `vite preview`（:4173）孙进程**已实测复现 3 次。
- 排查：`CI=1`（→ `reuseExistingServer=false`）**不改变**该现象 → 根因非 `reuseExistingServer`。
- 根因：WebServer 命令为 `npm run preview -- --port 4173`（npm → node 两层），Windows 下 Playwright 关停**孙进程未回收**，stdout 管道不闭合 → 进程挂起。
- 影响：**本机/Windows 沙箱环境**；断言本身有效。**Linux CI 通常不受此影响**。
- 处置建议（**待拍板**，见 §7-D）：① CI 用 Linux runner（首选）；或 ② 给 `webServer` 加 `gracefulShutdown:{ signal:'SIGKILL', timeout:5000 }` / 命令改直连 `npx vite preview`（**`playwright.config.ts` 不在本批显式可改路径，未擅动**）。

### 边界二：**当前 spec 不覆盖玩法语义**
`smoke.e2e.spec.ts` 仅断言「能启动」（canvas 可见 / `framesAdvanced` / `sceneReady` / 无 console.error），**不覆盖玩法语义**（如「化身击杀不通关」等逻辑判据仍需**单测级断言**，批 D 已补，见 `tests/unit/run/avatar-defeat.test.ts`）。本批 e2e 的价值 = 补上「P0-1 点击开始黑屏」类**启动期回归**的判别式。
