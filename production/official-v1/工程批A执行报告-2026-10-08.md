## 二、D1 三桶实测值

**测量方式**：以工程实现 `damageBucketEquiv()/survivalBucketEquiv()` 实测（临时测量用例打印后已删除），并经 `talent-tree-b5.test.ts:61-71` 独立真值断言复核。

| 桶 | 口径 α 实测 | 红线 | 判定 | 余量 |
|---|---|---|---|---|
| 伤害（damage） | **6.10%** | ≤ 8% | ✅ | 1.90pp |
| 生存（survival） | **3.41%** | ≤ 6% | ✅ | 2.59pp |
| 合成（d + s） | **9.51%** | ≤ 10% | ✅ | **0.49pp** |

**明细（折算系数 × 可购层数）**：
- 伤害 = `a_attack`(0.4×2) + `a_attack_2`(0.4×1) + `a_damage`(1.2×2) + `a_damage_2`(1.2×1) + `a_attack_speed`(0.5×**1**) + `a_cooldown`(0.4×2) + `br_edmund_2`(0×2) = **6.1**
- 生存 = `a_life`(0.47×2) + `a_life_2`(0.47×1) + `a_move_speed`(0.5×2) + `a_heal_efficiency`(0.5×2) + 6 项 `br_cassandra/violet/galvan`(0×2) = **3.41**

**对照（修复前状态）**：EN-02 修复前 `_2` 子节点因 id 失配被静默漏算 → **假 PASS**；补键后 α 实算曾为 **10.7%（越线）**。EN-12 降档后落 **9.51%**，与 `gdd-talent-tree.md` v1.3 §6.1 目标锚（6.1/3.4/9.5）一致。

**关键机制澄清（防误改）**：A-13 假 PASS 的根因是**查表键失配**（`node.id` 精确匹配不到 `_2` 独立 id，被 `if (per)` 静默跳过），**非遍历遗漏**——遍历本身完整。故 EN-02 只改查表归一化，**未动遍历逻辑**。
