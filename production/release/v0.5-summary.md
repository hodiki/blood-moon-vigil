## 一、版本定位

Demo（0.1.0）验证核心循环后，正式版开发走过 **M0 立项 → M1 内容设计定稿 → M2 玩法核心扩展 → M3 叙事与局外** 四个里程碑，并经历 **R2/R3 两轮外部测试与两个修复批次**。V0.5 是内容与系统完整、经外部验证、已知问题全部登记在案的稳定落定版。

## 三、系统与架构要点

1. **数据驱动内容管线**：武器/敌人/角色/升级/地图全配置表（`balance.ts`），行为注册表模式（WeaponId→Behavior / spawnByConfig），帧名契约注册表（194 帧 + CI diff 校验）。
2. **升级体验 v2**：保底席位 P1~P5 向心性抽取（「0 张 build 相关卡」从 21.6~29% → ≤1%）、阶段节奏权重、数值卡方向化（武器共鸣/专精疾射/鲜血契约/踏月而行）、进化前置（类强化 ≥2 + 持钥必占一席，达成率 84~100%）。
3. **遥测体系**：结算页「真机遥测」块 + `window.__BMV_LAST_RUN`（offersPerRun / xpGainedPerRun / evolutionComplete / relatedCardShare / bossFightSeconds）+ `?qa=1` 控制台辅助（`__BMV_QA.unlockAll/setHero/setMap/status`）。
4. **美术双轨**：外部素材（契约帧名不变零代码替换）+ 程序剪影兜底；管线门禁（`tools/asset-pipeline/`：时间轴 41 PASS/17 FAIL 台账）。
