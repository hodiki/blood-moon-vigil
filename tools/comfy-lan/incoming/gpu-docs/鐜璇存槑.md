## 1. 这台机器是什么

- 主机名 **HodikiX**，机械革命光晓，RTX 4070 Laptop **8GB**，32GB 内存。
- ComfyUI **0.37.0** 装在 `D:\ComfyUI`（2026-09-22 由 0.34.0 覆盖式升级，依赖同步更新），启动脚本 `D:\ComfyUI\start_lowvram.bat`。
- 角色：**局域网 GPU 机**。编码机 **Hodiki**（`192.168.101.82`）远程调用 `8188` 出图。
- 本机也可以直接出图（个人需求、冒烟、验收升级）。

## 2. Agent 在这台机器上做什么

**主要任务**：维护、优化、升级生图环境（节点、权重、监听、防火墙、文档、握手）；**同时准备参考工作流和各类工具**（放大、锁角色/姿势、风格与分级预设等）。Hodiki / 用户按需直接用、改参数、或参考另建，不把某一张图当成唯一用法。

**仍须保持生图能力**：不要卸掉底模或关掉 Comfy 的 Queue。升级后必须能文生图；加了新能力还要为新能力冒烟。  
本机 Agent **不为游戏任务冻 walk / skill API 工作流**，那是 Hodiki 的事。进度以 `docs\任务清单.md` 为准。

## 3. 怎么启动

1. 双击 `D:\ComfyUI\start_lowvram.bat`（或等价命令：`--lowvram --reserve-vram 0.8 --vram-headroom 0.4 --disable-api-nodes --enable-manager --listen 0.0.0.0 --port 8188`）。会弹出自己的黑框，不要关。不要从 Cursor 终端拉起后再把该终端掐掉——进度条一写控制台，KSampler 会报 `OSError: [Errno 22] Invalid argument`。
2. 本机打开 http://127.0.0.1:8188  
   Hodiki 打开 http://192.168.101.200:8188
3. 健康检查：`GET http://127.0.0.1:8188/system_stats` 必须 200。

防火墙规则名 **ComfyUI LAN Hodiki only**：只允许 `192.168.101.82` 进 TCP 8188。不要对公网开放，不要 ngrok。

环境变量（已写进 bat）：

- `TRANSPARENT_BACKGROUND_FILE_PATH=D:\ComfyUI\models\background_removal`（抠图权重在 D 盘）

## 5. 本机怎么出一张图（主理人 / Agent）

**个人与学习**：Comfy 里 Workflow → Open，按需求选：

- **二次元**（立绘 / 厚涂 / 锁脸锁姿势）：`WAI-Illustrious-个人学习.json` / `WAI-底图加精修.json` / `WAI-锁角色-IPAdapter.json` / `WAI-锁姿势-OpenPose.json`
- **非二次元**（长提示、出字、写实/风景/产品）：日常 `KREA2-Turbo-基础.json`（Enhancer 可关）；对照裸跑 `KREA2-Turbo-t2i.json`；风格/Bypass/A2R 从 `KREA2-Turbo-仓库.json` 单件复制，不要 Queue 仓库图
- **Qwen-Image-2.1（推荐优先试）**：通用 `QWEN21-T2I-基础.json`（1024²/40 步）；原生 2K `QWEN21-T2I-2K.json`；**透明 sprite/图标** `QWEN21-T2I-透明RGBA.json`（自带 alpha）；改图 `QWEN21-图片编辑.json`（最多 10 张参考图，提示词用 `<image1>` 指代）；抠主体 `QWEN21-去背景.json`
- **Qwen 2.1 提示词改写（PE）**：`QWEN21-PE改写.json` —— 只改最后一行 `User brief:`，Queue 后复制输出的 `rewritten_prompt` 去出图。**150–500s/次，属批量工具；与出图分开跑（先本图，再 POST /free）**。产出喂 Qwen 或 Krea 都有效
- **视频试跑 T2V（H3，0.2 MP 已通到约 15 秒）**：`MiniMax-H3-T2V-8GB.json`
- **视频试跑 R2V**：**0.4 MP × 362 已通** `video/S01_dance_v3_studio_480x864_362f_00001_.mp4`；**0.98 MP × 124 已通**；**0.98 MP × 362 未达**。参考图 `MiniMax-H3-R2V-8GB.json`。打之前 `POST /free`。
- `FLUX2-Klein4B-*.json` / `Wan-Animate-2.json` 已移出到 `_backup\deprecated-workflows\2026-09-22\`（权重早已删，不再出现在 Workflow 列表）
- 外来底图用 WAI 精修：`WAI-精修外来底图.json`（与 Krea 分 Queue）
- 一次性无节点：Cursor `GenerateImage`（补位，不是主力）

都是参考图，可改可另存。不是 Hodiki 的 API 契约。提示词片段见 `docs\提示词预设.txt`。

最小手搭：`CheckpointLoaderSimple` → WAI → `CLIPSetLastLayer` -2 → 正负向 `CLIPTextEncode` → `EmptyLatentImage` → `KSampler` → `VAEDecode` → `SaveImage`。

无背景：在 `VAEDecode` 后接 `InspyrenetRembg`（`torchscript_jit=default`），再 `SaveImage`。首次抠图会加载约 350MB 的 `ckpt_base.pth`。

8GB：一次一种 ControlNet；IP-Adapter 与 OpenPose 拆两轮；**Krea 与 WAI 拆 Queue**，换引擎先 `POST /free`。不要默认 1536。Krea 不要开官方 `prompt_enhance`。

## 6. Hodiki 怎么用

按**文件名和节点类名**组自己的图。本机 `workflows` 里有参考 JSON，可直接用、改参数、或只当接法说明书；冻 walk / skill API 仍由 Hodiki 做。  
参考工作流也可拉：`GET http://192.168.101.200:8188/userdata?dir=workflows`。  
需要无背景时，在任务图末尾加 `InspyrenetRembg`。  
握手里的 `walk_strip_api` / `skill_strip_api` 由 Hodiki 冻好后再改，本机不抢填。  
环境说明 / 任务清单 / 更新日志用方案 A 的 `/userdata/env-docs%2F…` 拉，不必等本机传文件。
