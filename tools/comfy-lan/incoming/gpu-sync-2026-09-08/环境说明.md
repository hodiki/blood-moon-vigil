## 1. 这台机器是什么

## 2. Agent 在这台机器上做什么

**主要任务**：维护、优化、升级生图环境（节点、权重、监听、防火墙、文档、握手）；**同时准备参考工作流和各类工具**（放大、锁角色/姿势、风格与分级预设等）。Hodiki / 用户按需直接用、改参数、或参考另建，不把某一张图当成唯一用法。

**仍须保持生图能力**：不要卸掉底模或关掉 Comfy 的 Queue。升级后必须能文生图；加了新能力还要为新能力冒烟。  
本机 Agent **不为游戏任务冻 walk / skill API 工作流**，那是 Hodiki 的事。进度以 `docs\任务清单.md` 为准。

## 5. 本机怎么出一张图（主理人 / Agent）

**个人与学习**：Comfy 里 Workflow → Open，按需求选：

- 单段入门：`WAI-Illustrious-个人学习.json`
- 要更清楚：`WAI-底图加精修.json`
- 锁脸：`WAI-锁角色-IPAdapter.json`（换 `input\ref_character.png` 或节点里的图）
- 锁姿势：`WAI-锁姿势-OpenPose.json`
- 听长提示 / 非二次元底：`FLUX2-Klein4B-个人学习.json`（自然语言，Euler 4 / CFG 1）
- Klein 出底后再用 WAI 精修：另开 `WAI-精修外来底图.json`（不要和 Klein 同一 Queue）
- 用句子改已有图：`FLUX2-Klein4B-改图.json`

都是参考图，可改可另存。不是 Hodiki 的 API 契约。提示词片段见 `docs\提示词预设.txt`。

最小手搭：`CheckpointLoaderSimple` → WAI → `CLIPSetLastLayer` -2 → 正负向 `CLIPTextEncode` → `EmptyLatentImage` → `KSampler` → `VAEDecode` → `SaveImage`。

无背景：在 `VAEDecode` 后接 `InspyrenetRembg`（`torchscript_jit=default`），再 `SaveImage`。首次抠图会加载约 350MB 的 `ckpt_base.pth`。

8GB：一次一种 ControlNet；IP-Adapter 与 OpenPose 拆两轮；**Klein 与 WAI 也拆两轮**。不要默认 1536。不要为扩写提示词再挂本地 LLM。

## 6. Hodiki 怎么用

按**文件名和节点类名**组自己的图。本机 `workflows` 里有参考 JSON，可直接用、改参数、或只当接法说明书；冻 walk / skill API 仍由 Hodiki 做。  
参考工作流也可拉：`GET http://192.168.101.200:8188/userdata?dir=workflows`。  
需要无背景时，在任务图末尾加 `InspyrenetRembg`。  
握手里的 `walk_strip_api` / `skill_strip_api` 由 Hodiki 冻好后再改，本机不抢填。  
环境说明 / 任务清单 / 更新日志用方案 A 的 `/userdata/env-docs%2F…` 拉，不必等本机传文件。
