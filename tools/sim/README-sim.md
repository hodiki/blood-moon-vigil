# 沙盘模型假设清单（README-sim）

> 维护：程基岩 · 更新 2026-08-30（SIM-CALIB 批次）。
> ⚠ **近似模型声明：所有生存/走位结论为 1D 径向等效模型推演，最终以真机为准。**

## 1. 敌潮/武器层（B2-W6 接真，可信度高）
- 敌潮预算 = `spawner.budget(t)` 真实曲线；敌面板 = `ENEMY_CONFIGS` 真配置。
- 专武结算 = `exclusive-math` 真实状态机逐帧 step（伤害/CC/弹药/质变卡全生效）。
- 升级需求 = `needXp(level)` 真实 XP 曲线；升级 offer 为**占位序列**（不消费升级加成 → 全程 mul=1 开局口径，保守）。

## 2. 生存/走位模型（SIM-W1，近似——结论需真机复测）
1. **1D 径向等效走位**：玩家移动建模为「敌相对速度修正 drift」——后撤 drift=+playerSpeed、逼近 drift=−0.6×speed、带内 drift=0。玩家的横向绕行（2D 语义）不建模；**真实 2D 走位生存力预计优于本模型**（1D 是最坏情形：敌人是单列逼近）。
2. **专武距离带**（`SIM_MOVEMENT_DEFAULTS.kitingBands`）：近战系贴身（提灯 70~120 / 双刃 40~80 / 巨斧 50~90）、中距（圣铃 110~170 / 十字 150~230 / 号角 140~210）、风筝系（左轮 200~280 / 长弓 260~340）。锚为手感归属推断，未逐武器实测。
3. **后撤边界**：playerOffset 上限 = 出生环内径 60%——被逼墙角后敌恢复全速接近（1D 无绕后脱身路径，最坏情形）。
4. **XP 拾取**：拾取倾向不建模（宝石即拾即得近似）；经验获取量偏乐观（无漏收）。
5. **承伤判定**：接触半径（敌 radius + 玩家 14）内按敌攻击间隔全额扣血，无玩家减伤/无敌帧/回复（up_g_* 不消费——开局口径）。
6. **无升级消费**：升级只记账不消费（mul=1）→ 后期生存力偏保守；升级后的伤害/冷却成长未计入。

## 3. 树工况（SIM-W2）
- b/d 通武贡献 = `COMMON_WEAPON_ANCHOR_DPS` 锚常量直加（GDD gdd-weapons-v2 §3 面板 DPS），**非结算层**；与专武结算层叠加。
- s1（bds1）= 前 30s 全部伤害 ×1.2（Q-s1 独立乘区口径）。
- Q-d 预选典型 = 银针连弩（10.7 锚）。

## 4. 双轨口径声明
- **DPS 双轨**：本沙盘 = AOE 环境值（多敌同屏）；GDD §6.2 平台带锚 = 单目标等效对照混合口径。对照时按「环境 DPS ≈ 单目标 × 同屏均数」折算，报告已标注。
- **invincible 模式**（dps-baseline/batch-run）：隔离走位与承伤，专测输出效率；生存结论一律用 movement 模式。

## 5. 已知不可信项（校准报告局限性来源）
- 死亡时点绝对值（接触伤害模型粗糙）；P1 窗口命中率（升级时点近似）；圣物占比（演出型恒 0）；XP 曲线绝对等级（offer 占位无消费 → 后期偏保守）。
