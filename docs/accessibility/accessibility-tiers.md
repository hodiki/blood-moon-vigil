# 《血月守夜》可访问性分级与特性矩阵

> 版本：v0.1 · 垂直切片 Demo 版
> 作者：林绘澄（美术总监）· Phase 3 并行线 B
> 依据：《美术圣经》§2 色彩 / §3 可读性 / §6 UI / §7 动画特效 / §9 可访问性
> 状态：待主理人与程基岩（工程）确认交接项后定稿

## 1. 分级定义

- **Basic（基础）**：垂直切片 Demo 必须达到的最低门槛——零额外成本、美术与现有管线可独立落地，保证色觉障碍与操作不便玩家"能玩、不误读"。
- **Standard（标准）**：正式版应达——补全设置开关、持久化与自定义入口，覆盖主流障碍场景，体验完整。
- **Comprehensive（进阶）**：无障碍打磨期做——提供细粒度自定义与逐项开关，接近平台级无障碍标准，投入最高、排期最后。

## 2. 特性矩阵

| 特性项 | Basic | Standard | Comprehensive |
|---|---|---|---|
| 色盲双编码（颜色+形状/图标） | 必须 S | 必须 S | 可选 M（逐类型自定义色板） |
| 高对比模式（描边 2→4px / 背景降饱和 30% / 文字黑底） | 推荐 S（独立开关，默认关，设置可开） | 必须 M（含设置开关与持久化） | 可选 M（描边/对比度独立滑杆） |
| 描边强度（敌我 2px / 精英 3px / Boss 4px） | 推荐 S | 必须 S | 可选 S（玩家可调） |
| 字号缩放（跟随系统，不锁死画布像素） | 推荐 S | 必须 M（内置 100%/125% 两档） | 可选 L（任意比例 + 布局重排验证） |
| 减少闪烁（陷阱闪烁/受击白闪/屏幕震动） | 必须 S（一键开关） | 必须 S | 可选 S（逐项细分开关） |
| 音效替代提示（听觉信息 → 视觉双通道） | 推荐 S（升级/受击/稀有拾取） | 必须 M（全事件双通道） | 可选 M（自定义事件提示） |
| 震动反馈（移动端 `navigator.vibrate`） | 可选 S（默认关闭） | 推荐 S | 可选 S |
| 触控热区（可点目标 ≥44×44px） | 必须 S | 必须 S | 可选 S（自定义热区尺寸） |
| 按键重映射 | 可选 M（预留接口，Demo 可后置） | 必须 M | 可选 L（多预设+自定义） |
| 摇杆位置自定义 | 可选 M | 推荐 M（至少左右互换） | 必须 M（全布局自定义） |
| 焦点可见（键盘/手柄导航高亮） | 必须 S（冷青描边+缩放 1.03） | 必须 S | 可选 S（焦点样式自定义） |
| 弹窗 125% 档（升级三选一） | 推荐 S（文字自适应） | 必须 S | 可选 M |
| 对移动端性能的影响 | 必须 S（全部 Basic 特性不增 draw call） | 必须 S | 可选 L（叠加需回归测试） |

> 成本标记：S=低（美术/配置即可，≤0.5 人日）；M=中（需少量工程配合，1~2 人日）；L=高（涉及系统级重构或打磨专项，≥3 人日）。

## 3. Basic 级落实清单（垂直切片 Demo 必做）

1. **信息双编码**：危险=红 `#FF3B30`+三角、治疗=绿 `#43D17C`+十字、精英=紫 `#B06AF0`+双角饰、经验=蓝 `#4FC3F7`+菱形；形状优先于颜色，任意色盲类型下仍可辨。
2. **对比度硬标准**：UI 正文对背景 ≥4.5:1、图形/图标 ≥3:1；地图背景明度 L\* ≤18、主体剪影 L\* ≥45；描边禁止与背景同色系。
3. **触控热区**：移动端所有可点目标 ≥44×44px；桌面 ≥32×32px（视觉 24px + 外扩热区）。
4. **字号下限**：正文 ≥16px、HP/数值 ≥20px、升级卡片标题 ≥22px 加粗；移动端实际渲染 ≥14px 物理像素；跟随系统字号缩放，不锁死画布像素。
5. **减少闪烁开关**：设置页一键关闭 ①陷阱 0.8s 周期闪烁（透明度 60%→100%）②受击白闪 0.1s ③屏幕震动（幅度 ≤4px、时长 ≤0.15s）；移动端震动默认关闭。
6. **焦点可见**：键盘/手柄导航时选中项冷青 2px 描边 + 缩放 1.03，禁用态 60% 透明度；Tab 顺序与视觉顺序一致。
7. **高对比基础版**：全局描边 2px→4px、背景降饱和 30%、UI 文字加黑底；作为独立开关（**默认关，设置页可开**，主理人裁决）。
8. **重要事件双通道**：升级可用、玩家受击、稀有拾取必须同时有"视觉表现+音效"，不依赖纯音效传达；受击白闪与红闪不与危险区全屏红晕混淆。

## 4. 与工程对接说明

**美术侧可独立完成（无需工程排期）**：双编码形状资产（三角/十字/菱形/角饰）、全部对比度数值落实、高对比模式的描边/降饱和参数、触控热区视觉外扩、字号下限规范。

**需工程层配合（交程基岩）**：
1. **设置数据与持久化**：承载"减少闪烁/高对比/震动"开关，存 localStorage，Demo 期至少一处设置页入口。
2. **字号缩放不锁画布**：UI 字号走相对单位 + 跟随系统字体缩放；弹窗 125% 档需布局重排验证，避免文字裁切。
3. **焦点系统**：Phaser 3 无原生 DOM 焦点，需输入层支持键盘/手柄导航状态机 + 焦点事件，美术侧只提供高亮样式。
4. **色板统一走配置**：颜色从全局调色板 token 读取、禁止硬编码，为 Standard 级替换色板/高对比切换预留全局生效路径。
5. **震动 API 封装**：移动端 `navigator.vibrate` 包装 + 开关联动；桌面端空实现不报错。
6. **输入映射预留**：action→键位/触控映射表数据结构，Demo 期可不开放 UI，但禁止把键位写死在逻辑里。

## 5. 后续排期建议

- 垂直切片：仅做第 3 节 8 条 + 工程交接项 1~3（S 级成本）。
- Standard：随正式版设置系统一并落地（替换色板、125% 档、键位重映射 UI）。
- Comprehensive：打磨期专项（任意字号比例、逐项特效开关、全自定义布局），排最后。
