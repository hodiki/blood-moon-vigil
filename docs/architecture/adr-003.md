# ADR-003：游戏状态与时间——单 GameScene + 状态机，暂停用物理/Tween 暂停而非重建场景

> 状态：**已接受** · 日期：Phase 3 · 作者：程基岩（工程主程）
> 关联：`architecture.md` §3.1/§3.5 · 上游：`upgrade-pool.md` §6.2（暂停状态）、`spawner.md` §6（玩家死亡停止生成）

## 背景

幸存者 like 存在多个"时间暂停"场景：**升级三选一**（每 30–90s 一次，敌人静止、玩家无敌）、**玩家主动暂停**、**GAMEOVER 收束**。此外全流程需要 20 分钟计时、波峰波谷节奏、Boss 20:00 准时出场。状态切换的正确性直接影响：
- upgrade-pool §6.2："选卡期间全局暂停、玩家无敌，杜绝边挨打边选"；
- spawner §6.2："玩家死亡立即停止生成"；
- 核心体验"决策时世界静止"（支柱 2 的专注决策）。

设计问题：暂停如何实现？多场景拆分（Play/Pause/LevelUp 各一个 Scene）还是单场景 + 状态机？

## 决策

**单 `PlayScene` + 四状态状态机（RUNNING / LEVEL_UP / PAUSED / GAMEOVER），暂停用"物理暂停 + Tween 暂停 + 逻辑短路"，绝不销毁重建场景。**

```ts
// core/game-state.ts（签名详见 architecture.md §3.1）
export enum GamePhase { RUNNING, LEVEL_UP, PAUSED, GAMEOVER }
```

1. **状态切换副作用**集中在 `GameState.set()`：
   - 进 `LEVEL_UP`/`PAUSED`：`physics.pause()` + `tweens.pauseAll()` + 粒子暂停 + 战斗输入禁用（摇杆隐藏）+ 玩家无敌。
   - 回 `RUNNING`：`physics.resume()` + `tweens.resumeAll()` + 输入恢复。
2. **`PlayScene.update` 第一行短路**：非 RUNNING 直接 return（`architecture.md` §3.1），战斗逻辑天然冻结。
3. **计时**：20 分钟局时、生成预算、波峰波谷全部基于"游戏内秒"（RUNNING 态才累加）的累加器；暂停不消耗局时（升级选卡/主动暂停不计入 20 分钟）。
4. **DOM 覆盖层动画不受 Phaser tween 暂停影响**（ADR-004 联动）：升级卡出现动画、倒计时等 UI 动效在暂停态仍可播放，与游戏世界静止互不干扰。
5. **GAMEOVER**：清空子弹/环绕球（weapons §6.5）、生成器停止（spawner §6.2）、进入结算覆盖层；"再来一局" = 重置 `GameState` 与各系统数据（`scene.restart()` 重建场景是允许的——仅在局终时）。

## 后果

**正面**：
- 单场景零切换开销、状态集中管理，暂停/恢复语义单一来源，不会出现"漏恢复"竞态。
- 升级选卡期间世界完全静止（物理 + 逻辑双冻结），杜绝"边挨打边选"（upgrade-pool §6.2）。
- 场景对象/图集/池常驻内存，局内零加载。

**负面**：
- 单场景文件会较长，需靠目录结构与职责拆分控制（§2 已按子系统拆分模块，PlayScene 只做装配转发）。
- 暂停需同时冻结 physics/tweens/粒子/输入四处，漏一处会出现"敌人不动但子弹飞"的 bug——用 `GameState.set()` 集中副作用规避。

**缓解**：
- `GameState.set()` 是暂停副作用唯一入口，配单测断言"任意状态切换后 physics.isPaused 与 phase 一致"。
- 若未来加多场景（如独立 TitleScene），PlayScene 仍保持单局单场景，不拆暂停子场景。

## 备选方案

| 方案 | 评价 |
|---|---|
| **多场景拆分（Play / PauseScene / LevelUpScene）** | 语义清晰，但场景切换有启动开销、图集/实体状态传递复杂（跨场景传参）、暂停/恢复时序易错（`scene.launch/pause/stop` 组合）。Demo 规模下**过重，否决** |
| **暂停 = `this.scene.pause('Play')` + 挂新场景** | Phaser 原生暂停方案，但需多场景架构支撑，且被挂场景与 Play 共享输入/相机易出竞态。**否决** |
| **重建场景实现"重开"式暂停** | 暂停即销毁重建，状态全丢，玩家/武器/局时全重置。**否决** |
| **时间缩放 `time.timeScale` 实现慢动作** | 本游戏无慢动作需求；且 Phaser `timeScale` 影响 tweens 但不暂停物理/输入，不满足"完全静止"。**否决（仅作慢动作扩展预留）** |

## 验收核对

- upgrade-pool §6.2"选卡期间全局暂停、玩家无敌" ✔（LEVEL_UP 态物理冻结 + 玩家无敌帧）。
- spawner §6.2"玩家死亡立即停止生成" ✔（GAMEOVER 态 update 短路，生成器不再累加）。
- Boss 20:00 准时出场：局时累加器 RUNNING 态推进，暂停不消耗 ✔。
- 全流程 20 分钟恒定：暂停（升级/主动暂停）不计入局时 ✔。
